# 审查面板仅显示最近一轮

当前 Codex 的 Git 设置有“Disable Git-Based Review”。开启后审查面板的有效来源固定为 Last Turn，未暂存、已暂存、提交与分支来源不再可选。Codex 以 `full`／`last-turn-only` 配置保存该模式，同时保留切换前的来源选择；关闭后原选择恢复。

ShipiOS 的 Git 设置现在提供对应开关。审查范围把用户选中的 Git 来源与当前有效来源分开：仅显示最近一轮时，面板的加载与修改资格使用有效来源；各工作区和独立任务窗口的布局继续保存原选择。打开或关闭开关会同步当前主工作区与已打开的任务窗口；分离审查窗口在页面变化或重新配置时同步。受限模式下菜单只列出“最近一轮”，刷新重读最近一轮记录，面板不再提供 Git 提交、推送和 PR 操作。无 Git 仓库时仍可展示最近一轮记录。设置搜索可定位开关；旧配置默认保持完整 Git 审查。

原生隐藏窗口测试覆盖受限菜单及恢复；状态测试覆盖持久化、布局保存、独立任务窗口和修改资格。Git 审查、最近一轮、只读与设置导航相关 **96 项回归通过**；`script/build_and_run.sh --build-app` 构建及严格深度签名通过。前台检查时 Mac 仍锁定，无法确认新包工作区交互，也无法进行 Codex 与 ShipiOS 的逐页对照；完整双端验收仍为 **0/47**（主工作区 21 项、设置 26 项）。
