# 新任务工作树的环境选择

项目新任务选择“工作树”后，输入区现在提供“无环境”、项目中有效的本地环境，以及仅在旧版私有配置存在时出现的本地配置选项，并可进入环境设置。选择按项目保存；已有待恢复的托管任务保留创建时的选择，不能在重试途中改用另一环境。

创建托管任务时，ShipiOS 重新从 Agent 读取所选 TOML 文件，将名称、平台脚本和 Actions 固化到任务的工作树记录。setup、失败重试、归档前 cleanup 及工作树中的顶部 Actions 使用这份任务配置；之后来源项目切换或编辑环境不会改变旧任务的脚本。“无环境”会清空工作树任务的环境操作并跳过来源项目已有的 setup/cleanup。旧记录没有环境快照时继续沿用原有项目配置。

真实 Git 工作树回归验证了所选环境覆盖来源项目中失败的 setup/cleanup，以及“无环境”跳过这两个脚本。真实 Agent 回归验证了环境文件的选择和快照读取。当前 Codex Mac 的输入区菜单布局、焦点与快捷键仍待原生配对；父目录继承环境、云环境和远程运行仍未接入。
