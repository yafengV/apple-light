## 实现

审查工具栏独立检查 GitHub、源提交、远端、目标分支和实际可提交内容，不调用可编辑草稿的加载/重置方法。已有 PR 使用“查看 PR”直接打开系统浏览器；只读或历史审查仍可查看，创建与提交保持修改权限限制。查看前再次校验仓库、分支、提交、远端、工作区及所属任务；打开失败可重试，成功仅保存所属任务的已确认 PR。

普通默认分支和空分离 HEAD 保留禁用创建项。分离 HEAD 没有目标分支之外的新提交时，必须包含实际本地变更；取消勾选立即禁用动作。合并冲突阻止提交路径，已发布分支的单独创建路径仍可使用。提交统计使用独立临时索引，包含未跟踪文件，识别已暂存变更被工作文件抵消的空选择，不修改真实索引。

后台检查按仓库、任务、版本及工作区身份隔离；旧请求、取消和暂停不能恢复旧状态。Git 操作或刷新期间暂停检查，结束后重新读取。CLI/认证或读取错误结束 loading 并提供重新检查入口，不清除手填标题、描述、目标分支、分支名称及勾选。

弹层的独立检查若发现来源或 PR 状态与原表单元数据不同，会禁用创建、显示原因并提供重新检查入口；重查仍保留手填字段。新分支校验绑定名称、目标分支、仓库及版本，防抖期间不沿用上一个名称的成功结果，目标同名不能创建。
