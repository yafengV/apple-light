## 原生交互保护

- 本地统一差异的删除行使用旧侧 token，其余源行使用新侧；元数据和 hunk 标题保持普通文本。暂存/撤销、评论和编辑器行打开的原动作保持。
- 文件预览继续使用只读、可选择的 NSTextView。高亮只修改 NSTextStorage 样式；浅/深主题、代码字体与字号变更保留控件、选区、滚动和焦点，不重新赋值整份字符串。
- 正确处理 UTF-16 token 范围、emoji、CRLF 和空行；原文件不被改写。两个规范等价但字节不同的 Unicode 字符串需要不同内容版本，防止观察层跳过真实源更新。
- 文件读取完成后启动高亮；关闭、切换、重新读取、失败及迟到结果按控件和内容版本取消/丢弃。窗口各自持有控制器，后台计算使用独立非持久、无窗口的 WKWebView，不访问网站或个人浏览器。

## 分词中断恢复

首次冷启动的 TypeScript 样例曾出现局部颜色差异，单独复验可通过。源码显示底层 TextMate 的 500 毫秒逐行预算可能返回 `stoppedEarly` 的未完成样式；这是排查线索，不能仅凭耗时断言首次差异的唯一原因。

现在直接检测分词器中断标志：保留 500 毫秒预算，只重算一次；持续中断则抛出错误并回退普通文本，避免缓存不完整颜色。每次同步调用在 finally 恢复原 grammar 方法，不残留覆盖。Node 使用确定性中断验证恢复和耗尽；实际隔离 WebKit 测试在本引擎内临时控制一次计时越界，检查恢复计数和最终完整 token，并立即恢复时钟。
