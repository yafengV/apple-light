2026-09-26。依据 [OpenAI 工作树说明](https://learn.chatgpt.com/docs/environments/git-worktrees)，Handoff 要让同一聊天和代码在本地检出与关联工作树之间继续。本阶段接入**干净本地检出 → 托管工作树**：主窗口任务标题栏、独立任务窗口及侧栏任务菜单提供“移交到工作树”；任务保留 ID、会话历史与私有 Codex Core rollout，创建 detached 工作树后在目标目录继续执行。来源项目中的旧回合不会重建成重复任务。按 `.worktreeinclude` 指定的忽略文件与 `AGENTS.override.md` 使用现有安全复制流程。
