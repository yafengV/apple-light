# 设置行的标题、说明与控件布局

2026-09-18。接续 [外观与终端按钮组](125-appearance-and-terminal-buttons.md)，修正通用页和外观页中说明文字被拆成独立表单行的问题。

## 参考与实现

本机 Codex 26.908.70816 的公开设置行实现将标题和说明放在左侧同一列，列内间距 2；右侧控件与整个标签区域垂直居中。分组容器仍有圆角、背景和行间分隔，不能将其误判为完全无卡片的页面。

新增 `SettingsControlLabel` 和带说明的 `SettingsToggle`，菜单与按钮组接受可选说明。共迁移 16 处：通用页 13 处（含默认编辑器），外观页 3 处。说明不再成为独立行，因此标题与说明之间没有额外分隔线，也不再各自占据行高。只合并属于同一控件的说明，独立操作和状态信息继续保留。

带说明的原生菜单和按钮组以标签整体中心对齐，避免默认 LabeledContent 使用第一行文字基线使控件偏上。说明允许换行，标题和控件的辅助功能名称保持；开关附带说明提示。搜索定位修饰符仍覆盖完整控件行，偏好绑定及动作未改变。
