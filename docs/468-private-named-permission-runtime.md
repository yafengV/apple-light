# 私有命名权限档案运行时

2026-10-01。ShipiOS 的独立 Codex Core 线程现可由 Agent 启动参数显式指定 `permissionProfileId`。选中后，Core 只读取该任务私有 Codex home 的常规 `config.toml`，忽略项目目录内的 Codex 配置，并验证所选档案确实生效；缺失、非法、符号链接配置及未知档案均报错。未指定档案的旧任务继续走原有的无配置路径，不读取用户个人 Codex 配置。普通回合向 Core 保留命名档案、活动 ID 与工作区根目录；计划和只读回合仍使用只读权限。任务恢复沿用已保存的 ID；分叉将来源任务的私有配置复制到子任务，拒绝目标配置冲突或越界链接。

本阶段仅接通运行时参数和私有持久化。Swift 客户端尚未提供命名档案编辑和选择控件，也不会自动生成任务配置；用户现有 UI 路径不改变。档案中更复杂的网络或文件规则尚未做实际工具级沙箱验收，不能仅凭配置事件认定规则已执行。
