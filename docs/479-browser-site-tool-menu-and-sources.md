# 站点工具菜单与来源入口

浏览器地址栏的站点工具菜单现在显示当前网页注册的工具总数、网站声明只读的数量和可能修改数据的数量。每个工具可打开详情，查看名称、说明和网站声明；详情明确提示这些声明来自网站，实际调用仍逐次显示参数并请求用户确认。网页动态移除已展开的工具时，菜单返回清单。

本页成功调用过的工具显示在“最近使用”中。点击记录会打开该任务的“来源”标签：主工作区直接切换，独立任务窗口在所属任务内打开，分离浏览器先恢复所属任务的主工作区再打开来源。来源页沿用现有网页 URL 来源记录，不展示调用参数。导航到其他文档会清除本页最近使用状态。
