# Appshot 快捷键无目标时的行为

本机 Codex 参考客户端的全局 Appshot 快捷键在找不到可截取的前台窗口时结束本次操作，不打开系统窗口选择器。ShipiOS 此前把全局快捷键和手动附件入口共用同一回退路径，因此可能意外弹出选择器。

现在捕捉流程区分全局快捷键与手动入口：快捷键无法完成自动截取时直接结束；用户主动点选附件入口时仍可用系统窗口选择器。首次使用说明弹层会保留原入口类型，确认后继续执行对应行为。

已通过 33 项 Appshot 相关测试、`script/build_and_run.sh --build-app` 正式构建及 `codesign --verify --deep --strict` 签名验证。真实跨应用按键、系统窗口选择器以及 Codex/ShipiOS 双端前台实操仍需 Mac 解锁后验收；完整配对维持 **0/46**。
