# 新任务与无项目任务入口

2026-09-27。官方 [macOS 快捷键说明](https://learn.chatgpt.com/docs/reference/commands#keyboard-shortcuts) 分别列出“新建聊天”（⌘N、⌘⇧O）和“新建独立聊天”（⌘⌥O）。ShipiOS 此前把普通新建一律切到无项目，导致从项目任务继续新建时丢失当前项目上下文。

现在主窗口侧栏与普通新建命令在已连接项目中创建该项目的新草稿；无项目时继续创建无项目草稿。项目菜单保留明确的“无项目新任务”，命令菜单与应用菜单新增 ⌘⌥O 入口。独立任务窗口和分离内容窗口的普通新建按窗口所属任务的项目路由到主窗口；把标签拖到侧栏“新任务”也遵循当前项目。跨入口保留旧任务草稿，不会把已有任务内容改属其他项目。

项目导航、独立/分离窗口命令、快捷键、无项目历史及标签迁移共 60 项相关测试通过；`script/build_and_run.sh --build-app` 构建与签名检查通过。全量 Swift 回归在 Git 丢弃用例处长时间无进展后中断；该用例随后单独运行通过，不把中断的全量回归记为通过。当前 Mac 锁屏，窗口激活、焦点和用户安装版本 Codex 的真实新建行为尚未原生配对。普通新建沿用当前项目是依据官方两类快捷键与项目上下文说明作出的实现选择，仍须双端验收。
