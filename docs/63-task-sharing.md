# 主窗口任务共享

2026-09-17。任务工具栏的“更多”菜单增加“共享任务…”和“复制任务内容”。共享入口使用 macOS 原生分享面板，只有用户在面板中选择目标后才会发送内容；ShipiOS 不会自动发布任务。

共享文本包含任务标题、按时间排列的用户输入与 ShipiOS 结果，以及 `shipios://task/<id>` 本机深链接。任务链接仍只解析当前独立 ShipiOS 数据目录中的任务；共享给未安装 ShipiOS 或没有该任务数据的设备时，文本记录仍可阅读，但本机链接无法打开对应任务。

设置页继续通过同一个主窗口路由显示。共享功能没有增加 `Settings` Scene 或设置窗口。

当前实现是明确的用户发起式本地共享，不包含公开 HTTPS 页面、访问控制、链接撤销、跨设备同步或服务端脱敏。这些能力需要独立后端，不能用本机深链接冒充。

定向测试覆盖共享记录的逐轮内容与深链接。最终完整回归为 332 项 Swift、12 项 Rust、fmt/Clippy 与 IPC 冒烟通过，日志 `.cache/task-sharing-full-tests.log`。完整回归还暴露并修复了 Rust 协作式取消测试的落盘竞态：断言现在最多等待一秒，仍会拒绝未执行清理的实现。

使用原数据目录重建并启动 App 后，原生辅助功能树在任务“更多”菜单中确认“共享任务…”、“复制任务内容”和“复制任务链接”依次可见。应用仍只有一个标准窗口；设置页在该窗口内切换并可返回原任务，原草稿未丢失。最终进程 PID 为 47635。
