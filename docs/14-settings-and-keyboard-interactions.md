# 设置页与键盘交互补齐

2026-09-16。延续主窗口内设置改造。这是已实现行为的验收记录，**不是全部页面已经与 Codex 一致的结论**。

参考：[官方设置说明](https://learn.chatgpt.com/docs/reference/settings)。文档描述快捷键按名称搜索、按组合键搜索、修改与恢复默认；归档页显示日期和项目上下文并支持恢复。当前 Codex 版本的像素布局仍待参考证据核验。

## 快捷键设置

- 31 个已实现命令统一使用命令目录和可持久化绑定。原生菜单、命令面板、侧栏提示、输入区提示共用绑定来源。
- 搜索命令名，或开启按键搜索并录制组合键。
- 点击绑定按钮录制；Esc 取消；Delete 移除；单项菜单支持恢复默认；恢复全部默认包含确认步骤。
- 检查与其他应用命令的重复绑定，保留 macOS 常见窗口/文本编辑组合键；错误不写入设置。
- 持久化到独立数据根目录的 `shortcuts.json`，权限 0600。无效文件不被静默覆盖。
- AppKit 本地键盘监听只挂载在当前录制控件中，并限定其所属窗口。结束录制或离开分类时清理，不拦截其他应用键盘事件。

实机验证：搜索“搜索任务” → 尝试 ⌘K 收到冲突提示 → 设置 ⇧⌘L → 退出设置并使用新组合键打开任务搜索 → 重启 App 后仍生效、侧栏同步提示 → 按组合键反查命令 → Esc 取消录制并保留设置页 → 恢复默认 → 原组合键不再触发搜索。测试自定义绑定已恢复。

## 归档任务设置

- 按任务或项目名称/路径筛选，显示所属项目和归档时间，按归档时间降序排列。
- 新归档记录时间，恢复清除时间；历史数据没有时间时明确显示“归档日期未记录”。不伪造历史时间。
- 恢复任务后留在当前设置页，列表立即更新，任务重回项目侧栏。

实机验证：归档现有“环境诊断”测试任务 → 同一设置窗口显示任务、HelloShipiOS 项目和归档日期 → 无匹配搜索空状态 → 按项目搜索命中 → 恢复任务 → 页面保留且列表清空 → 返回工作区确认任务重现。最终恢复验收前选中的任务和原草稿。

## 文件搜索

- ↑/↓ 改变选中项并跟随滚动，Enter 打开当前选择，Esc 关闭。
- 筛选变化时重置选择，异步列表变化时限制索引范围，空列表不能触发打开。

实机验证：⌘P 后按两次 ↓ 和 Enter，实际打开第三项 `HelloShipiOSApp.swift` 的文件标签与源代码，而不是始终打开第一项。
