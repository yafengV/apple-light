# 本地环境导航与损坏文件修复

Codex Mac 当前的本地环境设置采用“项目列表 → 项目环境概览 → 编辑器”的层级，并把继承环境折叠在项目条目下。ShipiOS 的环境页现按同样层级组织：从已保存项目进入概览，查看项目环境与可展开的继承环境，选择文件后进入编辑；添加项目也从此页返回环境概览。设置仍在主窗口内。设置搜索定位到环境字段时直接打开编辑器。

损坏的 TOML 环境现在会保留文件修订摘要和“需要修复”状态。打开它时清空旧编辑表单，避免把上一个环境的脚本误写入；用户明确编辑并保存后，以修订摘要保护原文件不被外部修改覆盖。损坏文件不会作为新工作树任务的可执行环境。

Rust 测试覆盖损坏文件修订与显式修复；Swift 真实 Agent 测试覆盖读取、清空旧表单和保存。原生页面的实际视觉、焦点、键盘、滚动与窗口行为仍受 Mac 锁屏阻碍，不能据此记为完整配对。Codex 的项目列表会直接列出每个项目的环境，ShipiOS 当前仍需进入项目后查看；这一细节及云环境另待对齐。
