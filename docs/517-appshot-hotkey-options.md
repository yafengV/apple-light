# Appshot 快捷键选项与发送目标菜单

核对当前 Codex 桌面包的 Appshots 设置资源后，macOS 快捷键菜单有 `⌘ + ⌘`、`⌥ + ⌥`、`⇧ + ⇧` 和“无”四项。ShipiOS 已改为同样的四项弹出菜单，全局和应用内监视按左右物理修饰键识别所选组合；切换选项或松开按键时清理旧状态。旧版保存的启用／关闭偏好迁移为 `⌘ + ⌘`／“无”。

发送目标也改为带“自动／当前聊天／新聊天”说明的弹出列表，页面仍留在主窗口设置中。参考页面右侧还有循环演示视频；ShipiOS 尚未加入对应的自有演示素材。原生菜单视觉、全局三种双键的权限与按键实操以及双端逐项验收仍需解锁 Mac 后完成，完整配对继续为 0/46。

7 项选项与旧数据迁移定向测试及包含设置导航和截图归属的 23 项回归通过；`script/build_and_run.sh --build-app` 正式构建与严格签名通过。Mac 桌面控制仍报告锁屏，不能把这些结果当作全局按键的实操验收。
