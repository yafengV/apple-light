# 听写词典逐行编辑

当前 Codex 的语音设置把“添加词条”放在词典标题行，每个词条都是可编辑的输入行；按回车在当前行后插入空行，失焦时修剪并保存非空文本，行尾按钮删除该行。ShipiOS 此前只有单一添加框，已有词条不可编辑，且会去重、截断并限制数量。

ShipiOS 现使用同类逐行交互。页面首次展示已有词条或一条空行；添加按钮、回车、失焦、删除和离开页面分别维护编辑草稿与独立持久化词典。保存会修剪前后空白并移除空行，保留重复条目和完整文本；下次听写仍把这些条目送入设备端语音识别请求。

25 项语音、设置导航及听写草稿回归通过，760×650 整页离屏图像已检查；正式构建与严格签名检查通过。真实前台回车、焦点与 Codex 双端页面和交互尚未验收，完整配对仍为 **0/47**。
