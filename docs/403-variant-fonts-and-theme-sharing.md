## 字体与状态

- 三类字体按变体独立保存。内容默认项“与界面字体相同”持续跟随其界面字体；显式内容选择与另一侧不受影响。旧全局界面／代码字体在缺少变体字段时继续作为迁移回退。
- 系统字体目录读取真实本机 family 和 face；代码菜单只列出全部 face 均为等宽的 family。样式记录 family、fullName、postscriptName；选择默认或新 family 清除旧 face，缺失字体按既有 CSS 候选／系统回退。
- 预设只更新其明确指定字段，并在指定字体时清除对应旧 face；没有指定字体的 GitHub 保留用户样式，Xcode 清除旧代码 face。导入完整替换目标侧，缺少或 null 的内容字体恢复跟随界面，不遗留旧 face。
- 原生字体解析使用有效 face；普通文字不再强制把用户粗体样式改成 regular。助手 Markdown、用户提示、同轮引导、独立任务窗口正文、计划文档与推理正文接入内容字体。macOS 14 原生链接段落的行内代码使用所选代码字体。
- 外观先保存独立 `workspace.json` 后发布和应用；字体或导入保存失败保留外观、任务草稿和已选择菜单，并显示错误。无加载状态不能保存。
- 手改强调色记录 custom，重置移除标记；复制文本保留实际单侧 accentSource，不误标记为账户强调色。复制仅包含主题，不包含工作区、草稿、服务或凭据。
- 设置搜索新增八个分侧目标。120 个字段定义中，四个旧外观目标保留路由／定位兼容并从正常搜索排除，当前有 116 个可搜索静态目标，避免新旧字体入口重复。
