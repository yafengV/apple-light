# Codex Core 重连与中断状态

2026-09-26。Codex Responses 收到 `stream_error`、`stream_info` 或认证恢复事件时，运行中的任务会显示 Core 的状态消息；恢复输出或完成后清除。Core 的 `turn_aborted` 现作为终止事件结束传输流，外部中断不会让任务继续显示运行中。普通中断、替换及审查结束标记为已取消；预算限制标记为失败并保留已收到的内容。

本地假服务先发送部分 SSE 响应再断开，固定版 Core 实际发出重连事件；Swift 集成测试确认提示出现、恢复回复后清除且任务成功。另一个真实 Core 集成测试从 Agent 外部中断正在运行的回合，确认任务变为已取消且不再可引导。服务直接拒绝请求的集成测试确认 `task_complete` 中携带的错误会将任务标记为失败。HTTP 503 在此固定配置下没有产生同样的 `stream_error` UI 事件，因此重连测试使用真实响应流断开。

当前桌面窗口读取再次超时；重连提示的视觉、焦点与辅助功能朗读，以及中断后的原生页面状态，仍需与当前 Codex Mac 实机逐项对照。本阶段不增加完整页面配对验收数量。
