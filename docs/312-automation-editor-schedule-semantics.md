# 自动化编辑与日程语义

自动化编辑器现在按实际生效的字段呈现时间：小时日程选择每小时的分钟，日/周日程选择具体时间，周日程额外选择星期。筛选栏的“已启用”对应启用状态，不再把启用误称为正在执行。

保存名称、项目或指令时保留原定的下次运行时间；改动频率、小时、分钟、星期，或在编辑器内从暂停切回启用时，才从当前时间重新计算。这避免了临近执行前修改文字意外推迟该次日程。

10 项自动化测试通过，涵盖仅改文字保留时间、修改日程重新计算，以及重新启用时重新安排。原生应用构建和签名检查通过。Mac 锁屏仍阻止了时间控件、键盘焦点和 Codex 双端实际交互验收；多日程、自定义 RRULE 与应用退出后的后台执行仍缺。
