# 项目技能启停

2026-09-28。Codex 的[技能文档](https://learn.chatgpt.com/docs/build-skills#enable-or-disable-local-codex-skills)支持按实际 `SKILL.md` 文件路径停用本地技能而不删除文件。ShipiOS 现为项目技能的卡片、紧凑列表及预览接入启停开关，状态保存到自己的 `plugins.json`，保持独立配置约定。

停用后的项目技能仍留在列表并可预览和编辑，但从主窗口与独立任务窗口的输入候选、立即尝试和发送上下文排除。状态按解析后的实际文件路径保存：不同项目的同名技能互不影响，Git 上级共享技能在所有适用子项目同步停用，路径别名也使用同一记录。删除后恢复同一路径文件保留停用状态；重新启用恢复候选和上下文。立即尝试重新读取磁盘配置和仓库来源，避免旧预览在外部停用或删除后创建任务。技能文件与当前任务草稿保持不变。
