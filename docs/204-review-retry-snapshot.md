# 代码审查重试与差异快照

2026-09-26。代码审查回合的“重新运行”现在重用原来的范围、呈现方式与 Git 差异快照，不会把审查标题当作普通聊天发送。Codex Responses 的重试继续使用独立只读线程；兼容 API 也重用同一快照。项目此后产生的新改动不会悄悄进入重试。旧记录若没有快照，会显示明确错误，用户可重新发起审查。

快照以回合 UUID 命名，单独写入 ShipiOS 私有数据目录中的 `ReviewSnapshots`，目录权限为 0700，文件权限为 0600；工作区记录只保留审查元数据。创建回合失败时移除刚写入的快照。归档任务真正删除后，未被分叉任务引用的快照才删除。

本地假服务集成测试覆盖大差异审查、写入拒绝、应用重启后修改工作树并重试、分叉后删除原任务仍可重试，以及最后删除分叉时清理快照。原生“重新运行”按钮和当前 Codex Mac 的页面行为仍待可见配对；完整页面验收数不变。
