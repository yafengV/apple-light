# 新任务深链接与独立草稿

[OpenAI 命令参考](https://learn.chatgpt.com/docs/reference/commands#chats)列出新聊天深链接的 `prompt`、`path` 和 `originUrl` 参数。ShipiOS 现支持对应的 `shipios://threads/new`，以及至少带一个参数的 `shipios://new?<query>`。链接在主窗口创建未发送的新任务；`prompt` 只预填输入框，`path` 选择现存本地目录，`originUrl` 在已保存项目中按 Git `origin` 远端查找。若同时提供路径和远端，路径优先。找不到项目时显示错误，不改变当前草稿。

链接任务使用独立的草稿槽，普通项目及无项目草稿不会被覆盖。链接草稿写入 ShipiOS 私有工作区记录，应用重启后仍可恢复；随后从普通“新任务”入口进入时，原有普通草稿重新可见。链接不会自动提交模型请求。解析器拒绝重复或未知参数、无参数的 `shipios://new` 以及超长字段。

验证：42 项深链接、项目导航和输入区相关测试通过；真实临时项目测试覆盖路径优先、Git 远端匹配、无项目入口、未发送、原草稿隔离、跨应用恢复及错误路径。应用构建与签名检查通过。主窗口激活、输入框焦点以及与当前 Codex Mac 的可见行为仍待实机验收。
