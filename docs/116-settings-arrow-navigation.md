# 设置侧栏方向键的原生焦点

2026-09-18。补做 [上一轮](115-settings-accessibility-and-focus.md) 因锁屏未完成的方向键实测，发现点击导航后上下键未切换页面。把焦点交给整个窗口可以解决 Esc 返回，但不能可靠地让 SwiftUI 的导航按钮继续收到方向键。

## 实现

- 设置侧栏使用一个窄范围的原生键盘焦点入口。点击导航后，在所属主窗口中聚焦该入口，上下键按设置页顺序移动；首尾不循环。
- 不注册全局方向键监听。文本输入和其他控件取得焦点后，继续处理自己的键盘事件；修饰键组合不作为导航上下键。
- 延迟聚焦检查最新请求、可见/启用状态、所属窗口与弹层；卸载后作废。
- 侧栏选中项、页面内容及滚动定位仍由原有设置导航状态驱动，不创建新窗口或销毁缓存页面。

## 验证

34 项设置与布局回归通过，日志 `.cache/settings-navigation-keyboard-tests.log`。新增原生事件测试覆盖启用/禁用状态、上下键、修饰键、卸载及列表边界。

修复版原生检查：

- 通用 → Down → 通知 → Up → 通用；继续 Up 保持通用。
- 已归档任务 → Down → 运行时；继续 Down 保持运行时；Up 回到已归档任务。
- 导航后 Esc 返回同一 `ID: main` 的原任务，原待发送草稿保留。
- ⌘F 聚焦设置搜索，实际键盘输入 `browser` 后，Down 不改变当前设置页面。
