# 父目录本地环境

Codex Mac 会从当前项目向上查找 `.codex/environments/*.toml`，在 Git 根目录停止，并在环境设置中把项目环境与继承环境分组。ShipiOS 现沿同一项目边界列出父目录环境，保留完整路径作为继承环境标识。因此父子目录中同名的 `environment.toml` 可以分别选择。环境页显示来源目录，编辑和保存时沿用文件修订摘要冲突保护；新工作树任务会把选中环境的脚本与 Actions 固化到任务快照。

ShipiOS 的独立认证与个人 Codex 配置隔离仍然有效：只读取项目链上的环境文件，不读取 `~/.codex/config.toml`、认证或会话数据。对没有 Git 根目录的路径，搜索会在进入用户主目录前停止，避免将个人 `~/.codex/environments` 当成项目环境。这是刻意保留的隐私边界，与 Codex 向文件系统根目录搜索的边缘行为不同。

验证：Rust 本地环境测试覆盖 Git 根目录停止、同名区分、继承环境读取/保存和越界拒绝；Swift 的真实 Agent 集成测试覆盖列表、选择、新任务快照与写回。完整 Codex Mac 可见页面与键盘交互尚未配对，43 项完整验收数仍为 0。
