# 自动化结果全部标为已读

[OpenAI Scheduled 页面说明](https://learn.chatgpt.com/docs/automations?surface=app)展示了「Mark all as read」入口。ShipiOS 自动化页的「等待审查」区域现在提供「全部标为已读」；有待审查结果时显示，点击后批量清除所有自动化的待审查运行，并清除这些运行所属任务的未读标记。其他任务的未读状态、日程时间、运行历史和运行中的状态保持原样。旧版单条待审记录也会迁移为已读状态。

验证：23 项自动化测试通过，其中新增回归覆盖多个日程、多次运行、旧版单条记录、持久化和非自动化任务的未读状态。应用构建与签名检查通过。Mac 桌面仍无法读取，按钮布局、焦点和与当前 Codex 的可见交互尚未完成配对验收。
