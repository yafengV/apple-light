# 应用窗口截图上下文

本机 Codex Mac 客户端 26.911.61220 的 Appshot 发送路径除窗口图片外，还携带应用名、窗口标题、Bundle ID 与辅助功能文本。ShipiOS 的窗口截图现在把这些信息绑定到同一图片附件，发送给独立 API 服务或 Codex Core 时随图片提供。会话恢复、分叉和运行中追加消息也保留该上下文；普通图片附件不受影响，旧版附件记录仍可读取。

辅助功能文本只在 macOS 已授权且可按所属进程和窗口标题唯一匹配截图窗口时读取；不主动弹出辅助功能授权。读取限制深度、节点、耗时和总长度，并跳过安全输入控件的值。发送文本将截图上下文标为不可信屏幕内容。macOS 14 的系统窗口选择器不提供所选窗口身份，因此该路径仅保留可确定的截图信息，不猜测窗口标题或辅助功能文本。

55 项相关自动化测试覆盖附件兼容性、上下文长度、图片与请求数据同步、草稿归属以及会话分叉恢复；正式应用构建和严格签名检查通过。当前仍缺 Codex 和 ShipiOS 前台双端验收，包括真实授权后的辅助功能内容、截图动画、焦点和选择器行为；这项代码实现不代表 Appshot 或整体 UI 完全对齐。完整页面和交互配对维持 **0/45**。
