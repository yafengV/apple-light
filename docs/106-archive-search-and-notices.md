## 搜索行为

本机 `app-primary-4af6ed7f68d1.js` 的 `nYt` 使用完整查询、独立 `searchValues` 字段、`ignoreLocation: true` 和 `threshold: 0.4`；`rYt` 在搜索后按用户选择重新排序。原实现把标题、项目名和完整路径拼接后逐词查找，会产生不同的命中结果。

新增原生 Swift 匹配器，用半全局编辑距离实现忽略位置的匹配；保留 UTF-16、32 单元长查询分块、大小写归一和重音区别。查询使用 ECMAScript 的 trim 字符集，包括粘贴内容中的 BOM，并区分 U+0085。字段分别为任务标题、项目标签与项目目录简称，不再搜索父目录或跨字段拼接的词组。排序仍由归档排序设置决定。

测试使用 [Fuse 官方 v7.1.0](https://github.com/krisk/Fuse/tree/v7.1.0) 未修改的 basic CJS 构建作为参照；这不是对本机 Codex 所捆绑 Fuse 版本的断言。`script/archive_search_reference.cjs` 生成并保存 1,144 组对照样本，覆盖插入、删除、替换、长查询、空白、中文、emoji、重音和多字段。所有样本命中结果一致。产品运行时不加载 JavaScript 搜索库。

## 恢复通知

依据本机 `data-controls-177358ad1ff5.js` 的恢复流程，以及 `app-initial-4d7ea7f81c2d.js`/CSS 中的通知容器：

- 恢复通知不再插入列表，改为主窗口顶部按内容宽度居中的浮层，不改变列表滚动文档。
- 正在恢复时显示无自动关闭期限的进度；成功后提供“查看”和关闭，默认 5 秒消失；悬停或按钮聚焦暂停计时。
- 相同任务的进度、成功、失败共用通知身份。保留通知队列，最多展示三个，悬停/聚焦时展开，支持向右拖动关闭。
- 保存失败保留原归档状态，显示错误；查看时读取当前任务状态，保护已有草稿。任务已不存在、当前无法切换、项目打开失败分别显示失败反馈。
- 通知操作不创建新窗口，设置仍留在主窗口，用户点击“查看”后才切换到任务。
