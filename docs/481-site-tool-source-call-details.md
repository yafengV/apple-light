# 站点工具来源中的逐次调用

本阶段对照本机安装的 Codex 桌面客户端 `26.911.61220` 的公开静态界面资源 `local-conversation-sources-side-panel-tab-6ca81b3a21b9.js`、`local-conversation-webmcp-tools-model-27cf238f54eb.js` 和 `webmcp-tool-calls-f1d07eefe73f.js`。资源显示 Sources 按网站组织站点工具，再按工具名聚合调用；展开后按次展示输入和结果，长内容在限高代码块中滚动，并标出截断状态。此处对照的是公开打包代码，尚不是运行中的双端交互验收。

ShipiOS 的 Sources 现按“网站 → 工具名 → 调用记录”呈现，工具行显示使用次数，展开后显示每次调用的输入与结果。输入只存入工具调用的来源元数据，不进入时间线标题；失败、拒绝和中断的调用清除待保存的输入。新字段随任务记录持久化，旧任务没有输入字段时仍可从已有结果字段显示结果。每次输入最多保存 16,000 个字符，并记录是否截断；结果沿用浏览器工具的截断标记。

定向 `CodexBrowserTimelineTests`、`TaskSummarySourceTests` 和 `BrowserPanelLifecycleTests` 共 10 项通过；`BrowserTests` 68 项在允许本机回环夹具的环境通过。正式应用构建与深度签名校验通过。最初在受限环境执行浏览器组时，本机回环夹具无法启动，68 项均未运行有效断言；允许回环后全部通过。

本次未完成实际前台配对：桌面控制接口拒绝访问参考 Codex 客户端，且 ShipiOS 所在 Mac 处于锁屏，无法确认新包的可交互工作区。因此本阶段只算代码实现、自动化测试和静态资源对照，21 类工作区与 24 类设置的完整双端验收保持 **0/45**。待验重点包括 Sources 的真实展开/滚动/键盘焦点、真实独立 API 服务会话，以及设置与主工作区的逐页视觉和行为。这里的 45 是验收类别数，不是 45 个确定缺陷或完成百分比。
