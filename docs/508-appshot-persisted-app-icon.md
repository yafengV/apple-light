# Appshot 应用图标随截图保存

Codex 桌面端的 Appshot 附件数据包含捕捉时的应用图标。ShipiOS 此前仅在渲染卡片时依据 bundle ID 向本机查找；应用退出、卸载或历史记录在另一台机器恢复后，卡片可能丢失当时的图标。

自动捕捉现在使用目标运行应用的图标，系统单窗口选择器捕捉则从所选窗口的 bundle ID 查找。图标缩成 128×128 PNG，限制为 256 KiB，和应用名、窗口标题、辅助功能文字一同存入 Appshot 元数据；卡片优先显示这个快照。旧数据缺少图标字段时继续解码并按 bundle ID 查找。图标不进入发给模型的文字上下文。

相关测试覆盖 PNG 编码、大小限制、序列化往返和旧格式解码；正式构建与签名结果见本阶段提交。Mac 锁屏，尚未进行可见卡片和 Codex 双端逐项验收；捕捉动画仍未实现，完整配对保持 **0/45**。
