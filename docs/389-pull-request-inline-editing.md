## 实现

- 标题编辑器沿用原生文本系统的选区、输入法及撤销，自动随内容增高到最多 96 点；保存前去除首尾空白。保存/取消用图标按钮，标题编辑时隐藏页头复制链接及 GitHub 打开按钮。标题入口没有额外作者限制，实际写入权限由 GitHub 决定。
- 描述区有读取、空、错误、Markdown 正文及编辑状态。输入保留原始多行文字，允许清空保存；只向开放 PR 的作者提供描述操作。保存期间阻止再次提交和取消，失败保留输入，继续输入清除错误。
- 同一独立数据目录中的同一个 GitHub PR 共享内存草稿，覆盖多个窗口、任务和检出目录；不同独立数据目录隔离。草稿没有写入用户配置或工作区文件。关闭最后一个使用者取消未完成工作并保留本次进程中的草稿。
- 标题、描述与已有 PR 合并操作共用修改互斥。执行前复查当前 PR 和描述编辑资格，写入前再次验证任务范围和只读设置。描述通过 0700 临时目录中的 0600 文件传递，完成、失败和取消均清理文件。
- 服务端写入后重新读取并确认字段；响应断开但远端已保存可确认成功；结果无法读取时保留草稿并提示待确认。重试先检查远端值，已经保存的相同值不再重复写入。成功更新所属任务的已记录 PR，并同步其他打开窗口的元数据。
- 新编辑结果可以使旧后台读取失效；重新打开 PR 时，旧编辑快照不会覆盖刚读取的远端状态。旧任务失效后的迟到保存结果不会发布到任务，输入仍保留。
- 生成读取真正的远端 PR 差异，读取前、差异捕获后及模型返回后核对作者、开放状态、头提交和源/目标分支。提示包含既有描述与测试说明、当前标题及独立 PR 指令，分别限制描述、指令和差异上下文长度，并补齐截断的代码围栏。结果只进入编辑草稿，需另按保存才修改 GitHub。
- 生成支持用户选择的 Chat Completions 与 Codex Core Responses。Responses 沿用独立临时 Core 会话，禁止工具，不修改原聊天；停止、超时及结束清理临时会话。生成中可停止，停止后保留编辑器，取消后的迟到结果不会覆盖手动草稿。
- 描述编辑使用本控件的 Cmd/Ctrl+Enter，标题使用 Enter/Esc；均保护输入法组合。标题粘贴在注册原生撤销范围前规范化换行，撤销/重做完成后显式同步绑定草稿；根据 [Apple 的 Undo 通知文档](https://developer.apple.com/documentation/foundation/nsnotification/name-swift.struct/nsundomanagerdidundochange)，监听当前编辑器所属 UndoManager，退出时移除监听。描述退出时通过本视图的弱焦点探针和操作按钮焦点判断，避免抢走其他原生输入控件的焦点。
