# 浏览器数据按时间与类型清除

2026-09-27。设置 → 浏览器 → 历史与数据中的“清除浏览数据”现可选择过去一小时、24 小时、7 天、4 周或所有时间，并分别勾选浏览历史、Cookie 与网站登录状态、缓存文件、其他网站数据。未选择任何类型时无法执行。确认框说明清除后无法恢复。

所选时间截止点同时用于 ShipiOS 本地历史和 WebKit 网站数据；清除网站数据时仍覆盖主窗口与独立任务窗口共享的资料。只清历史不会清 Cookie；只清 Cookie 不会删浏览历史。现存调用保留原来的“清除全部网站数据、可选历史”行为。

依据：[OpenAI 官方浏览器说明](https://learn.chatgpt.com/docs/browser)要求“清除浏览数据”选择时间范围与数据类型。真实 WebKit fixture 已验证按最近时间清理历史时保留旧历史和 Cookie，以及单独清 Cookie 后保留历史。当前 Mac 锁屏，设置页原生控件位置、键盘与当前 Codex Mac 的视觉配对仍未完成。
