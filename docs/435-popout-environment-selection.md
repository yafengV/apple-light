# 弹出首页环境选择

参考桌面资源的弹出首页“聊天设置”菜单包含“环境”。ShipiOS 现在在选择 Git 项目及工作树启动模式后显示项目默认、无环境、ShipiOS 本地配置和该项目可用的环境文件，支持刷新列表。选择保存在该项目的新任务环境偏好中；若已有待恢复的弹出工作树，则冻结选择，以沿用已准备检出的环境快照。独立聊天和本地启动模式不提供工作树环境选择。

工作树发送使用所选项目的主目录读取环境文件，保存环境快照并执行设置脚本。真实临时 Git 仓库集成测试验证了选择后的脚本在新检出目录生成标记、原项目没有该标记，并验证恢复“项目默认”会清除显式选择。

弹出窗口、跨项目环境与工作树的 14 项定向回归通过；`script/build_and_run.sh --verify` 构建启动及严格深度签名通过。参考菜单的权限控制、云环境与本地模式环境语义仍需继续对照。当前 Mac 锁屏，前台菜单操作和 Codex 双端配对尚无新证据，完整验收保持 **0/45**。
