# 浏览器可见区域截图

2026-09-17。内置浏览器现在可以把当前标签的可见区域截图直接加入触发操作时的任务输入区。地址栏右侧的相机按钮只在页面完成加载后启用；捕获期间显示进度，并阻止重复截图、页面元素选择和附件并发导入。

截图由当前 `WKWebView` 的 `takeSnapshot` 生成，再转换为 PNG 并交给现有图片附件管线。异步捕获开始前固定任务 ID；即使用户随后切换任务，图片也不会进入另一个草稿。页面在捕获期间导航、重新加载或关闭时，旧截图会被丢弃并显示可关闭的错误。WebView 尚无可见尺寸、图片编码失败、超过附件数量/大小限制或工作区保存失败时，不会留下半写入文件。

图片只保存在 ShipiOS 独立数据目录，使用与选择、粘贴图片相同的校验、原子持久化、权限和清理规则。点击截图按钮不会自动发送模型请求；只有用户发送当前消息时，附件才会进入已配置的独立 API 请求。

`BrowserTests` 新增两项真实 WebKit 测试：一项加载回环网页、生成有效 PNG、写入精确任务并验证私有附件文件；另一项确认仍在加载的页面不能截图且不会改变附件。浏览器定向测试共 17 项通过。

原生隔离实例加载 `http://127.0.0.1:54696/one` 后，相机按钮从禁用变为可用。点击后输入区出现 `网页截图-127.0.0.1.png`；打开预览可见真实 Fixture 页面内容和 38 KB 文件大小，Esc 返回后附件仍属于原输入区。全量回归为 357 项 Swift、12 项 Rust、fmt/Clippy 和真实 IPC 冒烟全部通过，日志 `.cache/browser-snapshot-full-tests.log`。

验收后以原数据目录重启为 PID 85868。主窗口仍选中“验证新输入框的真实构建”，草稿“这是一条待发送草稿，重跑后应保留”保持不变；`⌘,` 在同一个 `ID: main` 窗口显示设置，Esc 准确返回原任务。
