# 跨项目任务内容与分支搜索

2026-09-17。补齐任务搜索只能匹配标题、项目名和用户说明的差异。

依据：[官方搜索说明](https://learn.chatgpt.com/docs/reference/commands#search-past-chats-and-find-in-a-chat) 描述搜索历史任务，并在扩展匹配可用时匹配消息内容和 Git 分支。当前用户版本的搜索布局、结果排序和精确焦点仍须原生配对；该文档不是截图证据。

## 当前行为

- 搜索所有已登记任务，包含其他项目、无项目和已归档任务；保留任务列表顺序。
- 匹配标题、项目显示名、用户消息、模型回答、代码块、表格单元、诊断和保存的执行结果。Markdown 按实际显示文本检索，不把隐藏的格式符号当作回答。
- 新回合开始时读取仓库当时的真实分支并保存。切换分支不会重写旧回合记录；分叉只复制纳入分叉范围的回合分支。旧任务没有记录的历史分支不推测、不以当前分支补写。
- 内容命中显示来源与上下文片段，高亮搜索词，支持大小写、重音不敏感匹配及 Unicode。方向键跳过暂不可打开的任务，Return 打开，Esc 关闭。打开任务与会话内查找仍是独立操作。
- 查询在后台计算；输入变化使旧结果不可操作，取消或过期计算不能覆盖新的结果。空白查询显示任务列表。

其他项目的本地执行记录通过独立数据目录内的 SQLite 数据库只读加载，不切换项目、不启动另一份 Agent，也不将运行中的记录改成已中断。只读取已登记任务所属的回合并核对项目归属；当前内存中更新的回合覆盖旧历史版本。数据库缺失、版本不支持或损坏时保留其他来源的结果，并显示部分历史读取失败与重试入口。拒绝数据目录外的路径及被符号链接替换的数据库/WAL/SHM 文件。

## 长列表、Unicode 与历史重试复测

在同一隔离工作区添加 30 条本地会话：输入 `cafe` 同时匹配 `Café` 和组合重音的 `Café`，截图确认片段高亮。连续按 18 次 Down，列表自动滚动至“长列表验收 17”，Return 打开同一任务并聚焦输入区。输入复杂 emoji `👩🏽‍💻` 也匹配正确，片段保留完整字符。

新增缺失历史数据库的项目，原生错误提示暴露 `/private/tmp` 与 `/tmp` 别名判断不一致：内部文件被误报为数据目录之外。历史加载现使用与工作树相同的规范化路径解析，先解析已存在的父目录，再拼接尚不存在的文件；外部数据库及符号链接保护仍保留。修复后原生提示为“无法读取本地任务历史”。保持搜索词 `retry-needle` 不变，补入隔离的 SQLite 历史后点击“重试”，错误消失、原面板显示恢复的回答，并保留输入焦点。

新增缺失文件、别名和恢复后当前查询的回归测试；搜索共 11 项通过，包含原有路径边界及符号链接保护（`.cache/search-boundary-tests.log`）。快速取消竞争仍只有自动测试，未声称原生压力验收。上述原生结果仍非 Codex 配对。
