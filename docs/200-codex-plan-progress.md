# Codex Core 计划进度卡片

2026-09-26。ShipiOS 独立的 Codex Core 会话现已启用固定版 Core 的 `update_plan` 工具。Core 发出的 `plan_update` 事件会进入主窗口和独立任务窗口共用的时间线，显示待处理、进行中和已完成的步骤。同一回合后续更新保持卡片身份，只更新步骤；计划和时间线顺序随任务记录保存并恢复。

`update_plan` 是执行中的进度清单，不是输入区已有的“计划模式”。它使用 ShipiOS 会话配置，不读取用户个人 Codex 配置。本地假模型连续两次调用真实 Core 工具后，Swift 集成测试确认最终状态、单张卡片及持久化；43 项模型传输回归、Rust 测试、Agent RPC 冒烟、应用构建和签名验证通过。

当前桌面读取窗口状态超时，因此卡片的尺寸、颜色、焦点、辅助功能朗读和 Codex Mac 原生交互尚未配对。真实用户 API 服务也需在用户填写后验证。此阶段不增加完整页面配对验收数量。
