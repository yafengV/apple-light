# 提交统计与任务分支建议

2026-09-18。继续补齐 [提交范围与新分支弹层](97-commit-selection-and-new-branch.md) 的建议名和统计反馈。

## 对照证据

本机 Codex 静态 UI 包 `git-branch-picker-dropdown-content-17fc53789202.js` 根据分支前缀与会话标题计算建议名，并在所选变更旁显示彩色增删行统计；读取中显示进度，无变更时显示 No changes。

其引用的 `app-initial-4d7ea7f81c2d.js` 中 `adi/odi` 明确采用：前缀去除两侧空白，标题转小写，按空白切词并取前 5 个词，再删除每个词中的非 ASCII 字母/数字字符，过滤空词并用连字符连接。中文等标题可能得不到后缀，这种情况下保留前缀，仍需手动填写有效分支名。

## 实现

- 新分支建议名采用上述规则。主窗口使用当前任务标题，独立任务窗口使用自己的任务标题；找不到显式任务时不回退到主窗口任务。
- 未编辑过建议名时跟随标题及前缀变化；手动编辑后保留用户输入，包含清空后的输入。最终名称仍需通过 Git 名称和重名校验。
- 提交范围旁显示绿色 `+新增行` 与红色 `−删除行`，无变化时显示“没有变更”。辅助功能提供完整描述，帮助提示保留文件数和二进制文件数。
- 使用 Git 的 `--numstat -z` 读取真实统计，正确处理重命名、含制表符/换行的文件名和二进制标记。行数统计不依赖模型差异的 512 KiB 限制。
- 统计与提交说明生成共用临时索引选择逻辑，保留真实索引、稀疏检出和分离索引。包含未暂存内容时使用工作区最终内容；暂存后又还原到 HEAD 的文件不重复统计。
- 切换范围或 Git 审查快照更新时重新读取统计，读取期间不使用旧摘要启用提交。旧请求的完成或错误不会覆盖新请求；失败可重试。
