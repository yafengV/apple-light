## 配置版本与数据保留

快捷键快照版本改为 2，仍接受版本 1 和更早的裸字典文件。旧版把主／备用命令分别保存，升级时合并各旧行实际生效的绑定：

| 旧配置 | 升级后的行为 |
| --- | --- |
| 两行都没有修改 | 保持两个默认绑定，不生成自定义状态 |
| 只改主绑定 | 保留自定义主绑定及未修改的默认备用绑定 |
| 只改备用绑定 | 保留默认主绑定及自定义备用绑定 |
| 明确清除其中一行或两行 | 保持相应取消状态，不重新加入默认按键 |
| 其他命令已经占用原默认按键 | 保持旧版默认让位规则，不重新抢占该按键 |
| 两个旧行包含重复值 | 按原顺序去重，保留其他值 |
| 两个旧行合计超过六个绑定 | 最多十二个旧值全部保留，可替换或逐个删除，不允许增加数量 |

迁移移除 `palette-alternate`／`new-alternate` 旧键。版本 2 重读不会再次加入用户已删除的备用默认值；未知版本拒绝加载，保留当前状态。裸字典文件的首次读取不改写原文件，下一次成功编辑才保存规范快照。

工作区恢复本来会保存布局／外观等恢复信息，不能承诺整个 `workspace.json` 字节不变；本次验证的是快捷键原版本和字段在显式设置保存前不被迁移改写。保存继续使用既有单工作区原子事务和全局快捷键批次协调；失败保留内存绑定、旧工作区快照及原生登记。语音页和通用页均接受版本 2，旧配置后续语音编辑也保存规范快照，不再回写版本 1。
