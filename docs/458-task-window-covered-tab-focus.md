# 独立任务窗口被遮盖标签的命令焦点

独立任务窗口打开右侧文件检查面板时，原右侧内容标签仍保留在窗口状态中。此前部分浏览器、关闭和查找命令按该旧焦点执行，可能操作被检查面板盖住的网页或文件。

现在命令聚焦只认实际可见的内容标签；左侧当前内容标签作为回退目标。浏览器地址栏与复制链接明确作用于目标网页，避免浏览器会话中最后选中的隐藏网页抢走命令。打开聊天运行详情时，焦点回到聊天，使被详情覆盖的右侧标签不再接收命令。文件检查面板被运行详情盖住时，也不会被当作可见文件页。

98 项独立任务窗口及文件相关回归通过，定向测试覆盖文件检查面板覆盖右侧浏览器后，左侧浏览器接收地址栏与关闭命令。`script/build_and_run.sh --verify` 完成正式构建和进程启动，严格深度签名通过。Mac 锁屏，前台键鼠及 Codex 双端配对仍未完成；完整验收保持 **0/45**。
