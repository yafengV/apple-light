# 推理强度命令

本机 Codex macOS 客户端 26.911.61220 的命令注册表包含提高、降低和循环切换推理强度。ShipiOS 此前只能在模型弹层修改推理档位，现在三个操作进入命令菜单和原生“任务”菜单，并可在快捷键设置中自定义；没有增加默认快捷键。

命令从当前独立 API 服务的模型元数据读取明确支持的档位，按设置中已显示的高级档位过滤。提高和降低在边界处禁用，循环在末档回到首档；服务没有声明支持档位、少于两个可切换档位，或“服务默认”无法解析为服务声明的默认档位时，命令禁用。主工作区修改当前任务或新任务的模型选择，独立任务窗口只修改自己的任务；更改用于下一次请求，不覆盖正在运行的请求。模型弹层在独立任务窗口也按该任务的协议获取目录。
