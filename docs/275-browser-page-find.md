# 浏览器网页内查找

2026-09-27。浏览器标签现在提供独立的网页查找栏。主窗口、独立任务窗口及独立浏览器窗口在浏览器标签聚焦时，将“查找”命令送到当前网页；输入后由 WebKit 搜索页面内容，Return/⌘G 查找下一个，⌘⇧G 查找上一个，Esc 关闭。非浏览器内容继续使用原有会话查找，设置页继续聚焦设置搜索。

查找状态逐网页标签保存，切换标签不会把查询串带到另一页；导航清除上一页匹配状态。WebKit 当前只向此接口返回是否命中，因此查找栏显示“无匹配”，不虚构匹配总数。

验证：真实本地网页 fixture 上命中与未命中、标签隔离测试通过；主窗口和独立浏览器窗口命令归属测试通过。浏览器相关回归共 93 项、会话查找及任务窗口命令相关回归 20 项通过。`script/build_and_run.sh --build-app` 构建成功，应用签名验证通过。桌面状态读取超时，当前 Codex Mac 与 ShipiOS 的查找栏外观、焦点、键盘及三个窗口的原生操作尚未完成配对验收。
