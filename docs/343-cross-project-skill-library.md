# 跨项目技能库与尝试路由

2026-09-28。官方[技能入口说明](https://learn.chatgpt.com/docs/build-skills)支持浏览跨项目创建的技能。ShipiOS 原先只显示当前项目及其适用仓库范围；本阶段补齐本机保存项目、已有任务项目和当前项目的统一浏览。该参考说明不能替代当前用户版本 Codex 的精确页面配对。

项目卡片从所有已知本地项目的适用 `.agents/skills` 目录读取。同一实际 `SKILL.md` 文件在多个子项目可用时只显示一次；当前项目适用时优先保留当前执行范围，否则绑定到一个保存过的适用项目。同名但不同来源的技能保持独立。损坏项目单独显示错误与重试，其他来源继续展示；读取在后台执行，取消的旧请求不会覆盖新结果或清除新请求的加载状态。

卡片、预览和编辑器携带相同的项目范围：可在不切换当前工作区的情况下编辑或启停其他已保存项目的技能。创建表单可选私有目录或一个保存过的项目。不再属于已知项目范围的路径不能通过旧弹层继续创建、编辑或启停；保存仍校验原文，防止覆盖外部修改。

“立即尝试”先验证当前磁盘启停与来源，再打开适用项目，创建独立预填草稿而不发送请求。切换过程中阻止其他尝试；项目无法打开、技能被停用或移除时不创建任务，尝试恢复原项目与页面并报告错误。路径别名按实际目录连接，再重新定位准确的技能文件。原任务、草稿和附件继续保留；技能页搜索词保存在应用内页面状态，跨项目导航后返回可继续搜索。

102 项相关定向回归通过，包括共享文件去重、同名来源、损坏目录隔离、跨项目创建/编辑/启停、实际 Agent 连接与项目切换、原任务草稿/附件保留、返回原任务、路径别名、过期来源及连接失败恢复；同时复测模型按需读取、技能自动刷新与 MCP 工具循环。`script/build_and_run.sh --build-app` 构建与严格签名检查通过。本轮没有重跑全量回归。
