# 资料页返回按钮的反向焦点

第 120 篇记录的前台失败路径是：从“个人资料”侧栏进入，连续 Tab 到“返回应用”，再按 Shift-Tab 时焦点跳到“外观”，没有返回资料页最后的“保存资料卡”。设置导航现识别这条边界，把反向焦点请求送到资料卡按钮；搜索活跃、资料未加载、确认弹层打开或不在资料页时沿用原生路径。资料卡只在当前资料页且仍可操作时响应请求。前向 Tab 仍进入设置搜索。

设置导航、交互、资料、布局、操作菜单及确认焦点相关 **44 项测试通过**；`script/build_and_run.sh --build-app` 正式构建及严格深度签名检查通过。隐藏原生窗口不能获得系统的完整键盘焦点链；本次没有把状态测试当作“24 次 Tab 后 Shift-Tab”的实机证明。当前 Mac 锁屏，需解锁后在主窗口按原序列复测，随后继续其他设置页和 Codex 双端配对。完整验收保持 **0/45**。
