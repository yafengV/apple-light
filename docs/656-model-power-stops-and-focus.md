## 实现与验证范围

- 同模型滑杆只展示至少两个真实、可见、已声明的档位。完整列表的“服务默认”选项保留。
- 默认值映射到有效实际档位；隐藏/未知/不受支持的当前值不被伪装为第一档，仍进入完整列表。
- 查看弹层或重复选择当前有效档位不改写空字符串的请求语义；选择其他档位才显式保存。
- 前台发现原滑杆打开后焦点仍在主窗口，方向键可能关闭弹层。单独增加 SwiftUI focus binding 和 focusable 仍未修复，保留这些观察，不把它们描述成成功。
- 使用小的 `ModelPowerSlider` AppKit 桥接让原生滑杆实际成为 first responder。SwiftUI/WorkspaceStore 仍拥有选择、保存和失败回滚；AppKit 只处理滑杆焦点、原生指针、可访问性增减和按键入口。左右键调用参考对照的档位规则，Return 完成；失效、恢复中、隐藏、离窗或拆除后的回调不能写入。

新增原生弹层测试使用独立数据目录与仅监听 127.0.0.1 的 `model_power_server.py`，通过真实 `/v1/models` 请求加载目录，无外部服务、模型 completion 或凭据。检查默认位置、无效/单档回退、任务独立保存、失败回滚/重试，以及实际原生控件焦点和键盘边界。

阶段中间结果：档位/模型/预算 **23 项通过**；加入实际弹层后 **26 项通过**；扩大 **287 项通过**。增加键盘规则后的中间扩大集 **288 项通过**，但该次结果不包含之后最终桥接变更，不能作为最终版本通过证据。原生桥接第一次构建因构建中输入文件被继续修改而 exit 1；源码固定后重新构建，不掩盖该次失败。
