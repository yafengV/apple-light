# 归档加载、错误与空状态

2026-09-18。对照公开分发资源 `data-controls-177358ad1ff5.js`、共享 `settings-row`、`settings-loading-row-52101fca68c8.js` 及 CSS：普通状态行居中、最小高度 4rem，加载行左侧显示进度；无数据、错误和加载阶段不显示筛选栏或全部删除。

## 实现

新增 `ArchivedTasksStatusRow`，将大图标占位改为简洁的加载、读取失败、空列表、无匹配结果四种状态行，最小高度 64。读取成功且有归档数据时才显示筛选栏和全部删除；搜索无匹配结果仍保留这些入口，全部删除范围保持为所有归档任务。

工作区读取现在单独记录 `libraryLoading` 和 `libraryReadError`。关闭主工作区的普通错误横幅不会清除归档读取失败状态；无关的 Agent 错误也不会被显示成归档读取失败。文件修复并重新加载成功后清除专门的读取错误。加载或读取失败期间，操作处理层拒绝恢复和删除确认。
