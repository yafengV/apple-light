# 切换模型时的推理等级

2026-09-26。当前模型选择器原先在切换模型时无条件沿用旧模型的推理等级。独立服务如果声明新模型的 `supported_reasoning_efforts` / `supportedReasoningEfforts`，新模型不支持旧等级时现在改用服务默认值；兼容时保留，服务未提供能力信息时也不臆测。当前已保存的等级若与模型声明冲突，选择器会提示用户更改。

11 项模型选择相关测试通过。此阶段仍未完成 Codex Mac 模型选择器的完整配对。安装包源码显示它的滑杆综合模型版本、预设和推理等级；ShipiOS 当前独立服务的标准 `/models` 数据没有这些预设，不能把简单的推理下拉框或普通滑杆称为同一交互。桌面锁屏，实际页面、焦点和键盘验收仍待进行。
