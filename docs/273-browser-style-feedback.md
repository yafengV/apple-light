# 浏览器评论的样式调整与临时预览

2026-09-27。网页元素评论现在提供“调整样式”：可给出替换文字、字体、字号、内边距、字距、文字颜色和背景颜色。用户可在当前网页临时预览，再保存评论；取消选择或保存后恢复网页原状。调整值和原评论一起存入所属任务草稿，发送时作为结构化上下文交给 Agent，主窗口与独立任务窗口共用同一套能力。区域评论仍保留原有文字说明，不提供元素样式预览。

预览通过隔离的 WebKit 内容世界修改当前元素，选区网址与当前页面不符时拒绝操作；文字预览只处理元素的直接文本节点，以免破坏页面子元素。保存后的目标值是给 Agent 的修改说明，不直接写入项目文件。真实 WebKit fixture 已验证文字与样式生效、恢复、旧评论兼容、保存序列化和发送上下文。

依据：[OpenAI 官方浏览器说明](https://learn.chatgpt.com/docs/browser)的“Styling feedback”描述可在批注中调整字体、文字、间距和颜色，预览后发送。当前 Mac 锁屏，表单布局、颜色选择、页面焦点与当前 Codex Mac 的原生配对仍待完成。
