- 保存比较弹层打开时的初值。未修改的输入不会覆盖另一窗口后来改出的名称；失效请求不写入，旧保存／关闭不能操作后来打开的弹层。关闭后发布回到固定行的焦点请求，取消固定及行移除取消关联弹层。

- 主窗口弹层期间禁用工作区、任务／项目改名入口、审批、归档和最近任务快捷键；标签栏行内输入继续属于文本编辑，不作为主窗口模态。任务窗口来源的标题同步到其固定引用，主任务、草稿及布局保持。

## 冷恢复缺陷与修复

首次测试发现，后台主窗口浏览器保存布局时 `savedBrowserTab` 只保存地址和 URL，覆盖了完整快照的自定义标题；显式空地址草稿标记也丢失。现改为复用 `savedWorkspaceTab` 的完整快照。新增测试实际保存磁盘、重新实例化来源，核对标题、空地址草稿／编辑状态、空白页保护和固定项元数据；主／任务窗口固定项均验证了冷来源先打开再重命名。

最初分离来源断言使用当前 B 任务的动作去移动隐藏 A 来源，实际没有移动。夹具已先选择真实来源 A，再移动并确认 placement 为 detached，然后验证旧请求被拒绝；没有根据这次夹具错误更改产品移动行为。
