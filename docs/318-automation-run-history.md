# 自动化按次任务与运行记录

[OpenAI 官方 Scheduled tasks 文档](https://learn.chatgpt.com/docs/automations?surface=app)说明独立计划任务每次运行会创建新聊天，并在 Scheduled 页面展示各次运行。ShipiOS 现为每次自动化运行创建独立任务；自动化列表可展开全部运行记录，查看状态、时间和待审查标记，打开旧结果或最近结果。

多次运行积累的待审查结果独立保存。打开其中一条仅标记该条为已审查；其余结果仍留在等待审查区。旧版仅存单条 `lastRunID` / `reviewedRunID` 的数据按原状态迁移。活动页打开自动化任务时，也只审查属于该任务的运行。

本阶段由本地 HTTP 夹具实际运行三次并验证任务及运行 ID 各不相同、旧结果可打开、待审查队列逐条清除；Codex Core 跨项目工具运行回归和自动化/活动页面测试通过。原生应用构建与签名检查通过。Mac 锁屏，页面视觉、键盘、焦点、展开与 Codex 双端交互仍未实机验收。多项目、计划任务工作树和应用退出后的后台运行仍缺。
