# PR 评论的嵌套媒体

Codex Mac 的 PR 评论媒体解析会继续遍历 Markdown 子节点与表格单元格。ShipiOS 原先只把正文顶层段落拆成媒体片段，因此列表、引用、标题和表格中的 GitHub 图片仍退化为链接文字。本阶段把允许来源的媒体接入共享 Markdown 渲染树，并只在 PR 评论启用：正文、列表项、引用、标题、表格单元格均能在原容器内显示图片；单独的 GitHub 附件视频 URL 与独立 HTML 媒体继续支持。普通会话仍使用原有解析路径；无候选媒体 URL 的 PR 评论也直接沿用旧路径。

HTML `src` 与 `alt` 属性现在解码常见实体及数字字符引用，带 `&amp;` 的私有图片签名查询参数可还原。非允许来源的图片、代码块中的媒体语法和混合额外 HTML 保持原文，不发起预览请求。

48 项相关测试通过，覆盖 PR 媒体解析、嵌套容器、评论折叠、普通 Markdown、会话搜索和导航轨道。`script/build_and_run.sh --build-app` 与严格签名检查通过。Mac 仍锁屏；列表/表格媒体的实际视觉、焦点、加载和 Codex 双端逐项配对尚未完成。完整页面验收保持 **0/47**，不是已确认缺陷数。
