# 输入区模型与推理强度选择

2026-09-17，继续处理审计 C02、K01 相关入口差异。此前点击输入区模型名称或按 ⌃⇧M 会直接进入设置；现在已配置服务时打开输入区内选择器。尚未取得当前 Codex 版本的配对界面证据，不能将此记为完整对齐。

## 当前行为

- 点击输入区模型名称、命令菜单“选择模型与推理强度”或对应自定义快捷键使用同一入口。
- 未配置有效基础地址时仍进入主窗口内“模型与 API”设置。已配置时保持在会话页，打开选择器。
- 从用户配置的服务请求 `/models`，只使用该服务地址的 ShipiOS Keychain 凭据，不读取 Codex 配置。
- 显示当前模型与服务返回的模型 ID，去重；支持搜索、上下键导航、回车选择和鼠标选择。大量条目使用懒加载布局。
- 服务未提供列表、列表为空、请求失败或模型未出现在列表时，可继续使用当前模型，也可直接输入服务商给出的模型 ID。
- 推理强度包含服务默认、低、中、高；默认值不发送 `reasoning_effort`。此列表不是模型能力声明，兼容服务是否接受该字段由实际请求决定。
- 选择模型或推理强度会保存到当前 ShipiOS 数据目录的模型配置，保留服务地址、自定义指令和独立凭据。当前实现仍是全局偏好，尚无逐任务模型覆盖。
- 正在运行的回复继续使用启动时捕获的配置；新选择用于后续请求，不清除草稿。
- Esc、完成或选择模型关闭选择器；返回主窗口设置时主动关闭，避免浮层留在隐藏工作区。焦点返回输入区的原生行为待解锁验证。
- 异步列表请求使用代次校验，旧服务或已取消请求不能覆盖新列表，也不会遗留加载状态。
