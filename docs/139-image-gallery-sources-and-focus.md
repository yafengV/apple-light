# 历史附件与工具图片图库、来源焦点返回

2026-09-18。接续第 138 篇，消除 MCP 工具图片仍使用独立 sheet 的分歧，并补验历史消息、原始文件保存及来源控件焦点。

## 改动

`ImageGalleryPreview` 共用窗口内覆盖层。新的不可变 `ImagePreviewItem` 描述磁盘附件或工具结果中的 Base64 图片；窗口通过环境回调接收预览请求，嵌套工具卡片不再自行弹出 sheet。图库仅包含同一次工具结果中的图片，保留内容块顺序，相同图片出现两次也有不同位置；不会混入其他工具或任务的图片。

工具预览按原始像素和方向解码，不再受旧预览 4096 像素缩略图限制；保留 8 MiB 编码数据限制，并在完整解码前检查 4000 万像素/单边 20000 的上限。无效数据与尺寸超限分别报告。保存直接写出来源数据，打开预览不向附件目录导入副本。

草稿、历史附件和工具图片在关闭时请求返回被点击的缩略图，窗口恢复底层交互后再设置焦点；新覆盖层已打开时不执行旧返回动作。来源缩略图支持 Tab、空格和 Enter。原生验收暴露 SwiftUI plain button 获得焦点却不处理空格的问题，已添加显式按键激活，并在禁用或附带修饰键时拒绝动作。没有来源回调的调用仍保留输入框回退。
