# 本地 Codex Core 文件夹路径上下文

参考客户端的本地文件夹附件保留文件系统路径，供 Agent 在会话中按需读取。ShipiOS 先前只保存选择时的内容快照；现在文件夹附件同时保存原目录路径。本地 Codex Core 回合和运行中引导消息在目录仍为真实文件夹时附上该路径，保留既有快照供历史恢复和目录不可用时使用。独立 API 请求仍只发送快照，不发送用户机器的目录路径。

如果原目录已删除或替换为符号链接，发送时不再提供路径，避免让路径指向选择范围以外的内容。旧附件记录无需迁移。此实现让可访问的本地目录可由 Codex Core 工具按需读取，但项目沙箱对项目外目录仍可能要求单独授权；它尚未证明与参考客户端在所有目录和权限状态下完全一致。

33 项相关自动化测试覆盖路径传递、独立 API 隔离、目录删除和符号链接替换；正式应用构建及严格签名检查通过。Mac 锁屏仍阻挡实际前台选择、发送、权限交互及双端逐页验收，完整配对保持 **0/45**。
