# 会话逐处查找与高亮

2026-09-17。继续审计 E03，替代上一轮按回合计数的查找。已完成代码与自动化测试接线；Mac 仍锁屏，原生显示与滚动验收未完成。

## 实现

- 一个段落内重复出现的词分别计数，上一项/下一项在各次出现之间循环；保持当前序号和已选结果。
- 索引来自实际显示内容：用户提示、Markdown 文本、代码、嵌套列表、引用、表格单元格，以及本地执行摘要、输出、诊断和错误。
- 不再搜索原始 result JSON。未显示的内部字段、Markdown 标记和链接目的 URL 不制造无法定位的结果。
- 使用 UTF-16 范围与原字符串转换，支持中文、emoji 前缀、大小写和组合重音。匹配采用不重叠的字面子串。
- 其他命中显示浅黄色，当前命中显示橙色；AttributedString 中原有链接、粗体等格式保留。复制回复与代码仍返回原文。
- 索引在后台构建。过期、取消、跨任务或不同查询的结果不能替换当前结果；取消后关闭等待指示。流式追加时尽量保留当前匹配 ID。
- macOS 15+ 使用 TextRenderer 的实际字形位置生成滚动目标，使长段落内、宽代码行内的当前命中可被定位。先显示所属回合/文本，再等待其字形位置就绪；用户开始滚动或返回底部时取消未完成的查找跳转。
- macOS 14 保留逐处高亮与计数，但定位回退到所属文本块；该平台的字形级定位仍未实现。

键位继续遵循 [官方 Commands](https://learn.chatgpt.com/docs/reference/commands#keyboard-shortcuts) 中的 ⌘F、⌘G、⌘⇧G。当前没有用户 Codex 版本的配对视觉证据，高亮颜色、定位动画与焦点语义均不能标为完全一致。
