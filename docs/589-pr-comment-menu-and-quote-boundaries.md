## 实现

评论菜单使用共用的窗口内弹层宿主，保留原有字体/主题选择器默认行为。菜单有独立的原生无障碍按钮、文字与图标，删除危险色、滚动和键盘高亮；弹层提供阴影与主题派生表面。AppKit 材料和阴影的最终合成仍需双端可见对照，不能将参数近似视为像素证明。

选择操作时重新检查最新快照、评论权限和线程身份。编辑/引用展开卡片并交给原生输入框自动聚焦，不安排迟到的入口焦点恢复。删除先将焦点放到仍挂载的触发按钮，再打开所属窗口内确认，取消后可返回该按钮。卸载、隐藏、禁用、窗口内模态及其他窗口事件均不能执行旧菜单回调。

新增 `JavaScriptText.trimmed`，集中精确的 ECMAScript 空白集合。展示和引用使用规范化正文；普通评论、回复、行内评论及审查的校验/提交/结果确认使用同一规则。编辑保存原文。BOM 可作为首尾空白移除，U+0085、U+180E、U+200B 不被误删。字体解析沿用原有相同集合，只复用 helper。
