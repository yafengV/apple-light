# 菜单触发时创建原生聊天分支

日期：2026-10-09。属于第 726 篇 R4，当前阶段处理侧栏聊天菜单及固定浏览器来源菜单的本地／同工作树路径。

## 实现

菜单冻结已结束历史的边界、模型与任务权限，再调用当前嵌入 Core 的原生分叉接口。独立子会话获得实际 Core ID 和历史后，才合并到最新工作区记录、保存并打开；创建动作不提交模型回合。项目外聊天使用独立输出目录，并保存该目录与实际 Core 历史归属。

等待时显示“正在创建聊天分支…”，成功或取消移除等待提示，失败显示“创建聊天分支失败”及具体错误。取消、异常确认、来源变化或工作区保存失败时只停止未发布的子会话，保留来源聊天与共享项目 Agent。拒绝把 Core 的失败改成文本复制成功。

创建期间的其他聊天草稿、历史、标题和配置通过合并最新记录保留，不用过期的整份快照覆盖。子聊天标题保留操作开始时的完整来源标题；去掉自动附加的“· 分叉”及 112 字符截断。侧栏菜单使用参考中的“创建聊天分支”“在同一工作树中创建聊天分支”“在新工作树中创建聊天分支”。等待／失败中文文案也核对既有冻结中文资源。

非原生导入历史与 Chat Completions 不具有可克隆的 Core rollout，继续保留已结束文本上下文，并在后续回合按对应协议发送；它们不被描述为原生克隆。
