## 参考与实现

参考版本 26.930.21537。只读取应用随包分发的公开界面资源，没有访问个人账户、凭据或会话。`pull-request-comment-ae0822c719d2.js` 的 PR 正文明确传入 `allowPlayableMedia: false`。提取实际媒体函数并用受控响应执行十个分支，源哈希及结果保存在测试夹具 `pr_comment_media_reference.json`；提取脚本、原资源和临时 HTML 留在忽略缓存。

- 加载：最小 160 × 96，横向/纵向内边距 16/12，居中进度，无成功/失败分支的外部纵向留白。
- 图片：接受 `image/*`（包含 SVG）及可解码的 `application/octet-stream`；不放大原始图片，宽度不超过容器，高度不超过窗口视口的 70% 与 640 的较小值，纵向外部留白各 12。HTML 和 Markdown 的 title 保留为提示，alt 保留为无障碍说明。
- 视频：有效视频或二进制响应显示“预览不可用”，入口交给系统外部打开；视频指令收到图片响应时仍显示图片。删除旧内联播放器及临时视频文件路径。
- 请求失败、类型不支持和图片解码失败：相同失败表面，按钮使用普通任务浏览器路由。不能把所有回退都改为外部打开。
- 失败表面最小 160 × 96，区块间距 8，正文及按钮字号 13；按钮为 24 点高的描边胶囊，沿用窗口模态保护、当前可用性检查、原生键盘与辅助功能操作，卸载后废止回调。

当前 Electron 样式的 rounded-md/lg 基础值为 8/10，`corner-shape` 支持时乘 1.25，因此图片/加载圆角为 10，失败表面为 12.5。公开样式夹具在浏览器中确认这两个计算值及 `superellipse(1.5)`，不是读取 Codex 实际页面。[CSS Borders 4](https://drafts.csswg.org/css-borders-4/#corner-shaping) 将 superellipse 参数 K 的指数定义为 2^K；原生形状依此采样，尚未完成像素级误差验收。

图片使用原生 NSImageView 并保留动画能力；双层盒阴影按元素外框生成，避免透明图片的内容轮廓决定阴影。阴影偏移为 4/2、模糊半径对应 6/4、负扩展为 1/2、透明度各 0.1；Core Animation 的具体模糊像素仍需前台配对。视口读取当前所属窗口 contentLayoutRect，窗口变化重新报告，离开或迁移后忽略旧窗口回调。

加载器保留 HTTPS 来源限制、跨主机重定向认证头剥离、禁用 cookie/缓存及 10 MiB 流式边界。生产默认仍使用 GitHub CLI 认证来源；测试注入独立 URLSession 与假令牌，不请求真实附件、不读取实际凭据。迟到响应、取消和同 URL 媒体类型变化均不得覆盖当前状态或打开旧地址。
