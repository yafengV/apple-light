# 文件搜索窗口内弹层

2026-09-18。继续修正主窗口和独立任务窗口的文件搜索呈现与键盘行为。

## 对照依据与改动

公开静态资源 `app-initial` 的 `yAo` 函数用 `$4.Dialog` 呈现全局命令菜单，其中 `files` 模式使用文件搜索提示；其内容类为 `codex-dialog command-menu-dialog global-command-menu-dialog`，定位在当前 renderer 内。本轮据此移除文件搜索的原生 sheet，不声称尺寸、材质及所有搜索规则已完全一致。

- 两类窗口共用窗口内搜索弹层：遮罩、结果列表、错误重试、取消；背景内容暂停交互并从辅助功能树隐藏，工具栏禁用。
- 搜索出现时清除旧响应者，再聚焦查询；刷新文件不清空用户已经输入的内容。
- 查询变化同步重置选中项，修复快速输入后立即按方向键，被延后的查询回调重置为第一项的问题。
- 上下键选择、Enter 打开、Esc/⌘W 取消；Tab/Shift-Tab 在查询、取消及可用重试之间循环。按钮焦点可见，输入法组词期间不截获确认、取消和方向键。
- 菜单和状态层阻止搜索背后的任务、设置、审批操作，独立窗口不回退执行主窗口命令。
- 主窗口从源码进入搜索时保存原文件焦点；两类窗口取消返回原输入/源码，打开结果后聚焦目标源码。重试先回到查询，避免成功后重试按钮消失导致焦点丢失。

## 验证

- 21 项定向测试通过：文件工作区、任务窗口命令/数据、AppKit 文件加载焦点及新增弹层键盘/状态隔离测试。日志 `.cache/file-search-dialog-tests.log`。
- 项目脚本构建并启动隔离工作区，AX 确认搜索是同一标准窗口的 `file-search-dialog`，没有 sheet；背景内容隐藏，工具栏不可操作。
- 主窗口从源码 `⌘P` 后连续 `pressKey` 输入 `beta`，查询完整、唯一结果正确；回车聚焦 Beta 内容。一次 `⌘P` 后直接 `typeText` 的自动化注入没有进入搜索框，不能据此宣称任意注入时序都已支持。
- 初版独立窗口连发查询与 Down 后错误打开 Alpha，定位到延后重置选择。修复后主窗口及独立窗口粘贴 `.txt` 后立即 Down，视觉高亮 Beta，回车确实打开 Beta 并聚焦。
- 独立窗口无匹配查询按 Enter 保留弹层；⌘, 不打开设置；Tab 聚焦取消并有可见焦点框，Enter 返回原源码。⌘W 只关闭搜索，任务窗口和文件保持。
- 从独立窗口草稿进入，Esc 返回原草稿，内容保持。隔离测试期间没有发送模型请求。
- 暂时移走隔离项目，显示错误和重试；还原后 Shift-Tab 到重试、Enter 恢复文件。最终版本主窗口复验确认重试后查询框聚焦，Esc 返回原草稿。
- 最终恢复原工作区，确认原任务和待发送草稿保持；严格签名校验通过。测试日志、缓存与工作区数据不提交。

## 剩余范围

模糊匹配及排序、路径行号语法、hover 与辅助功能结果选择语义、视觉尺寸/材质及全部输入时序仍需进一步配对。命令菜单、任务搜索等其他弹层也须分别继续核对；本轮不构成全产品 UI 对齐完成。
