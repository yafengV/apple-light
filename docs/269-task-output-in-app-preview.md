# 任务输出的应用内预览

2026-09-27。点击任务摘要或“查看全部输出”中的会话文件时，项目任务现在优先在所属窗口的文件面板打开预览和文件标签。主窗口和独立任务窗口各自使用自己的文件面板，不会把一个窗口的文件切换到另一个窗口。无项目任务没有文件面板，使用摘要所属窗口内的 Quick Look 预览；失效文件显示错误状态并可重试。

打开前会再次核对文件对应的任务、工作区及实际路径。若任务已切换或文件已移除，不会错误地打开其他任务文件。输出列表的日志预览同时从摘要子页移至共享容器，确保进入“查看全部”后仍能弹出。

这只是文件打开行为的局部对齐。Codex 的输出还可能是网页、云端资源和其他产物，其原生标签样式及双端点击行为仍需验收。
