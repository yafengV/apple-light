# 项目列表中的本地环境目录

Codex Mac 的“环境”项目列表会直接列出每个项目的本地环境，并将父目录继承环境折叠。ShipiOS 现通过独立的只读 Agent 会话查询所有已保存项目，将环境名称、文件名和错误状态显示在对应项目下；继承环境默认折叠，可按项目展开。浏览列表不切换当前工作区，也不读取用户个人 Codex 的认证或设置。项目目录失效只影响该行，其他项目仍可载入。

点击环境条目后打开该项目概览；损坏文件进入修复编辑器。项目行的添加按钮可直接新建环境。跨项目编辑目前会切换 ShipiOS 当前工作区，尚未与 Codex 的完整导航状态逐项配对。

真实 Agent 集成测试覆盖两个项目同时列出环境、失效目录局部报错和当前工作区保持不变。原生可见页面、键盘与焦点仍因 Mac 锁屏未验收；43 个验收面中的完整配对数仍为 0。
