# 搜索结果选择与辅助功能状态

2026-09-18。整理根命令菜单、专用任务搜索和文件搜索的选择行为。

## 实现

- 三种搜索接入原生 List 选择绑定与稳定行标识，使辅助功能树可以报告当前选中行。
- 任务搜索从当前有效结果推导默认首项，避免首次异步加载后没有选中结果；搜索期间和查询过期时不允许选择。
- 新增窄范围 AppKit 指针桥接，只处理当前活动窗口内可见行的鼠标移动；挂载和 tracking area 更新不触发选择，桥接不拦截行按钮点击。
- 指针选择不主动滚动，键盘导航仍滚动到选中结果；文件搜索滚动使用文件路径作为稳定标识。
- 命中区域取 bounds 与 visibleRect 的交集，排除窗口不匹配、隐藏、裁剪、禁用和已拆卸回调等情况。

## 验证

- 最终 27 项相关测试通过，覆盖指针桥接生命周期与命中保护、搜索弹层、任务分组、浏览器结果和任务检索回归。日志保留在 `.cache/search-pointer-final-tests.log`，不进入提交。
- 原生根菜单：默认最近任务及方向键切换后的结果均在辅助功能树中报告为选中；查询框保持焦点，回车打开目标任务并保留草稿。
- 原生专用任务搜索：修复后首次打开即选中首项，方向键切换正确；查询后点击结果进入目标任务，草稿完整。
- 原生文件搜索：默认 Alpha.txt 选中，方向键选择 Beta.txt，回车打开对应文件并聚焦内容；任务草稿保留。
- 提交前通过项目脚本重新构建并恢复原工作区，确认任务输入框可聚焦、原未发送草稿保留；严格签名检查通过。

## 验收边界

指针测试直接调用原生视图的移动处理入口，验证几何和窗口保护，并未证明操作系统真实鼠标移动事件的端到端投递。当前自动化工具没有独立悬停动作，此项仍待实机验收。辅助功能树的选中状态通过不等于 VoiceOver 全流程通过，也不代表全部页面或交互已经对齐。
