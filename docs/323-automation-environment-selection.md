# 自动化任务的项目环境选择

在自动化编辑器选择「托管工作树」后，每个 Git 项目可以单独选「项目默认」、ShipiOS 本地配置、「无环境」或项目及父目录提供的 `.codex/environments` 文件。编辑器从各项目读取环境列表，不依赖主窗口当前打开的项目。新自动化默认按项目默认环境运行；旧自动化保持原有本地配置行为。

每次运行在创建工作树前，从对应来源项目解析所选环境，并把配置快照固定在工作树记录中。setup、cleanup 和 Actions 使用该快照；中断后重试继续使用原快照。已删除或损坏的显式选择会在运行前报错，留给用户在编辑器中重新选择。非 Git 项目仍在原目录运行，不进入工作树环境流程。

验证：22 项自动化日程测试、跨两项目环境解析与重试快照测试、1 项真实 Git 工作树及 Codex Core 会话夹具通过。夹具确认所选 setup 脚本仅在任务工作树执行，来源项目保持原样。原生页面及当前 Codex Mac 的逐项配对验收仍待桌面解锁。
