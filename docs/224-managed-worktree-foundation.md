# 托管工作树基础

2026-09-26。依据 [Codex 工作树文档](https://learn.chatgpt.com/docs/environments/git-worktrees)，托管工作树通常服务于一个任务，而永久工作树作为独立项目可容纳多个任务。ShipiOS 原有的永久工作树不能直接充当新任务的托管工作树。

工作区记录现在为托管工作树单独保存任务 ID 与检出记录。创建前先持久化待完成状态，随后复用经真实 Git 测试的 detached worktree 创建与路径校验；创建成功再保存 ready 状态。同一任务的重试复用原路径，应用中断后可恢复已建立的检出，并保留工作树中的未提交修改。保存待完成状态失败时不运行创建命令。托管记录不会进入永久工作树列表，也不会自动登记为可容纳多个任务的项目。

13 项 `WorktreeTests` 通过，包括托管创建、重复请求、重启解码、中断恢复、脏目录保留和首轮持久化失败。此阶段只有数据与 Git 创建基础，尚未开放新任务输入区选项；从选中分支传递未提交修改、`.worktreeinclude`、任务归属、自动清理/快照恢复、Handoff 与原生页面配对仍待实现。
