# 文件作为主内容标签

Codex Mac 的文件位于工作区内容标签中，可与聊天、浏览器和审查等标签切换。ShipiOS 此前仅在文件检查面板内部切换文件，导致文件搜索、任务输出链接和“新建标签 → 文件”的落点与 Codex 不同。

本阶段将文件加入内容标签模型。主窗口和独立任务窗口均可从文件搜索、文件树、任务输出链接及新建标签入口打开文件内容标签。每个文件标签有独立编辑器工作区，保留文本、选区、滚动和查找状态；标签可按现有内容标签规则切换、固定、关闭、恢复和持久化。任务窗口文件标签仍归属于该任务及其项目。关闭有未保存草稿的标签时先保存，保存失败则保留标签；编辑器的 ⌘W 关闭当前文件内容标签。

118 项相关 Swift 回归通过，覆盖主/任务窗口恢复、两个实际渲染的文件编辑器、固定、关闭前保存、查找与行跳转，以及原有文件面板和搜索行为。`script/build_and_run.sh --verify` 完成正式应用构建和进程启动，`codesign --verify --strict --deep` 通过；进程存在不代表工作区可交互。

目前 Mac 锁屏，无法执行可见工作区操作或与 Codex 逐页、逐键鼠配对。本阶段是代码实现与自动化验证，不计入 45 项完整配对验收；文件页的焦点、拖放落点、菜单、细节排版和重启后的前台体验仍待实操核对。
