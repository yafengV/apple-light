# 主窗口技能页面

2026-09-28。主窗口侧栏、命令菜单“打开技能”和 `shipios://skills` 现在进入独立的技能页面；设置中的“插件 → 技能”分类继续提供同一份安装数据。页面支持搜索、导入本地技能文件夹、重新加载、查看技能内容、启停、立即尝试和卸载独立导入的技能。进入设置后关闭会返回技能页，返回任务或 Escape 回到任务工作区。

本次复用已有技能列表和预览操作，没有新增第二份安装状态。`PluginSettingsNavigationTests` 与 `DeepLinkTests` 覆盖命令、设置返回及链接解析和导航。

这完成了一个明确的页面层级差异；当前 Codex Mac 与 ShipiOS 的可见页面、焦点、键盘及菜单交互尚未在同一解锁桌面逐项配对。43 个验收面中完整配对验收仍为 0 项。
