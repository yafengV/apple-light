# PR 操作行、键盘选择与浏览器创建表单

## 参考证据

2026-09-29 重新读取当前安装的 `/Applications/ChatGPT.app` 公共应用包，版本 `26.911.61220`、构建 `9647`。PR 弹层和 Git 操作资源与此前提取的副本逐字节一致，没有读取个人认证、配置或历史。

`create-pull-request-modal-content-33cfaee2b7e2.js` 的 `N`、`P` 和 `ie` 显示三个独立操作行，依次为创建草稿 PR、创建 PR、在浏览器中打开 PR。初始选中项使用草稿偏好；已有 PR 时只有打开行；选中行显示 CmdOrCtrl+Enter 提示，操作列表循环导航。描述中的普通 Enter 不传播到操作列表。表单宽度为 420，仓库、源分支和目标分支同排展示。`git-action-new-branch-field-d7fd686030a3.js` 的浏览器分支在准备、生成及必要的 Git 写入后打开返回地址。

GitHub 浏览器表单使用 [GitHub CLI 的 compare URL 生成方式](https://github.com/cli/cli/blob/trunk/pkg/cmd/pr/create/create.go)和[查询参数及长度校验](https://github.com/cli/cli/blob/trunk/pkg/cmd/pr/shared/params.go)：分别编码源/目标分支，携带 expand、title 和 body，编码后的 URL 必须短于 8192 字节。

`local-conversation-git-actions-61fd0d6dad47.js` 的外层 `an` 还确认选择操作后先关闭弹层再启动后台 mutation，已有 PR 打开也关闭弹层；浏览器路径结算时保留输入状态。

这是分发代码和官方源码证据，不是 Codex 与 ShipiOS 原生界面的双端配对验收。

## 实现

PR 弹层将原来的主按钮和隐藏菜单改为三个可见操作行，保留草稿偏好的初始选择、悬停选择、方向键循环、当前选择的快捷键提示和 Tab 原生焦点。已有 PR 只显示打开行。标题和描述继续使用原生文字控件，描述保留普通回车、上下移动与选区编辑；Cmd+Enter 激活当前操作。输入法组合期间不接管按键；Esc/关闭命令和操作均遵守运行保护。窄 NSViewRepresentable 只在所属当前窗口、没有覆盖 sheet 时处理事件，不重置 first responder，卸载移除本地监听。

选择操作立即关闭弹层，后台流程继续；关闭不会取消已经开始的生成。审查页承载当前准备/生成/提交/推送状态、生成取消入口和失败提示。重新打开保留手填和已生成的 PR 内容。

浏览器入口复用第 376 篇的固定内容生成、提交与推送流程。勾选本地变更时先按需要提交/推送，取消勾选只使用已发布分支。标题/描述预填网页表单，由用户在 GitHub 页面完成创建；不会调用 `gh pr create` 或给任务记录不存在的 PR。预填地址保留分支斜杠、Unicode、换行、Markdown 与查询特殊字符，字面加号不被表单解析为空格。

编码长度在任何暂存/提交/推送前校验，包括生成后的内容。最后准备和实际打开前复查输入及写入授权。系统浏览器打开失败保留 PR 内容和已经成功的 Git 提交，重试继续而不重复提交。若准备期间确认已存在 PR，则使用校验后的已有地址；只有实际确认的 PR 才能进入任务记录。

## 验证

第一组 13 项定向测试通过，覆盖 6 项操作/键盘/URL 和 7 项浏览器串联流程，日志 `.cache/pr-modal-tests.log`。随后补充已存在 PR 竞争及弹层关闭后的后台生成，最终 87 项相关回归全部通过，零失败、无跳过，日志 `.cache/pr-modal-regression.log`。包括 26 项串联流程、22 项既有 PR、6 项操作/键盘/URL、10 项推送、9 项提交选择、7 项提交说明和 7 项提交统计；首轮 13 项包含在这 87 项中，不重复相加。本阶段使用临时仓库和 GitHub CLI 进程夹具，系统浏览器打开器由测试闭包替代，不打开用户浏览器或创建真实远端 PR。

回归结束后仅收敛取消勾选时的统计可见性，随后通过 `script/build_and_run.sh --build-app` 构建正式 macOS 应用包，并通过严格深度签名校验。日志 `.cache/pr-modal-app-build.log`、`.cache/pr-modal-signature.log`。仅构建，没有启动新应用或验收可交互工作区；没有 Rust 源码变更，不新增 Rust 全套测试结论。
