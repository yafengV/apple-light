# 工作树与本地检出的往返移交

2026-09-26。依据 [OpenAI 工作树说明](https://learn.chatgpt.com/docs/environments/git-worktrees)，同一任务应能从托管工作树移回本地，之后返回原关联工作树。现有“移交”入口按任务当前执行位置切换方向；工作树到本地时先确认两个检出没有已暂存、未暂存或未跟踪修改，工作树仍是 detached HEAD，且 `.worktreeinclude` 指定的本地文件在两边内容与权限相同。随后按 Git 设置中的分支前缀（默认 `codex/`）为任务保留独立 `shipios-<任务 ID>` 分支，在来源本地检出创建或切换该分支；只做快进更新，分叉时不重写历史。分支名先存入任务工作树记录，以便中断后按同一分支重试。

移交回工作树时复用原目录，若本地分支有新提交且工作树提交是其祖先，工作树通过 detached HEAD 前进到该提交。主窗口及独立任务窗口继续显示同一任务与此前回合。真实 Codex Core + 本地假服务测试覆盖本地 → 工作树 → 本地 → 原工作树 → 本地、各阶段命令执行目录、双向提交同步与会话连续性；真实 Git 测试覆盖脏检出拒绝和分叉拒绝。

这仍不是完整 Handoff：两边有未提交修改时尚不能安全迁移；新增或不同的忽略文件不会被覆盖，需先整理；本地分支的其他工作树占用由 Git 拒绝。当前 Mac 锁定，新增入口的点击、布局与当前 Codex Mac 版本未完成原生配对验收。
