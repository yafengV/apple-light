# 浏览器站点工具发现

2026-10-01。内置 WebKit 浏览器现在能识别顶层网页通过 `document.modelContext.registerTool` 声明的 WebMCP 工具。当前 WebKit 缺少这一路径时，ShipiOS 在顶层页面世界提供有限注册接口；页面可以在初次载入后增删工具。地址栏只在有工具且开启“显示站点工具清单”时显示入口，清单列出网站提供的标题、说明和只读声明。网站提供的字段均视为不可信内容；“声明只读”不构成行为保证。

页面导航、重载和关闭会清空旧清单。异步发现结果受页面版本约束，不会把上一页的工具写进下一页；iframe 声明不进入清单。开关独立持久化，旧浏览器权限配置默认显示清单。该开关仅控制显示，尚不是网站执行权限开关。

真实本地 WebKit 夹具验证了顶层注册、动态增删、iframe 排除、片段导航保留、跨页面导航清空和设置迁移；浏览器回归 **66 项通过**。`script/build_and_run.sh --build-app` 正式构建、严格深度签名检查通过。锁屏期间没有把构建成功当作工作区可交互验收。

**仍未对齐：** Agent 还不能调用站点工具；输入 schema、逐次安全审查、敏感操作确认、最近使用状态及地址栏图标/弹层的 Codex 双端原生配对均未完成。此阶段只完成发现与清单，不计入完整 45 项逐页配对。Mac 锁屏和 Codex 客户端桌面访问限制仍阻挡前台双端验收。
