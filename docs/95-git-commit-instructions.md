# Git 提交指令与提交说明生成

2026-09-18。补齐 Git 设置里的“提交指令”，并接入审查面板的真实提交说明生成流程。

## 对照

本机 Codex `git-settings-be89d122415f.js` 提供 Commit instructions 多行编辑区、自动保存、Save 按钮和 Saved 状态，说明此设置会添加到提交说明的生成请求。ShipiOS 原来只有分支前缀等基础设置，提交说明只能手动输入。

## 当前实现

- 主窗口 Git 设置加入“提交指令”，停止输入 600 ms 后保存，也可点击“保存”；离开组件时尝试保存未提交编辑。
- 设置搜索可定位此编辑区，旧配置自动使用空指令，不影响既有分支和审查偏好。
- 保存失败保留编辑内容和之前生效的偏好；分支前缀保存失败也不再错误显示“已保存”。
- 主窗口和独立任务窗口的 Git 审查面板共用生成入口。点击后显示进度与取消，完成后将生成结果填入提交说明输入框，用户仍可编辑并决定是否提交。
- 请求使用 ShipiOS 独立 API 配置和对应 Keychain 凭据；包含暂存差异与提交指令，不提供工具、不发起提交、推送或 PR 操作。
- 只允许从仓库根目录生成，支持尚无 HEAD 的新仓库。空暂存区和超过 512 KiB 的差异不会发送模型请求。
- 结果应用前重新读取暂存差异、HEAD 和分支。索引或分支改变、手动编辑提交说明、项目切换或取消后，不用旧结果覆盖输入。
- 离开审查面板、切换审查范围、启用只读审查、执行提交或退出应用时取消所属生成任务。
