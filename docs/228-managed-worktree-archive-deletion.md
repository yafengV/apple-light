# 删除归档任务时处理托管工作树

2026-09-26。永久删除归档任务时，托管工作树不再成为无任务归属的隐藏记录。若工作树已随归档清理，删除任务也清理受保护的 Git 提交、已跟踪修改引用和私有文件快照。若工作树仍在磁盘，删除前核对它仍是原仓库登记的工作树，再将它转为可打开的永久工作树项目，保留目录及未提交文件。路径被替换时拒绝删除任务，也不触碰该目录。

任务、托管记录与待清理记录在同一次工作区保存中变更；私有资源清理失败时保留待清理记录，并在下次启动重试。确认弹层说明两种工作树处理方式。带有尚未传递的来源修改快照的任务暂不删除，以免丢失唯一副本。

相关工作树和归档删除回归覆盖已清理检出的私有快照与 Git 引用、保留检出转永久项目、目录替换拒绝删除，以及保护引用变化后跨重启重试。当前 Codex Mac 的原生页面与交互配对、Handoff 和工作树数量限制仍待完成。
