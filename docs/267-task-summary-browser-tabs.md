# 任务摘要中的浏览器标签

2026-09-27。任务摘要新增“浏览器标签”区块，按当前任务列出仍打开且有有效 HTTP(S) 地址的内置网页标签。列表保留标签顺序，显示页面标题和主机名；点击后在所属窗口聚焦标签。主窗口中的分离标签通过现有窗口路由唤起，独立任务窗口中的标签在该窗口内切换。空白页、已关闭标签和其他任务的标签不会出现在列表中。

这是对 Codex Mac 任务摘要中网页标签导航行为的局部对齐。Codex 的对应区块连接外部 Chrome 标签，ShipiOS 目前列出的是自身 WebKit 标签；浏览器连接方式、视觉、焦点和实际点击仍需双端原生验收。

验证：`script/build_and_run.sh --build-app` 成功；摘要和两类任务标签测试共 44 项通过。原生 UI 因 macOS 锁屏未能点击验收，因此本阶段不计入完整配对页面。
