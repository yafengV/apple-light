# 主窗口记忆删除确认与弹层焦点

2026-09-18。对照公开分发资源 `personalization-settings-2428288d0130.js` 中的本地记忆删除流程：使用页内居中确认弹层，提供取消、危险操作按钮及执行中状态。

## 实现

记忆单条删除和清空入口改用现有 `SettingsConfirmationDialog`，移除系统 confirmationDialog。确认期间底层设置、导航和全局快捷键统一隔离，辅助功能树仅暴露弹层内容。失败后保留弹层、记录和错误，允许重试；执行期间阻止重复确认及取消。

确认请求保存当时的记录快照。重试只删除这些记录，不删除随后新增的记忆；若待删除记录自身发生变化或已消失，则要求取消并重新选择。成功后更新持久化和后续模型上下文；正在编辑的记录被删除时清理其编辑状态。未加载的记忆列表操作禁用。

实机检查发现共享弹层原先缺少按钮可聚焦能力，且 SwiftUI 初始焦点会被稍后的原生 responder 捕获清除。补充可聚焦按钮和可见焦点框，并在原生捕获结束后聚焦取消；已卸载弹层的迟到回调不能抢焦点。Tab/Shift-Tab 在两按钮间循环，Enter/空格激活当前按钮；没有明确确认焦点时默认取消。此修复也供归档删除和快捷键重置复用。
