# 更多设置页的行内说明

2026-09-18。接续 [设置行内说明布局](126-settings-inline-descriptions.md)，将同一控件的标题、说明和操作合并在一行，沿用该篇记录的公开设置行结构参照。

## 改动范围

共覆盖 9 个页面、12 处设置：个性化的建议提示、记忆开关、模型的 token 用量、Agent 的建议提示、Git 的强制推送与草稿 PR、代码审查的只读模式、电脑使用的任意应用与锁定状态、浏览器的下载询问与默认网站访问，以及通知时机。

标题和说明使用共享标签列，右侧控件按整个标签区域居中。独立状态、错误和操作继续单独呈现。绑定和搜索定位保持原有行为；Agent 的建议提示开关增加加载完成前禁用，与个性化页保持一致。
