# 弹出窗口首页项目选择

当前 Codex 桌面分发的中文资源为弹出首页列出“聊天设置”及其中的“项目”选择，且按项目范围改变输入提示。ShipiOS 首页原先只有“独立聊天”复选框和当前主窗口项目的只读名称，不能选择其他已保存项目。首页现在提供聊天设置菜单中的项目子菜单，可选择任一已保存项目、当前工作区项目或独立聊天；已选项目及输入提示随选择变化。

手动选择在弹出窗口隐藏／恢复及主窗口切换项目时保持，不改写用户的弹出窗口默认范围。没有手动选择且首页无草稿时，默认范围可随主窗口项目或通用设置变化。所选非当前项目被移除时回退到当前可用默认范围。提交首条消息时使用所选项目的主目录创建弹出任务，不切换主窗口项目；项目已移除或主目录不可用时保留首页草稿并显示错误。

固定 470×290 的原生离屏截图已检查项目名称和上下文提示。39 项设置、弹出窗口及项目主目录相关测试通过，其中包含另一项目的主目录路由、主窗口草稿不变、失效项目与缺失文件夹的失败保护。`script/build_and_run.sh --verify` 构建启动及严格深度签名检查通过。参考菜单中的启动模式、分支、环境和权限仍待补齐；Mac 锁屏阻挡实际菜单点击与 Codex 双端页面验收，完整配对保持 **0/45**。
