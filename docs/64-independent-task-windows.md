# 独立任务窗口

2026-09-17。任务工具栏“更多”菜单增加“在新窗口中打开”。主工作区使用单例 `Window`，任务使用按任务 ID 标识的 `WindowGroup`；重复打开同一任务复用其窗口身份，不把设置页变成独立窗口。

任务窗口直接绑定共享的 `WorkspaceStore`，但不依赖主窗口当前选中的任务。窗口拥有自己的任务 ID、滚动位置、计划/标准/目标模式选择和该任务草稿；显示按任务顺序排列的用户输入、附件与 Markdown/本地执行结果，并提供复制、共享、发送、停止以及“在主窗口中显示”。主窗口切换到其他项目后，任务窗口仍可向原任务发送，新回合始终保留任务所属项目。

模型发送复用了真实独立 API 流程。显式任务提交只清空该任务草稿，不清空主窗口的新任务草稿；回合记录保存任务原项目。不同任务可以并行运行模型请求，同一任务仍保持单活动回合；停止、队列、引导和目标续轮都按窗口绑定的任务处理。实现和验证见 [按任务并行模型会话](66-parallel-model-runs.md)。

任务窗口输入区现已复用文件/图片的选择、粘贴、拖入、预览、移除与持久化路径，并复用 `/`、`@插件`、`$技能` 候选的键盘和鼠标行为。可在窗口内切换 `/chat` 与 `/plan`；其余命令会先打开对应任务，再路由到单例主窗口的实际页面或动作，避免出现可见但无响应的命令。

3 项窗口状态测试覆盖任务独立草稿、运行顺序、跨项目发送和附件精确归属；真实 HTTP fixture 另行验证任务窗口提交、附件内容、草稿归属、任务归属和项目归属。并行会话扩展后的完整回归为 348 项 Swift、12 项 Rust、fmt/Clippy 与 IPC 冒烟通过，日志 `.cache/parallel-model-runs-full-tests.log`。

任务窗口已内嵌会话查找、文件、终端和 Git 审查；实现见 [独立任务窗口会话查找](67-task-window-conversation-find.md)、[独立任务窗口文件与终端面板](68-task-window-files-and-terminal.md) 与 [独立任务窗口 Git 审查](69-task-window-git-review.md)。
