# 模型会话执行详情

主窗口中的模型回复现可从消息标题打开右侧“执行详情”。该面板按当前会话记录显示概览、工具和输出：概览使用实际模型、协议、项目、时间、耗时及已返回的 token；工具页复用时间线中的工具调用与审批控件，保留参数、运行状态和输出；输出页显示该轮已收到的文字。没有工具调用或文字时分别显示明确空状态。

本地环境诊断及构建继续使用诊断、日志、产物三页。模型会话不再误显示为“构建”，也不再提供不适用的构建 JSON 导出。

此阶段通过 macOS 应用构建和签名检查。macOS 锁屏阻止了实际点击、焦点及与 Codex Mac 的双端视觉配对；独立任务窗口的执行详情入口也仍待对齐，因此不计入完整页面验收。
