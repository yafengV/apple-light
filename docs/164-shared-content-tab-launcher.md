# 主窗口与独立窗口共用新标签菜单

2026-09-19。

## 缺口与改动

沿用 [第 77 篇](77-task-content-tabs.md) 已记录的静态参考语义：新标签启动器包含推荐、最近工作、插件和 MCP、更多工具；底部入口提供新终端及终端选项。此前独立窗口单独实现菜单，遗漏已启用插件和终端选项。

两个窗口现在共用 `ContentTabLauncher`。插件区显示前 4 个启用项，超出时提供“显示全部”，没有启用项时提供“浏览插件”。底部菜单保留终端和终端选项，普通菜单保留项目工具及关闭标签恢复入口。

动作统一按来源窗口路由：网页与审查使用所在面板；新终端放到底部；文件搜索和关闭恢复属于当前任务窗口。项目为空的独立任务不能借用主窗口项目启动终端、审查或文件搜索。全局插件、自动化、终端设置进入主窗口页面，不创建独立设置窗口。

具体插件入口原先只打开插件列表，现在按稳定 ID 打开对应详情；“显示全部”仍打开目录。执行时重新检查启用状态，避免菜单打开期间已禁用或删除的条目触发跳转。这是 ShipiOS 入口语义修正，尚未取得当前 Codex 版本的逐项原生配对证据。

`ContentTabLauncher|TerminalHostFocus|TaskWindow|WorkspaceTab|Sidebar|TerminalSession|Plugin|PageNavigation` 范围 131 项测试通过，0 失败。日志 `.cache/content-tab-launcher-final-tests.log`。项目脚本构建运行和严格签名检查通过。

原生验收使用 `/tmp` 隔离工作区及 5 个启用、1 个禁用的合成插件，未连接外部服务。实际打开独立任务窗口并点击“＋”，辅助功能树确认四个分区、前 4 个启用插件、“显示全部”、文件和自动化入口；禁用插件不出现。

原生观察中断后重新进入隔离工作区，补充通过：

- 独立窗口打开真实终端，写入变量 `SHIPIOS_PIN_QA=retained`。固定、隐藏、主窗口切到任务 A 后点击最新终端固定项，直接键盘输入命令得到 `REVEAL:retained`。前后记录的 shell PID 均为 `81324`；主窗口及独立窗口草稿保留。第 163 篇重新挂载后的键盘复验至此通过这一路径。
- 底部“＋”实际包含“打开底部终端”和“终端选项”；后者将 `ID: main` 切到“设置”，运行时页面选中。Esc 返回后独立窗口终端和草稿仍保留，没有独立设置窗口。
