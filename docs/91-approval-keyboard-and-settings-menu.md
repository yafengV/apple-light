## 设置入口

`ShipiOSApp` 不包含 `Settings` Scene、`SettingsLink` 或打开独立偏好窗口的 selector。设置菜单、快捷键设置菜单和宠物设置菜单现在同时切换设置路由并通过 `openWindow(id: "main")` 唤起已有主窗口。从独立任务窗口或菜单栏调用时，不会只修改后台主窗口的页面状态。

现有设置导航继续保留 22 个顶级页面、24 个兼容路由，以及进入设置前的任务、草稿和来源页面。设置子编辑器先返回所属设置页，再返回应用。

## 审批键盘与焦点

对照本机 Codex 的静态 `app-initial-4d7ea7f81c2d.js`，`approval.approve` 默认绑定 Enter，`approval.decline` 默认绑定 Escape。本轮加入对应的 Return 批准和 Esc 拒绝命令，快捷键设置可搜索、修改、增添绑定、解除绑定及恢复默认。目前命令目录共有 65 项，并不代表覆盖官方全部命令。

- 键盘事件只在所属且激活的窗口处理；独立任务窗口使用自身任务身份，避免处理主窗口任务的审批。
- 纯 Return/Esc 在可编辑文本中不处理审批；输入法组合、终端、网页、列表输入、快捷键录制、按键重复、弹层和隐藏任务页面同样受到保护。
- 批准/拒绝菜单使用当前窗口的 focused scene value，并在执行时再次检查 sheet 和模态窗口。
- 备用快捷键不经过通用工作区路由，防止绕过上述上下文检查。
- 审批出现时，只有可见任务页面、当前窗口激活且输入区为空等条件允许移动焦点。设置覆盖下仍挂载的任务卡片不会主动抢焦点。
- 菜单明确执行批准/拒绝；没有给菜单注册会抢占文本输入的全局 Return/Esc key equivalent。
