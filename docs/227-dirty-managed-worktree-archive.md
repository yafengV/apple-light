# 脏托管工作树的归档快照与恢复

2026-09-26。托管工作树归档现在也覆盖含未提交文件的检出。归档前保护最新 HEAD 与已跟踪修改的 Git stash 对象，并把未跟踪和被忽略的普通文件复制到 ShipiOS 私有快照。工作区记录先持久化这些引用；删除前再次核对 HEAD、暂存区、工作区文件、文件内容与权限。任何一项变化都会保留原工作树，归档任务仍可恢复。

恢复任务时先在原路径重建受保护的提交，再按原状态应用已暂存和未暂存修改，复制文件并验证内容。目标路径被其他目录占用或文件不同，不会覆盖；快照和保护引用在恢复记录持久化后才清理。应用重启后仍可继续恢复。置顶任务、活动任务窗口、符号链接或空目录不能被完整快照时会保留原检出。

19 项 `WorktreeTests`、2 项真实 Codex Core 新任务集成测试和 29 项归档相关回归通过；覆盖脏工作树删除及重启恢复、暂存状态、未跟踪/忽略文件、占用路径后重试、快照后文件变化时拒绝删除以及快照清理。macOS App 构建通过。Handoff、自动数量限制、删除归档任务时的工作树处理，以及当前 Codex Mac 的原生页面/交互配对仍待完成。
