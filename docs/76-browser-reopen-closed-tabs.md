# 重新打开关闭的浏览器标签

2026-09-17。本轮依据当前 Codex 应用包中的 `codex.command.reopenClosedTab` 命令资源，补齐 ShipiOS 内置浏览器的关闭标签恢复栈。

## 行为

- 浏览器最多保留最近 20 个关闭标签，`⌘⇧T` 按后进先出顺序恢复。
- 已加载网页恢复其最后提交的 URL；尚未加载的地址草稿恢复原文本，不误发起网络请求。
- 关闭最后一个浏览器内容标签后返回聊天首标签，`⌘⇧T` 仍可重新打开顶部浏览器标签并恢复状态。
- 浏览器菜单、工具栏更多菜单和标签右键菜单都提供“重新打开关闭的标签页”；没有可恢复标签时禁用。
- 恢复会创建新的标签身份和 `WKWebView`，关闭标签仍完整执行原有清理生命周期。

## 验证

`BrowserTests.testTabSelectionClosingAndSettingsPreserveOwnership` 覆盖两个标签按后进先出顺序恢复、最后一个标签关闭、命令启用、地址草稿恢复及恢复栈清空。统一内容标签层的恢复顺序另由 `WorkspaceTabTests` 覆盖。

签名应用的隔离原生验收使用本地 WebKit fixture：加载 `One` 后按 `⌘W` 关闭最后标签，页面返回聊天首标签并把焦点交还输入区；随后在主界面按 `⌘⇧T`，顶部浏览器内容标签重新出现，标题、完整 URL 与网页内容均恢复为 `One`。主标签层改造后的原生证据见第 77 篇。
