# 弹出首页权限菜单与任务快照

弹出首页“聊天设置 → 权限”现提供沿用全局设置、审批策略、文件访问以及工作区写入模式下的网络访问选项。选择与首页草稿一起持久化。提交本地或工作树任务时，应用把当时生效的权限保存到任务；Codex Core 新会话启动时按任务读取，之后修改全局权限不会改变已创建任务的初始权限。取消尚未运行的弹出任务或删除归档任务时清除对应快照。

18 项最终定向测试覆盖旧数据解码、本地与工作树任务快照、全局设置变化、草稿清理及弹出窗口布局。`script/build_and_run.sh --verify` 构建启动和严格深度签名检查通过。当前 Mac 锁屏，仍需解锁后点击检查菜单、焦点和真实会话，并与当前 Codex 桌面逐项配对；完整验收保持 **0/45**。
