# Appshot 首次使用弹层图形

本机 Codex 参考客户端在首次使用弹层顶部显示 88×77 的彩色窗口图形。ShipiOS 此前只显示同尺寸的单色系统图标，弹层的视觉重心不同。

现在改为 SwiftUI 自绘图形：蓝色四角框、白色窗口、三色窗口按钮和 ShipiOS 自有文字。没有把参考客户端的图片文件加入项目。实际离屏渲染为 264×231 像素（三倍缩放），已检查图形边界、文字可读性和透明背景。

`script/build_and_run.sh --build-app` 与 `codesign --verify --deep --strict` 均通过。

当前运行的 ShipiOS 进程尚未按获批流程重启，因此前台暗色/浅色弹层和 Codex 双端视觉配对仍待验收；完整配对保持 **0/46**。
