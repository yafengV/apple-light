# 全局切换听写接入

Codex 的“切换听写快捷键”从桌面其他应用按一次开始、再按一次停止，并把识别结果放入原输入光标。ShipiOS 现在在主窗口语音设置提供可录制与关闭的快捷键，绑定保存在独立配置中，由 Carbon 全局注册。录制期间禁止触发全局动作，和已有命令绑定冲突时拒绝保存。

按键时先取得当前聚焦文本目标，再复用设备端听写语言、所选麦克风和词典开始识别；第二次按键结束后将结果写回原目标。内容或光标变动、目标不支持辅助功能写入时拒绝覆盖并提示错误。辅助功能授权缺失时按键触发 macOS 权限提示；无默认音频输入时先报错，不再进入可能抛出异常的音频节点。设置页和已开启的菜单栏入口可结束正在进行的全局听写。快速连续按键的待授权、停止和自动完成状态使用独立模型处理，防止取消后迟到的授权重新开始录音。

26 项语音、热键状态和设置导航回归通过；760×650 页面离屏图像、正式应用构建及严格签名通过。**当前机器没有可枚举麦克风，实际跨应用录音、权限提示和文字写回尚未实测。** Codex 的按住听写、裸修饰键快捷键、语音悬浮状态、录音历史及整页视觉／交互配对也未完成，完整验收保持 **0/47**。
