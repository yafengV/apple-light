# 独立且持久的内置浏览器资料

2026-09-27。正式 ShipiOS.app 的主窗口与独立任务窗口现在共用同一份应用专属 WebKit 持久资料，Cookie、缓存及网站存储可在应用重启后保留。它与用户的系统浏览器、其他应用及个人 Codex 浏览器资料分开。历史仍保存在 ShipiOS 的任务库；“清除浏览数据”清理共用的网站资料，并按勾选状态决定是否同时清除历史。

通过 `--data-root` 启动的隔离实例以及默认单元测试仍使用临时资料，避免验收实例读取或修改正式应用的登录状态。设置页面据实际资料类型说明持久性。

依据：[OpenAI 官方浏览器说明](https://learn.chatgpt.com/docs/browser)描述内置浏览器使用独立资料、可在其中登录，并可在设置中管理浏览数据。持久跨重启是对“浏览器资料”及可反复使用登录会话的实现推断；当前 macOS 锁屏阻止了正式应用的原生重启验收。

真实 WebKit fixture 验证主窗口和独立任务窗口共享 Cookie、另一临时会话隔离、清除后两窗口 Cookie 消失。用户版 Codex 的站点授权、资料导入、视觉和焦点仍待配对。
