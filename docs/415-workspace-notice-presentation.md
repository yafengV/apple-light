# 通知卡片、叠放布局与辅助功能播报

工作区通知从通用毛玻璃卡片改为按状态呈现的独立卡片。短通知按内容收缩，长通知受可用宽度约束；图标和关闭按钮各占 24×24，内容内距为 8px 加 1px 边框，单行通知高 42px。标题保留换行，说明按 HTML 的 normal 空白规则合并连续 ASCII 空白；说明存在时，查看按钮单独放在底部右侧，包括空说明字符串。

## 原生实现

`WorkspaceNotice` 增加每次创建独立的 generation。相同业务 ID 替换后移到栈顶，刷新寿命；关闭、查看任务和异步项目打开后的回调检查 generation，旧卡片不能关闭或处理新通知。

通知布局保留全部通知值，前三条可见。收起时层间位移为 8px，缩放分别为 1、0.95、0.9；后两层采用首条高度的中心作为变换原点，但内容保留自然高度。展开时按各自自然高度和 8px 间距排列。隐藏内容不参与指针命中。

`NoticeIntrinsicWidth` 只负责模拟受视口约束的 max-content 宽度，包括说明下方有可伸缩空白的按钮行。隐藏原生窗口验证五种短卡高度为 42、42、74、63 和 95px，短卡不占满窗口，长卡占满 600px 可用宽度并换行。状态颜色使用当前浅/深语义色；info 使用已有的独立主题角色，状态颜色不借用自定义差异标记颜色。

辅助功能桥接使用零尺寸、不可命中和不可获取焦点的自有 NSView。SwiftUI 提供 generation、标题和说明；桥接只在自有窗口可见、未最小化、未隐藏时以 low 优先级发布新增或文字变化，倒计时和删除不会重复播报。窗口卸载后移除观察者，旧异步队列失效。隐藏阶段只保留最新通知，已经过期的内容不会在恢复时播报。

正向播报测试只覆盖注入的记录函数，并通过自有 NSWindow 子类模拟可见属性；窗口从未展示，测试不发送真实辅助功能公告。另一个真实隐藏窗口测试确认默认可见性守卫不发布公告。不能把模拟可见性当作桌面或 VoiceOver 验收。
