## 交互与实现

- 点击路径/统计所在标题区域展开或收起文件，不打开编辑器；复制和折叠按钮独立，鼠标悬停或按钮获焦时显示。
- 普通标题操作仅改变该文件；Option 按被点击文件的当前状态展开或收起全部，更新工具栏批量状态，保留文件选择和窗口间独立状态。
- Return、数字键盘 Enter、Space 保留事件修饰键；Tab/Shift-Tab 沿窗口按键视图链移动。原生辅助功能 press 和禁用状态有明确行为，重用控件更新回调，拆除释放回调。
- 复制成功显示短暂确认，路径变化清理确认。生产使用通用剪贴板；测试只使用临时命名剪贴板或注入复制函数。
- SwiftUI 拥有文件、折叠和布局状态，AppKit 桥接限于原生标题按钮与滚动锚点，没有全局视图或窗口。
- 页面用垂直 ScrollView 和带吸顶 Section 的 LazyVStack；文件代码在关闭换行时使用自己的水平 ScrollView，开启换行时不创建水平容器。评论和行后编辑器按文件视口限制宽度。
- 实际隐藏窗口坐标测试发现，`ScrollViewProxy.scrollTo` 对嵌套代码行只移动内部水平容器，评论行仍不在视口。现在先物化文件 Section，再将目标原生视图坐标转换到祖先的垂直文档；文件定位预留标题高度，评论行居中，不更改水平偏移。
- 滚动锚点只等待尚未完成的布局，定位成功立即结束；新请求、控件拆除或离开窗口取消旧请求。重复跳转不会让旧行重新覆盖新目标，也不会在定位后把用户手动滚动拉回。
