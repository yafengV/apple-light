# 内置浏览器整页截图

2026-09-27。浏览器“更多”菜单新增“添加整页截图到输入区”。现有相机按钮继续截取可见区域；整页入口逐段滚动当前网页、截取 WebKit 视口、拼接为一张 PNG，然后恢复原滚动位置。截图只附加到启动截图时所属的主窗口或独立任务窗口草稿，文件名以“整页截图”区分。

Apple 的 [`WKSnapshotConfiguration.rect`](https://developer.apple.com/documentation/webkit/wksnapshotconfiguration/rect)只能位于 WebView 当前边界内，因此不能直接用一个超出边界的矩形截取整页。实现采用分段截图与拼接；若网页在截取期间导航、内容尺寸变化、无法滚动到预期位置、需要超过 400 个区块，或超出附件支持的 4000 万像素/单边 20000 像素限制，会明确失败并恢复滚动位置。生成的 PNG 仍须通过现有 10 MiB 附件校验。

真实 WebKit 长网页 fixture 验证了视口外底部内容出现在输出 PNG、尺寸大于可见区域、原滚动位置恢复及任务附件归属。固定定位元素、动态加载页面和当前 Codex Mac 的菜单、进度、焦点与视觉交互仍待原生配对。
