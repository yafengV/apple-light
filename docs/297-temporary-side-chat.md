# 临时侧聊

2026-09-28。对照 [Codex 命令参考](https://learn.chatgpt.com/docs/reference/commands) 的 `⌘⌥S` 与 [开发者命令参考](https://learn.chatgpt.com/docs/developer-commands) 的 `/side`：从普通任务创建独立侧聊，让主任务继续运行，关闭窗口后清理临时会话。

主窗口、独立任务窗口的菜单和命令入口，以及 `⌘⌥S` 均打开侧聊窗口。`/side 问题` 打开侧聊并自动发送问题；`/side` 打开空白侧聊。侧聊窗口标明来源任务及其运行状态，可关闭窗口返回主任务。不能在侧聊中再次开启侧聊或分叉到普通任务。

创建时捕获来源任务**已经完成**的回合。正在运行的主回合继续独立执行；其未完成内容不会进入侧聊。侧聊拥有自己的 Codex Core 线程、模型回合和草稿，不改变主任务选择、时间线或运行状态。侧聊使用只读沙盒，并拒绝写入审批和 MCP 工具调用。它不出现在普通侧栏、搜索、最近任务或归档中；关闭窗口时停止线程、删除任务记录与私有 Core 目录。应用重启时清理未正常关闭的侧聊。

96 项相关回归测试覆盖入口、上下文快照、任务隔离、隐藏与清理；另有 1 项本地模型服务集成测试覆盖主任务运行中开启侧聊、独立回复、写入拒绝，以及关闭后私有 Core 目录删除。`script/build_and_run.sh --build-app` 和严格签名检查通过。当前 macOS 桌面处于锁屏，原生菜单、窗口、焦点、视觉和 Codex 双端逐项配对尚未验收；此功能不计入完整配对数。
