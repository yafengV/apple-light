# Git 分支选择与主窗口导航

> 后续已接入 [永久工作树与主窗口设置](38-permanent-worktrees.md)。本页记录分支选择完成时的范围。

2026-09-17。审查页此前只显示分支名称，本轮接入真实 Git 分支操作。

## 已实现

- 主窗口工具栏、审查页分支名称、工作区菜单和命令面板共用分支选择入口。
- 弹出列表支持搜索、方向键、Return 选择、Esc 关闭、当前分支标记和刷新。
- 显示本地与已缓存的远程分支；远程分支进入命名表单，明确点击“创建并切换”后创建跟踪分支。
- 支持从当前提交创建分支，包括 detached HEAD；尚无首次提交时解释原因并禁用创建。
- 标记其他工作树占用的分支并禁用选择；当前工作树的分支不会误判为占用。
- 设置、项目页、全局弹层和模型选择器会关闭分支弹层。所有设置仍在主窗口内导航。
- 切换后刷新文件树、Git 审查和当前文件预览，保留会话草稿。

Git 使用正常的 `switch` 冲突检查，并启用 `--no-overwrite-ignore`，避免覆盖同名的被忽略文件。不会自动暂存、丢弃、强制重置或网络拉取。切换前重新验证当前 HEAD、目标引用和提交；列表过期时提示刷新。任务运行中和其他 Git 操作进行时禁用切换。

工作树清单按 NUL 分隔解析，支持目录名称中的空格、换行。使用实际文件系统路径规范化，处理 macOS `/var` 与 `/private/var` 等别名。项目目录内的 Git 命令继续保持原有父仓库发现限制；从普通仓库子目录不能意外切换父仓库。
