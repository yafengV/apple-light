# `/worktree` 工作树命令

2026-09-28。[Codex 官方斜杠命令参考](https://learn.chatgpt.com/docs/reference/slash-commands)将 `/worktree` 定义为在新 Git 工作树中运行聊天；[工作树说明](https://learn.chatgpt.com/docs/environments/git-worktrees)也描述了新聊天选择工作树、现有聊天与本地检出之间的移交。

ShipiOS 原先已有新任务的“本地 / 工作树”选择器与已有任务的移交操作，但输入区没有 `/worktree`。现在 Git 项目的新任务输入 `/worktree` 会选择工作树执行，随后可在原输入区选择起始分支和本地环境，再发送实际提示创建工作树。已有且空闲的本地任务输入该命令会使用同一任务的现有移交流程；独立任务窗口按本窗口任务移交，不改变主窗口选中的其他任务。命令菜单提供同一操作。非 Git 项目、不相关或运行中的任务不会把命令误当作普通模型提示执行。

17 项命令相关测试、2 项真实 Git 脏检出移交与中断恢复测试、原生应用构建及签名检查通过。完整工作树环境、原生点击和当前 Codex Mac 的视觉与焦点配对仍待验收。此入口本身不改变 43 个验收面的完整配对计数。
