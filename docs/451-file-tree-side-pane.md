# 文件页侧边文件树

## 本阶段变更

文件列表从编辑器上方移到编辑区左侧。宽面板使用可调整宽度的分栏，文件标题栏提供“显示文件树／隐藏文件树”；隐藏文件树后，已打开的文件继续占满文件页。窄面板优先展示已选文件，按钮以覆盖层打开文件树，点选文件或点击覆盖层外侧即可返回编辑器。没有选中文件时仍展示文件树，避免出现空白入口。

该阶段针对当前本地 Codex 桌面资源中的文件页 `sidePane` 和文件树显隐入口进行实现。ShipiOS 保留现有文件标签、保存、查找及选区审阅能力。

## 验证范围

隐藏原生窗口测试检查宽面板文件树显示／隐藏／恢复，以及窄面板编辑器占满宽度；55 项相关文件编辑回归通过。`script/build_and_run.sh --verify` 完成构建启动，严格深度签名检查通过。桌面状态读取超时，尚未确认前台点击、拖拽分栏、焦点或与 Codex 的双端页面验收。本阶段不计入 45 项完整配对验收。
