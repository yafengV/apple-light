# PR 自动生成与指令设置

2026-09-18。对照本机 Codex 的 `create-pull-request-modal-content-e1563a1fb9c7.js`：描述输入提示为留空生成，创建操作支持 Command+Enter。`git-settings-be89d122415f.js` 提供独立的 Pull request instructions，并与提交指令共用自动保存行为。

## 实现

- 主窗口 Git 设置加入 PR 指令，支持延迟自动保存、立即保存、失败后保留输入，以及切换设置页或离开设置时保存。提交指令使用同一编辑组件。
- PR 指令独立持久化，旧数据默认空字符串；保存失败不提前改变内存配置，超过 16 KiB 显示错误。设置搜索可以定位到该控件。
- 创建 PR 时，标题或描述为空会通过用户配置的独立 API 生成缺失字段；已填写的标题或描述保留。两个字段均已填写时直接使用手动内容，不请求模型。
- 请求带有 PR 指令、仓库/分支、已提交的差异与提交说明，不包含未提交的暂存区和工作区内容。目标分支提交从托管服务读取，通过本地提交对象计算共同祖先到源提交的差异；不会默用过期的本地目标分支。若尚未获取该远端提交，提示先获取更新。
- 生成采用结构化标题和描述返回；拒绝空内容、非法标题、过大内容或工具调用。内容超过 512 KiB 时提示手动填写，不静默截断生成上下文。
- 生成期间显示独立进度和取消入口；取消不创建 PR。生成后核对源分支、HEAD、PR 状态和目标分支提交，变化时要求重新检查。用户改写输入时不覆盖、不发布旧结果。
- 生成完成才进入已有的 PR 创建流程；创建失败保留生成内容，结果不确定时继续使用查询已有 PR 的恢复逻辑。主窗口与独立任务窗口共用此状态机；项目切换取消旧生成。
- 主创建操作支持 Command+Enter。设置仍在主窗口内。
