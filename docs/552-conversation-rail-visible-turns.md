# 会话轨道的可见回合高亮

本机 Codex 的消息轨道使用滚动容器内的回合可见性来标记当前位置。视口内有多个回合时，它会高亮从首个到末个可见回合之间的全部用户消息；上沿留出 16 像素。此前 ShipiOS 只依据消息顶部坐标选中一条，短回合同时出现在窗口里时反馈不同。

主会话、独立任务窗口和弹出窗口现在都记录每个回合在滚动坐标系中的完整矩形及视口高度。轨道依据交集求首尾可见回合，并高亮其间的连续消息；暂时没有布局位置时沿用末条消息作为加载期标记。自动化测试覆盖上沿边界、多个可见回合、懒加载导致的中间位置缺失和空布局。

真实滚动时的更新节奏、虚拟列表挂载/卸载以及 Codex 双端视觉仍待前台验收；完整配对保持 **0/47**（主工作区 21 项、设置 26 项），这是待验收面数量，并非 47 个已确认缺陷。
