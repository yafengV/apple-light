# 状态页按需获取模型窗口上限

上一阶段的上下文百分比只读取内存里的模型目录。用户未打开过模型选择器、任务又没有触发技能目录加载时，即使独立 API 服务的 `/models` 提供 `context_window`，状态页仍无法显示百分比。

主窗口和独立任务窗口现在打开状态页时，在最近一轮已有实际用量且缓存缺失的条件下，向当前任务选择的独立服务读取模型目录。读取使用 ShipiOS 自有凭据和三秒超时，不访问用户个人 Codex 配置。页内先显示读取进度，取得上限后按原有模型和用量匹配规则更新百分比；服务没有 `/models`、请求失败或上限缺失时，任务 ID、累计用量和最近输入照常可见。成功结果按服务与协议缓存，切换模型不会套用另一个模型的上限。任务或模型变更时，迟到的页面结果不用于新状态。

状态、模型选择和技能元数据相关 **25 项** Swift 测试通过，其中新增用例覆盖首次获取、命中缓存、未知模型和服务失败。`script/build_and_run.sh --build-app` 构建和严格深度签名检查通过。Mac 锁屏阻挡该版本的可见点击与焦点验证；Codex 参考应用仍不可由桌面接口读取，45 项双端逐项配对仍为 **0/45**。
