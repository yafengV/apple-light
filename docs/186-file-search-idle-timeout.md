# 文件搜索按进展计时

2026-09-26。搜索会持续送出部分结果，用户可以在完整扫描结束前选择文件。此前 Swift 会话从发送查询起设定固定 20 秒期限；即使 helper 连续返回部分结果，期限也不会更新，最终可能把仍在工作的搜索误报为超时并关闭索引进程。
