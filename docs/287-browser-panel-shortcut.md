# 浏览器面板快捷键

2026-09-27。官方 [macOS 命令说明](https://learn.chatgpt.com/docs/reference/commands#keyboard-shortcuts) 将 ⌘⇧B 指定为内置浏览器面板切换。ShipiOS 此前把该组合绑定到“显示或隐藏内容标签”，浏览器切换命令没有默认快捷键。

现在 ⌘⇧B 路由到现有浏览器切换命令：主窗口首次创建浏览器标签，之后在聊天与已有浏览器标签之间切换；独立任务窗口使用本窗口的浏览器标签。内容标签显示命令保留在菜单与可自定义快捷键列表中，但不再占用官方默认键位。快捷键偏好仍可覆盖默认值。

快捷键唯一性、独立任务窗口命令路由和主窗口真实标签复用共 13 项定向测试通过；`script/build_and_run.sh --build-app` 构建和签名检查通过。依赖本地网页服务器的另一项浏览器用例在当前沙箱无法启动 fixture，因此不能记为通过。Mac 锁屏使原生键盘投递和与当前 Codex 窗口的配对暂不可验；浏览器面板具体开合与焦点语义仍待实机核对。
