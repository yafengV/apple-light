# 全局听写最近录音与恢复

Codex macOS 当前语音设置的公开界面资源显示“最近录音”：本机保留最近 20 条，提供听写文本复制、无文本录音重试转写、音频下载和删除。ShipiOS 原先只保留本次识别的内存文本，识别失败或应用退出后无法找回音频。

全局听写现在同时将默认麦克风 `AVAudioPCMBuffer` 和指定设备 `CMSampleBuffer` 异步写成私有 CAF 录音。磁盘写入不占用音频回调线程；指定设备输入结束后，等待样本队列排空再完成文件。记录索引与录音位于 ShipiOS 独立数据目录 `VoiceRecordings`，目录权限为 `0700`，文件为 `0600`，目录排除系统备份。设置页显示最近 20 条，提供复制文本、重新使用设备端 Speech 识别、下载和删除；重试期间防止重复操作。应用重启时未结束记录显示“录音已中断”，仍可下载或重试有音频的记录。

合成浮点、整数 PCM 和 CoreMedia 样本缓冲均写出可读音频文件，恢复、删除、20 条上限与语音设置页离屏渲染通过；20 项录音、语音设置、波形和浮窗相关测试、正式应用构建和严格签名通过。**当前机器没有可枚举麦克风，真实录音、跨应用输入、实际识别重试与 Codex 双端逐项验收仍缺。** 实时语音聊天也尚不可用；完整配对保持 **0/47**。
