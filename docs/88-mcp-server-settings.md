# 主窗口 MCP 配置编辑

2026-09-18。MCP 设置从只有插件声明列表扩展为独立服务器配置管理。设置和编辑器均保留在主窗口。

## 对照依据

本机 Codex `/Applications/ChatGPT.app/Contents/Resources/app.asar` 的 `plugins-page-8862e0071989.js` 包含自定义 MCP 详情编辑器：

- 新增页的名称、STDIO / Streamable HTTP 类型选择。
- STDIO 的命令、逐条参数、环境变量、透传变量和工作目录。
- HTTP 的 URL、Bearer token 环境变量、直接请求头和环境变量请求头。
- 返回、保存、错误反馈和已有服务器卸载。已有服务器不直接更换类型。

`mcp-settings-67e47c4060aa.js` 使用合并插件管理内容。本轮按此实现配置流程，不将保存配置等同于建立 MCP 连接。

## 当前行为

- 设置 → 插件 → 添加 → 添加 MCP 服务器，在同一内容区打开编辑页；既有设置列表保留挂载，隐藏时不接收点击或辅助功能焦点。
- 已有服务器点击名称进入编辑；返回或 Esc 先回到 MCP 列表，再返回设置来源页面。设置切页及搜索定位会清除编辑路由。
- 参数和变量可逐条增删；参数使用稳定行身份，删除前面的条目不会将后续行当作另一个输入框。
- 两种传输表单分别保留字段，新增时切换类型不丢失另一种表单的已填内容。已有服务器名称与类型固定，其余字段可修改。
- 保存、启停和确认卸载写入独立数据目录的 `mcp-servers.json`，文件权限为 `0600`。保存失败不更新列表或退出编辑器。
- 列表支持名称/类型筛选，数量包含自定义服务器；插件内声明仍单独列出并进入插件详情。
- 拒绝重复名称、重复请求头、不合法环境变量、请求头换行和超大配置；遇到配置路径为目录或符号链接时不覆盖。测试发现 CRLF 是 Swift 的单个字素簇，换行检查已改为字节判断。
- 界面明确显示“未连接”：本轮不会启动所填命令，不执行服务器工具，也不宣称具备 OAuth 或已连接状态。
