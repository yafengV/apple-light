# 非 Git 项目的审查入口与仓库创建

## 对照证据与实际差异

当前[官方审查文档](https://developers.openai.com/codex/app/review)说明：审查页需要 Git 仓库，非 Git 项目会在应用内提示创建仓库。ShipiOS 原来只提示去终端初始化，代码审查设置的打开入口也因 `gitAvailable == false` 禁用。

这一资料支持创建入口的功能要求，没有提供当前版本的精确按钮文案、布局或焦点顺序；本阶段不据此声称视觉和原生交互已完全一致。

## 当前实现

主窗口、独立任务窗口和分离审查共用审查空状态：有项目时可创建 Git 仓库或刷新，检查及创建过程显示进度，失败显示可选择的错误文字并可重试；没有项目时提示选择项目。代码审查设置可打开已有的非 Git 项目审查页，继续使用主窗口内导航。

创建成功刷新文件与 Git 差异，进入未暂存范围；保持原项目、任务、文件预览和提交说明。初始化沿用 Git 的默认分支规则，不自动暂存、提交或添加远端。任务窗口和分离审查仅操作各自所属项目，不改主窗口的项目或草稿。

创建使用共享只读设置；实际写入前重新检查只读状态、项目及代次，延迟的旧项目请求无法操作新项目。原路径的物理目录身份及符号链接目标也会重新检查，拒绝预检查后的目录替换。

Git 命令原有的项目发现上限会隐藏父目录仓库，因此初始化前单独检查祖先 Git 元数据，避免意外创建嵌套仓库。现有仓库、损坏元数据、悬空 `.git` 链接和裸仓库不自动修复或重新初始化。已启动的 Git 命令可能完成；不承诺撤销已经创建的仓库。
