# 隐藏面板后的命令焦点

右侧内容面板隐藏后，主窗口仍保存最后聚焦的右侧标签。此前部分命令只根据这份记录判断焦点，可能把隐藏的文件或浏览器当作当前页面；聊天中的 MCP 审批也可能被隐藏标签挡住。

现在命令焦点只接受当前可见面板中实际选中的标签。隐藏右侧面板后，左侧当前文件继续接收文件查找与关闭命令；隐藏的右侧浏览器不再被判为可见，侧栏固定项也不会保持错误的选中高亮。旧文件检查面板只有在右侧没有内容标签时才被判为可见。

119 项文件、浏览器、工作区标签与相关命令测试通过，其中定向测试覆盖隐藏右侧浏览器后关闭左侧文件及聊天审批可见性。`script/build_and_run.sh --verify` 完成正式构建和进程启动，严格深度签名通过。Mac 锁屏，实际键鼠及 Codex 双端逐页配对未完成；完整验收保持 **0/45**。
