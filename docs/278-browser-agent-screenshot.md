# 浏览器 Agent 当前视口截图

2026-09-27。`shipios_browser` 新增 `screenshot`，以当前任务的浏览器标签 ID 为参数，在网站授权后截取当前可见视口。宿主继续检查任务归属、标签仍打开、页面加载完毕、授权期间及截图期间的网址未变化。截图失败、页面变化、取消或超过 10 MiB 时向 Agent 返回错误状态。

图片经过独立的 `CodexBrowserStaging` 暂存目录交接，RPC 只传请求 ID 和字节数，避免超过 64 KiB 帧限制。Rust 侧验证请求 ID、普通文件、字节数与 PNG 签名，读取后删除暂存文件，把图片作为 Codex 工具结果的 `input_image` 送入下一次模型请求；日志及任务时间线只保留摘要，不记录图片数据。用户草稿附件不会被改动。

真实 WebKit 测试检查网站拒绝、跨任务隔离和有效 PNG 暂存；浏览器套件 57 项通过。Rust 单测检查单次消费与图片工具输出；假模型往返测试同时检查填写和截图结果，确认下一次模型请求包含 PNG 图片且暂存文件被清除。严格 Clippy、`script/build_and_run.sh --verify`、签名检查及 IPC 冒烟通过。桌面状态读取超时，系统辅助功能未能读取到 ShipiOS 窗口，因此启动后的可交互工作区未获验收。当前视口以外的整页 Agent 截图、跨 frame 页面控件、下载操作和 WebMCP 仍未实现。当前 Codex Mac 与 ShipiOS 的页面视觉、焦点及键盘交互也未完成双端原生配对，因此 43 项完整配对验收仍为 0。
