# 输入区文件与文件夹附件

本机 Codex Mac 客户端 26.911.61220 的输入区附件菜单把本地“文件与文件夹”作为一个选择动作，并把所选图片分到图片附件。ShipiOS 的主输入区、独立任务窗口和弹出窗口现使用同一路径：系统选择器允许文件和文件夹；常见图片仍作为图片附件，其他文件作为文件附件。独立的“添加照片”命令继续可用。

文件夹附件在选择时保存私有内容快照，列出相对路径并纳入有界的文本与 PDF 提取结果；超出可包含范围的内容标为省略，符号链接只列名称，不读取链接目标。附件卡片、来源列表和预览将其标成文件夹。快照随草稿、发送、队列、历史与分叉保存，原文件夹删除后仍可读取；旧文件附件记录无需迁移。

这一实现采用独立 API 会话可读取的内容快照，尚未等同于 Codex Core 对任意本地目录的按需工具访问。大型目录、二进制内容、包内文件和选择后变化仍有限制。47 项相关测试、正式应用构建和严格签名检查通过；Mac 锁屏阻止真实系统选择器、菜单焦点、取消行为以及 Codex 与 ShipiOS 的双端视觉和交互配对，完整配对保持 **0/45**。
