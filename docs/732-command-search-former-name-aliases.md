# 命令更名后的统一搜索别名

日期：2026-10-09。属于第 726 篇 R8，修复固定 `fdf4d46` 广泛回归中的设置快捷键搜索失败。

## 实现

“创建聊天分支”保留原名称“分叉”作为命令元数据中的搜索别名。设置总搜索、快捷键页文字搜索、命令菜单共用该别名，结果显示当前名称、使用原命令身份，不增加重复结果。命令菜单在当前名称及别名的匹配评分中取最高值，保留原有排序规则。

设置总搜索仍要求全部查询词匹配，并且只索引当前有效快捷键。移除或改绑后，旧绑定不再命中；没有绑定的命令仍可按名称发现。快捷键页的录制搜索只匹配真实按键组合，名称别名不能进入该路径。搜索结果的既有导航／权限检查继续由原路由处理。
