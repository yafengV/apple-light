# 技能库卡片布局

2026-09-28。主窗口技能页现以自适应卡片展示已安装技能的名称、用途、来源和 `$` 引用；卡片可预览、启停、立即尝试，独立技能另可编辑和卸载。窗口变窄时卡片自动收为单列。设置中的插件 → 技能继续使用紧凑列表，两个入口共用同一安装数据与操作。

本阶段让主窗口更适合浏览技能，尚未接入 Codex 的推荐目录、在线安装和项目/系统作用域。当前 Mac 锁屏且 Codex 应用不向计算机操作工具开放，因此卡片尺寸、颜色、焦点、菜单与当前版本 Codex 的逐项配对仍未验收，43 项完整配对验收计数不变。

21 项技能相关回归、应用构建与签名检查通过；这些检查只证明代码与数据操作，没有证明视觉一致。
