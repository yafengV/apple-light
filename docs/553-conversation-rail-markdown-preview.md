# 会话轨道的块级 Markdown 预览

本机 Codex 的轨道悬停卡片使用受限 Markdown 显示助手回复；正文通常限制三行，含表格时保留表格结构。此前 ShipiOS 只解析行内 Markdown，标题、列表、代码块和表格会以原始标记混在预览里。

ShipiOS 现在复用会话已有的 Markdown 解析树，在悬停卡片中压缩标题、列表、引用和代码块，保留行内强调；普通文本限制三行，表格用固定宽度单元格显示，不执行 HTML，也不打开预览中的外部链接。解析只在预览出现或正文变化时异步进行，解析期间保留简短文本占位。

自动化覆盖标题/列表文本与表格行列的解析、既有轨道、搜索和任务窗口回归。真实悬停卡片的行高、列宽、暗色主题和 Codex 双端视觉仍待 Mac 解锁后验收；完整配对保持 **0/47**（主工作区 21 项、设置 26 项），为待验收面数量而非已确认缺陷。
