# 派生任务继承权限快照

从弹出任务创建普通分叉、分叉到新工作树或开启侧聊时，新任务现在继承来源任务的 Codex Core 权限快照。工作树分叉先保存固定会话边界，再经历 Git 检出和环境准备；合并最新工作区数据时也保留该快照，防止异步流程把权限退回到随后变化的全局设置。侧聊仍强制只读运行。

独立任务删除沿用工作区的任务清理流程，同时删除其权限快照。29 项分叉、共享工作树、侧聊回归通过，包含真实 Git 检出和重启恢复；`script/build_and_run.sh --verify` 构建启动及严格深度签名检查通过。当前尚缺解锁桌面后的分叉菜单、焦点、窗口流转与 Codex 双端逐项配对；完整验收保持 **0/45**。
