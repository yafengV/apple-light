# 选区模型编辑的状态标记

当前 Codex Mac 文件编辑器在生成修改时以紫色标记原选区，短建议进入行内审阅后改用删除色。ShipiOS 此前只保留系统蓝色选区，用户看不出生成与审阅的状态变化。

现在选区在生成中显示紫色、行内审阅中显示删除色；取消、关闭、切换文件、原文或选区变化时恢复系统选区样式。标记只在 TextKit 绘制时合并临时属性，不写入文件文本或语法高亮存储；文件内查找在标记外仍保持自己的匹配颜色。大建议仍使用完整文件差异页。

隐藏原生窗口截图已核对两种颜色实际可见及审阅控件布局。**62 项**文件查找、语法高亮、选区编辑和工作区相关测试通过，覆盖颜色范围与查找颜色共存、选区变化清理、取消/关闭恢复、文件内容不变及既有编辑回归。`script/build_and_run.sh --verify` 完成正式构建和启动，严格深度签名通过。Mac 仍锁屏，无法确认可交互工作区或进行 Codex / ShipiOS 双端目视与键鼠配对；完整验收保持 **0/45**。
