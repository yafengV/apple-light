# 独立任务窗口文件固定项的恢复

文件内容标签加入固定侧栏后，独立任务窗口创建的文件固定项没有保存文件路径。原窗口关闭后，点击该固定项会落到空白文件页。

独立任务窗口现把文件路径存入固定项。恢复时先使用保存的路径；此前版本创建而缺少该字段的文件固定项，从其任务及源标签标识恢复原路径，并在恢复成功后补存。修复只涉及文件固定项，不改变浏览器、审查、终端等固定项的路由。

19 项文件标签、窗口固定项和恢复竞态测试通过，其中两项分别覆盖新固定项与旧记录在原窗口关闭后的路径恢复。`script/build_and_run.sh --verify` 完成正式应用构建和进程启动，严格深度签名检查通过。Mac 锁屏阻挡可交互工作区与 Codex 双端配对；完整验收仍为 **0/45**。
