# 弹出会话标题栏的新建与主窗口入口

当前 Codex 桌面分发的中文资源为弹出会话页列出“返回”、“开始新对话”和“在主窗口中打开”。ShipiOS 原先只有返回和隐藏；现在标题栏补齐新建与主窗口入口。新建返回弹出窗口首页，保留该首页尚未发送的草稿。主窗口入口先按弹出会话所属任务完成范围切换并核对选中结果，再隐藏弹出窗口并显示主窗口；其他任务的草稿和选择不会代替目标任务。

首条消息尚未形成正式任务的弹出草稿不在主窗口任务列表中，主窗口入口在此阶段禁用。任务切换失败时保留弹出窗口并显示可重试错误。主窗口的打开动作由主场景注册，因而弹出窗口自身不依赖独立 NSHostingView 中缺失的 SwiftUI 场景环境。

固定 470×640 的原生离屏窗口截图已检查标题栏两个新按钮及草稿阶段的禁用外观。39 项弹出窗口、项目、页面及任务导航回归通过；其中主窗口路由测试覆盖暂存草稿、任务切换受阻、成功选中目标、草稿保留和弹出窗口隐藏。正式应用通过 `script/build_and_run.sh --verify` 构建启动，并通过严格深度签名检查。Mac 仍锁屏，无法检查实际点击、主窗口恢复与 Codex 双端视觉交互；完整配对验收仍为 **0/45**。
