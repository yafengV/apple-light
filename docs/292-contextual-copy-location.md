# 按焦点复制浏览器网址或工作目录

2026-09-27。Codex 官方[命令参考](https://learn.chatgpt.com/docs/reference/commands)为“复制浏览器网址”和“复制工作目录”都列出 macOS 的 ⌘⇧C，并由浏览器是否获焦决定动作。ShipiOS 此前只把这个默认组合分配给浏览器网址，因此普通项目工作区没有对应动作。

现用一个按焦点分流的 ⌘⇧C 命令：浏览器真正获焦且有已加载网址时复制该网址；其余情况下仅在所属项目有绝对工作目录时复制目录。浏览器获焦但没有已加载网址时不会回退复制别的目录。主窗口、独立任务窗口与独立内容窗口均按各自任务或标签归属取值；菜单标题随上下文显示“复制浏览器网址”或“复制工作目录”。浏览器显式复制命令仍在菜单中，可另行设置自定义快捷键。

48 项相关测试通过，覆盖上下文选择、空网址边界、项目切换边界、窗口命令路由及默认绑定唯一性；`script/build_and_run.sh --build-app` 构建和 `codesign --verify --deep --strict` 通过。Mac 仍锁屏，真实按键分流、剪贴板和 Codex 双端视觉交互尚未验收；完整配对验收面仍为 0/43。
