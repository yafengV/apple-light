# PR Code 生成文件规则与默认折叠

Code 页现从 PR 的固定头提交读取根目录和修改路径全部祖先目录的 `.gitattributes`，按当前 Codex 的公开解析规则判断生成文件并默认收起。规则在差异载入后独立读取；主页面不等待规则网络请求。默认折叠、手动展开和评论定位各自保持明确的优先级。

该解析器覆盖参考实现识别的 `linguist-generated`、`linguist-generated=true`、`-linguist-generated`、`linguist-generated=false` 和 `!linguist-generated`。其他值、宏声明、仅有其他属性的行及引用空格路径按参考行为处理，不把完整 Git 属性语义替换进 Codex 的生成文件判断。更近的目录若显式取消或未指定，会阻止根目录的生成标记；没有匹配则继续查父级。

匹配区分大小写，包含隐藏文件；无斜杠模式按文件名匹配，完整 `**` 段才跨目录。关闭大括号展开、扩展通配、模式取反和模式注释，保留问号、字符类、范围、转义、未闭合方括号字面量、Unicode/POSIX 字符类及 UTF-16 行为。规则空白遵循参考的 JavaScript `trim/\s`，包括 BOM，排除 U+0085。超长表达式明确报错。

读取使用 [GitHub GraphQL Blob](https://docs.github.com/en/graphql/reference/git#blob) 的 `text/isTruncated/isBinary/byteSize`，核对完整文本与仓库；缺失属性文件、树和非文本 Blob 不产生生成标记。缺失返回字段、错误对象类型、GraphQL 错误及文本截断不会被当作完整成功。读取前后核对 PR 身份、源/目标提交、分支和文件数，与当前 Code 快照绑定；不使用本地检出、全局或 `.git/info/attributes`，不改变 Git 工作区。

## 页面与状态

- 普通文件默认展开；删除文件及规则确认的生成文件默认收起。
- 手动展开/收起优先于稍后到达的规则，页内批量操作也设置对应文件的明确选择。评论定位展开目标文件，规则完成后不会再次把它收起。
- 批量菜单保存自己的展开状态；生成文件恰好全部默认收起，不会自行把“收起全部”改成“展开全部”。逐文件操作也不修改这个菜单状态。
- 规则读取不更改差异、文件树、已选文件、评论位置或评论草稿。Code 页与新规则请求各自有取消/代际保护；任务更换、刷新和迟到请求不能安装到新快照。
- 按完整版本与路径列表缓存成功结果，读取失败可重试。按当前参考页面，规则故障不替换差异页，也不增加额外规则提示区域；保留内部错误/失效状态，工具栏刷新重新读取元数据、差异及规则。普通错误与版本失效分开记录。
- GraphQL 请求使用 0700 临时目录和 0600 JSON 文件，结束清理；PR 路径不拼接到 shell 命令，CLI 参数没有文件内容。新增测试只使用本机假 CLI 和临时仓库。
