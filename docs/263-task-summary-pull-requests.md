# 任务摘要中的 Pull requests

2026-09-27。审查页创建 GitHub PR 成功后，ShipiOS 将已验证的 PR 地址、编号、标题、草稿状态和分支记录到发起操作的任务。重新检查时发现已有 PR，也会保存到该任务；同一地址更新记录而不重复添加。保存时核对任务所属项目与仓库根目录，避免主窗口切换任务或独立窗口并行操作时串写。

任务摘要增加 Pull requests 区块，只展示本任务已记录且地址仍通过 GitHub URL 校验的条目。点击按所属窗口的网页链接规则打开，右键可复制链接。归档任务删除时一并清除关联记录。此区块不推断分支是否已有 PR，也不自动查询远端的最新合并状态；创建/检查后的状态为最后一次本机读取结果。

验证：`script/build_and_run.sh --build-app` 构建成功；GitHub PR 测试覆盖创建、任务隔离、重启恢复、重复保存、恶意地址过滤和删除清理。macOS 锁屏仍阻止实际点击验收，当前电脑使用工具也不允许读取 Codex 应用，因此视觉与原生交互配对仍未完成。
