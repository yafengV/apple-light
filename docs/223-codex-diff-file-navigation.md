# Codex 差异按文件浏览

2026-09-26。会话内的 `turn_diff` 卡可打开按文件浏览窗口。左侧文件列表使用原生单选列表，右侧显示该文件的完整补丁，可复制该文件差异；卡片仍可复制整个回合的完整差异。查看窗口从私有快照读取，因此内联预览达到 262,144 字符上限后仍能访问所有文件。

解析以 `diff --git` 为文件边界，新增、删除、重命名、二进制文件及 Git 的引号/八进制 UTF-8 路径均有定向测试。逐文件片段拼接后保持 Core 原始差异字节内容；没有标准文件头的旧差异仍作为一个整体显示。解析只用于呈现，不对项目文件执行写入。

窗口打开期间若 Core 更新差异，列表会刷新并尽量保持当前文件；用 Esc 或“完成”关闭时释放已加载内容。当前窗口不提供从差异跳转到文件预览或编辑器。

90 项相关 Swift 回归和 `script/build_and_run.sh --build-app` 构建通过，最后的窗口状态改动又通过定向编译与测试。Mac 仍锁屏，无法原生操作；视觉、列表键盘行为、焦点和文件打开方式仍需与当前 Codex 逐项配对，不能把这些检查记作整页验收。
