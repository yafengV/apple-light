# 网页链接的外部浏览器修饰键

2026-09-18。对照 Codex 26.908.70816（build 9275）的公开前端资源 `keyboard-shortcuts-settings-da30bad37b3c.js`、`src-996ff3571e1f.js` 和 `app-initial-4d7ea7f81c2d.js`。配置默认值为 `unassigned`，可选 `primary`、`alt`、`primary-shift`。macOS 使用 Command 作为 primary。

## 实现

- 主窗口快捷键页加入“在默认浏览器中打开网页链接”，提供未设置、⌘点按、⌥点按、⇧⌘点按四个选项，说明与保存失败反馈位于同一行。
- 该行参与文字搜索（标题、说明与当前选项），按组合键搜索时隐藏；设置全局搜索可以定位到此行，并清理之前的页内筛选。
- 主会话和独立任务窗口共用的 Markdown 回复入口在点击时捕获鼠标修饰键。仅精确匹配左键组合，额外 Control/Option/Shift 不误触发；Caps Lock 等无关标志不影响匹配。键盘或程序化打开不会继承陈旧的鼠标状态。
- 匹配后 HTTP/HTTPS 链接交给系统默认浏览器，不创建应用内标签、不切换任务，也不修改草稿。非匹配点击继续遵守通用设置里的链接目标。文件链接仍经过已有项目路径验证并走编辑器，未支持协议仍被拒绝。
- 偏好存入 ShipiOS 独立快捷键文件。旧字典及不含该字段的版本 1 文件都默认未设置；更新数字键和普通绑定时保留此值。
- 即使没有自定义命令绑定，只修改链接偏好也会显示“恢复全部默认”。恢复在一次持久化中同时清除绑定与链接偏好，保留数字键目标；失败保留两者和确认弹层以便重试。

应用构建及严格深度签名校验通过，日志 `.cache/external-link-shortcut-build.log`；已使用原数据目录重新启动，受保护任务与草稿仍在。

## 剩余差异

原生工具本轮仍超时，尚不能确认 SwiftUI 链接在真实鼠标与辅助功能操作下的所有行为。此项设置和路由已实现，页面尚未完整验收。

连续快捷键、裸修饰键、命令分组和按住修饰键时的侧栏提示仍未对齐。网页链接的默认分栏、前台/后台新标签、Option 下载等其他点击行为也需继续按参照实现核对；不能将本轮外部浏览器设置等同于全部链接交互对齐。
