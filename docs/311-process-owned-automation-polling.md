# 应用生命周期中的自动化轮询

自动化轮询已从主工作区视图移到应用生命周期。主窗口关闭而 ShipiOS 仍驻留菜单栏时，应用继续每 30 秒检查到期自动化；再次打开窗口不会创建第二个轮询器。退出应用时停止轮询并沿用现有运行任务的关闭流程。

到期检查不等待前一次模型运行完成才进行下一轮。工具审批可使某个自动化长期等待，其他到期任务仍能在后续轮询中启动。自动化本身仍使用既有的运行中标识防止重复提交。

8 项自动化测试通过，其中应用生命周期测试在没有挂载工作区视图的情况下确认到期任务被轮询。原生应用构建与签名检查见本次提交。此改动只覆盖 **ShipiOS 进程仍在运行** 的情形；用户明确退出应用后的独立后台服务、错过日程补跑和 Codex Mac 原生页面验收仍未实现。
