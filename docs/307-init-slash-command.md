# `/init` 项目指南命令

2026-09-28。[Codex 斜杠命令参考](https://learn.chatgpt.com/docs/reference/slash-commands)将 `/init` 定义为生成当前项目的 `AGENTS.md` 指南。当前集成的 Codex TUI 源码将它实现为一条模型请求，并要求检查已有文件、不覆盖。

ShipiOS 现在在主窗口和独立任务窗口的输入区提供 `/init` 候选，在命令菜单提供“生成项目 AGENTS.md 指南”。命令按窗口所属的项目目录运行 Codex Core · Responses 会话；独立任务窗口不切换主窗口工作区。请求让 Agent 根据项目实际结构、构建与测试命令、风格和提交习惯编写简短指南。已有 `AGENTS.md` 时直接提示并保留草稿，不覆盖文件或创建新回合。无项目任务、临时侧聊、非 Codex Responses 模式以及带未发送附件或评论的草稿会给出明确限制。

本机假模型与真实 Codex 工具回归确认两个不同项目各自生成指南，主窗口保持原项目，已有指南不被覆盖。命令、导航和项目路由相关测试 27 项、模型传输类 74 项以及补充的指南单元测试 3 项通过；原生应用构建及签名验证通过。Mac 锁屏期间无法确认实际候选弹层、焦点、文件预览和当前 Codex 的视觉配对；43 个完整配对验收面的计数不变。
