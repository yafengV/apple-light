# Appshot 全局快捷键的窗口归属

全局 Appshot 快捷键之前只读取主窗口的当前任务和草稿。即使用户刚在独立任务窗口工作，“自动”或“当前聊天”也会把截图放入主窗口草稿，截图卡片及移入动画的目标窗口同样不一致。

现在应用记录最近获得焦点的窗口：若它是已加载的独立任务窗口或弹出会话，复用聊天时沿该任务 ID 保存截图和临时卡片，并在截图完成时显示对应窗口；新聊天仍使用主窗口。独立任务窗口导航或恢复期间先清空显示中的任务 ID，避免把截图送入上一个任务。快捷键触发时固定已有草稿 ID，防止随后窗口导航改变归属。设置搜索也能通过 Option/Shift 找到 Appshot 快捷键项。

路由、设置、Appshot 交接、任务窗口恢复/导航与弹出状态共 44 项相关测试通过，`script/build_and_run.sh --build-app` 正式构建与严格签名检查通过。Mac 仍锁屏，不能验证真实跨应用快捷键、窗口重新激活、首用弹层焦点及 Codex 双端操作；完整配对保持 **0/46**。
