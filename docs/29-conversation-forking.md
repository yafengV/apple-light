## 实现

- 输入 `/fork`、命令菜单“分叉到新任务”、任务顶部菜单均可复制当前任务的已结束历史。
- 每条已结束回复下的“从此处分叉到新任务”只复制到该回合，排除后续回合。
- 运行中可从此前已结束回合分叉；不复制进行中的回合或触发新的 API 请求。当前单运行限制仍存在，新分支发送要等待已有运行结束。
- 新任务有独立 ID，每条复制记录也使用独立 ID。来源任务、源回合、原提示、回复、执行结果与时间得到保留；后续回复不会写回来源。
- 支持混合模型会话与本地诊断/构建历史。分叉的本地记录通过原始运行 ID 读取日志、事件和报告，不重复执行构建。
- 原任务草稿、队列、置顶、归档和评论保持原状态，不自动移入分支。`/fork` 成功时仅清除作为命令的源草稿，失败时保留该命令。
- 首次保存成功后才切换任务。保存失败不产生仅存在于内存的任务，也不改变当前选择与导航历史。
- 新分支显示来源入口；返回原任务后可继续阅读。工作区恢复与刷新包含复制记录，避免重启后只剩空标题。
- 分支的后续模型请求从独立复制记录建立上下文。原任务分叉点之后的提示与回复不会进入分支请求；本地执行记录遵循现有聊天规则，不自动发送给模型。
- 同时接入 `/model`、`/reasoning`，复用已实现的输入区模型选择器。
