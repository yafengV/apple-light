# 根搜索中的浏览器标签与分组导航

2026-09-18。继续补齐命令菜单根搜索的结果类型和键盘行为。

## 参考依据

本机已安装客户端的公开打包资源，不代表实时页面配对验收：

- `app-initial` 的 `Swo` 在非空查询时显示当前窗口各任务的打开标签，包含标题、网址和所属任务，最多 10 项。选择后激活原任务及原浏览器标签。
- 其引用的 `src-996ff3571e1f.js` 导出 `Vs`（函数 `Ec`）将标题、网页标题和网址小写拼接；以空白分词，要求所有词都出现。
- `qwo` 只在至少两个可用搜索分组存在时接管 Tab。第一次正向进入首组，反向进入末组，之后在组间循环；修改查询重置该状态。命令分类不算搜索分组。浏览器分组排在任务搜索分组前。

## 实现

- 新增独立浏览器结果模型，按上述多词规则筛选，保持打开标签顺序并限制 10 条。
- 从当前工作区窗口的活跃浏览器实例建立结果，排除已关闭、脱离当前窗口及失去所属任务的标签；包含当前窗口的新任务草稿标签。
- 结果显示标题、网址和所属任务。选择时重新核对原标签及来源，再切换项目/任务并激活原面板；保留已有网页实例和草稿，不重新加载网页。
- Tab/Shift-Tab 对浏览器、任务结果分组循环选择；少于两个可用搜索分组时沿用已有查询/取消/重试焦点导航。原键盘桥接继续排除输入法组合及修饰键冲突。
- 原生验证发现任务和命令的 `ForEach` 标识与选中行 ID 不一致，导致已选中的任务行无法滚入可视范围。统一为带类型前缀的标识后，任务和浏览器组均能显示选中行。
