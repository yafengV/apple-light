# Codex MCP 表单请求

2026-09-26。Codex Core 转发 MCP 服务的表单 `elicitation_request` 时，ShipiOS 现在把请求放进任务时间线。卡片按服务提供的字段类型显示文字、密码、数值、开关、选项或 JSON 输入；必填和基本类型约束在提交前校验。提交内容通过私有 Agent RPC 返回 Core，表单记录只保存请求与状态，不另存填写值。用户也可拒绝，请求会得到明确的拒绝响应。

本地模型与 STDIO MCP 假服务的集成测试验证了服务发起 `elicitation/create`、必填与类型校验、结构化内容传回、回合继续、拒绝状态及时间线记录。URL 模式和设备验证模式尚未接入；当前 Codex Mac 的视觉、焦点、键盘及辅助功能配对也尚未验收。
