## 原生入口与生命周期

主窗口和任务窗口的聊天标题、内容标题都接入 `ContentTabDragSource` 的左鼠标回调。聊天标题没有拖动 token，不启用内容拖动；SwiftUI 按钮继续承担键盘、辅助功能和右键菜单，关闭按钮也不参与标题双击。

第二次鼠标释放先执行选择，再按 `clickCount == 2` 切换布局；第三次只选择，不再次切换。禁用、释放到标签外、控件拆除，或选择回调当场禁用／拆除控件时不继续执行布局切换。拖动完成与既有单击清理继续使用原链路，禁用状态也传递到 AppKit 源控件。
