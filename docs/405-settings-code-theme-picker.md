菜单向按钮尾端对齐、间隔 2 点，空间不足向上显示并受窗口边界约束；内容滚动最大高度 320，加外围 4 点内边距为 328。每行 34 高、水平内边距 8、圆角 12；菜单圆角 16、边框 0.5。浮层位于调用窗口内容视图，避免设置 Form 裁切；没有新窗口或独立设置 Scene。

键盘打开定位第一项，指针打开不预选。方向键不循环，Home／PageUp 到第一项，End／PageDown 到最后一项，Tab 保留菜单，Enter／Space 选择；输入缓冲一秒失效，活动输入中的 Space 继续匹配。当前参考的 DOM textContent 含 Aa，因此匹配使用 Aa 加名称；540 组纯匹配器对照覆盖两种变体、所有当前项与空选择及 12 种查询。

Esc 只关闭主题菜单，保留设置并恢复按钮焦点。外部点击原样继续投递；焦点移出或窗口失活关闭且不抢回焦点。禁用、隐藏、卸载和失效选项不能执行。选择只保存当前侧，即使预设 ID 未变也重新应用；保存失败保留实际外观和草稿，关闭菜单，待视图更新后恢复原控件焦点。

验证发现 Form 内动态插入错误行会重建原生菜单，导致回滚后焦点丢失。错误提示移至 Form 外并保留区域身份；原控件仍附着、身份一致和焦点恢复均有断言。表单保留后暴露通用字体下拉的失败选择未复原，现读取绑定实际值恢复原生选项，新增拒绝写入回归。
