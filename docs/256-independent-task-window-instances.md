# 同一任务的独立窗口实例

2026-09-26。复核本机 Codex 客户端的“在新窗口中打开”消息处理后，发现 ShipiOS 旧路由使用任务 ID 作为窗口标识。SwiftUI `WindowGroup` 再次收到相同路由时可能只激活已有窗口，不能保证创建独立窗口。

主窗口任务菜单、命令菜单和独立任务窗口的命令入口现统一为每次打开生成新窗口标识；任务 ID 和独立数据目录仍保持不变。窗口资源、标签布局和系统恢复沿用各自稳定标识，因此同一任务的不同窗口可保留独立标签与导航状态。旧版保存的路由继续解码。

14 项相关 Swift 测试通过，覆盖连续打开的不同标识、路由持久化与旧路由恢复。`script/build_and_run.sh --build-app` 构建成功，`codesign --verify --deep --strict` 通过。当前 Mac 锁屏，真实窗口数量、激活顺序、重启后多窗口恢复及与 Codex 的实际交互配对仍未验收。
