# 独立任务窗口内容固定到侧栏

2026-09-19。按用户要求先整理并提交当前阶段；本阶段包含已知待修问题，不代表完整交互验收通过。

## 实现范围

- 独立窗口的浏览器、审查和终端标签提供“固定到侧栏”及取消固定菜单。
- 固定记录包含来源窗口，避免主窗口和多个独立窗口的同名审查标签相互覆盖。旧记录仍可解码。
- 来源仍打开时，侧栏唤回原窗口、原任务和原内容实例，不改变主窗口任务或草稿。来源关闭后，固定记录可在主窗口恢复；终端恢复会创建新会话。
- 标签关闭及应用退出前保存恢复信息；终端重启更新固定记录。窗口注册采用弱引用，并防止旧视图卸载清除新注册。
- 临时焦点诊断日志已移除，测试数据、缓存和个人配置不提交。

## 验证证据

提交前运行 `TaskWindow|WorkspaceTab|Sidebar|TerminalSession` 相关 Swift 测试，90 项通过、0 失败，日志位于本地 `.cache/task-window-pin-commit-tests.log`。其中 7 项新增测试覆盖窗口归属、同名标签隔离、关闭恢复、终端重启、旧记录兼容、退出保存和注册替换。

此前原生 macOS 验收确认：独立窗口网页固定后，主窗口点击固定项会唤回原网页，输入内容保留；独立窗口切换到其他任务后仍能由固定项返回原任务。终端固定项能够重新显示隐藏的原面板，但键盘焦点验收失败，见下文。自动化通过不能替代这一原生结果。

清理日志后，使用 `script/build_and_run.sh --app --data-root "$PWD/.shipios-local/desktop"` 重新构建并启动原数据目录，构建和严格签名检查通过。本次启动后的原生交互复查被 Mac 锁屏阻断，不能据此声称已确认工作区和草稿的恢复状态。
