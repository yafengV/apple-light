# 回复链接的原生菜单与鼠标命中

2026-09-18。参照 Codex 26.908.70816（build 9275）公开资源 `app-initial-4d7ea7f81c2d.js` 的 `FIi` 菜单定义与 `VIi` 点击入口。菜单顺序为应用内打开、外部浏览器打开、分隔线、复制链接、另存为；另存为动作在菜单关闭后执行。

## 当前实现

- macOS 15 及以上，回复链接增加原生 NSMenu，四个动作均有实际路由。明确“应用内/外部”打开不受普通点击目标偏好影响；复制使用完整网址。
- 通过 SwiftUI TextRenderer 获取实际排版后的链接 run 矩形。多链接、链接内部样式分段与跨行分别命中，不把整个段落当作一个链接。
- 原生透明指针层只截获对应链接上的修饰键点按、中键和右键；普通点击、正文拖选及原生文本语义继续交给 Text。Control 点按打开上下文菜单。
- 修复 AppKit 与网页事件的按钮编号差异：AppKit 右键 1、中键 2 转换为路由使用的右键 2、中键 1。
- 点按固定按下时的动作，抬起时核对链接仍一致；拖动超过阈值不执行点击。菜单固定创建时的网址和动作，之后界面变化不切换到另一链接。
- 查找高亮与精确匹配位置继续使用同一文字排版结果；内容/布局变化时旧链接区域不会用于新文本。
- “另存为”在菜单结束后异步开始，强制本次请求选择保存位置，不修改全局下载偏好。每个下载可单独指定目标选择回调，取消或完成后清理。
