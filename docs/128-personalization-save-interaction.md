# 自定义指令保存入口与快捷键

2026-09-18。接续 [设置说明覆盖](127-settings-description-coverage.md)，修正个性化页自定义指令区块的保存交互。

## 参考与实现

本机公开应用资源 `personalization-settings-2428288d0130.js` 中，Codex 的个人 AGENTS.md 编辑器将 Save 放在区块标题右侧，以 `CmdOrCtrl+S` 保存；没有改动或尚未加载时禁用，保存成功和失败使用浮动通知。编辑器具有空内容提示。此证据来自应用分发资源，不涉及个人 Codex 数据。

ShipiOS 将保存入口移到自定义指令标题右侧，合并区块说明，去掉编辑器下方的额外保存、重置及常驻保存状态行；保留原生文本撤销。空编辑器显示“添加自定义指令…”。保存成功或失败通过现有通知组件反馈，失败后保留草稿及错误详情供修正重试。

⌘S 接入已有窗口快捷键路由，只在个性化设置页已加载且有改动时处理；沿用键窗口、系统 sheet、应用弹层、快捷键录制及设置确认的隔离。失败时也消费快捷键，避免继续触发其他保存动作。未修改用户 API 服务、原工作区指令或认证配置。
