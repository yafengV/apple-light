# 语音设置与独立 API 配置的页面归属

对照本机 Codex 客户端资源中的语音设置结构，语音页保留音色选择、屏幕上下文、语音聊天快捷键，以及通用麦克风和听写设置。ShipiOS 的独立服务需要单独指定实时语音模型，因此将该字段放在“模型与 API”页，与基础地址、文本模型和密钥一起保存；设置搜索中的“实时语音模型”也跳转到这一页。

语音页不再显示实时模型输入框和额外的“开始语音聊天”按钮。尚未配置基础地址或实时模型时，页首显示配置入口；已配置后从输入区或全局快捷键开始会话。保存 API 配置时一并规范化并持久化实时语音模型 ID。

本阶段语音设置相关 11 项测试通过，两页离屏渲染确认入口、字段和分组可见，正式构建与严格签名通过。还需要在可启动的新包中实际点击配置入口、保存后重开页面，并在用户配置的服务和麦克风上验证语音会话；Codex 与 ShipiOS 的逐页交互验收仍为 **0/47**。这个数字是尚未完成配对的验收面总数，不是已发现缺陷数。
