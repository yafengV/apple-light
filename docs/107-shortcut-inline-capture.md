# 快捷键行内录制与重置确认

2026-09-18。静态对照应用版本为 26.908.70816（build 9275）。继续按本机 `keyboard-shortcuts-settings-da30bad37b3c.js`、`keyboard-shortcuts-search-input-ca807475e795.js`，以及 `app-primary-4af6ed7f68d1.js` 的 `GUn` 录制组件核对。设置仍在主窗口内显示。

## 本轮变化

- 移除页顶录制横条。录制输入和取消按钮直接替换正在编辑的绑定行，冲突警告紧邻该输入；保存失败显示在对应命令下。
- 每个绑定分别显示编辑、清除按钮；自定义命令在首个变更的绑定旁显示恢复默认。清除只移除选中的绑定，保留其他绑定。Shift 点按编辑或通过其上下文菜单可添加绑定。
- 新录制控件只有自己是所属窗口的 first responder 时才截获按键。失焦取消该行录制，卸载立即释放捕获；窗口失去活动状态也释放捕获标记，避免阻止其他任务窗口的快捷键。旧行的异步失焦不能取消新行。
- 忽略重复 keyDown；Esc 始终取消；录制已有值只退出，不新增自定义配置。Backspace/Delete 不再作为隐式删除绑定操作，删除使用明确的清除按钮。
- 按键搜索在输入区域内显示录制状态。切换搜索模式清空查询；按键搜索持续接收新的组合键，Esc 清空并返回文本模式；失焦后不拦截别处的输入。文本搜索有清除入口。
- 常规宽度下绑定区宽 384 点，窄宽度下标题与控制区纵向排列；页面仍只有一个滚动文档和顶部固定搜索栏。
- “恢复全部默认”从系统 alert 改为主窗口内 420 点宽的居中确认；执行中阻止重复确认，保存失败保留弹层、错误和原绑定，允许重试。
- 归档确认与快捷键重置共用窗口内确认组件；命令菜单、其他弹层、设置返回和通知查看动作均遵守统一的模态保护。

## 仍需完成

这一轮没有把快捷键页标成完全对齐。现有绑定模型仍只支持单个组合键，缺少原实现支持的连续按键和部分裸修饰键；命令分组/顺序、说明文字、数字快捷键在聊天/标签之间的目标切换，以及“修饰键点按链接在默认浏览器打开”的设置仍有差异。重置目前只作用于已经实现的绑定数据。

原生工具本轮再次确认 Mac 锁定。真实鼠标与键盘、录制焦点的可见反馈、输入法、辅助功能和 Codex 两边的完整配对验收仍待完成。离屏测试不是原生桌面验收。
