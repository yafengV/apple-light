# Agent 托管网页搜索

2026-09-26。Codex Mac 当前 Agent 设置提供网页搜索的关闭、缓存、索引和实时模式。ShipiOS 现于同一主窗口 Agent 页提供模式选择，并在独立模型设置中让用户声明 `/responses` 服务是否接受托管 `web_search` 工具。未声明能力时选择器禁用；默认关闭，不向未知服务发送搜索工具。模型页的 `/models` 连接测试不验证搜索能力，因此界面明确说明这一边界。

新线程把搜索模式与服务能力经私有 Agent RPC 交给固定版 Codex Core，线程重启从私有恢复记录取创建时的快照。Agent 拒绝无服务能力声明却请求非关闭模式的 RPC。Core 根据模式生成托管搜索工具；本地假模型集成测试确认缓存模式的第一次及续接 `/responses` 请求都包含 `web_search` 且 `external_web_access=false`。Swift 旧配置迁移、保存与设置搜索测试通过。

尚未使用用户的真实独立 API 服务测试搜索结果，也未对当前 Codex Mac 的页面布局、菜单、焦点和键盘交互做原生配对；不能认定 Agent 页完整对齐。
