# 分离终端重启保留窗口与焦点

2026-09-25。修复分离内容窗口内重新打开终端后，原窗口因标签 ID 改变而丢失内容的问题。

## 实现

针对单个终端的重启保留稳定标签 ID，只停止旧 shell 并创建新的 `TerminalSession` 和原生终端视图。窗口路由、固定标签、面板位置、顺序与任务归属不再需要逐项迁移到新 ID；主窗口停留在其他任务时，已保存布局仍能引用正确标签。

会话集合接入 Observation，终端面板读取当前会话，避免视图持有已失效的旧会话副本。原生视图宿主以会话对象身份区分，因此稳定的标签 ID 不会妨碍替换旧终端视图。

分离窗口使用本窗口的焦点请求；新 shell 挂载后可继续输入，不依赖主窗口当前选中的任务。已有的原生窗口激活检查仍生效，后台窗口不抢焦点。不存在的标签及应用退出阶段不再启动新进程。

## 剩余范围

本轮处理当前进程内显式重启，不代表分离标签跨进程、跨数据目录或后台任务恢复均已完成。分离审查的项目归属、窗口命令路由、完整拖放及全部 Codex 页面配对仍需继续。
