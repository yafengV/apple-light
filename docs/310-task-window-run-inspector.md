# 独立任务窗口执行详情

独立任务窗口的每条模型回复现在有“查看模型执行详情”入口，在本窗口的右侧面板显示该回合的概览、工具调用与输出。面板依据当前任务的回合列表查找运行记录，切换主窗口项目或打开其他任务时不会借用主窗口的选择状态；切换到另一个任务会关闭旧详情。任务窗口的文件面板与内容标签仍可按原布局使用。

详情组件与主窗口共用，两个窗口各自保存当前详情分类。工具审批按钮保留原有任务归属；详情中的重复工具卡片不主动争夺时间线的键盘审批焦点。

11 项任务窗口与面板定向测试、原生应用构建及签名检查通过。测试和构建不能证明窗口实际点击或 Codex Mac 的视觉、焦点配对；Mac 锁屏期间这些验收保持未完成。
