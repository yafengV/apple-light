# 主窗口内个性化设置

2026-09-17。继续补齐设置页划分与自定义指令流程。

## 对照依据

本轮读取 [官方 Settings 文档](https://learn.chatgpt.com/docs/reference/settings#personalization)：Personalization 包含 Friendly、Pragmatic、None 和自定义指令，个人指令写入 `AGENTS.md`。这证明页面内容与功能方向，不证明当前安装版本的布局、保存手势或默认值。

ShipiOS 的设置导航包含“个性化”，沿用主窗口内页面；“模型与 API”中的指令入口会路由到该页。新增独立“记忆”“个人资料”“宠物”和“电脑使用”页后当前共十五个设置分类，其余 Codex 设置页仍有缺口。

## 当前实现

- “回复风格”提供友好、务实、无。选择后独立保存，作用于下一次模型请求。“无”仅移除附加风格指令，保留基础行为约束和用户自定义指令。
- 风格文案是 ShipiOS 的实现，不声称等同于 Codex 内部完整 personality prompt。迁移已有用户时默认“无”，避免主动改变之前的回复风格。
- “显示建议提示”控制空白新任务页的起步卡片。关闭后立即隐藏项目内和无项目会话的建议，已有任务、草稿和会话不受影响；开关与回复风格保存在同一份偏好中，修改任一项不会重置另一项。旧偏好缺少该字段时默认开启。
- 自定义指令有明确保存、未保存状态和撤销未保存修改。切换设置分类或返回工作区再打开时保留编辑稿；未保存文字不进入模型请求，重启只恢复已保存内容。
- 不需要填写 API 地址或密钥即可保存个性化设置。风格位于当前数据根目录 `personalization.json`，自定义指令位于同目录 `AGENTS.md`；两个文件权限为 0600，不读写用户 Codex 的配置。
- 从旧 `model.json.instructions` 首次迁移自定义内容。若已有 ShipiOS `AGENTS.md`，以该文件为准。完成迁移后，清空或移除指令文件不会使旧指令重新出现。
- 保留旧模型配置字段用于兼容读取，实际模型请求使用已保存的个性化状态；API 设置保存不会覆盖新的指令文件。
- 指令须为 UTF-8 且不超过 64 KiB。配置损坏或指令读取失败时不静默覆盖原文件；页面显示错误与重新加载入口。未成功加载时，不丢弃指令后继续发起模型请求。
- 设置页之间切换会释放旧页面的键盘焦点，隐藏页禁用输入，避免保留在 ZStack 中的 TextEditor 继续接收按键；原生焦点效果仍待验收。
