# 浏览器站点工具调用

2026-10-01。ShipiOS 在上一阶段的顶层网页工具清单上接入真实调用。Codex Core 的 `shipios_browser` 新增 `site_tools` 和 `site_tool_call`：前者返回当前任务标签的工具说明与输入 schema，后者传入名称和 JSON 对象参数。Bridge 保留任务归属和取消语义，网站定义及结果继续标为外部上下文。依据：[OpenAI 站点工具说明](https://learn.chatgpt.com/docs/webmcp)、[桌面使用与安全要求](https://help.openai.com/en/articles/20001423-using-site-tools-in-the-chatgpt-desktop-app)。

宿主先检查任务所属标签、网站访问规则、浏览器设置开关、页面状态和工具注册。每次调用都在所属可见窗口显示网站、工具名称、网站声明的说明，以及可滚动的完整参数；没有可见窗口或已有 sheet 时拒绝。用户确认后再次检查任务、权限、页面版本与注册项，避免页面在确认期间更换工具。执行时限制跨站导航，网页输出最多回传 16,000 字符，错误明确提示先检查页面再决定是否重试。地址栏在执行中显示强调色并列出本页最近调用；会话时间线记录工具名与当前网页来源，不把参数写进卡片标题。

本地网页夹具验证顶层注册、schema、带参数执行、动态增删、旧注册拒绝、任务隔离和开关拒绝；隔离原生窗口验证确认后执行成功，以及确认期间工具注销后即使批准也不能执行。最终浏览器回归 **68 项通过**，时间线 **4 项通过**；Rust Codex 库 **16 项通过**，假模型的真实 Codex Core 回合另验证 `site_tool_call` 参数穿过 Agent 桥并将网页结果送回模型。格式与严格 Clippy 通过。`script/build_and_run.sh --build-app` 正式构建及严格深度签名检查通过。本轮桌面状态接口再次超时，未将构建成功或隔离测试窗口当作真实前台工作区验收。

**尚未完成完整对齐：** 现在每次调用要求用户确认，但尚无 Codex 的独立语义安全审查或敏感行为分类；超时/取消只向网页回调传递尽力而为的 AbortSignal，网页不配合时不能保证撤销已发生的副作用。“最近使用”尚未从地址栏直达 Sources；真实用户模型服务、当前 Codex 客户端的地址栏弹层、焦点、颜色、键盘和重启行为也未双端配对。整体验收仍为 **0/45**，不能由本地测试推断完全一致。
