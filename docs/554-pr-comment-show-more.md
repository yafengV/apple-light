# PR 长评论的展开与收起

本机 Codex 的 PR 评论正文默认显示三行；实际内容超过三行时出现“Show more”，展开后可用“Show less”恢复。短评论不显示按钮。该正文行为与整张评论卡片／线程的折叠是两套独立状态。

ShipiOS 的 PR Activity 和 Code 页面共用评论正文视图。现在根据 Markdown 实际排版高度决定是否显示“展开更多”，超过约三行时把正文裁到 60 像素；展开后保留完整 Markdown、链接、选择与现有编辑／回复表单。正文更新时恢复默认折叠状态，整卡片及线程折叠状态仍独立管理。

14 项评论卡片专项测试通过，其中离屏布局确认长正文收起后的高度。前一轮 60 项 PR 评论回归中 57 项通过，3 项本机 HTTP 夹具在沙箱中因端口绑定被拒；允许回环端口后单独重跑均通过。正式构建与严格签名通过。Mac 当前锁屏且自动解锁失败，按钮焦点、真实三行裁剪、复杂媒体和 Codex 双端页面视觉仍待前台验收；完整配对保持 **0/47**，是验收面数量而非已确认缺陷。
