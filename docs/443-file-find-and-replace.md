# 文件内查找与替换

2026-10-01。当前 Codex Mac 的文件编辑器在页内提供查找、替换、大小写、整词和正则选项。ShipiOS 文件页新增窗口内查找层，显示匹配计数并高亮匹配；支持上/下一个、逐个替换和全部替换。替换直接进入原生文本视图，更新同一文件草稿并保留撤销。无效正则显示错误；只读大文件可查找但不提供替换。
