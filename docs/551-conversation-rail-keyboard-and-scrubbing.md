# 会话轨道的键盘预览与拖动定位

本机 Codex 的用户消息轨道在键盘聚焦标记时显示浮动预览。普通点击平滑滚动到消息；按住轨道跨过标记时逐条即时定位，经过已有标记不会重复触发。同一悬停卡片中的书签按钮可继续取得键盘焦点。

ShipiOS 现把主会话、独立任务窗口和弹出窗口共用的轨道改为上述定位方式。Tab 聚焦标记或卡片书签按钮会保留预览；拖动经过不同消息时即时定位，回拖到起点也可定位，拖动结束的补发点击不会再次平滑跳转。普通点击采用短时滚动动画，开启减少动态效果时直接定位。

拖动状态转换及既有导航、搜索、任务窗口回归由自动化测试覆盖。桌面控制仍超时，实际指针捕获、Popover 焦点、滚动动效及 Codex 双端操作尚未前台验收；完整配对保持 **0/47**（主工作区 21 项、设置 26 项），该数字为待验收面而非已确认缺陷。
