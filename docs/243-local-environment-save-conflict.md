# 本地环境保存冲突

2026-09-26。本机 Codex Mac 应用包中的本地环境编辑器在磁盘文件于编辑期间发生变化时，阻止再次保存，显示冲突提示，并将主操作改为“放弃修改”以重新读取文件。ShipiOS 的独立环境编辑会话现在区分文件修订冲突和普通保存失败：冲突时保留草稿、不写入磁盘，禁用其他保存入口，主操作改为“放弃修改并重新载入”。重新载入后更新修订号，恢复可保存状态。

真实 Agent 集成测试在编辑其他项目期间外部修改 TOML 文件，确认冲突保存失败、磁盘原文与当前草稿均保留、重复保存被阻止，重新载入后冲突解除且主工作区任务和草稿不变。此项验证不等于当前 Codex Mac 页面的原生视觉、焦点和键盘配对；当前 Mac 锁屏，43 个验收面完整配对数仍为 0。
