# 插件详情页面与来源返回

2026-09-18。将插件详情从固定 520×410 的 sheet 改为主窗口内可滚动页面。

## 对照依据

本机 `/Applications/ChatGPT.app/Contents/Resources/app.asar`：

- `settings-plugin-selection-92a6a2b8485a.js` 中插件行通过导航函数打开详情路由。
- `plugin-detail-page-17f962f4fb50.js` 的 `cu` 接收 `parentPage` 和 `onBack`；返回处理优先调用传入的回调，否则按来源状态后退或导航父页面。
- 同文件 `_u` 渲染 `parentPage: manage` 的详情页，说明管理页面和目录都能作为来源。

该证据支持页面导航形态，不足以证明当前账号下的全部布局、控件或服务状态。

## 实现

- 目录“详情”按钮和设置中插件名称进入同一个详情页面。左侧主应用导航保留；详情自身提供返回按钮和 Escape。
- 返回目录时保持其列表视图挂载；返回设置时恢复原分类、插件标签、筛选条件和设置页原先的返回目标。
- 后退、前进命令处理插件详情，不消费任务历史。用户打开不同页面或设置分类后，旧详情前进路径失效。
- 从详情临时进入全局设置，关闭设置先返回详情，再返回原来源；项目、自动化或目录的底层页面保持挂载。
- 隐藏的来源页面禁止点击、快捷键和辅助功能访问，避免 Escape 被底层“返回任务”动作抢走。
- 详情每次读取当前安装状态，不再回退到打开时复制的旧插件。卸载或重新加载后插件缺失时展示缺失状态，并阻止前进恢复可编辑的旧详情。
- 详情操作菜单提供现有的 Finder 定位和带确认的卸载；只有配置成功加载后才能更改启用状态或卸载。
