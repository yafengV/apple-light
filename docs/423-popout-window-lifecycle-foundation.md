# 弹出窗口的设置分组与生命周期状态

当前 Codex 桌面分发的通用设置把“弹出窗口”单列，含“弹出窗口快捷键”和“默认使用独立聊天”两行。中文文案来自 `zh-CN-523d79e20e0e.js`（SHA-256 `43e8401d13c6b4a2554c2263406a2bc67a5106ec6b277aea2f19d3ce978553c6`），页面结构来自 `general-settings-ed7ca2006cd3.js`（SHA-256 `3a2ff568faaa71fa98cde8ca59a04d525baf13ce81a470ea8ae72c5283800753`）。

参考主进程 `main-DS3FMq4P.js`（SHA-256 `9f4ce005ae6422a85758fe1d8e8f26e049f85026dc65618f6901fa65b0be35c0`）将弹出窗口分为独立首页和会话表面：热键在隐藏时恢复上次表面，在显示时隐藏；打开会话会记住路由；返回首页后，下次热键恢复首页。参考初始尺寸分别为约 470×290 和 470×640，具体尺寸仍受显示器工作区约束。普通新任务窗口不承担这些行为。

ShipiOS 现将既有项目范围开关移入通用设置的独立“弹出窗口”分组，并使用参考中文标签与说明；搜索词也可定位“独立聊天”。新增 `PopoutWindowState` 表示隐藏、首页与会话表面及上次可见表面的恢复规则，避免后续把全局热键直接接成每次新建普通任务。

状态、设置搜索、导航与隐藏页面布局等 50 项相关 Swift 测试通过，日志 `.cache/popout-settings-targeted-final.log`。正式应用通过 `script/build_and_run.sh --build-app` 构建，日志 `.cache/popout-settings-build.log`；严格深度签名通过，29 个语法资源和七份许可证与源文件逐字节一致。隐藏页面快照只检查了通用设置的初始视口，未覆盖滚动到弹出窗口分组后的实际可见布局。

**仍待开发：**专用首页／会话窗口、全局热键录制与注册、从首页创建或打开任务、焦点和窗口位置、隐藏时保留草稿、跨应用激活、可见双端页面与交互验收。当前改动仅为分组和生命周期基础，完整配对仍为 **0/45**。
