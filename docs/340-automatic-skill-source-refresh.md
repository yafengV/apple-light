# 技能文件变化自动刷新

2026-09-28。Codex 的[技能文档](https://learn.chatgpt.com/docs/build-skills)说明会自动检测技能变化。ShipiOS 现在由应用生命周期每两秒检查独立插件/技能目录及已知任务项目的仓库技能范围；主窗口关闭但菜单栏进程仍运行时保持检查，退出时停止。检查读取技能指令、界面配置和图标状态，不扫描项目源码。

仓库技能新增、修改、删除会刷新技能页、输入候选、预览与试用提示；已注册的私有技能文件删除后不再进入候选，恢复文件后重新出现。配置损坏时清除旧候选并显示错误，文件修复后自动恢复。当前预览会重新读取，正在编辑的草稿不会被后台更新覆盖，保存继续使用原文冲突校验。图标路径不变但文件变化时也会重新加载。

相关 70 项定向回归通过，包括指令内容变化（即使恢复原修改时间）、嵌套插件路径、图标来源、普通项目源码不触发、无窗口轮询、取消、私有文件删除/恢复、损坏配置恢复与自动化生命周期。`script/build_and_run.sh --build-app` 和严格签名检查通过；本轮没有重新执行全量回归或原生可见验收。新增未注册的私有目录仍需导入；隐式激活、符号链接技能、依赖配置和原生双端页面配对继续待完成，完整验收仍为 0/43。
