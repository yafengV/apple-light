# 在应用内创建独立技能

2026-09-28。主窗口“技能”页新增“新建技能”。用户填写技能名称、用途描述和指令后，ShipiOS 在自己的 `Skills/<名称>/SKILL.md` 中生成标准 frontmatter 与正文；新技能立即出现在列表和 `$名称` 候选中。创建流程校验名称、单行描述及 64 KiB 文件上限，拒绝重复名称，不覆盖现有目录；失败时保留表单输入并显示错误。现有任务草稿不受影响。

技能仍只存在于 ShipiOS 独立数据目录，不进入用户个人 Codex 配置。导入、预览、启停、立即尝试和卸载沿用已有逻辑。当前只覆盖本应用内的独立技能；项目作用域、在线目录、资源文件编辑及与 Codex Mac 实际表单的视觉和焦点配对仍待完成。

`StandaloneSkillTests` 覆盖创建后的读取、重启加载、任务上下文、权限、无效和重复输入、Store 刷新与草稿保持。原生可见交互因桌面锁定尚未验收。
