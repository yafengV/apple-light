# `/mcp` 状态入口

2026-09-28。[Codex 官方斜杠命令参考](https://learn.chatgpt.com/docs/reference/slash-commands)将 `/mcp` 定义为查看已连接 MCP 服务器状态的入口。此前 ShipiOS 已在主窗口的插件设置内显示 MCP 服务器连接状态、错误及工具，但输入区没有对应命令。

现在主窗口输入 `/mcp` 可直接进入插件设置的 MCP 服务器页；命令菜单也提供“查看 MCP 连接状态”。独立任务窗口的输入区和命令菜单将主窗口打开到同一页，任务选择保持不变，独立任务草稿仍由该窗口管理。设置没有弹出独立窗口。

输入区命令、导航与 MCP 设置的 23 项相关测试通过。macOS 锁屏阻止了原生点击、窗口焦点与当前 Codex 双端页面配对。此改动只对齐状态入口语义，尚未证明视觉和所有交互完全一致。
