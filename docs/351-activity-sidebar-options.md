# Activity 侧栏、显示选项与已读处理

2026-09-28。第 294 阶段将 Activity 实现为主窗口整页，按状态单选筛选，并复用全局清除未读动作。本阶段纠正这些与参考实现不同的行为。

## 对照证据

本轮读取 OpenAI 官方[通知文档](https://learn.chatgpt.com/docs/notifications)：Activity 从侧栏铃铛和 `⌘⌥U` 进入，显示未读、运行中及等待答复的会话；选项随产品界面而异。此前提取的官方桌面静态资源包含 contextual activity sidebar、独立 Priority/Pinned/Scheduled 复选项、恢复默认值、Clear read chats 和 Mark all as read。资源的默认值分别为开启 Priority、关闭 Pinned、关闭 Scheduled；近期列表覆盖包含当天在内的七个日历日。

静态资源还明确只在 ChatGPT 侧栏模式显示 Work/Chat 两项；这不是按模型协议或项目路径划分的分类。本阶段没有将基础聊天协议冒充 Chat、将 Core 协议冒充 Work。当前 ShipiOS 仅有独立 API 的本地任务来源，其他产品来源仍需后续实现。资源仅用于确定行为和结构，不是用户当前安装版本的原生配对证据。

## 当前实现

Activity 现在替换任务侧栏列表，任务内容、输入区、终端、审查及其他面板继续显示和保持挂载。活动状态与主页面目的地分离；打开列表任务保留活动侧栏，设置往返保留列表，关闭侧栏恢复普通项目组织。标题、关闭入口、清除已读与选项位于侧栏内，底部资料/设置入口保留。方向键定位条目，Return 打开，列表随定位滚动；真实按键投递仍待原生验收。

显示选项可独立选择优先区域、置顶和计划任务，并保存到 ShipiOS 私有工作区配置；旧配置使用上述默认值，恢复默认值不会改变任务。置顶单独显示时不重复出现在优先区域或日期分组中；关闭优先区域后，符合近期日期范围的任务进入时间列表。归档和临时任务及尚无运行记录的草稿不进入列表。

打开活动视图时保留优先任务身份，运行状态、未读和待答复发生变化时更新内容并纳入新的活动。读过或完成的任务继续保留，直到“清除已读任务”移除空闲条目；运行中和仍待用户处理的条目保留。该操作不修改任何未读标记。“全部标为已读”仅处理当前优先列表中的未读任务，保留隐藏的计划任务、单独置顶区域和归档任务的未读状态；相关计划运行仍沿用实际已审查处理。

近期列表按日期分组并去重，已展示的近期日期保持稳定，避免用户阅读时因记录更新换组。优先列表及日期快照仅属于本次窗口状态，关闭后重新计算。显示偏好和未读修改先保存候选配置，保存失败保留原状态并在侧栏报错。跨项目打开失败保留活动和未读状态。
