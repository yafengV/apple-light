## 实现

根评论采用六行高度预览，线程回复和编辑/非空回复草稿保护的正文保持完整。空白回复不阻止收起，原草稿仍保留。Activity 与 Code 内联分别使用对应默认规则，批量切换只作用于当前页面的卡片。

标题按两组控件排版，按自然宽度判断是否换行，窄视口不足时把右侧组移到下一行，而不是先压缩作者组到最小宽度。修正根正文、根编辑、回复标题/正文、引用回复页脚和线程操作留白，根作者使用 12 点、回复作者 14 点、元数据和正文 13 点；展开按钮 14 点。PR 的紧凑正文样式不改变普通会话字号。

第 589 篇菜单的背景/边框角色按实际 CSS 别名纠正。原生菜单视口使用有限尺寸测量；这不是原生约束警告已经消除的证明。
