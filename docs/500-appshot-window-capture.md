# 应用窗口截图进入聊天草稿

本机 Codex Mac 客户端 26.911.61220 注册 `composer.captureAppshot` 命令。ShipiOS 现提供“截取应用窗口…”入口，位于命令菜单、原生任务菜单、主输入区、独立任务窗口和弹出窗口的附件菜单，并可设置快捷键。

用户触发后，已获屏幕录制权限时优先截取最近五分钟使用的其他应用的最前方常规窗口；找不到可用窗口时，由 macOS 系统单窗口选择器让用户明确选择。ShipiOS 自身窗口从选择器排除。截图按不超过 3200 像素最长边编码，复用现有图片附件的格式、大小、数量、私有存储、预览、草稿归属与发送路径。取消选择不添加附件；同时进行的图片导入会阻止重复启动。

本阶段有意保留验收边界：截图的实际前台选择、权限弹窗、焦点回归和 Codex 的捕捉动画／辅助功能上下文尚未在双端实测。单窗口图片附件已接通，但不能据此称 Appshot 完全对齐。

验证：38 项窗口选取规则、尺寸边界、截图编码与附件存储、所属任务草稿及取消状态、命令状态和弹出窗口相关测试通过；正式应用构建、严格深度签名和差异检查通过。Mac 锁屏阻止原生工作区可交互性和双端前台验收，完整配对仍为 **0/45**。
