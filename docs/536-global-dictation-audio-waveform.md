# 全局听写采集音量波形

Codex macOS 当前分发资源 `global-dictation-page-3d28a1fd7ea2.js` 在录音状态使用 `waveformCanvasRef`，随音频输入更新胶囊内波形。ShipiOS 第 535 阶段的浮窗仍是静态波形图标，无法反馈麦克风实际收到的声音。

现在默认麦克风的 `AVAudioPCMBuffer` 与指定设备的 `CMSampleBuffer` 都在送入 Speech 的同时计算有限采样的 RMS 音量，经 50 毫秒节流后更新 14 根波形条。支持常见的小端 Float32、Int16 和 Int32 PCM；不支持的缓冲格式不会中断听写，只是不提供波形。录音结束、取消或切换会话时清空音量，迟到样本不能更新新会话。界面遵守减少动态效果设置。音量只用于内存中的状态显示，不另存录音。

18 项采集音量、全局浮窗、语音设置和热键相关测试通过；合成 Float32、Int16 及 CoreMedia 样本缓冲均测得预期音量，72×30 波形离屏图像已检查。正式应用构建及严格签名通过。**当前机器没有可枚举麦克风，真实设备振幅、跨应用录音及 Codex 双端波形视觉/交互仍未验收。** 录音保存、恢复、重试和实时语音会话仍缺，完整配对保持 **0/47**。
