# 冷恢复任务窗口的等待与续接

日期：2026-10-09。属于第 726 篇 R4／R7，补任务窗口恢复未完成工作树时的可操作状态。

## 实现

原视图发现待恢复工作树后发起创建动作便返回；工作区切换、其他工作树或本地操作占用时，动作会被拒绝，窗口没有准备页或任务面板，最终显示空白，也不会在占用结束后恢复。

现在窗口显示具体占用原因，支持关闭；条件恢复可用后自动继续同一检查点，也提供可用时的重试入口。视图与恢复方法共用可用性判断，禁用状态和实际动作一致。其他工作树、工作区更新、本地运行和任务分支占用结束均触发重新判断，不提前打开待恢复目录的编辑器。

请求排队后条件变化也会保留等待状态；导航离开清除等待，窗口关闭后拒绝迟到恢复和分支动作。失败或取消已进入准备页的流程仍保留原页面及重试检查点。恢复不新建第二个工作树、不重复环境初始化，保留子任务和来源草稿，主窗口选择保持不变。普通任务准备阶段改为明确进度提示，避免就绪但尚未建立面板时空白。
