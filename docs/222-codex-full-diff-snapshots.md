# Codex 完整差异快照

2026-09-26。此前 `turn_diff` 卡为了限制 `workspace.json` 体积，只保存前 262,144 个字符。大型改动的剩余内容无法从历史任务查看或复制。

现在每次非空累计差异都写入 ShipiOS 数据目录的 `CodexTurnDiffs/<卡片 ID>.patch`，工作区记录仍仅保留预览、字节数和 SHA-256。卡片可打开完整差异，也可将完整内容复制到剪贴板；私有文件读取时校验长度与摘要。旧版未截断的差异记录仍可复制，旧版已截断且没有快照的记录会明确提示无法取得完整内容。

同一回合的累计更新复用卡片 ID，即使变化只发生在预览之外也会更新快照。Core 清空差异时，持久化成功后清理无引用文件；分叉任务继续引用同一已完成回合的快照，删除归档任务时只在最后一个引用消失后清理。

89 项相关 Swift 回归通过，覆盖超长内容、预览外更新、重启读取、清空和分叉删除；真实 Core 补丁集成测试也读取了私有快照。`script/build_and_run.sh --build-app` 构建通过。Mac 锁屏使原生卡片的视觉、焦点、键盘和文件导航未能与当前 Codex Mac 配对，因此 43 类完整配对数量仍为 0。
