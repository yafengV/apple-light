# 网页搜索外部来源

2026-09-27。固定版本 Codex Core 的 `web_search_end` 可以携带独立的结构化结果。ShipiOS 现从结果对象中的标题和 HTTP(S) 网址，以及 `open_page` 动作中的网址提取来源，去重后保存到对应运行记录；来源独立于时间线输出预览，后续回复更新与应用恢复不会覆盖它。无效协议、登录凭据和过长网址被拒绝。

任务摘要在附件之后列出这些外部来源。主窗口及独立任务窗口点击来源时，复用会话链接偏好和当前窗口的浏览器路由。
