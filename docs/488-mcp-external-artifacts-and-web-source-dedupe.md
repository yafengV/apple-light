# 外部资源输出与网页来源去重

本阶段继续对照本机 Codex 桌面包 `26.911.61220` 的静态资源汇总实现。成功 MCP 调用中明确标为 `created` 或 `updated` 的 HTTP(S) 资源现进入任务摘要的“输出”及完整输出列表，并可直接打开；同一资源若也被读取，仍按规则显示在“来源”。失败调用和纯读取资源不进入输出。

网页搜索实际打开的页面若已有独立来源条目，现从搜索的已打开页面中移除重复项；若没有查询和剩余网页，空的搜索条目不再展示。普通网页搜索打开、用户提供链接和 MCP 读取的相互关系均有回归覆盖。

本阶段覆盖资源输出、来源去重、摘要状态及真实本地 MCP 调用的 32 项测试通过；正式应用构建和严格签名检查通过。上述静态资源对照和自动化测试不代表 Codex 与 ShipiOS 的前台逐页、逐交互验收；Mac 锁屏仍阻挡可见检查。同一 MCP 资源 ID 变更 URL 后的跨地址合并及其他服务特定的无元数据结果推断仍未实现。
