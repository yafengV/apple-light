# 内容标签显示命令与两种窗口行为

日期：2026-10-09。接续第 712 篇，修正普通聊天工作区中 ⌘⇧B 被错误限制为浏览器的行为。

## 参考与差异

参考为已经保存的公开分发版本 **26.930.51102 / 13100**，`app-initial-f9b16fbf8fc7.js` SHA256 为 `22f3ea455585cfc0508e3d3627eac161c80c849c0aace3d76d09fdebaa0aeca3`。命令注册中的 `stepWorkspaceLayout` 使用 ⌘⇧B，`showWorkspaceTabView` 使用 ⌘⇧F。工具栏引用的实际布局动作分别为 `fwa` 和 `pwa`，不是仅选择浏览器。

`script/extract_workspace_visibility.cjs` 校验上述摘要，只执行实际布局函数及其状态分支，使用明确的 atom、惰性原生/动画/遥测适配，不初始化应用或 native bridge。参考结果保存在测试资源 `workspace_visibility_reference_713.json`，共 12 组连续三次命令状态，其中 10 组已有非空内容、两组初始无内容。两种窗口分别核对已有内容的 30 次转换。它不证明原生焦点时序、空浏览器丢弃、primary workspace 或前台页面配对。

| 状态 | 参考动作及本阶段实现 |
| --- | --- |
| 已有内容处于完整视图 | 转为普通分栏，继续显示同一内容 |
| 分栏内容可见 | 隐藏主内容侧栏，回到聊天，保留内容和选中身份 |
| 内容隐藏且有保留标签 | 恢复保留的选中内容；聊天仍保持焦点，不创建额外浏览器 |
| 没有主内容标签 | 创建一个分栏浏览器并给予内容焦点 |
| 空任务窗口执行完整视图命令 | 允许创建完整视图浏览器，与主窗口入口一致 |

## 实现范围

- 主窗口和任务窗口统一 ⌘⇧B 的内容语义。主工具栏也使用同一命令；既有内部 ID `browser` 保留，已有自定义快捷键无需迁移。
- 命令名称按同一公开分发的 `zh-CN-3ed9eb1db28a.js` 资源（SHA256 `c6ac10a9fb407a393ea002d9aa818a4c7ed0e215e9c8bf0cfe2b798a98e3756f`）改为“循环切换工作空间布局”和“完整视图”；英文默认名称前者为 `Show or hide tabs`，不能将自行翻译当作中文菜单配对。工具栏说明使用“显示或隐藏标签页”。仅隐藏标签栏的额外命令明确命名“显示或隐藏标签栏”，避免把不同动作写成同一个名称。
- 恢复范围只包括当前任务的主内容，排除其他任务、底部终端和分离内容。完整视图聊天返回时，优先最近主内容选中项，避免恢复陈旧的侧栏选中项。
- 恢复已有网页并保留聊天焦点时，不发布地址栏或网页焦点请求；浏览器对象保持原实例。隐藏后的持久布局可冷恢复，再执行同一命令恢复原标签。
- 非工作区页面不允许主窗口执行此命令。任务窗口保持自己的布局、资源和快捷键路由。
