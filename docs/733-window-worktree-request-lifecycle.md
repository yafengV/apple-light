# 任务窗口工作树请求的排队与导航身份

日期：2026-10-09。属于第 726 篇 R4／R7，处理创建动作排队到主线程之后、真正开始工作树创建之前的窗口变化。

## 实现

窗口工作树动作返回可等待的实际请求任务。每次接受请求记录独立请求身份、窗口身份、当前显示任务及导航修订；真正开始前重新检查全部身份与取消状态。切换任务、返回原任务、冷窗口路由改变或关闭，都使尚未开始的旧请求失效。连续排队只允许最后一次请求从其指定来源创建，完成回调也检查同一请求身份。

创建已开始后，返回或切换只离开准备页，任务仍可在后台完成；关闭继续取消请求与底层创建。已有创建执行时不接受另一动作，保留原取消句柄和回调。完成后释放请求任务引用，失败／取消页面继续保留身份，以支持原检查点重试。完成回调仍核对实际显示任务，不能强制导航到已经离开的聊天。

窗口路由在准备任务尚未建立目录面板时也显式更新导航修订，因此不能依赖显示任务是否已经赋值来检测冷窗口切换。
