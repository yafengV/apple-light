## 参考依据与边界

本轮读取此前固定的公开资源 `app-initial-f9b16fbf8fc7.js`，SHA-256 为 `22f3ea455585cfc0508e3d3627eac161c80c849c0aace3d76d09fdebaa0aeca3`；原分发版本 `26.930.51102`、build `13100`。没有绕过 Codex 的界面访问限制或初始化参考应用的原生桥接。

参考控制器 `FBn` 的实际迁移函数 `ee` 先拒绝 workspace home，再清理移动项的来源家族、移除标签并修剪 recent 列表。移动当前内容时优先最近使用的剩余内容，然后才取右邻／左邻；回选不再录入一次人工选择。接收端未指定锚点时追加标签。关闭仍沿用第 696 篇 opener／邻居规则，不能把迁移直接当作关闭。

`script/extract_content_transfer_reference.cjs` 校验资源摘要，提取并执行 `ee` 及其实际纯依赖；信号容器、布局修复与帧回调是显式惰性替身。生成 18 组参考序列，其中 17 组非 home 序列由 Swift 逐步重放，比较顺序、当前选择、最近列表、迁移返回值及完整来源家族状态。workspace home 拒绝序列保留在夹具中，但 primary workspace 尚未实现，不冒充已覆盖该页面。

另外确认：本固定资源中，`besideTabId` 的实际调用入口是 Spaces Pages 的并排打开；普通 WebKit 子页不能自动视为配对。Pages 分支的账号／功能可见性、配对伙伴完整生命周期和 primary workspace 继续未完成。

## 已实现的行为

| 动作／状态 | 实现与验证范围 |
| --- | --- |
| 移动当前内容 | 同任务、同内容集合内先回选最近使用的剩余项，缺少近期记录时才按右邻／左邻；普通关闭规则保持独立 |
| 源任务焦点 | 当前可见内容被移走时请求替代内容焦点；聊天已有焦点、隐藏面板或其他任务迁移时不抢输入焦点 |
| 接收任务 | 追加保存的标签和对应实例，更新目标选择、布局、底部／侧栏可见性；未访问目标也立即保存，不依赖先打开页面 |
| 冷恢复顺序 | 按保存的目标顺序重建；已经迁入的存活实例不会抢到原有未 materialize 标签之前 |
| 草稿转正式任务 | 重写选择、近期列表与来源家族中的 ID，保持原来源回退关系；这里只覆盖新任务目标的实际提升路径 |
| 文件身份 | 先把源路径解析为源项目／关联文件夹中的真实绝对位置，再验证目标范围；目标同名相对文件不会被误当成源文件 |
| 文件与终端实例 | 保留文件编辑器及固定标签引用的归属；终端保留原进程和 PID，只改变会话归属，不重启 shell |
| 失败前置检查 | 已移除目标、不可迁移的任务专属内容、范围外文件或不可用终端在切换项目／新草稿之前拒绝；保留当前工作区与草稿 |
| 显式浏览器激活 | 恢复曾以不抢焦点方式选中的同一浏览器后，显式打开仍产生新的原生焦点请求 |
| 原生展示容器 | SwiftUI 展示位置拥有独立容器，BrowserSession 继续拥有同一 WKWebView；未挂载或离场容器不会夺走已进入新窗口的网页 |
| 输入框自动聚焦 | 只阻止内容显式激活后迟到的自动请求；用户主动获得第一响应器仍可清除内容焦点，不禁用真实输入 |
| 地址栏 | 实际挂载时才登记字段；挂载前未完成的焦点请求在挂载后重试，旧请求、失效协调器、非活动窗口和弹窗保持隔离 |

任务专属计划、来源、PR／监控、后台命令输出和子任务继续保留原所属约束。本轮没有把它们改成任意可迁移内容，也没有实现独立任务窗口间的所有拖放／接收协议。

## 验证记录

本阶段最初的 7 项测试出现 26 条断言失败；文件身份专项 2 项出现 6 条断言失败。随后 96 项基础回归通过。增加完整原生根视图后，169 项中 5 条失败集中在目标任务挂载和地址栏焦点，失败轮保留。

原生追踪确认显式激活跳过聚焦、地址栏挂载前消费请求，以及侧栏换边时旧容器竞争共享视图。单独延迟创建的初版用例没有提前 materialize 控件，不能作为复现证据；补齐非零布局与实际字段存在断言后复现 1 条失败。后续 56 项修复轮仍有挂载／焦点失败，日志分别为 `.cache/content-transfer-container-repair-698.log` 与 `.cache/content-transfer-outgoing-editor-repair-698.log`；同步结束旧地址栏编辑没有解决问题，已撤销。
