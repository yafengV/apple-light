# 命令菜单分组与置顶任务

2026-09-26。本机安装的 Codex 客户端命令菜单资源显示置顶、最近和最近访问会话分区，以及会话、导航、面板、项目、配置、应用、技能等命令分组。ShipiOS 此前把除两项快捷操作外的命令全部放在单一“命令”组，并把置顶任务混入最近任务。现在使用现有命令的真实执行路径分组；首页先显示侧栏顺序的已置顶任务，再显示最近任务，搜索结果的命令也按组显示。没有对应真实动作的组不显示。

7 项命令菜单相关测试通过，覆盖分组、置顶顺序、置顶与最近结果不重复，以及既有搜索和导航行为。当前 Mac 锁屏，未完成两端菜单外观、焦点、键盘、悬停和滚动的实机对照；Codex 的完整命令清单及每项快捷键也仍待逐项配对。
