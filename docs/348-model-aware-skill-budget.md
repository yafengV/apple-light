# 按模型上下文分配技能目录预算

2026-09-28。此前技能目录已经能在预算不足时优先保留标识和路径、缩短描述，但始终使用固定字符预算，没有使用当前服务提供的模型上下文大小。本阶段接入模型目录信息，并匹配 Codex 的 token 预算选择规则。

依据本地 Codex 源码快照 `50d7795` 的 `ext/skills/src/render.rs` 和 `protocol/src/openai_models.rs`：已知上下文时，技能元数据预算为其 2%，至少一个近似 token；缺少有效上下文时回退到 8,000 字符。显式覆盖优先且最多使用 10,000 token。近似 token 成本采用 UTF-8 字节数除以四并向上取整，按完整目录行核算；通用技能使用说明位于元数据预算之外，与上游预算范围一致。

模型目录读取服务明确提供的正整数 `context_window`，支持相应 camelCase 字段；缺少有效值时可使用 `max_context_window`。不通过模型名称猜测大小。布尔值、字符串、非整数、零、负数及超出整数范围的值不能成为有效上下文。已有模型名称、可见性和推理等级信息保持原有读取方式。

模型选择弹层和自动化模型选择表单加载目录后，会把实际服务、协议及模型信息交给工作区。发送含可隐式调用技能的任务时，如果当前服务和协议尚未提供目录，则向当前独立服务读取 `/models`，整个探测最多三秒；不支持、格式错误或超时均回退到字符预算，继续会话。没有隐式技能或已有预算覆盖时无需该探测。失败结果在本次应用生命周期中复用，模型弹层刷新可重新提供信息。

目录缓存仅在 ShipiOS 进程内，按独立服务地址和协议隔离，再按本轮固定的模型 ID 查找。切换模型、服务或 Responses/Chat Completions 不沿用其他来源的大小。设置保存新凭据时同时使对应来源缓存失效；延迟返回的旧目录不能恢复已失效信息，取消请求也不保存探测结果。旧任务使用其实际协议和模型获取预算，运行中的请求仍使用提交时的配置快照。

独立高级覆盖字段是 ShipiOS 私有 `model.json` 中的 `skillMetadataMaxTokens`，缺省为空，兼容旧配置。值须为正整数；配置值大于 10,000 时实际使用上限 10,000。该覆盖对应上游可配置的技能目录 token 预算，保存在 ShipiOS 自有配置，不读取用户个人 Codex 的配置或登录状态。

任务保存本轮预算单位、限额、元数据成本、已提供与省略的条目数量，供后续诊断；模型实际收到的是同一份目录。目录仍先保留完整身份，再公平分配描述空间；UTF-8、JSON 转义、中文、组合字符和 Emoji 纳入成本核算。既有缩短/省略提示继续进入主窗口和独立任务窗口的会话时间线。

新增七项模型预算回归覆盖选择规则、覆盖上限及迁移、数字校验、Unicode 与序列化成本、当前模型选择、服务/协议隔离、未知目录回退、刷新、取消和凭据失效时的延迟响应。两种真实请求协议经本机 HTTP 模型服务验证：400,000 上下文产生 8,000 近似 token 预算并保留全部 17 项长描述目录；切回未提供大小的服务使用字符预算；10,000 上下文使用 200 近似 token 并记录省略。实际请求中的当前目录与本轮保存数量一致。

慢速目录服务超过探测期限后仍成功发送会话，取消探测在一秒内结束且没有模型回复或缓存残留。测试仅使用临时数据、本机服务和测试模型目录，不使用用户凭据。153 项技能、模型选择、插件、MCP 及真实 Core 提问相关定向回归通过，日志 `.cache/skill-model-budget-regression.log`；另有 4 项 HTTP 流式模型目录、重定向拒绝、异常响应及运行中模型选择回归通过，日志 `.cache/skill-model-budget-api-regression.log`。本阶段未重跑全量产品回归。
