## 实现

加入“提交或推送”“创建 PR”“创建草稿 PR”三个真实命令，进入现有提交/推送及 PR 流程。命令菜单只列出当前可执行的 Git 动作，按项目分组；快捷键设置可搜索并配置所有三个命令，包括备用绑定。没有猜测默认快捷键。

可用状态独立读取实际 Git 变更和本地推送跟踪引用。包含未跟踪文件，冲突不能启用提交；没有提交内容但尚有未推送提交或未发布分支时仍可打开推送选项。GitHub 读取失败不会让本地提交能力消失，菜单显示读取状态、失败信息与重新检查入口。打开菜单时刷新状态；菜单重查按钮参加 Tab/Shift-Tab 和 Return 导航。

普通默认分支、空且没有新提交的分离 HEAD、已有 PR 不提供创建命令；本地变更或新提交允许分离 HEAD 打开现有新分支 PR 流程。默认分支判断使用本地分支而非远端目标，保留三角推送配置的含义。附加仓库可以提交，但不查询或创建主仓库的 PR。

主窗口、独立任务窗口与分离审查窗口分别提供自己的命令上下文、状态读取和弹层承载。弹层不再依赖审查面板是否挂载。创建草稿只覆盖本次初始选择，关闭或下次普通创建恢复全局偏好；不会修改设置。接受操作时固定任务归属，任务目录变更、删除、仓库版本/范围改变及迟到请求均不能将旧命令落到当前主任务。

没有窗口上下文时不回退主窗口执行 Git 命令。原生菜单与按键使用同一资格；搜索、其他弹层、输入法组合状态以及 Git 忙碌期间受各自窗口保护。读取取消/失败结束 loading，项目重置清除状态和单次弹层选择。
