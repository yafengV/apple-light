# 独立任务窗口的 Codex 会话归属

2026-09-28。此前 Codex Responses 复用主工作区的 Agent 进程：独立任务窗口打开其他项目的任务时，发消息会因项目不匹配而失败；切换主窗口项目还会关闭原进程，打断仍在运行的模型回合。

Codex 会话现在按任务目录选择私有 Agent 进程。主工作区诊断和构建仍使用原 Agent；模型进程另用 `CodexAgents/<项目路径摘要>` 保存自己的运行数据库和独占锁，并沿用 `Projects/<项目路径摘要>/Codex/Tasks/<任务 ID>` 中已有的私有会话记录。主窗口切换项目或进入无项目页不再重置其他项目的模型回合。同一项目的并行任务共享已初始化的模型进程；任务移交到另一工作树或本地目录时，先关闭旧线程，再从新目录创建线程并带入已有会话上下文。应用退出时统一关闭模型进程。
