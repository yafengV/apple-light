# 归档类型、排序与项目菜单

2026-09-18。对照公开分发资源 `data-controls-177358ad1ff5.js` 的 `an`、`on`：类型和排序在同一菜单中平铺，各有分区标题和独立选中标记；项目菜单以分隔线区分全部项目、具体项目和无项目/计划任务。

## 实现

两处 SwiftUI Menu/Picker 改用共享 `SettingsDropdownMenu`。原生菜单支持不可选择的分区标题、分隔线、独立勾选、选项图标及路径提示；底层复用 `SettingsMenuControl` 的鼠标、辅助功能、Tab、空格、Enter 和方向键行为。触发器宽度调整为参考中的常规 144/176。

归档菜单内容由 `ArchivedTaskMenu` 生成。类型、排序、项目仍独立保存状态；同名项目以完整路径作为值，项目不再存在时回到全部项目。选项回调通过原生菜单项身份映射，不依赖显示文本。禁用、隐藏、空选项和卸载后的控件不能执行动作；普通数据更新不回写选择。
