# 回复链接的 macOS 14 兼容与辅助功能入口

2026-09-18。接续 [链接原生菜单](112-message-link-context-menu.md)，补齐不支持 SwiftUI TextRenderer 的系统路径。设置仍位于主窗口；没有新增 Settings Scene 或设置窗口。

## 实现

- macOS 14 中带链接且配置动作的段落改用可选择、不可编辑的 NSTextView。现代系统保留 TextRenderer 路径；没有链接的正文仍使用 Text。
- 两条路径共用链接菜单及动作路由：应用内打开、外部打开、复制、另存为。菜单固定创建时的网址，另存为在菜单关闭后调度。
- 兼容层通过实际字形定位链接，支持修饰键和中键点击。拖动取消点击后继续消耗该手势，避免将缺失 mouseDown 的 mouseUp 交给正文选择。
- 原生富文本保留粗体、斜体、行内代码、删除线、链接及查找颜色；标题、表头权重、引用颜色和行距单独传入。重新高亮保留选择，文本缩短时收敛选择范围。
- SwiftUI 与 AppKit 路径增加逐链接辅助功能动作，名称含显示文字及完整 URL。相邻样式 run 合并为一个链接，不合并被普通文字隔开的重复链接。
- 尺寸测量使用独立 TextKit 容器；零宽最小尺寸查询返回零，避免理想宽度污染真实换行或把主窗口撑高。

## 验证

55 项定向回归通过，日志 `.cache/message-link-legacy-tests.log`，覆盖外观、主窗口设置、通用设置、正文查找及两种链接实现。新增 4 项兼容测试包含 Markdown 转换、辅助功能名称、选择保持、强制使用兼容层的实际 AppKit 排版、菜单目标与拖动取消。

初轮测试发现理想尺寸污染实际布局，以及零宽测量抬高窗口最小高度；均修复后重新验证。240/420 点截图位于 `.cache/message-link-legacy-snapshots`，人工检查换行与高亮。测试不投递系统鼠标事件、不打开外部网页、不操作用户剪贴板。

应用构建日志 `.cache/message-link-legacy-build.log`，严格深度签名验证通过；使用原开发数据目录启动。原任务及待发送草稿存在性检查通过。
