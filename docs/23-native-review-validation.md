# 原生审查、撤销与导航验收

日期：2026-09-17。设备已解锁，本轮在真正的 macOS 应用中操作，未使用 iOS Simulator。以下只表示 ShipiOS 实测结果，不代表与当前 Codex 逐像素一致。

## 新增与修复

- 未暂存审查支持撤销单文件、撤销全部；确认框列出文件、恢复与移入废纸篓的数量。恢复以当前索引为基准，保留已暂存内容。
- 执行前重新验证状态快照，拒绝过期操作；覆盖 intent-to-add、重命名、冲突、子仓库与部分失败。未跟踪文件通过系统 API 移入废纸篓。已跟踪文件被撤销的未暂存内容不可由应用恢复。
- 修复原生验收发现的问题：右键代码文字曾弹出系统文本菜单，只有行号区域能添加评论。现在文字区域提供添加评论、在编辑器打开此行、复制此行；普通拖动选中文字仍正常。
- 分块按钮的辅助功能标签包含文件名和差异范围，解决多个“暂存此块”无法区分的问题。
