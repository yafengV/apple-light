# 任务菜单永久删除

普通侧栏与 Activity 共用的任务右键菜单新增“永久删除…”。它按任务 ID 打开主窗口内确认，不切换当前会话、不先归档目标。目标和确认请求 ID 固定；旧弹层回调不能确认或关闭新请求。取消保留任务、草稿、Activity 会话及当前页面，执行期间禁用取消和重复确认。

参考依据是此前缓存的 Codex 26.908.70816/build 9275 静态资源：`h6t` 在 Codex 模式的侧栏菜单加入 `delete-thread`，关闭菜单后打开 `DeleteThreadDialog` 并传入任务身份与焦点来源。这里沿用已有同窗确认组件，不宣称已匹配当前 Codex 删除弹层的精确布局或焦点。

## 停止、保存和清理

确认后保留固定目标，复用归档的真实停止流程：模型请求取消并等待任务句柄和活动状态结束，本地 Agent 通过 IPC 取消并查询终态。目标不能由队列、目标续轮或独立窗口重新启动；其他模型任务继续运行。句柄丢失、Agent 未连接、停止超时、工作区失效或保存失败时保留目标和确认框，显示错误并允许重试。

删除共用原有归档删除的持久化和附件清理，在候选快照中处理资格并一次性保存，不向运行中的界面或磁盘发布中间归档状态。删除会移除目标回合、草稿、队列、导航选择和侧栏固定标签；运行记录 tombstone 防止本地 Agent 的旧审计回合重新生成任务。其他任务的草稿、队列和固定标签保留。

托管工作树沿用真实 Git 登记校验、未完成移交和未传递来源修改保护。仍在磁盘的有效检出保留为独立项目，包含其跟踪和未跟踪修改；已清理的私有快照和保护引用沿原有持久清理队列处理。删除任务不删除普通项目或项目外输出文件。
