# Appshot 卡片布局与截图落点

当前 Codex 桌面资源中的历史 Appshot 卡片使用 232×140 的图像区域；截图按原始宽高比缩入这一区域并贴底，左右有 12pt 延伸空间，遮罩在 79% 位置降至约 21% 不透明度、底端透明，截图带向下的阴影。应用图标居中贴底；历史卡片额外有 10pt 顶部间距和窗口标题。

ShipiOS 此前让通用缩略图占满 232×140 框，宽截图实际停在垂直中部。现依据解码图片尺寸计算图像高度，把截图贴到固定高度容器底部，修正遮罩和阴影，保留底部图标。默认卡片不再强制填充背景，悬停时显示浅背景；普通图片沿用原卡片。

离屏原生渲染最初捕捉到宽截图仍居中的错误，固定容器高度后复查截图已贴底，并以像素行断言防止回归。相关测试、正式构建与签名见本阶段提交。Mac 锁屏使可见指针、焦点与 Codex 双端对照无法进行；输入区捕捉过渡动画仍缺，完整验收保持 **0/45**。
