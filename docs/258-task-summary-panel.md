# 任务摘要面板

2026-09-27。当前 Codex Mac 的本地会话页有标题栏摘要入口；窄窗口以浮层显示，宽窗口占用右侧布局空间。ShipiOS 此前没有相应面板。

主窗口和独立任务窗口现在都有摘要按钮与“切换任务摘要”命令，命令由当前窗口的任务接管。窗口较窄时显示标题栏浮层，较宽时显示约 316 点宽的右侧栏。关闭按钮收起当前窗口的面板。面板读取本任务已有的运行状态、最近一次计划、已记录附件和模型服务返回的真实 token 用量；没有记录的内容不补造。

`script/build_and_run.sh --build-app`、严格签名检查通过。命令分组、主窗口路由、独立窗口归属及设置导航相关的 30 项 Swift 测试通过。本机 Mac 仍锁屏，无法在两个 App 的真实窗口中验证按钮位置、浮层切换阈值、焦点、键盘和滚动；因此本阶段是功能实现及自动化验证，不计入 43 个完整配对验收面。Codex 的环境、触发器、后台任务、浏览器标签、PR、侧聊等摘要区块还需按实际数据能力逐项补齐。
