# 外部资源身份与跨地址合并

本阶段根据本机 Codex 桌面包 `26.911.61220` 的静态资源目录合并规则，使“来源”和“输出”共用一份任务资源目录。每个资源同时记录规范化 URL 与 MCP 服务作用域下的资源 ID；同一资源换地址，或多个记录由共同 URL 连通后，会合并为一个条目。活动仍按回合判断来源资格，创建／更新过的资源也会进入输出。最新地址用于打开，较新的描述性标题用于显示。

Google Docs、Sheets、Slides、Drive、Notion、Linear 和 Figma 的文档链接现在还能从 URL 提取稳定身份，因而不同编辑／查看地址可合并。对普通网址仍使用规范化 URL；包含账号密码的网址被拒绝。

已覆盖跨地址 MCP 身份、URL 桥接、常见服务链接、来源与输出一致性、摘要及本地真实 MCP 服务调用的 36 项相关测试；正式应用构建与严格签名检查通过。Mac 仍锁屏，静态资源与自动化测试不能代替 Codex 和 ShipiOS 的前台视觉、焦点及键鼠逐项验收。
