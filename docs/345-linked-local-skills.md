# 符号链接技能的发现与交互

2026-09-28。官方[技能文档](https://learn.chatgpt.com/docs/build-skills)明确支持技能文件夹的符号链接，并在本地发现时跟随目标。此前 ShipiOS 的项目来源会拒绝链接，私有目录会跳过未登记链接；已登记目录被替换成链接时也不能读取。本阶段补齐这项已记录的行为差异。

ShipiOS 私有 `Skills` 和适用项目的 `.agents/skills` 直接子目录现支持绝对、相对及多级文件夹链接。相对目标按链接所在目录解析。技能入口路径和所属项目保持不变，实际指令、界面配置与图标从目标读取；项目外的目标不会使技能自动出现在其他项目，也不新增个人 Codex 目录的默认扫描。损坏、循环或非目录目标不成为候选，其他有效技能继续显示；目标恢复后由自动刷新重新发现。

技能引用保留入口路径和来源标识，同时捕获实际文件路径。预览可显示链接目标，编辑器明确说明保存会修改哪个目标文件。读取编辑原文时同时保存实际路径，保存前核对目标与原文；外部更换链接目标，即使指令文字相同，也拒绝覆盖，重新载入后可以编辑新目标。资源文件和链接本身保持原样。基础聊天的按需读取检查本轮目录捕获的目标，过期目录不能读取更换后的目标；跨项目“立即尝试”也核对切换前后的实际来源。

私有技能的启停仍按入口标识持久化；项目技能按实际 `SKILL.md` 路径保存停用状态，同一目标的项目别名共享状态。跨项目浏览按实际文件去重并保留优先项目作为执行范围。卸载确认说明普通目录会删除目录和资源，而链接只删除入口；卸载的暂存和删除作用于链接本身，保留目标文件。已登记且目标丢失的链接也可以由存储管理移除并清理偏好。

来源监控现跟踪本地链接目标的指令、界面配置、图标及目标路径变化，更新列表、候选和预览；不会把插件包的任意链接递归扫描引入本地来源规则。私有技能根目录、项目 `.agents` 和 `.agents/skills` 根仍要求位于所属范围，导入插件/技能副本沿用原有包含关系检查；独立 `SKILL.md`、界面配置和图标文件的外链不因此变成有效资源。本阶段支持的是本地技能文件夹链接。

123 项相关定向回归通过，涵盖链接发现、相对路径、同名来源隔离、图标与配置读取/刷新、目标更换、编辑冲突、启停、共享来源去重、循环/丢失目标、卸载保留目标及现有技能与 MCP 流程。两种协议经本地真实 HTTP 模型服务验证：基础聊天读取私有链接并记录调用，Codex Core 使用原生文件工具读取项目链接的实际内容；目标路径包含空格和括号。测试仅使用临时数据及本地服务，不使用用户凭据。本轮未重跑全量回归。

`script/build_and_run.sh --build-app` 构建及严格签名检查通过。新增目标说明、编辑器、启停、卸载和原生双端焦点仍待实际验收。此前打开 ShipiOS 被自动审批因 Mac 锁定且无法自动解锁而拒绝，仍待用户手动解锁，本阶段未绕过限制。完整双端验收保持 0/43；在线来源目录、系统作用域、依赖配置、动态目录预算及各页原生配对继续待完成。
