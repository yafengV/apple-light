# 设置下拉菜单的键盘操作

2026-09-18。接续 [焦点分区修复](121-settings-focus-regions.md)，补齐六个设置菜单的键盘入口。

## 实现与参考

本机 Codex 26.908.70816（9275）公开资源中的 DropdownMenuTrigger 接受 Enter、空格及向下键，并在关闭菜单后恢复触发按钮的焦点。ShipiOS 原先的 SwiftUI Picker 在当前系统键盘偏好下会被 Tab 跳过；给外层简单添加 focusable 只能聚焦包装视图，无法操作菜单。

新增 `SettingsMenuPicker`，由实际 NSPopUpButton 持有原生焦点和菜单跟踪。已接入默认编辑器、发送快捷键、网页链接目标、终端位置、通知时机和基础主题。保留原绑定、保存逻辑、设置搜索及标签；原生菜单负责选项导航、取消与辅助功能语义。

禁用、隐藏、空选项及卸载后的控件不参与焦点或写入。重复选择当前值不重复保存；外部选项更新不会反向写入绑定，同名标签仍对应各自的值。禁用焦点释放延后到当前视图更新完成，并确认控件仍持有焦点。侧栏切页前明确结束旧原生菜单的响应者状态，避免它随后禁用时取消新的 SwiftUI 导航焦点。鼠标打开菜单时也先聚焦实际控件。
