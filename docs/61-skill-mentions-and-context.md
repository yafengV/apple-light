# 输入区技能选择与上下文调用

2026-09-17。在 [主窗口插件目录与本地包管理](57-plugin-directory-and-local-packages.md) 的 `@插件` 调用基础上，输入区增加更细粒度的 `$技能` 调用。设置和插件详情仍使用主窗口页面路由，没有增加独立设置窗口。

## 当前实现

- 插件加载时发现启用插件中的 `skills/**/SKILL.md`，从 frontmatter `name`、一级标题或技能目录名生成候选名称。发现结果保存在工作区状态中，输入每个字符时不会重新扫描磁盘。
- 在输入区行首或空白后键入 `$` 会显示技能候选；可按技能名称、标识、插件名称或限定标识过滤，支持鼠标、上下方向键、Return、Tab 和 Esc。
- 技能标识唯一时插入 `$技能`。两个插件具有同名技能时，候选自动使用 `$插件/技能`，避免静默选择错误插件。
- `$` 必须位于行首或空白后，因此金额、变量片段等内嵌美元符号不会打开候选。确认只替换当前尾部查询，不会发送消息。
- 发送时 `$技能` 只加载所选 `SKILL.md`；`@插件` 继续加载该插件的全部技能。两种调用同时出现时按文件去重。
- 运行记录分别保存 `plugins` 和 `skills`。自动化提示中的 `$技能` 使用相同解析、边界和元数据。
- 单个技能仍限制为 64 KiB，一次调用合计限制为 128 KiB；非普通文件、符号链接、无效标识和非 UTF-8 内容在安装或调用前拒绝。

## 测试证据

`PluginTests` 覆盖技能发现、frontmatter/标题名称、候选过滤、尾部替换、内嵌美元符号忽略、同名技能限定引用、歧义引用拒绝，以及只加载所选文件。

模型传输集成测试通过本机 HTTP fixture 验证：system message 包含所选技能且不包含同插件的另一个技能；user message 保持 `$技能` 原文；运行记录同时包含插件标识和技能标识。

完整回归通过 327 项 Swift 测试、12 项 Rust 测试、Rust fmt/Clippy 和真实 Agent IPC 冒烟，日志为 `.cache/skill-invocation-full-tests.log`。

## 验收边界

当前 macOS 会话处于锁屏状态，无法对候选浮层、键盘焦点、鼠标悬停和主窗口往返做本轮可见验收。此功能的编译、状态和真实请求路径已有自动化证据，但不能据此声称与当前 Codex 桌面客户端逐像素或逐焦点一致。

插件 MCP、浏览器扩展、钩子、远程目录、账户授权和完整 Codex Core 工具生命周期仍未实现。
