# `/local` 本地项目命令

2026-09-28。[Codex 官方斜杠命令参考](https://learn.chatgpt.com/docs/reference/slash-commands)将 `/local` 定义为在所选本地项目运行聊天；[工作树说明](https://learn.chatgpt.com/docs/environments/git-worktrees)描述了现有聊天从托管工作树移交回本地检出。

ShipiOS 现在为两种场景提供输入区和命令菜单入口：在已选本地项目的新任务输入 `/local`，将该项目的执行选择设为本地；在已有且空闲的托管工作树任务输入 `/local`，使用现有 Handoff 将同一任务与代码移交回来源项目。独立任务窗口操作自己的任务，不借用主窗口当前选择。没有所选项目或任务不符合移交条件时，命令不可用，不会作为普通模型提示发送。

17 项命令相关测试、1 项真实 Git 脏检出移交测试、原生应用构建及签名检查通过。原生点击、焦点、工作树冲突提示及当前 Codex Mac 双端配对仍待桌面解锁验收。此入口不改变 43 个完整配对验收面的计数。
