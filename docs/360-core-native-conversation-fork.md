# Core 完整历史分叉与真实会话路径

日期：2026-09-28。普通侧栏、Activity、主会话及独立任务窗口共用的分叉，现可为有完整来源身份的新 Core 回合使用原生历史分叉，保留工具调用、工具输出、上下文与事件。复制聊天文字的兼容方式不再代表这些 Core 分叉的行为。

## 参考与固定边界

实现依据是项目固定的 Codex `50d77959bf927293c4b5ddcca81d05331ae582ea` 的 `ThreadManager.fork_thread_from_history`、`InitialHistory` 和 canonical rollout parser。旧 Codex 桌面缓存资源 `a3t` 使用会话分叉接口，是菜单入口的静态参考；本阶段仍没有当前 Codex Mac 的原生双端配对证据。

真实 Core 回合的 UI 记录新增线程 ID 和回合 ID，任务保存实际传输工作目录。分叉捕获来源身份及所选已结束回合边界，重启后仍固定该边界。Agent 从来源私有 rollout 精确读取到对应 `TurnComplete` 或 `TurnAborted`，通过 Core 的原生分叉创建新的线程和 rollout；之后恢复子线程，不再次复制来源。结束事件发布前刷新真实 rollout，避免 UI 已结束而分叉边界尚未持久化。

来源后续已结束回合和正在运行的后缀均不进入子线程；不会截断或停止来源。历史分叉、尚未首次续聊的嵌套分叉、已生成子线程后从祖先旧回合再分叉及再次嵌套均保留准确的来源与边界。真实回归发现子线程保留祖先 `SessionMeta`，现以文件首条元数据验证所属线程，完整保留合法祖先记录，避免多层历史分叉误拒绝或退回文字重放。子线程首次发送只追加本轮输入，不重复重放整段 UI 历史；来源权限、回复和搜索设置随线程保存，子任务的当前模型、独立认证和目录由其传输提供。

## 私有目录与路径修复

跨工作目录来源由已捕获的传输路径定位到 ShipiOS 私有 `Projects/<digest>/Codex/Tasks/<UUID>`。验证任务与线程身份、绝对工作区、私有根目录、引用和 rollout；拒绝改变的线程以及逃出私有目录的文件/目录链接。API 参数没有接受任意来源 rollout 文件路径。

真实无项目回归发现 Foundation 与 Rust 会把同一 macOS 临时路径分别表示成 `/var/...` 和 `/private/var/...`，重新哈希规范化路径会找错来源目录。现使用来源传输保存的路径拼写计算其已有目录哈希，实际目录与范围仍按规范化路径校验；路径别名已纳入 Rust 回归。

「复制会话记录路径」此前仅读取旧根目录和 snake_case 字段，无法定位当前项目传输真实生成的 camelCase 引用。现按任务实际工作目录定位项目私有文件，包含无项目任务；兼容旧目录和旧字段，不跨实际工作区回退到其他引用。
