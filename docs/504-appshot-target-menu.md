# Appshot 菜单目标呈现

本机 Codex Mac 客户端 26.911.61220 的输入区附件菜单在有可用目标时显示 “Attach {appName}” 并使用应用图标，无目标时禁用。ShipiOS 现在在菜单展开时检查最近使用的其他应用是否仍有可截取的常规窗口；有目标时显示“附加〈应用名〉”和应用图标，点选后使用该窗口身份截取。无目标时菜单项禁用；命令菜单与快捷键仍可进入 macOS 单窗口选择器。已点选的目标若失效，操作也回退到该选择器。

主输入区、独立任务窗口和弹出窗口共用菜单组件，图片数量达到上限时禁用对应入口。命令菜单和快捷键仍使用通用截图名称。现有窗口过滤规则与捕捉路径保留，不依赖菜单文字推断应用。

本阶段 35 项相关测试、正式应用构建及严格签名检查通过；无目标禁用状态在第 505 篇补齐。Mac 锁屏仍阻止真实菜单打开、图标、焦点、捕捉动画及 Codex 双端交互验收，完整配对保持 **0/45**。
