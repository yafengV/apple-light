## 实现

真实 Git 检出、来源文件和环境初始化完成后，已有原生历史的 Responses 聊天立即创建实际 Core 子会话。Core 确认的子线程身份、历史目录和解除准备状态在同一次工作区写入中保存；返回的任务取最新已保存记录。创建动作不发送模型回合。导入文本历史及 Chat Completions 保持既有上下文路径，不称为原生克隆。

任务保存是否必须原生创建，并在 Git 等待前捕获模型选择及运行权限；来源原生身份改变时拒绝继续。创建期间的新草稿及其他最新记录保留。Core 拒绝、无效确认、取消或最终保存失败时，断开未发布子连接，保留同一任务、工作树、固定历史和已完成环境，继续创建不重新复制来源或运行成功的初始化脚本。

Agent 在独立私有线程引用中保存尚未发送首轮的分支来源。最终保存中断或重启后，仅相同任务、来源线程、目录和回合边界能恢复同一个 Core 子线程；响应明确标识已验证的分支恢复，不能把任意普通恢复当成原生创建。首轮提交及整理上下文前消费该记录，此后不再接受创建重试。正常新会话没有此记录，不要求其延迟生成的历史文件已经落盘。
