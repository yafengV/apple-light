# PR 溢出表格的窗口内展开预览

后续普通表格区域焦点、复制滚动保护与展开/预览无障碍角色见[第 597 篇](597-pr-comment-table-scroll-region.md)。

日期：2026-10-04。接续第 595 篇，在普通 PR 表格实际横向溢出时显示展开入口，并把预览放在来源窗口内。完整前台双端验收及字体像素对齐仍未完成。

## 参考与行为

参考版本 26.930.21537 的公开 `LJc`：普通表格只有 `scrollWidth > clientWidth` 时提供展开；复制和展开共用工具栏，两枚 36 点按钮、4 点间隔、2 点边距，整体 80 × 40。展开按钮具有对话框及展开状态语义，悬停或内部焦点时可见。表格内容和视口变化重新测量；展开入口隐藏前清理旧焦点，防止已隐藏控件保留键盘响应及布局循环。

`LJc` 使用共享 `HKc` 图像对话框框架，但 `previewContent` 替换图像，关闭下载和缩放控件。本地实现通过 `WindowDialogHost` 把表格预览加在所属窗口内容之上，保持原工作区，不创建 sheet 或另一个窗口。90% 黑色遮罩、右上 40 点关闭按钮、32 点内边距、1 点边框、20 点超椭圆圆角和 80% 最大宽度按公开 CSS 实现。外层顶部 48、底部 52，窗口宽度达到 640 时两侧 32，否则 16；居中面板按表格自然尺寸缩小，并受可用高度限制。

预览保留完整表格、双向滚动、可选择文字及原链接路由。底部和尾侧各有 8 点不拦截输入的遮盖，减少文字贴边；表格文档不放入复制/展开工具栏。预览新建 Markdown root，字号从聊天字体和代码字号得出，表格不继承普通 PR 小号容器的等宽数字。**当前 `eUc` 预览调用没有传 `stickyHeader`，因此不固定表头**；不能仅凭 CSS 中存在固定表头类就额外启用。

初始焦点在关闭按钮，Tab/Shift-Tab 在关闭和滚动区域循环；点击可选择正文时保留原生文字选区及焦点。方向键、翻页、Home/End 和空格可滚动当前区域，不移动另一个轴。关闭按钮在空格松开时触发，Esc、⌘W 与遮罩点击关闭；面板内边距点击不会关闭。关闭恢复来源焦点，背景工作区命令受所属窗口的模态范围保护，其他窗口不受影响。卸载、窗口迁移和旧回调继续使用公共宿主的身份保护。

PR 图片加载器与头提交版本环境也传到新建的预览宿主，版本改变重新加载；表格媒体单元包含 PR 相对图片，不再只识别普通媒体。复杂媒体自然尺寸与混排仍需继续验证。

## 证据与未完成项

公开 CSS 及 `LJc/HKc/eUc` 结构重建在临时 loopback 页面中，未加载 Codex 前端或用户状态。CSS 层顺序在样式表加载前明确为 theme/base/components/utilities，聊天字号显式为 14/12，并补全边框颜色变量。缺少这些变量时边框无效，会误把二十条分隔线当作不存在。
