## 对照依据

本机 Codex 的 `mcp-tool-item-content-7382fa98d0b0.js` 中，`Wn` 组件分别处理图片、音频、资源链接、嵌入资源、未知内容与纯文本。图片进入预览，音频提供原生播放控件；文本是带标题的滚动纯文本区，不按 Markdown 或 HTML 执行。该页面也为结构化结果和原始输出提供独立显示。

内容类型遵循 [MCP 工具结果规范](https://modelcontextprotocol.io/specification/2025-11-25/server/tools)：`content` 包含类型化内容块，`structuredContent` 单独保存结构化数据，服务可能同时返回等价的 JSON 文本以兼容旧客户端。

## 当前行为

- 文本：保留原文、选择、复制与独立滚动，不将工具文本渲染成网页。
- 结构化结果：格式化 JSON；只省略与结构化结果等价、且没有独立注释的重复 JSON 文本，保留解释性文本。
- 图片：解码实际 Base64 图片数据，显示缩略图；点击打开当前窗口所属的预览弹层，支持缩放、拖动滚动条、适应窗口和 Esc 关闭。
- 音频：在内存中解码，提供播放/暂停、进度拖动和时长；不自动播放。折叠卡片、离开任务页面或移除视图时暂停或停止。
- 资源链接：显示名称、URI 和说明，不自动请求 URI。
- 嵌入资源：显示 URI、MIME 类型、文本或 Base64 内容，以及注释。
- 未知类型与无效内容：保留可读的原始表示；旧错误字符串仍直接显示。
- 原始输出：原有完整输出弹层保留，所有原始数据继续存入任务历史。

媒体预览最多解码 8 MiB，图片最大预览边长为 4,096 像素。无效数据或不支持的编解码器在卡片内显示错误，原始输出仍可访问。读取服务器结果不启动浏览器、不自动打开本地资源，也不调用其他服务下载内容。
