# 文件末尾的选区审阅与滚动

行内审阅最初只在选区后还有代码行时扩大文本布局。选中没有末尾换行的最后一行时，审阅块虽被加入编辑器，却没有增加文档可滚动高度，底部控件可能被裁掉。

现在 TextKit 为这种末尾行扩大行片段，文本视图同步扩展文档高度；新建议出现时滚动到完整审阅块。关闭或返回修改要求后，末尾额外高度移除。文件内容、选区和原生撤销路径不变。

隐藏原生窗口测试覆盖末尾行审阅的完整可见范围、文档高度、关闭恢复及原文保持。文件编辑、工作区和语法高亮相关 **51 项**测试通过。`script/build_and_run.sh --verify` 完成正式构建和启动，严格深度签名通过；前台工具仍明确报告 Mac 锁屏，因此工作区可交互检查和 Codex / ShipiOS 双端操作配对仍未完成，完整验收保持 **0/45**。
