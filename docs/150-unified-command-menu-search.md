# 根命令菜单的最近任务与统一搜索

2026-09-18。补齐此前根菜单只列命令、必须另开任务搜索才能查找会话的差异。

## 对照依据

公开静态资源 `app-initial`：

- `yAo` 在空查询根菜单显示 `RAo` 最近任务、快捷操作和命令；有查询时在命令后加入 `MAo(presentation: quick)` 的任务结果。
- `dwo` 对根菜单使用去除两端空白后的查询长度：2 个 UTF-16 单元起检索任务元数据，3 个起包含正文，结果上限 9。`ajo` 为 7。
- `$ko` 依次优先未读、最近访问、更新时间，排除当前任务并去重。`njo` 中的快捷操作为新任务、打开文件夹。
- `Back to commands` 仅在 root 的命令下一级选择栈存在时出现；files/chats 模式本身不会因此获得返回按钮。`qwo` 的 Tab 跳转针对带搜索分组标记的聊天/浏览器结果，不是所有命令分类。本轮没有给独立文件/任务搜索添加无依据的返回行为。

## 实现

- 根菜单显示“最近任务 / 快捷操作 / 命令”，输入后显示匹配的命令和任务分组。任务行显示项目、来源、摘要和高亮，与专用任务搜索复用同一组件。
- 查询长度门槛、7 条最近任务、9 条任务搜索结果按上述资源实现。两字符可查标题、项目和分支；三字符起查消息、回答及已有本地执行历史。
- 最近任务排除当前任务、归档任务和尚未发送的独立窗口草稿；未读优先，其后按访问记录和更新时间排列。
- 新增工作区内 `recentTaskIDs` 持久化，兼容缺少该字段的旧数据。主窗口选择和独立窗口展示记录访问；从旧工作区首次切换时也补记原任务。删除归档任务会清理相关访问记录。
- 命令和任务使用带类型前缀的选择 ID，方向键跨分组选择并跳过不可用项。任务结果仅在查询版本匹配且搜索已完成时可选，避免快速改词后回车打开旧结果。
- 直接从根菜单打开任务，沿用跨项目切换、未读清理和草稿聚焦；命令执行仍经过专门的可用性检查。

## 验证

- 最终 60 项相关测试通过，覆盖查询门槛、元数据与正文区分、最近任务排序/过滤/上限、旧格式兼容、访问持久化、归档清理、草稿保护、搜索、命令、任务窗口与页面导航。日志 `.cache/unified-command-search-tests.log`。
- 原生根菜单在同一标准窗口内展示最近任务和快捷操作；当前 B 不出现在最近任务中。
- 查询“主窗口”直接得到 A，回车跨项目打开 A 并保留草稿。查询 `la` 无正文结果，改为 `lat` 后显示 4 条带高亮的消息摘要；方向键选中 B 后打开正确任务和草稿。
- 查询“任务”同时出现命令与任务分组。换为无匹配查询后立即回车保留空结果，没有打开上一批任务。
- 访问 A 再访问 B 后，最近任务首项为 A；重启后顺序保持。
- 初版新增的 SwiftUI `onHover` 会在列表挂载时覆盖默认选择，导致未移动鼠标就执行屏幕外的侧栏命令。已撤下该处理，最终截图确认 A 默认高亮，回车确实打开 A；悬停选择仍列为待对齐项。
- 最终回归“设置”查询，立即 Down/Enter 仍正确打开主窗口内设置。隔离 A/B 草稿保持，未发送模型请求。
- 最终脚本恢复原工作区，确认原任务和未发送草稿可交互，严格签名检查通过。缓存、运行数据、日志不提交。
