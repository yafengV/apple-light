# 归档筛选、排序与项目操作

2026-09-18。对照本机 Codex 静态资源 `data-controls-177358ad1ff5.js` 的归档页及 `app-primary-4af6ed7f68d1.js` 的归档投影函数：默认按项目分组，项目筛选后显示单列表；筛选栏包含类型与排序菜单、项目菜单，标题区的全部删除不受当前搜索缩小。

## 实现

- 增加所有项目、具体项目、无项目任务和计划任务筛选；相同名称的项目以完整路径区分身份。项目菜单保留已知项目，失效的项目筛选回退所有项目。
- 增加全部/本地/云端类型筛选。ShipiOS 当前任务均为本地执行，使用远端模型 API 不会被误标为云端任务；云端筛选当前为空，不代表已支持云任务同步。
- 增加更新时间、创建时间和名称排序。所有项目下按项目分组，项目组按其最新相关任务时间排序；项目筛选后按任务排序。相同键使用稳定的标题与 ID 次序。
- 行信息改为任务更新时间，删除按钮放在恢复按钮之前；分组显示项目名与数量，项目操作菜单提供当前分组任务的批量删除。
- 搜索/筛选栏保持顶部固定，窄视口自动换行。归档为空时显示空状态，不展示无效的筛选栏。
- 单条、项目分组及全部删除在打开确认时固定任务 ID。确认后重新检查归档资格：后来新增的归档任务、已恢复任务、其他项目和未提交的窗口草稿不会被扩大删除范围。
- 恢复任务采用候选工作区保存后提交；保存失败保留原归档状态并显示错误。成功后提供查看入口。

## 时间数据

任务新增可选创建/更新时间，旧 JSON 继续可读；从已存在的运行记录归集时间并在历史同步时持久化。新建窗口任务、技能试用和待提交审查任务记录创建时间；明确重命名更新任务时间。分叉任务使用自身创建时间，复制来的历史不会将其创建时间倒退。

缺少运行记录且从未记录时间的历史任务显示“时间未记录”，不把归档时间冒充创建时间。投影合并当前运行和持久化运行，以较新结果为准。
