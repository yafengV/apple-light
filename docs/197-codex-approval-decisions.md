# Codex 审批选项与快捷键

2026-09-26。Codex Core 的命令审批事件可附带 `available_decisions`。此前 ShipiOS 固定展示“允许本次”和“拒绝”，即使本轮只提供会话级批准或其他上游决策；审批快捷键也没有按可用选项限制。

现在命令卡片从事件读取 `approved` 与 `approved_for_session`，分别展示“允许本次”和“在本任务中允许此工具”。没有提供的批准方式不显示，键盘、焦点菜单和命令入口均不可绕过；拒绝仍可执行。缺少决策列表时使用保守的本次批准与拒绝。补丁审批保留本次批准与拒绝。若 Core 只提供当前版本未实现的批准类型，卡片明确说明，并保留拒绝入口。

本地 Agent 假模型回归覆盖本次批准、会话级批准、拒绝及无需审批的项目内写入。Rust 测试核对固定协议中 `approved_for_session` 的序列化；Swift 回归覆盖选项解析、禁用项、快捷键和任务焦点路由。与上一阶段共用的 Swift 审批卡片集成回归及应用构建通过。

尚未覆盖 execpolicy、network policy 等上游特殊批准决策，补丁审批的真实模型端到端验证也未完成。桌面自动化接口持续超时，无法将本阶段记作与当前 Codex Mac 客户端的原生 UI 配对验收。
