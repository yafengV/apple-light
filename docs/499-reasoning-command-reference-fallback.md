# 推理强度命令的 Codex 回退与边界行为

对本机 Codex Mac 客户端 26.911.61220 的静态命令实现继续核对：模型目录没有当前模型记录时，命令仍使用 `minimal → low → medium → high → xhigh → max` 的回退列表；缺省推理档位归一为 `medium`。提高与降低在边界保持当前档位，命令入口仍存在；循环在末档回到首档。上阶段 ShipiOS 因缺少服务能力元数据或遇到边界而禁用命令，与这一行为不符。

ShipiOS 现保留服务明确声明的档位顺序，模型弹层和提高、降低、循环命令共用该顺序；缺少能力记录时使用上述回退列表。命令仍要求已配置有效 API 地址及模型；达到边界时不重复写入任务或默认模型选择。独立任务窗口只修改自己的模型选择。高级档位的“显示”设置只影响模型选择器，不删除命令可用的服务档位。

验证：62 项模型选择、命令菜单、快捷键、任务窗口与模型元数据相关测试通过；补充空档位边界后，14 项模型选择测试再次通过。正式构建、严格深度签名及差异检查通过。Mac 锁屏时不能验证原生窗口交互，Codex 双端逐项验收仍为 **0/45**。
