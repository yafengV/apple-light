# 自动化多项目选择与运行

[OpenAI 官方 Scheduled tasks 文档](https://learn.chatgpt.com/docs/automations?surface=app)说明同一独立计划任务可以在多个项目中运行。ShipiOS 自动化编辑器现可勾选多个已保存项目，“无项目”与项目选择互斥。旧版单项目记录无需迁移文件即可继续读取；新记录验证项目列表无重复、排序一致，且主项目与列表一致。

到期或手动运行时，所选项目按顺序各创建一个独立任务；每个结果都进入运行历史与待审查记录。单个项目启动失败会继续尝试其他项目，并在页面显示各项目错误。全部项目尝试后才安排下一次运行。

验证：21 项自动化单元测试；本地 HTTP 夹具的两个项目独立请求测试、既有单项目运行记录测试、Codex Core 单项目工具执行回归，共 3 项集成测试通过。原生应用构建与签名检查通过。Mac 锁屏，项目勾选、滚动、键盘焦点及 Codex 双端页面对照仍未验收。工作树模式和中断后的逐项目继续运行随后见[第 320 篇](320-automation-managed-worktrees.md)；退出应用后的调度仍缺。
