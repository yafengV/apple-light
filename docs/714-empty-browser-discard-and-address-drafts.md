| 行为 | 当前实现及验证范围 |
| --- | --- |
| 普通分栏隐藏唯一空白网页 | 主窗口和任务窗口移除浏览器实例，保留聊天及 split 模式；再次显示创建新页 |
| 主内容存在多个标签或空白页已固定 | 保留内容；固定检查按窗口及任务归属执行 |
| 地址栏输入后清空 | 仍存在草稿，不按初始空白页丢弃；明确取消地址编辑后才清除标记 |
| 有导航、加载、历史、缩放或正在使用的浏览器状态 | 已实现的状态参与保护；不把未实现的参考状态视为已覆盖 |
| 自动丢弃与主动关闭 | 自动丢弃不写浏览器或内容标签的关闭历史；先前主动关闭的页仍可重开 |
| 任务／窗口隔离 | 仅检查当前任务主内容，其他任务浏览器、底部和分离内容不参与唯一页判断 |
| 冷恢复 | 新格式独立保存草稿存在状态；旧格式及既有直接地址写入按地址与已提交 URL 推断；已提交网址单独恢复，不提交草稿 |

原生地址栏的实际文字变化回调写入草稿标记，单纯聚焦不创建标记。保存布局时兼容原有直接写入 `address` 的调用方式，避免新字段显式 `false` 使旧草稿在网页加载后被同步 URL 覆盖。自动丢弃原因贯穿 `BrowserSession`、主内容关闭回调和任务窗口关闭回调；普通关闭默认行为不变。
