# 新建本地环境后的项目选择

2026-09-26。本机 Codex Mac 的本地环境编辑器在首次保存新配置时，还会为正在编辑的项目选择该环境。ShipiOS 以前只保存 TOML，原有当前环境和新任务默认环境可能保持旧值。现在保存新环境后将其设为对应项目的当前环境及后续新任务默认环境；编辑已有环境不会擅自改变选择。跨项目保存仅更新目标项目的配置记录，不切换当前任务、草稿或主工作区。

真实 Agent 集成测试覆盖在其他项目和当前项目分别新建环境、保存、选择及保持原任务草稿。项目列表刷新失败时会报告“文件已保存但无法选中”，避免把部分成功描述为完整成功。相关测试和签名应用构建通过；当前 Mac 锁屏，页面与键盘交互仍未和 Codex 原生窗口配对，43 个验收面完整配对数仍为 0。
