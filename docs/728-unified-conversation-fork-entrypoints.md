# 聊天分支入口统一原生创建流程

日期：2026-10-09。属于第 726 篇 R4，延续第 727 篇菜单即时创建，处理本地／同工作树的主聊天、历史消息、任务窗口、浮窗、命令面板与 `/fork` 入口。

## 实现

各入口共用异步创建、等待提示、来源校验、保存和清理流程。已有原生历史的 Codex Responses 聊天先创建实际 Core 子会话，获取有效确认后保存；创建动作不提交模型回合。历史消息传入精确回合边界，嵌套分支使用实际子会话历史。非原生导入历史及 Chat Completions 保留文本上下文路径，不能称为原生克隆。

主窗口在发起操作时捕获聊天身份和原始命令；异步任务尚未启动时若已切换聊天，不创建另一聊天的分支。历史按钮按点击回合的前缀判断可用性，后续历史尚未加载时仍可创建已有完整前缀的分支；最新历史菜单继续保持不可用。`/fork` 只有保存成功且来源输入仍等于捕获的原命令时才清空；启动前或等待期间的新输入保留。不可执行的命令显示原因并保留原输入。

独立任务窗口和浮窗的等待／失败提示显示在发起窗口，创建本身不切换主窗口的任务或返回历史。窗口关闭或更换聊天取消尚未发布的操作；已取消的任务在启动前即退出。真实原生创建后的取消、来源变化和保存失败仍只停止未发布子会话，不中断来源聊天。任务窗口导航前额外核对显示任务及资源实例，防止迟到回复打开错误页面。

主菜单、任务窗口菜单、命令面板及 slash 选择项使用“创建聊天分支”；同工作树目标沿用“在同一工作树中创建聊天分支”。已保存但暂时打不开项目的分支保留在侧栏，并提供具体错误，避免反复创建。
