# 任务摘要的会话文件与可搜索输出

2026-09-27。任务摘要“输出”区块现在除了诊断、构建的运行目录及标准文件，还索引助手回复中链接的本地文件。只有文件仍存在、并且真实路径落在该轮工作区内部时才显示；仅出现在用户输入或代码块中的链接、缺失文件、越界路径、指向工作区外的符号链接及网页引用不会被当成输出。助手引用已有项目文件时也会出现在此处，因此列表表示“回复所链接的文件”，不保证文件由本轮新建。后续文件打开方式见[第 269 篇](269-task-output-in-app-preview.md)。

“查看全部”在原摘要面板内打开可搜索的输出列表，支持返回摘要、刷新现存会话文件、打开运行目录和文件，以及预览已知日志。主窗口和独立任务窗口共用这一实现。

Codex Mac 的 Outputs 还包含其他生成资源和网页结果，也有创建文件/站点入口；这些仍需接入真实数据来源。当前页面的视觉、键盘焦点和双端原生交互尚未配对。
