# 外观与终端位置按钮组

2026-09-18。接续 [追加消息按钮组](124-follow-up-settings-buttons.md)，根据具体设置的参考实现修正控件类型。

## 参考与改动

本机 Codex 26.908.70816 的公开 `general-settings` 资源中，差异标记、减少动态效果和默认终端位置都使用 `segmented-toggle` 独立按钮组。选项顺序分别为颜色 / 加减号、系统 / 开启 / 关闭、底部 / 右侧。

ShipiOS 的两个外观选项从原生分段 Picker 改为 `SettingsSegmentedPicker`。默认终端位置从此前实现的下拉菜单改为同一按钮组，并更正选项顺序。第 122 篇记录的终端菜单操作是历史实现，不能作为该控件与参考一致的证据；本次实现替代它。

按钮选项增加独立辅助功能名称，差异标记不再只朗读颜色或符号。组件使用原始 Button 的同一动作处理鼠标、键盘及辅助功能激活，先聚焦再选值。原先仅在 PrimitiveButtonStyle 内增加聚焦，会被辅助功能激活绕过，实测已复现并修正。原绑定、偏好保存及终端路由保持不变。

- 最终 22 项相关测试通过：8 项外观、6 项设置布局、7 项桌面偏好与功能、1 项真实终端位置快捷键路由。日志 `.cache/settings-segment-activation-tests.log`。这不是完整产品回归。
- 项目脚本在原工作区完成构建运行，严格签名检查通过，日志 `.cache/settings-segment-activation-build.log`。原任务和草稿恢复，无持续加载遮罩。
- 外观页滚动到可见控件后，辅助功能点击颜色按钮正确取得焦点；Tab 到加减号不改值，空格选中，Shift-Tab / Enter 恢复颜色。
- 继续 Tab 依次进入跟随系统、开启、关闭；空格和 Enter 可激活。反向导航后恢复跟随系统。实际截图检查按钮组和焦点框正常。
- 实际鼠标点击颜色按钮取得焦点；切回通用页，侧栏焦点正常。
- 终端按钮从底部 Tab 到右侧，焦点移动不改值；空格选中右侧，Shift-Tab / Enter 恢复底部。没有创建或移动真实终端。
- Esc 返回原任务及原草稿。
