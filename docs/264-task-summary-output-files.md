# 任务摘要输出文件

2026-09-27。Codex Mac 的任务摘要 Outputs 区块逐项列出可打开的结果。ShipiOS 原先只显示本地诊断和构建运行的产物目录。现在“输出”区块在每次运行目录下列出 Agent 明确写入且当前存在的 `stdout.log`、`stderr.log` 和 `build.xcresult`。日志在所属窗口的只读弹层中预览，可复制并在 Finder 中定位；大日志只读取前 1 MiB。结果包交给系统打开，运行目录仍可在 Finder 中显示。

条目仅从运行结果里的产物目录和 Agent 固定文件名生成，不将任务输入附件或普通源码文件算作输出；符号链接越过产物目录的文件不展示。文件删除后再打开会给出读取失败和重试入口。

验证：`script/build_and_run.sh --build-app` 构建成功；7 项摘要相关测试通过，覆盖固定文件识别、读取上限和目录外符号链接。Mac 锁屏阻止了弹层点击、复制、焦点与 Codex 双端视觉配对；会话生成的其他文件/网页结果仍需后续索引。
