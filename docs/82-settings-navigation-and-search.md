# 设置导航、搜索与键盘切页

2026-09-18。本轮直接复核本机 `/Applications/ChatGPT.app/Contents/Resources/app.asar` 中设置导航组件 `mn` 的实现，而非仅凭翻译键推测行为。

后续更正：进一步检查实际可见性过滤，发现插件页启用时技能和 MCP 不作为独立侧栏项。现已合并为一个设置页内的标签，详见 [合并插件设置导航](83-combined-plugin-settings.md)。下面的 24 页统计是合并前记录；当前为 22 个顶级设置页、24 个兼容路由，94 个静态控件或区域目标仍保留。

## 对照依据

- 折叠按钮和“返回应用”按钮在纵向容器中依次排列。
- 分组顺序为个人、集成、编码、归档；Hooks 和连接属于编码，电脑使用、MCP、插件和浏览器属于集成。
- 展开状态显示搜索框；折叠后隐藏搜索和分组标题，保留图标、选中状态与标签提示。
- 导航项拥有焦点时，上下方向键移动焦点并选择相邻页，不循环越过首尾。
- 搜索支持方向键选择结果，Return 打开，Escape 清除搜索；没有自动选中第一条。

## 实现与修复

拆出 `SettingsNavigationView` 和独立导航目录。修复原来 68 点折叠栏内横排两个 28 点按钮、8 点间距及两侧 20 点留白导致的宽度溢出，改成与参考实现相同的纵向按钮结构。

调整分组顺序和归属。ShipiOS 独有的模型与 API、记忆、运行时页面保留在对应分组；未实现的账户和云服务页面不伪造可操作入口。

加入设置搜索，支持页面名、英文标识和现有控件关键词、多词查询、空状态、清除、方向键高亮及 Return 打开。现有 24 个设置页均已接入目标，共 94 个主要控件或设置区域；结果按页面分组，命中后在同一设置页滚动定位并高亮。外观浅色/深色配色、已保存记忆、插件列表和用量汇总等定位到对应完整区域。这不是每个动态列表行的独立索引；插件动态设置入口和其余细粒度控件仍需继续补齐。

快捷键页另支持逐命令搜索：命令标题、标识和当前实际显示的组合键均可检索。索引使用生效绑定，包括备用键、用户解绑和重新绑定；已移除的默认键不会继续命中旧命令。选择结果仅导航，清除快捷键页保留的文本或组合键筛选、取消当前录制，再滚动并高亮对应行；不会执行命令、修改绑定或自动开始录制。重新筛选会清除旧命令定位，重复选择仍产生新请求。不存在的命令、跨页和混合控件/命令目标均被拒绝。

搜索文档仅包含预定义控件标题、页面名、检索别名和生效快捷键，不包含用户填写的密钥、地址、个人指令或会话内容。重复选择同一结果生成新的定位请求，允许手动滚开后再次定位。普通导航和退出设置会清除旧定位状态；跨页目标必须与所属页一致。定位不自动修改控件值，也不获取输入控件焦点。

浏览器搜索先选择“历史与数据 / 下载 / 权限”子页；连接搜索先选择“控制此 Mac / 控制其他设备 / SSH”。滚动任务在子页插入后再解析目标，并检查请求仍然有效。用户手动切换子页会取消旧请求；项目改变时也取消项目相关定位。没有打开项目时，Scheme、容器和构建配置不作为具体控件结果出现，过期结果不能重新触发定位。

移除旧的“任何设置分类变更都清空 first responder”处理；该处理会中断新加入的键盘导航。现在导航按钮管理自己的焦点，搜索打开结果时保留搜索焦点；方向键切页时滚动目标导航项进入可见区域。

设置仍位于唯一 `main` 窗口。内容区保持挂载，导航收起/展开不重建各设置页。
