## 实现边界

- 完整列表改为默认及模型单选行，保留服务目录顺序、可访问单选角色/选中值、模型标题和说明。未列出的当前模型不再生成假选项；没有匹配已选项时焦点回退到首个有效项。手动填写模型 ID 保留在同主窗口的模型与 API 设置。
- SwiftUI 继续拥有选择、模式、能力加载和错误状态；`ModelPickerMenuItem` 只桥接实际 NSButton 行、绘制和按键。每个选择器拥有独立 `ModelPickerMenuFocus`，没有全局事件监控或跨窗口共享焦点。
- Tab / Shift-Tab / 上下键循环只移动实际焦点并滚动到目标，不选择模型、不写配置。禁用、隐藏、已移除和不属于同一窗口的行不参与。初始请求在原生视图挂载后执行；失效代次、关闭和拆卸阻止旧回调抢走新输入焦点。
- Return / 空格选择模型后回到该模型的档位视图；选中项不重复保存。默认项恢复服务默认档位及默认模式。真正完成沿用滑杆 Return / 完成按钮 / Escape。没有两档能力时保留完整列表，不伪造档位。
- 保存错误保持列表和原选择，可从当前响应器原位重试。任务/全局模型隔离沿用既有实现；模式与模型配置仍分别保存，不宣称跨文件事务。
