# 设置分区跨版本与嵌入布局统一

日期：2026-10-08。本阶段继续第 664 篇的共享卡片工作，修正 macOS 14 和嵌入子页仍走不同 Form 容器的问题。全部 UI／交互与核心功能对齐的原目标保持。

## 参考与实现

参考沿用第 664 篇固定的 Codex 26.930.51102 / build 13100 公开分发组件及 `settings_card_layout_reference_664.json`。标题、默认卡片、默认行的尺寸没有重新取生产常量作为预期。未读取 Codex 私人账户／项目／配置；Codex 窗口的直接操作此前被工具安全限制拒绝，本阶段没有绕过，也没有取得双端页面配对证据。

- 新增显式 `SettingsSection`，在所有支持的 macOS 14 及以上系统使用同一实现。移除 `Group(sections:)` 的 macOS 15 分支及 macOS 14 grouped Form 分支，最低系统版本仍为 14。
- 15 个设置页面源文件内的 21 处 `SettingsForm`，以及三个共享子分区，统一使用新的分区容器。页面已有绑定、保存动作、权限与未保存确认逻辑未改；提交前逐文件比对，迁移页面只替换 Section 类型。
- 普通页面仍由 `SettingsScrollPage` 管理唯一滚动文档；嵌入 MCP／技能／记忆等已有滚动页时，只使用垂直内容，不增加滚动容器或重复页面标题。嵌入表单不再使用 columns Form。
- 默认卡片及行保持 16 点圆角、1 点边框、左右 16／上下 12 点行边距，标题 14 点、46 点最小高度和 6 点底部间距；标签与控件之间 24 点。分隔线通过实际行边界锚点定位，按视觉纵坐标排序，并在每个分区外清除偏好，避免跨卡片绘制。
- 标题、无标题和页脚初始化均保留。原始控件直接由 SwiftUI builder 承载，条件行和带稳定 ID 的列表继续由自身身份管理。

这是支持系统共用代码路径的实现证明；本机运行的是当前系统，没有 macOS 14 真机／虚拟机运行证据，不能将其称为该系统最终验收通过。其他非共享表单编辑器、所有紧凑／堆叠等卡片行变体尚未统一。
