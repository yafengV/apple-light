# Codex Responses 服务切换

2026-09-26。独立 API 设置的服务地址或 Key 变化后，已有 Codex 任务会在下一回合先关闭旧运行线程，再用新配置恢复同一私有 rollout。会话历史和任务身份保留，后续模型请求发往新地址。运行中的回合不会中途切换；新回合准备期间也会阻止同任务重复提交。内存中只保留 Key 的 SHA-256 摘要用于检测变化，不另存明文凭据。

Agent 关闭线程时会先从活动映射移除，再确认完成，避免立即恢复与旧线程清理发生竞态。本地假服务集成测试覆盖从 `/v1/responses` 切到 `/alt/v1/responses` 并保留前一轮上下文。Key 轮换由同一重连路径处理，但当前锁屏环境未进行 Keychain 实际轮换验证。

这解决的是设置变更后的请求去向。设置页、模型弹层及当前 Codex Mac 的原生焦点和视觉交互仍未逐项配对，完整页面验收数不变。
