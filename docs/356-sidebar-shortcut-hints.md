# 普通侧栏的修饰键快捷键提示

2026-09-28。第 355 阶段补齐 Activity 数字命令，本阶段继续核对行内提示的实际展示路径，避免把普通侧栏的行为直接套到 Activity。

## 参考行为与界面范围

此前缓存的官方桌面资源中，`njn` 在当前侧栏修饰键保持按下时等待 500 毫秒，使用 `E8t` 将前九个位置的生效绑定映射到任务身份。目标或绑定变化会重新等待；松键后清除提示。`Epa` 取每个命令的首个生效绑定，`sjn` 根据数字快捷键目标偏好选择 Command 或 Control。普通任务行 `_8t` 将 `shortcutLabel` 交给尾部 `overlayMetaContent`。

进一步沿 `UIn → $In → ZW → _8t` 核对发现，此参考版本的 Activity 本地任务行没有传入 `shortcutLabel`。因此第 355 篇中的“Activity 行内数字提示”不再作为待补功能：数字命令仍按 Activity 列表执行，但本阶段只给普通侧栏增加行内提示。ChatGPT 来源有不同的提示路径，ShipiOS 当前的独立 API 本地任务不冒充这种来源。这些静态资源没有构成用户当前版本的原生双端验收。

普通侧栏现可按住其数字快捷键修饰键，500 毫秒后看到对应任务的真实生效绑定。标签使用当前侧栏展开顺序，最多九项；置顶、折叠、归档与任务身份变化同步更新。改绑显示新绑定，解绑或被旧自定义配置占用的默认槽没有提示，后续任务不挤占该槽；不是将键位硬编码成连续数字。数字目标交换同时改变触发修饰键和默认标签。

## 原生边界与清理

SwiftUI 拥有提示控制器及显示字典，`NSViewRepresentable` 只观察当前侧栏所属窗口的修饰键变化与窗口通知，返回原事件。零尺寸桥接视图不参与点击；不持有原生窗口，监视器弱引用视图。松键、窗口失去键状态、应用失活、sheet 开始和关闭窗口时取消当前延迟并清除提示。侧栏卸载时移除事件监视器和通知观察者，析构也清理观察资源；旧延迟由请求身份和取消状态保护。

进入 Activity、设置、搜索/命令/图片弹层、重命名、模型/分支选择、按键录制或工作区尚未加载时，当前提示上下文为空。目标或有效绑定变化后先清除旧标签再等待，重复的相同上下文更新不会不断推迟显示。提示不触发任务选择，不安装另一套数字命令路由。
