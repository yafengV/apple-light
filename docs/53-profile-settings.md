# 主窗口个人资料与活动洞察

2026-09-17。依据 [Codex Settings 的 Profile 说明](https://learn.chatgpt.com/docs/reference/settings#profile) 补齐个人资料设置入口、活动洞察和可导出的资料卡。该实现使用 ShipiOS 独立数据目录，不冒充 ChatGPT 账号资料。

## 当前实现

- “个人资料”是设置侧栏中的独立分类，和通用、外观、个性化、记忆等页面一样替换主窗口内容，没有创建 `Settings` Scene 或第二个设置窗口。
- 主侧栏底部使用账户菜单样式的入口，集中提供个人资料、设置、模型与 API、用量、已归档任务和独立数据目录；所有设置入口都路由到同一个 `ID: main` 窗口。
- 用户可设置显示名称和用户名，用户名允许字母、数字、句点、下划线和连字符。资料保存到当前数据根目录的 `profile.json`，文件权限为 0600。
- 用户可从系统文件选择器导入头像。应用校验图片可解码、尺寸不超过 8192 × 8192、规范化后的 PNG 不超过 5 MiB，再复制到独立数据目录；不会保存外部原图路径。
- 活动洞察显示独立 API 返回的终身 token、单次峰值、连续活跃天数、任务/回合数量和最长任务。token 不估算，也不读取用户个人 Codex 的记录。
- “保存资料卡…”生成 900 × 520 PNG。渲染和 PNG 编码均由本地 AppKit 完成。
- 配置损坏、头像缺失或图片无效时页面显示可恢复错误，不会静默覆盖原文件。

## 自动化与原生验收

`ProfileTests` 覆盖资料校验、0600 持久化、权威 usage 聚合、头像规范化与删除、重启恢复及 PNG 文件签名。个人资料与页面导航的 11 项定向测试通过。

完整回归通过 299 项 Swift 测试、12 项 Rust 测试、Rust fmt/Clippy 与真实 Agent IPC 冒烟，日志为 `.cache/profile-settings-full-tests.log`。

原生验收使用隔离目录 `.shipios-local/profile-validation`：从主窗口进入设置后切换“个人资料”，填写 `ShipiOS 验收` 和 `shipios.validation`，保存后卡片预览立即更新；完全重启应用后两项值仍恢复，页面仍在同一主窗口。验收完成后应用切回 `.shipios-local/desktop`（PID 8050），原任务“验证新输入框的真实构建”和草稿“这是一条待发送草稿，重跑后应保留”保持不变。

## 尚未对齐

当前资料只代表本机 ShipiOS 身份。ChatGPT 登录与退出、头像/名称云同步、订阅与组织身份、邀请资格、云端 token 活动以及跨设备资料卡仍未接入。资料卡视觉、页面间距、键盘焦点、悬停和动画也尚未取得当前 Codex 用户版本的逐项配对证据。
