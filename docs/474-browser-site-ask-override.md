# 浏览器站点级“每次询问”规则

[OpenAI 官方浏览器说明](https://learn.chatgpt.com/docs/browser)描述了内置浏览器按网站询问、允许和阻止的行为。ShipiOS 的浏览器权限页原先也显示“每次询问”，但选择它会删除站点规则；当全局默认设为“允许”或“阻止”时，实际访问仍直接沿用全局值，菜单选择没有生效。

现在站点级“每次询问”作为明确规则持久化，并进入 Codex Core 浏览器工具的现有授权判断。添加规则表单提供询问、允许、阻止三种选择；规则列表可在三种选择间切换。“移除规则”明确恢复全局默认，避免把它误当作“每次询问”。旧数据无需迁移。

本机网页夹具下的 `BrowserTests` 全部 **65 项**通过，包含站点级询问覆盖全局允许/阻止、保存与重载、移除后恢复默认及原有浏览器与 Agent 路径。`script/build_and_run.sh --build-app` 构建、严格深度签名检查通过。Mac 锁屏阻挡菜单实际点击；Codex 参考客户端的桌面访问仍被拒绝，因此不把这些测试计入完整双端逐页验收，仍为 **0/45**。浏览器插件安装、扩展、完整 CDP 和视觉细节继续保留在总清单中。
