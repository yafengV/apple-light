# 选区旁的模型编辑审阅

上一阶段的选区操作已在文字旁显示，但输入和建议审阅仍插入文件页顶部，导致编辑器整体布局跳动。现在点击选区操作后，输入框在同一选区旁的浮层打开；生成建议后浮层切换为原文/替换预览和“编辑、拒绝、接受”操作，修改要求可返回编辑。浮层在切换文件、关闭文件页或会话结束时关闭，Escape 可退出。接受时仍通过原生文本视图修改，撤销、草稿和磁盘冲突处理沿用文件编辑器现有规则。

本机 Codex 参考资源在选区处使用浮动操作，随后在编辑器内插入审阅控件；ShipiOS 的审阅目前锚定选区但仍是浮层，没有在文本布局内插入原位差异块。这项视觉与滚动差异，以及真实鼠标、键盘焦点和双端交互，仍待前台验收和后续实现。

验证：29 项相关 Swift 测试通过，包括隐藏原生窗口中建议出现时浮层扩展、返回编辑时浮层收缩的状态检查；`script/build_and_run.sh --verify` 构建并启动成功，严格深度签名校验通过。Mac 锁屏导致应用可交互性与两端页面对照仍未取得实际证据，完整配对保持 **0/45**。
