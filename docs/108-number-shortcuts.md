# 数字快捷键与侧栏聊天导航

2026-09-18。对照本机 Codex 26.908.70816（build 9275）的公开前端资源：`keyboard-shortcuts-settings-da30bad37b3c.js`、`app-initial-4d7ea7f81c2d.js` 与 `src-996ff3571e1f.js`。没有读取 Codex 的个人配置、认证或会话。

## 本轮实现

- 主窗口快捷键设置加入“数字快捷键”选项。默认 ⌘1–9 切换标签、⌃1–9 切换聊天；可交换两组修饰键。说明文字、命令菜单和实际键盘路由随设置更新。
- 聊天位置按当前侧栏展示顺序计算：置顶、自定义分组、项目、无项目任务。排除折叠的分组/项目子项、归档任务、独立窗口草稿和固定内容标签；项目与任务混合排序生效。第 9 个快捷键只对应第 9 个聊天，没有“跳到最后一个”的别名行为。
- 九个聊天命令进入命令菜单和任务菜单。使用现有任务选择路径，保留项目切换限制；设置页、确认弹层、按键录制期间不触发后台聊天切换。
- 显式自定义绑定优先于动态默认值。切换偏好导致默认数字键被其他自定义命令占用时，保留用户绑定、停用冲突默认值并显示提示。用户主动禁用的命令不误报冲突。
- 单命令恢复默认使用当前数字键偏好；恢复全部绑定不重置该偏好，与参照实现的处理一致。
- 独立 `shortcuts.json` 使用版本 1 的封装格式保存偏好与绑定；仍能读取旧字典格式，下一次写入时迁移并保留未知命令。未来版本或损坏文件不会被覆盖；读写失败保留最后有效内存状态。
- 设置搜索加入数字快捷键入口，宽窗口横排、窄窗口纵排，仍在同一主窗口内。
