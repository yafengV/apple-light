# 独立任务窗口统一内容标签

2026-09-19。

## 实现范围

沿用 [主窗口内容标签](77-task-content-tabs.md) 已记录的参考行为，独立任务窗口现在由窗口持有逐任务的布局和内容资源。聊天、浏览器、审查与多个终端进入统一标签体系，主内容区、右侧及底部面板分别保留选择；切换任务不重建网页或终端。

- 标签支持选择、关闭、关闭其他/右侧、混合类型的重新打开、数字选择和循环切换。聊天标签不可关闭；关闭终端停止对应进程，重新打开创建新 shell。
- 提供新增内容菜单、标签显隐、全宽/分栏、左右交换及面板间移动。移动保留同一 WebView 或 PTY；底部仅接受终端。拖动令牌限定当前任务窗口，避免误接收其他窗口的内容。
- 回复链接按呈现方式进入当前窗口的主内容区或右侧；后台打开保留聊天焦点。多浏览器面板的地址栏选择与复制网址指向实际操作的标签，已关闭标签不会退回复制另一个网页。
- 原有文件面板保留；项目变化回收旧项目的审查和终端标签。窗口关闭统一停止终端并释放浏览器资源。
- 修复审查空状态使标签条下移的问题，标签条固定在内容区顶部。

## 验证

126 项任务窗口、浏览器、真实终端、工作区标签和文件预览相关 Swift 测试通过，0 失败。日志为 `.cache/task-window-tabs-tests.log`。新增测试覆盖混合标签顺序与恢复、面板边界、网页实例保留、后台链接焦点、关闭后台标签不抢焦点、跨窗口拖动隔离、实际 PTY 变量隔离、单终端重启及项目变化。

通过项目脚本构建并在隔离数据目录原生验证：

1. 新建网页、输入页面内容、切换全宽/右侧后，页面输入保持；审查与聊天数字切换、关闭及重新打开正常。
2. 两个真实 zsh 分别运行，第二个看不到第一个设置的变量。第一个终端从底部移到主内容区后，变量及 PID 保持；关闭它只停止对应进程，第二个仍运行。重新打开获得新 shell。
3. 标签显隐、左右交换、通过任务搜索离开及返回后，网页输入、审查与各终端布局保留；另一任务及主窗口草稿未被覆盖。
4. 关闭独立窗口后，已记录的两个 shell PID 均不存在；主窗口仍显示原任务。
5. 最终构建确认审查空状态的标签条位于顶部；普通点击回复链接在右侧打开本地测试网页，聊天和草稿保留。

最终恢复原工作区并检查原任务、未发送草稿及原生输入焦点；严格签名检查通过。合成工作区、测试服务器、终端标记、日志和缓存不提交。
