## 实现

`CommandGlobalHotkeyRegistration` 在同一个主线程事务中先准备所有变化的宠物／弹出窗口候选，只在保存成功后提交。任一候选或保存失败会释放候选并保留原注册；未变的不可用组合不阻止其他设置保存。默认恢复／全部恢复与普通编辑共用 `ShortcutPreferences.persist` 入口，按候选完整设置计算实际全局组合。

启动逐命令恢复，可用命令独立注册；错误归属快捷键页对应行，弹出窗口常规设置复用同一错误。修复后重新读取文件会更新实际注册，不重写文件。AppDelegate 使用与测试相同的连接方法，退出清除三个回调并释放原生对象，避免强引用循环。

常规设置弹出窗口行改为共享原生编辑／清除／取消控件，录制取消保留焦点，过期取消受会话身份保护，录入先退出再验证／提交；同值走专用注册重试且不重写偏好。通用快捷键页同值仍退出而不提交。
