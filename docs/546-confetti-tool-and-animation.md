# 通用设置：彩纸效果与模型工具

本机 Codex Mac 通用设置的“玩具 → 彩纸效果”允许用户开启后要求 Codex 在应用中撒彩纸。ShipiOS 现提供独立偏好，默认关闭，保存在自己的工作区数据中；设置搜索可定位该开关。开启且未选择“减少动态效果”时，独立 API 会话提供 `shipios_fire_confetti` 函数工具，内嵌 Codex Core 会话注册同名原生工具。两种协议的调用都会触发主窗口顶层、非交互式的短时彩纸绘制。关闭偏好后下一轮不再提供工具；Codex Core 的已有线程会按服务身份变化重新建会话并续接历史。减少动态效果时不提供该工具，运行时再次检查以防设置变化。

本地模型夹具验证了独立 API 开关关闭时不触发、开启时真实工具调用触发并写入会话工具记录。Codex Core mock Responses 服务验证原生工具进入请求、调用后向所属任务发出彩纸事件、继续下一轮并返回文字；无 UI 接收者时原生工具报告连接失败。离屏原生窗口测试确认实际彩色像素被绘制，覆盖层不获取窗口焦点。Swift 定向 26 项和 Rust 定向 2 项测试通过；另完成 Rust 格式检查、正式构建及严格签名。

当前仍缺前台真实点击、Codex 与 ShipiOS 的动画视觉/时序双端配对，以及独立任务窗口归属验证。本项不能计为 47 个验收面的完整通过。
