# 技能预览的立即尝试

2026-09-18。补齐技能预览中的“立即尝试”，并在技能行的菜单中提供相同入口。

## 对照依据

本机 `/Applications/ChatGPT.app/Contents/Resources/app.asar` 的 `plugin-detail-page-17f962f4fb50.js`：

- 技能预览底部的 `ic` 将尝试按钮连接到 `onTryInThread`，技能无效或正在更新时禁用。
- 对应回调使用 `activeProject`、`prefillPrompt` 和 `startInSidebar: true` 创建新任务入口；不是直接发送模型请求。

## 当前实现

- 在当前项目范围下创建独立、未发送的任务，输入框预填 `$插件/技能 `。使用完整标识，避免同名技能混淆。
- 每次尝试都有独立任务与草稿；不覆盖通用新任务槽、原任务草稿或附件，也不继承原任务的附件。
- 未发送任务正常显示在侧栏，可离开后重新选中，并在重启后恢复。任务尚无 run 时使用任务标识作为选择标识；首次发送后归入同一个任务。
- 创建前重新读取已安装技能状态。父插件或技能被停用、技能被移除、工作区尚未加载、正在切换范围或导入附件时不能执行。
- 创建及选择状态先持久化；写入失败时留在原页面，不留下内存中的空任务。
- 成功后关闭预览并进入主窗口输入区，不执行模型请求；用户仍需确认内容并发送。
- 预览底部加入技能启用开关，与列表的独立启停状态一致。
- 未发送任务归档后删除，会同时清除以任务标识保存的当前选择和后退/前进历史，避免出现已删除草稿的导航项。
