# 设置开关样式与键盘操作

2026-09-18。设置表单统一使用 `SettingsSwitchStyle`，保留原设置绑定及持久化逻辑。

## 实现

参考本机 Codex 26.908.70816（9275）公开随包资源中的设置开关：32×20 轨道、16×16 滑块、150ms 过渡、禁用时 60% 透明度。支持自定义强调色、减少动态效果和从右到左布局。

开关参与 Tab 导航，空格和 Enter 激活，显示焦点边框；带修饰键的按键不触发切换。禁用时不可聚焦。辅助功能通过原生 Toggle 表达开关角色、标签、值和禁用状态。
