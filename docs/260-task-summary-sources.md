# 任务摘要来源区块

2026-09-27。Codex Mac 当前客户端的任务摘要把文件、外部资源、工具和网页搜索汇入“来源”区块，来源行按类型提供相应打开动作。ShipiOS 本阶段从所属任务的运行记录汇总已经保存的文件/图片附件、实际调用过的 MCP 服务，以及 Codex Core 网页搜索事件；同一附件或服务只列一次，Core 内部命令不误列为外部工具。

文件和图片来源在当前主窗口或独立任务窗口打开现有预览。区块的添加菜单可向当前任务草稿添加文件或图片；项目外任务即使尚无来源也保留添加入口。来源与运行记录关联，不扫描任意回答链接来推测曾使用过的材料。

验证：`script/build_and_run.sh --build-app` 成功；来源汇总、计划文档和任务标签相关 14 项测试通过。原生窗口仍被 macOS 锁屏阻断，点击位置、焦点和菜单时序尚未实机验收。外部网页资源、WebMCP 主机、插件图标与完整“显示全部”页面仍待按当前 Codex 配对。
