# 通用设置与输入区行为

2026-09-17。依据本机当前 Codex 应用资源中的 `settings.general.enterBehavior`、`composer.plainTextMode`、`contextUsageIndicator`、`bottomPanel`、`plugins`、`defaultTerminalLocation`、`openLinkTarget` 和 `projectlessChatFolder` 文案，继续补齐主窗口“通用”设置。设置仍由 `AppContentView` 在唯一 `main` 窗口内呈现。

## 当前实现

- 发送快捷键支持 Enter、始终 ⌘Enter、多行消息使用 ⌘Enter。主窗口和独立任务窗口读取同一偏好；旧 `shipios.sendWithEnter` 只迁移一次，不覆盖新选择。
- 主窗口与独立任务窗口共用原生 AppKit 编辑器。默认富文本模式实时呈现标题、列表、围栏代码、行内代码、强调和链接；Markdown 标记在光标离开对应格式后隐藏，进入该格式编辑时恢复，底层草稿始终保存完整 Markdown。列表按 Return 自动续行，选中文字后粘贴 HTTP/HTTPS 地址会生成富链接。
- “纯文本编辑器”关闭上述自动格式、列表续行和富链接粘贴，所有代码、Markdown 和链接按字面显示。切换模式不改写草稿；中文输入法处于 marked text 阶段时不刷新属性或消费候选键。
- “显示上下文窗口用量”读取模型服务最近一轮返回的权威 `input_tokens`，在主窗口和独立任务窗口输入区显示；没有服务用量时不伪造数字。
- “底部面板”直接控制标题栏布局菜单是否出现。终端快捷键、命令菜单和已经打开的底部终端不依赖该按钮。
- “插件”是全局运行开关。关闭后，`@插件` 与 `$技能` 候选立即清空，真实模型请求也使用空插件配置，不注入插件或技能上下文；逐插件启停状态保留。
- “打开网页链接”支持应用内浏览器和系统默认浏览器。应用内模式把 HTTP/HTTPS 消息链接打开为所属任务的内容标签，并在跨项目或项目外任务中先恢复正确任务归属；`mailto` 仍交给系统处理。
- “项目外任务文件夹”支持选择目录和恢复默认。每个新项目外任务会在该根目录创建稳定、独立的 SHA256 子目录，将路径写入真实模型请求与 system 上下文，并仅在该目录内安全解析回答中的相对文件链接。默认根目录位于 ShipiOS 独立数据目录的 `Projectless`，不访问用户个人 Codex 状态。
- “弹出窗口默认从项目外开始”只决定新建弹出任务的初始范围。关闭时继承当前项目；当前没有项目时仍使用项目外范围。任务菜单的“在新窗口中新建任务”创建隐藏草稿，首条真实模型请求成功建立后才进入侧栏、搜索和归档体系；关闭未发送窗口会清理草稿及私有附件。
- “显示教育提示”控制输入框上方的功能提示。逐条关闭会持久保存，主窗口和独立任务窗口的操作都保持任务草稿归属；它与空白新任务的建议卡片开关彼此独立。
- “在菜单栏中显示”控制真实 macOS 菜单栏入口和最后窗口关闭后的驻留行为。菜单提供显示主窗口、新建任务和退出应用。
- 上述工作区偏好只写入 ShipiOS 独立 `workspace.json`。旧数据默认使用富文本编辑器、启用插件、显示底部面板、隐藏上下文用量、在应用内打开网页、使用 ShipiOS 自己的项目外任务根目录，并让弹出窗口继承当前项目。
