# 文件搜索结果归属

2026-09-26。修正快速改写文件搜索词时旧结果可能被新查询的回车操作打开的问题。

文件路径模糊检索和文件名排序此前已由[第 155 篇](155-file-search-fuzzy-candidates.md)实现，增量会话见[第 156 篇](156-file-search-incremental-session.md)。本轮检查发现：同项目新查询启动时，目录缓存会暂存上次结果；搜索弹层只核对项目、可执行文件和重试次数，未核对结果属于哪个查询词，因此新结果到达前仍可能显示并打开上次文件。

目录现在记录每批候选所属的完整请求。弹层只展示当前请求的候选，方向键和回车均从这份可见结果中取目标。输入刚变化、查询进行中、项目或重试改变、空查询以及弹层关闭时，旧候选不会作为当前结果操作；增量更新一到达即可展示该查询的部分结果。

文件搜索、增量会话和弹层相关的 12 项 Swift 测试通过，覆盖旧查询已完成、新查询尚未启动、正在加载、部分结果、乱序返回和取消。签名应用已构建并进入原生文件搜索弹层；本轮搜索过程中曾出现超时，随后 Mac 锁屏中断界面复验。独立 helper 用同一测试项目、与应用相同的工作目录和精简环境查询 `App`，约 0.03 秒返回 `HelloShipiOSApp.swift`；原生超时原因与完整回车路径仍待解锁后复核，不能据此宣称原生闭环通过。
