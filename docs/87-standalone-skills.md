# 独立技能导入与卸载

2026-09-18。继续补齐主窗口设置中的技能管理。设置依然没有独立窗口。

## 对照与实现范围

已检查的 Codex 静态界面代码 `plugin-detail-page-17f962f4fb50.js` 包含按技能路径预览、启停、立即尝试和条件卸载入口。本轮实现独立本地技能的完整管理路径；不把本地文件导入称为 Codex 在线目录或完整安装来源对齐。

- 设置 → 插件 → 添加 → 导入技能，选择顶层含 `SKILL.md` 的文件夹。不需要伪造插件清单。
- 技能和资源复制到 ShipiOS 独立数据目录的 `Skills/<名称>`，登记在 `plugins.json`；不修改源文件夹或个人 Codex 目录。
- 只有独立技能时也显示“技能”标签和数量。导入后选中该标签并清空筛选；最后一个技能卸载后按既有规则回退。
- 独立技能复用单项启停、Markdown/源文件预览和立即尝试；列表菜单及预览提供带确认的卸载入口。插件内技能仍由父插件管理卸载。
- 立即尝试创建未发送任务和独立草稿。独立技能使用带文件路径的 Markdown 引用，输入区补全使用同一引用，确保与插件内同名技能区分。
- 模型上下文仅读取已登记且启用的技能。未知文件链接、远程链接不会被作为技能加载；单纯 `$名称` 存在重名时不注入任何技能。独立技能不会生成虚假的插件调用标识。
- 导入拒绝重复名称、无效说明文件、符号链接与特殊文件，限制资源总量；保存失败时回滚安装/移除。卸载仅移除已登记副本并清理启停偏好。
