## 实现与边界

| 行为 | 当前实现 | 验证 |
| --- | --- | --- |
| 草稿身份 | 独立 workspace.json 的 `subagentDrafts`，按 task/root/child 归属保存 ChatMessage 和文字版本 | 同子会话跨面板同步；不同子任务独立；旧记录缺字段解码为空 |
| 返回和重建 | 选择/历史/加载留在 SubagentDetailState，输入改为读取 WorkspaceStore 的对应草稿 | 返回列表、再次进入、关闭内容标签并重开；实际主/独立任务窗口同步 |
| 冷数据恢复 | 文字、图片和文件元数据与引用均恢复，未加载子任务仍可读取已存草稿数据 | 状态/磁盘测试；**未实现冷子线程完整加载和实际续聊**，只读冷详情仍不显示可编辑输入器 |
| 保存失败 | 保留可见输入和新引用；显示原位“重试保存”；发送前刷新保存失败则不调用 RPC | 实际失败路径保持文字/两类附件，发送前后本机请求均为 4 条；修复路径后重试成功 |
| 旧快照保存 | 通用 commitLibrary 保留最新子草稿；只有显式指定 scope 才替换/清空它 | 旧工作区快照改标题后，较新的文字/附件仍保持；任务删除仍移除其作用域 |
| 共享引用 | 父草稿、多个子草稿与提交历史统一持有引用，最后持有者移除才删除副本 | 清父/清一个子/删一个共享任务均保持；最后清空或任务删除才回收 |
| 失败后回收 | 写盘失败时被移除的旧副本暂存到退休引用池，后续完整保存成功才回收 | 修复并重试后回收，失败期间磁盘副本仍可读；没有把失败写入当作成功 |
| 并发导入 | 清空更新共享 epoch，其他面板的迟到导入不能复活草稿；完成时再次核验共享数量 | 跨面板清空；两个导入竞争第八张图，拒绝第九张并只清其新副本 |
| 提交确认 | 只移除提交快照中的附件；文字版本变化则保留新输入，包括删除后重输同样文字 | 新文字/新图片保留；原附件继续由 pending/历史元数据持有 |
| 发送后返回 | 回执清理原 task/root/child 的已提交草稿，不改新选择的子任务输入或错误状态 | 挂起提交→返回/切换→确认，原草稿清理，新子任务输入保持 |

同一会话草稿是共享状态；发送/历史加载仍有每面板临时状态，不能据此称全部跨窗口并发发送已完成。未确认提交继续保守持有附件，不因 RPC 错误擅自回收可能已接受的输入。
