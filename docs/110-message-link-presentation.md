# 回复链接的分栏、全宽和前后台标签

2026-09-18。参照 Codex 26.908.70816（build 9275）的公开应用资源：`app-initial-4d7ea7f81c2d.js` 中的点击请求生成、`.vite/build/main-DaMR-wdT.js` 中的目标路由，以及 `open-handler-6ed8923c6539.js` 的标签打开/复用处理。

## 已调整

- 普通回复网页链接打开到右侧分栏，保留聊天；不再每次覆盖主区。
- ⌘点按或鼠标中键生成新的后台标签；⇧⌘点按或 Shift 中键生成前台标签。两者即使网址已打开也创建新标签。未被显式外部浏览器修饰键覆盖时，新标签手势优先于通用外部浏览器偏好。
- ⌥⌘点按全宽打开，可将已存在的网页移至主区并隐藏右栏；普通点按同一网页可以移回分栏。
- 显式配置的外部浏览器组合键优先于普通前后台标签行为；独立全宽手势保留优先级。非网页协议不进入这些标签路由。
- 普通/全宽打开优先复用当前任务已打开的相同文档。比较时忽略 fragment，但保留 query；已完成加载的完全相同网址不重新导航，改变页内锚点保留文档状态。尚未提交的相同加载中地址也可复用。
- 新增真正的后台标签创建路径：注册标签与选中标签分离，不发布焦点或地址栏请求。已有右栏标签保持选中；第一个后台标签可以显示右栏，但不抢输入焦点。属于另一任务的后台标签留在其所属任务，不切项目或任务。
- 前台打开把焦点请求交给网页内容，避免打开链接后落在地址栏。失效的来源任务会报错，避免误挂到当前任务。

主会话与独立任务窗口继续共用回复链接入口。跨窗口、非当前来源任务的前台呈现仍需要实机配对，不能以共用函数替代该项验收。
