## 已实现

### 摘要与操作

主窗口和独立任务窗口的行内摘要、摘要弹层均接入真实后台命令。只显示已结束模型回合中仍存活且未请求清理的命令，按回合及执行顺序排列。命令行打开右侧只读输出标签，已有标签保留其位置；悬停或键盘聚焦时显示清理入口。打开与清理具有不同焦点身份。

清理整个任务所绑定 Core 会话；同项目其他任务保留自己的进程。全部清理按钮在请求期间禁用，所选行显示等待。RPC 成功只确认操作已提交，随后实际输出/结束通知继续更新历史，不伪造 PID 已退出。捕获请求开始时的命令身份，避免把稍后开始的命令标成已请求清理。失败保留摘要行、解除等待，通知出现在发起操作的窗口；没有额外导航动作。

### 输出与任务归属

命令通知先由传输层按任务/原生线程传递给独立路由，再进入活动回合流。通知因此可以在模型回合结束后继续更新原命令。原生 begin/end 的 turn ID 定位对应历史回合；不含 turn ID 的增量通知仅在 thread/call 唯一标识一个存活命令时接受，歧义不猜测。下一回合、另一任务及另一原生线程不能接收这些迟到输出。

历史文档从所属任务的原生命令读取；只有任务与回合同时匹配时才引用运行缓冲。分叉复制的历史执行 UUID 不能读取原任务后来的实时输出。断联取消仍运行的命令并保存状态，保持模型回复及已有输出。模型回合结束与命令进程结束分别处理。

输出使用只读 SwiftTerm `TerminalView`，不创建 `LocalProcessTerminalView`、shell 或输入进程。支持 ANSI、中文宽字符、增量追加、全文替换、上下/左侧内边距、用户代码字体/字号、复制/全选和所属窗口的链接路由。原生焦点在视图挂入当前活动窗口且该窗口允许操作后申请；无关输出刷新不抢焦点，卸载后取消待投递焦点/链接。

### 历史与标签恢复

新增明确的后台终端标签类型与任务/执行身份，接入主窗口、独立任务窗口、关闭后重开、固定项及布局恢复。拒绝移入底部 PTY 区域和转移到其他任务。重启仅恢复历史输出，不据历史构造“仍运行”的进程；已完成模型回合中的未结束命令被规范化为取消，模型成功状态和回复保留。

## 发现与修正

- 初始渲染断言将中文宽字符后的空占位单元误认为正文；实际缓冲为“你”、宽字符占位、“好”。现同时核对第 0/2 列字符和去除宽字符占位后的完整文本，保留连续追加与全文替换断言。
- 增加分段 ANSI 的回归，修复前实际显示 `1mRED` 并丢失红色。原因是每次输出后馈入隐藏光标的 escape，打断了尚未完整的 CSI。改用终端模拟器的直接隐藏光标方法；替换全文前用 CAN 取消未完成 OSC/CSI，再重置缓冲。
- 宽窄原生渲染检测到期望 16 点却得到 20 点。`nativeFont(size:code:)` 已将用户 codeSize 加到 12 点基线，传入 codeSize 会重复应用。恢复正确基线，保持真实字号断言。
- 移除原活动回合专用的重复输出缓冲与记录路径，命令输出统一由所属执行身份接收。
