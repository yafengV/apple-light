# 分离标签关闭与聊天归属

2026-09-25。修复主窗口切换任务后，分离内容窗口的关闭、聊天跳转和终端标题使用错误任务的问题。这里的分离内容窗口与第 172、173 篇的独立任务窗口是不同场景。

## 行为修复

- 关闭分离窗口时，原实现调用仅接受当前任务标签的移动方法；主窗口已切到 B 时，A 的标签无法回到主区。现在按标签实际归属更新位置及缓存，保持 B 的选中内容与输入焦点不变，返回 A 时显示原实例。后台网页地址编辑也随之保存。
- 应用退出时不把分离标签改为主区标签；重复关闭回调不会再次改变选择。关闭窗口同步清除该标签尚未消费的恢复请求。
- “聚焦聊天”先切换到标签所属任务或未发送草稿，再聚焦输入框；保留两边草稿和分离内容。不允许已删除任务、已回到主区的标签或忙碌状态发起跳转。
- 原生验收中发现主窗口最小化时，单独调用 SwiftUI 打开窗口没有显示聊天。现在对已存在的主窗口显式还原并激活。
- 分离终端标题从终端 scope 对应任务读取，主窗口切到 B 后仍显示 A，不再跟随全局选择变化。
