# 会话导航轨道的回复预览与定位反馈

本机 Codex 应用的会话轨道组件以用户消息作为悬停卡片标题，以该消息后续的助手回复作为正文预览；尚无回复时显示加载占位。点击标记后，对应的用户消息气泡短暂高亮，减少动态效果时不播放该动画。

ShipiOS 现按会话时间线把初始提问和同轮追加消息分段，逐段收集助手回复作为预览；标题使用实际用户文字，附件消息使用文件名或“图片”。主窗口、独立任务窗口和弹出窗口定位后会短暂高亮目标气泡。书签继续对应原消息 ID，滚动及拖动定位保留原行为。

28 项导航、搜索和任务窗口相关测试通过，覆盖分段回复、运行中加载状态、书签及减少动态效果。`script/build_and_run.sh --build-app` 正式构建通过。桌面控制当前超时，悬停、动画、焦点与 Codex 双端逐项操作仍未前台验收；完整配对仍为 **0/47**（主工作区 21 项、设置 26 项），这是待验收面数量，不是已确认缺陷数量。
