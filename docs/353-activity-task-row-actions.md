# Activity 任务行菜单与单条归档

2026-09-28。第 351、352 阶段提供了 Activity 侧栏及优先区域批量归档。本阶段补齐每行的菜单、悬停置顶/归档、复制与新窗口路由，并为近期和单独置顶任务提供单条归档。

## 对照依据

此前提取的官方桌面资源中，Activity 的 `$In` 包装共享任务行，传入 `showPinActionOnHover`、`floatStatusIconsEnd`、`hideTimestamp` 及归档回调。共享行 `e8t` 使用 `h6t` 构造任务菜单；`jW` 提供置顶与归档悬停按钮。菜单包含重命名、置顶、已读状态、归档、组织、复制与新窗口等分组。单个空闲任务直接归档；运行中的任务先进入 `hU` 的停止并归档确认。这些静态资源证明参考实现的行为，不能证明用户当前版本的原生页面已经配对一致。

## 任务身份与状态

Activity 与普通侧栏现使用同一任务菜单组件，按任务 ID 在操作时读取最新状态。重命名、置顶、已读、复制和新窗口不先选中目标任务；当前任务、未发送草稿及 Activity 保持。重复新窗口请求使用独立窗口身份；其他项目存在本地运行、主窗口无法切换项目时，菜单仍可请求打开目标独立任务窗口。真实窗口创建、焦点和跨窗口行为仍需原生验证。

置顶及已读切换先保存候选工作区，失败保持原状态；不存在或正在归档的任务不能被旧菜单重命名、置顶或打开。Activity 的已读操作只审查该任务所属的自动化运行，并在工作区保存成功后执行。分组菜单共用侧栏组织状态，但 Activity 不显示普通侧栏的上移/下移，避免把时间排序误作手动排序。

复制子菜单按目标任务获取工作目录、本机任务链接和会话 Markdown。无项目任务使用已记录的输出目录，缺少目录时禁用相应入口。会话文本同时查询持久模型/本地运行与当前运行，修复从跨项目任务复制时遗漏历史回答的问题；任务中仅剩用户提示的旧记录也保留提示。

任务行将状态放在末端，运行状态使用真实进度控件；悬停、列表定位或按钮获焦时显示置顶和归档按钮，并提供辅助功能名称及选择状态。选中入口的禁用与任务操作分离，不因主窗口暂时不能切换项目而禁用整个菜单。上述具体命中区域、Tab 顺序、按钮焦点与布局尚未实机验收。

## 单条归档

每行按固定任务 ID 归档，可以作用于近期或单独置顶任务，不扩大为优先区域批量操作。空闲任务直接执行；活动任务显示单任务停止确认，取消不改变任务，重复请求不替换确认目标。空闲归档在让出执行权后再发现活动状态时会进入确认，不能未经确认停止新开始的工作。

执行复用第 352 阶段的停止/终态验证、任务保留、队列防重启、先持久化后更新及工作树清理机制。操作其他任务不改变正在查看的任务与草稿；归档当前任务仍进入新任务。已停止的部分输出和待发送队列保留；归档失败保留目标并显示原因。
