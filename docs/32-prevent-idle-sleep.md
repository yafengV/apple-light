# 通用设置：运行时防止休眠

2026-09-17。继续补齐 [官方 General 设置](https://learn.chatgpt.com/docs/reference/settings#general) 中的 Prevent sleep while running。页面仍位于主窗口内。

## 实现行为

- “通用 → 运行”提供“运行时防止休眠”开关，默认关闭，按 ShipiOS 数据根目录保存。
- 开启时，至少一个实际由应用管理的模型会话或本地任务正在运行，才创建 macOS 空闲休眠断言。只有历史记录、未执行队列或空闲页面时不保持断言。
- 通过 IOKit 的 `kIOPMAssertPreventUserIdleSystemSleep` 实现。根据当前 Xcode SDK 的 `IOPMLib.h`，该类型允许显示器熄灭，系统仍可因合盖、Apple 菜单、低电量等原因休眠；不点亮屏幕、不解锁 Mac。
- 流式文本刷新和其他重复状态更新复用已有断言，不反复创建。切换任务或设置页面不会丢弃正在执行的工作。
- 成功、失败、取消、中断、关闭开关和应用退出释放断言。Agent 断线时不为失去连接的本地运行持续保持；独立 API 模型任务仍存在时继续保持。
- 应用退出后迟到的状态更新不能重新获取断言。底层资源对象销毁时还有释放兜底。
- 创建或释放失败会显示错误和重试入口；流式刷新不会反复重试失败的系统调用。释放失败时保留持有对象，避免失去再次释放的句柄。
- 偏好保存失败时保留旧的实际偏好；工作区未加载完成时不会写入默认空数据覆盖已有记录。

## 剩余验收

本轮 CUA 仍报告 Mac 锁屏。系统接口测试通过不等于原生开关与 Codex 完全一致。需解锁后检查设置页布局、运行中切换、状态提示、失败反馈与返回；长期运行时的真实空闲休眠行为仍需实机观察。

本功能只覆盖应用管理的任务，不根据终端面板是否打开就阻止休眠；单独手工运行的终端命令未纳入任务生命周期。General 中的 Steer 默认行为，以及其他未实现页面和逐页配对验收仍有缺口。
