# 外观页 Dock 图标与原生应用更新

本阶段补齐外观高级区的 Dock 图标选择、独立保存、即时原生更新、系统外观观察、重启恢复及重置。仍不能将外观整页或全部产品称为完全对齐。

## 公开参考与范围

核对当前安装的公开分发版本 `26.930.51102`、构建 `13100`。`Zs`/`Qs` 提供 Dock 单选卡片与选择回调；平台可见性函数要求 macOS 和可用预览。默认值为 `app-default`。卡片 48 点、图标容器 40 点、间距 8 点、圆角 12 点；使用单选语义、选中边框、悬停边框和键盘焦点。

新增 `script/extract_dock_icon_reference.cjs`，以三个公开资源的固定 SHA-256 为前置条件，仅执行相关 JSX/可见性函数，保存 36 组平台、预览、空间功能开关、选中项和实际回调结果。没有启动或操作参考应用，没有读取其个人配置、会话或凭据。

ShipiOS 现提供默认彩色图标和随系统浅深变化的自适应图标，使用自身矢量纸飞机图案。公开参考在空间功能启用时还有第三种图标，本阶段没有伪装该能力已经实现；该条件选项及精确图像/布局配对继续保留缺口。

## 数据与原生行为

- `AppearancePreferences.dockIcon` 独立保存于 ShipiOS 工作区；旧文件缺少字段或遇到未知字符串时回退默认，其余外观值保持。
- 保存成功后才调用现有 `appearanceHandler`，由 AppDelegate 持有的小型 `DockIconController` 更新 `NSApplication.applicationIconImage`。失败保留原选中项和原图标，提供现有错误与重试；重复选择不重复保存。
- 自适应图标观察应用的有效系统外观，保持界面模式偏好独立。观察回调进入 MainActor，并以每次观察的身份隔离停止或重新建立观察前排队的旧回调。
- 选择卡片提供原生 radio group/radio button 角色。单选组只有当前选项参与 Tab，左右/上下方向键循环，空格选择；停用、恢复中、模态或已卸载控件不能写入。
- 高级重置包含 Dock 偏好；`Dock`、`程序坞` 和 `应用图标` 可定位该设置并展开高级区，保持同一主窗口路由。

前台实际操作确认：

1. 默认 `other` 工作区恢复可交互，没有持续 loading；⌘, 仍在 `ID: main` 内打开设置。
2. `Dock` 搜索进入外观高级区，显示两张实际图标卡片；鼠标选择自适应，重置入口出现；右方向键回到默认，左方向键返回自适应，并正确移动焦点。
3. Esc 返回原聊天与空输入焦点；标准脚本重启后，通过 `程序坞` 搜索再次进入，自适应选中保持，界面仍是系统模式、界面字号 14、代码字号 12。
4. 高级重置恢复默认图标；Tab 从当前单选项到返回应用，Shift-Tab 返回当前单选项。清空搜索并 Esc 后，默认聊天空输入获得焦点。没有发送模型消息。

实际系统外观通知在独立测试进程内以 AppKit 外观覆盖验证，没有修改用户的系统主题。没有取得参考应用与 ShipiOS 的整页双端截图/全部行为配对；完整双端配对仍 **0/47**。
