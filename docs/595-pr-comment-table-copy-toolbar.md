日期：2026-10-04。接续第 594 篇，为 PR 表格加入复制入口、Markdown/HTML 剪贴板及键盘滚动。展开预览仍待实现，本阶段不代表全部表格交互或全产品完成配对。

## 参考与实现

参考版本 26.930.21537，只读取应用随包分发的公开资源。`app-initial-60d038a052d7.js` 的 `LJc/NJc` 将工具栏放在表格右上角，表格悬停或工具栏内焦点时显示。工具栏有 2 点内边距，复制按钮使用共享 `blockAction/inputIcon` 的 36 点尺寸，单按钮表面为 40 × 40。共享复制组件 `BNi` 成功后切为勾选、“已复制”提示及无障碍名称，两秒内不再触发复制；失败不显示成功。

新原生工具栏以相同尺寸和显示条件呈现。隐藏时不拦截鼠标，仍可通过 Tab 聚焦；焦点进入即显示，离开后根据悬停状态隐藏。复制按钮按当前启用状态与所属窗口的模态范围检查操作，来源替换清理旧成功状态，卸载取消计时、按键状态与回调。图标由原生矢量绘制，完整轮廓、焦点和色彩像素尚需前台配对。

参考复制函数把表格 Markdown token 的 `raw.trim()` 放入 `text/plain`，另从表格 DOM 获取已去除类名、样式及工具栏等装饰的 HTML。解析树现在保留表格的原始范围，用 UTF-8 列位置提取，排除周围的引用/列表容器标记，并按 ECMAScript trim 去除边界空白。保留原来的列分隔、空格、中文、转义竖线、强调与代码语法；CRLF/CR 规范为 LF。不得把原文改成重新格式化的 Markdown。

剪贴板一次写入同一项的 Markdown 与 HTML；测试使用独立临时剪贴板，没有改变用户剪贴板。原生 HTML 保留表头/正文结构、安全链接、强调、删除线、内联代码与换行，转义文字，排除界面装饰。空的可见表格或写入失败不显示成功。

只在 loopback 的夹具中执行公开资源的实际 `Nnr/Inr/Bnr/Vnr` 等 DOM-copy 函数，复制普通三行表格（包含加粗与内联代码）后，HTML 与原生结果完全一致。夹具未包含文件提及、数学或媒体；文件提及解析器在夹具中设为无结果，不能据此声称这些分支已验证。源哈希、HTML 结果和行为事实保存在 `pr_comment_table_copy_reference.json`，原始资产及临时页面不进入提交。

普通 HTML 按钮夹具确认顺序：空格 `keydown → keyup → click`，回车 `keydown → click → keyup`。原生复制在空格松开、回车按下时执行。空格期间失焦、出现模态、来源替换或卸载会取消待触发动作；按键重复不会额外复制。左右键每次水平滚动 40，Option+左右键滚动一个视口宽度，保留纵向位置；Command/Control/Shift 组合不截取。已在实际挂载的 SwiftUI 表格中验证能到达真实横向滚动容器。滚动锚点卸载只清理当前持有的视图，迟到的旧卸载不能清空新锚点。
