# Codex 命令实时输出

2026-09-26。Codex Core 的 `exec_command_output_delta` 现在更新任务时间线中同一条命令卡。命令运行时，折叠卡片显示最新一行，展开后可查看已收到的输出。原始事件中的 base64 字节按调用 ID 暂存并限为 64 KiB，跨事件拆开的 UTF-8 字符在字节合并后解码；回合或命令结束时清理暂存。

固定版 Core 还可能把命令首段或完整输出放在 `raw_response_item` 的 `function_call_output` 中。ShipiOS 仅对已有命令卡及带 `Output:` 标记的工具结果提取正文，按调用 ID 与后续输出合并。命令结束事件给出最终状态和输出，工具结果补齐首段，不新增重复卡片。

本地假模型通过真实 Codex Core 执行一条分三段输出的命令。集成测试在命令运行时观察到中段输出，结束后确认首、中、末三段均在同一卡片中；边界测试覆盖拆开的 UTF-8 字符、重复工具结果和结束后的迟到片段。相邻的命令审批、补丁、网页工具回归通过，`script/build_and_run.sh --build-app` 构建通过。

这只验证本地 Core 事件与 Swift 时间线。Mac 仍锁屏，未进行实际原生卡片视觉、展开、焦点与键盘操作配对；43 类完整配对数量不变。
