# 空闲会话停止与操作身份

接续[后台终端摘要与输出标签](611-background-terminal-summary-and-output-tabs.md)。本阶段补齐回合已经结束、后台命令仍存活时的停止命令，同时固定异步操作发起时的任务与执行身份。完整页面及核心对齐目标仍未完成。

## 参考与要求

本机参考版本 26.930.21537 的公开前端 `app-shared-59042e7300f7.js`，`A8t` 在没有活动回合时调用后台终端清理，失败只记录 warning；活动回合则走中断及独立的 Node REPL 收尾。`interruptConversationSelf` 在用户中断前暂停活动目标。摘要行的 `nx` 另行拥有清理等待与失败通知。这些分支不能合并为“停止总是关闭全部进程”。

公开资源核对没有读取个人配置、认证或历史，也不等于完整前台双端操作验收。

## 实现与交互范围

| 入口或状态 | 当前行为 | 保留的边界 |
| --- | --- | --- |
| 主窗口停止命令/菜单 | 优先当前任务的活动回合，空闲时允许清理其后台终端 | 无所属后台终端时才保留原本本地构建/诊断停止路径 |
| 独立任务窗口停止命令 | 使用该窗口任务的活动回合或后台终端 | 不回退到另一任务的本地运行；浏览器取得键盘焦点时继续过滤停止快捷键 |
| 主/任务/侧聊输入区停止按钮 | 同步捕获操作身份，再调度取消 | 没有新增未经参考证明的空闲停止按钮 |
| 活动模型回合 | 暂停所属活动目标，再取消捕获的模型任务 | 不因此清理 unified-exec 后台进程；保留原有回复/队列收尾 |
| 已结束回合的后台命令 | 经原生 Core 通道清理该任务会话 | 保留完成回复和命令输出；同项目另一任务不受影响 |
| 空闲停止失败 | 保留后台行和输出，记录私有错误日志 | 不冒用摘要行的等待指示或危险通知 |
| 摘要行显式清理 | 保留原来的所选行等待、全按钮禁用和所属窗口错误通知 | 与快捷键回退共享实际提交逻辑，不合并可见反馈 |

`WorkspaceStopTarget` 捕获 run/task 或 task/terminal/thread 身份。执行前重新检查原运行仍活动；旧运行结束后不能转而取消新运行。空闲目标重新检查任务当前线程、具体后台命令以及没有新活动回合；切换主窗口任务不会改变原目标。保护范围是操作派发前的身份检查，不能用本阶段测试宣称全部 RPC 并发组合已经证明。

实际清理只标记请求开始时捕获的命令，并继续接受原命令迟到的输出/结束事件。RPC 返回代表清理提交，不伪造进程退出；进程退出另由真实 PID 断言验证。内部请求去重与摘要行的可见清理状态分开。清理请求尚未完成时，重复 Stop 不会回退到另一任务的本地构建。
