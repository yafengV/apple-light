# 命令菜单的附件选择入口

本机 Codex macOS 客户端 26.911.61220 的命令目录注册 `composer.addPhotos` 与 `composer.addFiles`，在输入区可用时打开对应选择器。ShipiOS 此前只有输入区“添加图片”和“添加文件”按钮，命令菜单与可配置快捷键无法触发。

现在“会话”命令组和原生任务菜单提供“添加照片…”与“附加文件…”。主工作区使用当前草稿，独立任务窗口使用该窗口的任务 ID；命令弹层在选择器出现前关闭。导入进行中以及离开聊天输入区时，主窗口入口禁用；独立任务窗口导入期间也禁用。这两个命令沿用现有图片和文件选择器及附件存储。

命令目录的附件操作仅完成入口接线。Codex 的“Attach files and folders”还包含文件夹，而 ShipiOS 当前文件选择器只允许文件；这一能力、真实系统选择器、取消后的焦点和两个客户端的视觉及操作仍待对齐。

验证：命令菜单 14 项测试，附件、任务窗口、命令弹层与快捷键 42 项回归通过；正式应用构建、严格深度签名和 `git diff --check` 通过。Mac 仍锁屏，前台选择器和 Codex 双端操作未验收；完整配对维持 **0/45**。
