# Codex Responses 目标模式

2026-09-26。目标模式现在可用于已连接项目的 Codex Responses 会话。每一轮由应用保存目标、成功标准、轮次与上限，并把当前轮次的目标规则加入 Codex Core 的 Default collaboration mode 指令。Core 的命令和补丁工具仍可在普通工作区权限下执行。模型回复末尾的 `SHIPIOS_GOAL_STATUS` 由现有目标状态机解析并从界面移除。

返回 `continue` 时，在没有排队消息的情况下自动开始下一轮；返回 `complete` 时标记完成。缺少明确状态、失败、取消或达到轮次上限时暂停。目标完成后的普通回合重新使用未附加目标规则的 Default 指令，避免目标状态泄漏到后续任务。

本地假服务集成测试覆盖两轮目标指令、继续与完成、持久状态和后续普通回合清理；另有无状态回复的暂停测试。此项是功能与自动化验证，目标编辑页、状态卡片、继续/暂停按钮和当前 Codex Mac 的原生交互尚未逐项配对，完整页面验收数不变。
