# Appshot 当前前台窗口优先级

此前 Appshot 自动目标只依赖“最近激活的外部应用”记录，记录超过 5 分钟就失效。用户在 Xcode 等应用持续工作超过 5 分钟时，即使窗口仍处于前台，快捷键也会退到系统单窗口选择器。

现在目标选择先读取按键当下的 macOS 前台应用，只要它不是 ShipiOS、仍在运行且有符合条件的可见窗口，就直接截取该窗口。当前前台应用没有可截取窗口时，再尝试 5 分钟内记录的外部应用；两者均不可用才打开系统选择器。原有菜单与选择器入口继续共用该目标选择逻辑。

候选优先级、超时和回退的定向测试及 Appshot 捕捉／偏好／交接相关 30 项测试通过；`script/build_and_run.sh --build-app` 正式构建和严格签名检查通过。Mac 仍锁屏，真实跨应用前台检测、系统录屏权限和 Codex 双端操作尚未实测；完整双端配对保持 **0/46**。
