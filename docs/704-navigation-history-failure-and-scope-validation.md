# 返回／前进的失败回滚与项目准备有效性

日期：2026-10-09。继续推进 M02、M03、M14，处理第 699 篇记录的异步打开失败后历史已弹出的问题。上一阶段 `108b5a9` 已验证并推送；本阶段继续实现新的导航修正。原范围保持 47 类页面入口、29 项核心功能，完整双端页面验收仍为 0/47。

## 已复现的问题

原实现先从返回／前进栈弹出目标，并把当前页面加入另一侧，再异步打开目标项目。一旦初始化、项目检查、配置读取或运行列表读取失败，当前页面仍可保留，但历史已移动，下一次重试会跳过原目标或跳到其他页面。

使用真实进程的可控 RPC 夹具，四个方法各检查返回／前进与普通任务／关联草稿四种组合。修复前共 104 条失败断言、0 unexpected，exit 1（`.cache/navigation-history-red-704.log`）。断言覆盖两侧历史、原页面与草稿、预览／布局、错误及连接状态，以及移除故障后的原目标重试。

第一轮实现后 86 项关联通过；补充竞态用例的 129 项中出现 2 条失败（`.cache/navigation-history-lifecycle-final-704.log`）。历史已不再被消费，但准备中的请求取消或历史改变后，`open` 仍可能先应用目标项目记住的任务。没有放宽断言，而是把有效性检查前移到目标项目状态提交之前。

## 实现与交互覆盖

| 动作／状态 | 实现及证据 |
| --- | --- |
| 返回／前进打开失败 | 读取栈顶并保存两侧快照，目标成功选中才同时移动两侧；四个核心准备阶段失败均保留原位置 |
| 修复后重试 | 删除夹具故障后再次执行同方向导航，仍到原任务或同一关联草稿；历史只移动一次 |
| 草稿与内容保留 | 普通任务／关联草稿保持各自身份、文本和布局；完整隐藏主页面实际保留原生文件编辑器实例、选中标签与未保存文本 |
| 正在准备目标时重复点击 | 工作区历史请求串行，在准备期间禁用同类命令；重复请求不提前消费另一侧历史，结束后恢复可用状态 |
| 已取消的请求 | 开始时直接拒绝，不改变当前页面、连接及两侧历史 |
| 准备中的取消／历史变更 | 在提交目标项目状态前再次检查取消、退出、页面与历史快照；过期请求停止自己的 Agent 准备，不应用目标任务、不弹出后来改变的历史 |
| 无效／不匹配草稿目标 | 维持原页面与历史，不将错误 owner 当作新的项目打开 |
| 项目与无项目 scope | `openTaskScope` 将同一有效性回调传给有项目和无项目打开流程；无项目重置布局移到 Agent 停止后的有效性校验之后 |
| 关联草稿的其他返回入口 | 已有 `stillValid` 回调可前置到 scope 提交；关联草稿、分离窗口、命令浏览器、迁移返回与设置焦点纳入关联回归 |
| 连接状态 | 旧 Agent 已停止时保持 disconnected 的真实状态，不为保留页面伪称连接仍有效；下一次导航可重新建立目标连接 |

不新增导航页面，不改返回／前进的默认快捷键、设置页返回优先级或独立 API 配置。历史选择完成后，详情加载仍沿用现有版本隔离；没有把详情读取变为新的历史栈。
