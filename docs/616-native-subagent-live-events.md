# 原生子任务实时事件与历史合并

接续[第 615 篇](615-native-subagent-history-and-detail.md)。本阶段接通实际原生子线程的主机事件队列，详情不再只依靠持久历史轮询显示文字。审批动作、提问表单和完整子会话仍未完成；本阶段不是全部页面验收。

## 来源与归属

参考仍为本机 26.930.21537 的公开子任务详情组件，运行时仍固定 Core `50d77959bf927293c4b5ddcca81d05331ae582ea`。当前 Core 的 `CodexThread.next_event` 是单接收队列，原生 AgentControl 完成观察器使用独立状态订阅。因此主机按所属父任务的真实子树验证成员，再为每个已加载子线程建立一个事件读取任务；不读取父事件、不装载冷线程、不用父会话流代替子事件。主/任务/分离窗口通过同一个 WorkspaceStore 读取子运行状态，选择和输入草稿仍各自独立。

| 行为 | 实现与边界 |
| --- | --- |
| 创建及发现 | 原生创建通知/实际子树发现后，先发送完整成员快照再启动读取；未成功取得已加载队列时继续发现重试 |
| 空闲父会话 | 父回合结束不关闭子读取，实际子任务的部分输出、最终回复和终止仍能到达；不会修改父回复或终止父流 |
| 独立事件 | `shipios_subagent_event` 包含父任务/父线程、子线程、读取流 UUID、事件序号和原生事件 ID；Swift 在父会话路由之前单独分派并返回 |
| 长事件 | 每个完整 JSON 事件采用 48 KiB UTF-8 分块、偏移、总字节数、终态及 SHA-256；没有按消息长度截断。多子线程可交错，但单子事件完整校验后才发布 |
| 错误与身份 | 拒绝无关父任务、变更父线程、未知子线程、错子身份、跳序、缺块、混合 ID/长度/摘要和损坏内容；已完成重复不重复呈现，旧读取流不能覆盖新流 |
| 隐私 | 持久回放和实时事件共用公开呈现投影，排除 SessionConfigured、系统/开发者消息、加密内容、私有元数据和原始思考；Reasoning TurnItem 只保留公开摘要 |
| 文字与公开思考 | 原生逐 delta 文字/思考摘要到达就更新详情；最终文字替换所属部分回复，旧回合 delta 不追加到新回合 |
| 原生事件呈现 | 命令开始/输出/结束、警告/错误和等待操作提示已有基础呈现。审批按钮、提问/elicitation 表单、全部工具/附件及重复归并仍有缺口，传输全部公开事件不等于全部 UI 已呈现 |
| 历史合并 | 保留首次实时回合之前的完整持久前缀；同回合使用实时记录。持久终态或下一回合先于 IPC 到达时，保留较新的完整历史，避免回退成旧部分回复；按每轮选择 Legacy/TurnItem/Raw 消息，避免旧 Raw 回合被新 Legacy 回合整体抹掉 |
| 多窗口 | 新打开的子详情可读取已收到的实时前缀；历史读取期间继续收到的输出不会被迟到加载覆盖；每个窗口保留自己的草稿和选择 |
| 生命周期 | 原生父/子会话关闭后，再给子读取最多两秒的收尾机会；三秒外部上限及 JoinSet Drop 取消残余读取。任务断开/替换清除临时状态，不把每个 delta 写入 workspace.json |
| 事件缺口 | 原 Agent 广播缺口会触发所属项目连接重置；子帧损坏保留已确认内容并提示重新读取历史。独立重连、未恢复父会话的离线历史仍未实现 |

详情保留每秒持久读取，作为持久历史更新与错误恢复的路径；实时文字来自原生事件队列。不能把轮询当成实时流证明，也不能把本阶段的基础等待提示当成可操作审批。
