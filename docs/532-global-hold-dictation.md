# 全局按住听写接入

Codex 语音页还提供“按住听写”：在其他桌面应用按住快捷键录音，松开结束并把文字放到原输入光标。ShipiOS 此前只有全局切换模式。

语音设置现提供独立的按住快捷键录制和关闭行，按键与松开事件分别启动和停止已有设备端识别。两种全局模式互斥；同一绑定不能同时用于按住和切换。按住期间调整切换绑定不会重注册按住热键，以免失去松开事件。快速松开会撤销尚未启动的任务；如已进入授权等待，会通过现有录音代际保护终止迟到回调。识别结果沿用原桌面文本目标的内容／光标校验写回。

相关 Carbon 按下／松开事件、按住状态、配置持久化、搜索与语音页回归通过；760×650 整页离屏图像、正式构建和严格签名通过。**当前机器没有可枚举麦克风，真实跨应用录音与写入尚未验收。** 裸修饰键快捷键、松开后等待短音频最终识别、悬浮录音状态、历史和 Codex 全页视觉／交互仍缺，完整双端配对保持 **0/47**。
