# 主窗口宠物设置与浮动交互

2026-09-17。依据 [官方 Pets 文档](https://learn.chatgpt.com/docs/pets?surface=app) 和 [Settings 文档](https://learn.chatgpt.com/docs/reference/settings) 补齐宠物设置、浮动面板与全局入口。设置仍在 ShipiOS 主窗口内。

## 当前实现

- 设置侧栏增加“宠物”，可选择内置 Codey、仅保留聊天控件的 Mini，以及导入后的自定义宠物。
- `NSPanel` 提供无边框浮动层，支持跨 Space、全屏辅助层、拖动位置、大小调整和位置持久化。SwiftUI 继续管理内容和状态，AppKit 只负责窗口能力。
- 默认全局快捷键为 `⌥Space`；快捷键设置允许为宠物命令使用 Option 单修饰组合。Carbon 全局快捷键覆盖字母、数字、常用标点、空格、Return、Tab、Escape 和方向键。
- 输入 `/pet`、菜单“宠物”以及设置页按钮都切换同一份显示状态。右键浮层可隐藏；Mini 和 Codey 选择、显示状态、大小及位置保存在当前数据根目录的 `pet.json`，权限为 0600。
- 浮层聊天控件可创建无项目任务并发送独立 API 会话。活动状态目前来自运行中、失败、未读和空闲四种本地状态。
- 自定义图集支持带透明通道的 PNG/WebP，尺寸为 1536 × 1872 或 v2 1536 × 2288，最大 20 MiB。应用检查文件类型、透明通道、几何尺寸和帧裁切；动作语义及每行姿态仍由宠物制作者负责。
- 系统开启“减弱动态效果”时自定义图集停在静态帧，内置 Codey 关闭周期动画。

## 自动化与原生验收

`PetTests` 覆盖偏好校验、0600 持久化、图集格式与裁切、导入/移除回滚、`/pet` 命令和 Option 单修饰快捷键。完整回归与电脑使用设置一起通过 306 项 Swift 测试、12 项 Rust 测试、Rust fmt/Clippy 和真实 Agent IPC 冒烟，日志为 `.cache/pets-computer-use-full-tests.log`。

原生验收使用隔离目录 `.shipios-local/pets-validation`：设置页在主窗口内显示；Codey/Mini 选择状态即时切换；`⌥Space` 两次操作分别隐藏和重新显示宠物；选择 Mini、保持显示后完整重启，Mini 和显示状态均恢复。完成验证后已将隔离目录中的宠物恢复为隐藏。

隔离验收结束后，最新应用已切回 `.shipios-local/desktop`（PID 19008）；原任务“验证新输入框的真实构建”和草稿“这是一条待发送草稿，重跑后应保留”均保持不变。原数据目录默认宠物为隐藏，没有把隔离测试状态带入用户工作区。

CUA 的应用截图只返回 ShipiOS 主标准窗口，没有单独返回浮动 `NSPanel`，因此本轮没有用该截图声称浮层像素与 Codex 一致。面板显示状态通过设置页辅助功能树、全局快捷键状态变化、持久化重启和代码测试确认。

## 尚未对齐

内置 Codey 是 ShipiOS 的程序化绘制，不是 Codex 官方素材。语音入口、从界面生成宠物、完整动作图集语义校验、工具审批产生的“需要输入”状态以及浮层视觉、悬停、动画、右键菜单的逐像素配对仍未完成。Pets 页面已存在且可用，不代表与当前 Codex 完全一致。
