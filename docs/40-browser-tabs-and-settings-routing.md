# 浏览器标签与主窗口设置路由

2026-09-17。该记录描述实现和测试范围，不表示与当前 Codex 完全对齐。

后续桌面解锁后的实机检查与焦点修复见 [设置与浏览器原生交互复测](41-native-settings-browser-validation.md)。下文锁屏限制是本篇记录当时的情况。

## 设置入口复核

设置继续作为 `AppContentView` 内的页面显示。应用声明单例 `Window("ShipiOS", id: "main")` 和按任务身份创建的 `WindowGroup`，没有 `Settings` Scene 或用于设置的独立 `NSWindow`。侧栏、应用菜单、快捷键、模型选择器和工作树面板都调用 `openSettings`。

现有九个设置分类为通用、外观、个性化、模型与 API、快捷键、通知、工作树、已归档任务、运行时。分类切换保留同一设置容器；返回按钮、Esc 与后退路由返回进入设置前的工作区或项目页。工作区保留挂载，草稿、任务、面板和浏览器会话不因设置导航而销毁。

`PageNavigationTests` 覆盖每个分类、重复进入、运行中进入、全局命令和搜索弹层、返回目的地与草稿保留。这些是路由状态验证，不是窗口外观和焦点顺序的配对验收。

## 浏览器实现

- 每个标签拥有独立的 WebKit 页面、导航历史、地址草稿、标题、加载和错误状态。切换标签保留页面表单内容。
- 前进与后退根据实际历史启用；支持刷新、忽略缓存刷新、停止加载和出错后重试。
- 地址栏支持域名和本地开发地址；提交后导航，Esc 恢复当前页面地址。复制网址使用当前页面 URL，不复制尚未提交的地址草稿。
- 网页打开新窗口时由标签集合接管；网页关闭标签与点击关闭共享生命周期。关闭最后一个标签隐藏浏览器面板，设置页打开期间不会抢占输入焦点。
- 隐藏面板或进入设置保留标签。退出应用关闭 WebView。标签共享本应用内存中的临时网站数据，不读取用户浏览器配置，也不提供跨应用重启的页面恢复。
- 新标签、显示/隐藏面板接入命令菜单。地址、历史、刷新、复制和关闭的键盘处理只在浏览器具有原生焦点时执行。浏览器外仍保留原输入控件的编辑行为；原生键盘分发待实机验证。
- 页面元素选择、取消与输入区结构化引用已在第 70 篇补齐。选择模式不会自动发送内容，页面导航与标签关闭会清理选择状态。
- 当前标签可见区域截图及任务附件归属已在第 71 篇补齐。截图复用图片附件的原子保存与回滚，页面在捕获期间变化时不会附加过期画面。
- 真实下载、保存位置、每次询问、进度/取消、同名保护和记录恢复已在第 73 篇补齐。
- 点击元素、拖选区域、多条评论、页面编号标记与下一条模型消息上下文已在第 72 篇补齐。评论按任务持久化，其他任务与窗口不会混入。

## 验证

`BrowserTests` 使用本机临时 HTTP 服务和真实 WKWebView，覆盖地址验证、标签与设置归属、历史和重定向、缓存绕过、页面表单保留、同文档 URL 更新、取消请求、网页弹出/关闭、最后标签关闭、独立测试剪贴板复制以及原生方向键编码。

全量 `./script/test.sh` 通过 230 项 Swift、12 项 Rust、fmt/Clippy 和真实 Agent IPC 冒烟。日志：`.cache/browser-tabs-full-tests.log`。其中浏览器 9 项、主窗口页面导航 6 项测试全部通过。

使用 `./script/build_and_run.sh --verify --data-root "$PWD/.shipios-local/desktop"` 重新构建、签名并启动，进程验证 PID 88250；日志：`.cache/browser-tabs-launch.log`。这确认最新二进制启动成功，不证明锁屏期间不可见的 UI 已完成实机验收。

Mac 在本轮检查时锁定，自动解锁失败。无法检查当前应用窗口、真实鼠标键盘、焦点、动画、字体与间距；也没有当前用户版本 Codex 的逐页截图或录屏。因此不将上述测试通过记为“UI 一致”。
