# 输入区内置浏览器提及

Codex Core 已有 `shipios_browser` 原生工具，但输入区的 `@` 候选先前只显示已安装插件。主工作区与独立任务窗口现在共用 `@Browser` 候选：Core · Responses 会话可用，Chat Completions 会话不展示；插件总开关关闭也不会隐藏这个内置工具。键盘上下选择、回车或 Tab 确认、鼠标选择、Esc 关闭沿用原候选菜单，插入 `@Browser ` 后用户可继续写具体网页任务。包含该完整提及的 Core 请求会收到工具使用提示，要求先列出当前任务标签；网站访问与敏感操作继续由现有浏览器授权路径处理。

`PluginTests` 14 项及输入区、命令和独立窗口相关回归合计 38 项通过；浏览器回归 65 项通过。`script/build_and_run.sh --build-app` 已构建正式应用，严格深度签名检查通过。上述测试验证候选状态和现有浏览器路径，未调用用户真实独立模型服务。Mac 仍锁屏，未取得新构建的前台输入、鼠标和焦点验收；Codex 参考客户端仍无法从当前桌面接口读取，完整双端逐页验收保持 **0/45**，其中主工作区 21 项、设置 24 项。
