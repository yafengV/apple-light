# 输入区教育提示与菜单栏驻留

2026-09-18。依据本机当前 Codex 应用资源中的 `showEducationalTips`、`macMenuBarEnabled` 及对应设置文案，补齐输入区教育提示与 macOS 菜单栏驻留。两项开关都位于主窗口内的“通用”页面；应用没有独立 `Settings` Scene。

## 教育提示

- `显示教育提示` 默认开启，旧工作区缺少字段时也按开启迁移。
- 主窗口和独立任务窗口都在输入框上方显示同一类提示。提示包含“提示”标记、说明、带下划线的操作和悬停或键盘聚焦时出现的关闭按钮。
- 关闭只永久隐藏当前提示；关闭总开关会隐藏全部提示，但不会清除逐条关闭记录。该状态与“个性化”中的空白任务建议卡片完全独立。
- 当前只呈现 ShipiOS 已有真实落点的提示：计划模式、技能、运行中追加、自动化、插件、多任务、通知和电脑使用。操作会填入当前任务草稿或进入对应主窗口页面，不创建无效入口。
- 独立任务窗口执行提示操作时仍写入该窗口所属任务的草稿，不会串到主窗口当前任务。

## 菜单栏驻留

- `在菜单栏中显示` 默认开启，说明为“主窗口关闭后，让 ShipiOS 保留在 macOS 菜单栏中。”
- 开启后创建真实 `MenuBarExtra`，提供“显示 ShipiOS”“新建任务”“退出 ShipiOS”。“显示 ShipiOS”激活应用并恢复唯一 `main` 主窗口；“新建任务”复用主窗口的新任务路由。
- 开启时关闭最后一个窗口不会结束应用；关闭该偏好后，最后一个窗口关闭可结束应用。偏好写入 ShipiOS 独立 `workspace.json`。

## 设置导航

- 设置继续替换唯一 `main` 主窗口的内容，没有 `Settings` Scene 或独立设置窗口。
- 左侧设置导航增加“收起设置导航 / 展开设置导航”。收起后保留图标、当前页选中态、提示文本、键盘焦点和返回按钮，内容区不被卸载；展开后恢复分组标题与页面名称。

## 验证

定向测试覆盖旧数据默认值、开关和关闭记录跨重启、建议卡片状态隔离、主窗口/任务窗口草稿归属、提示真实页面路由，以及最后窗口关闭的应用生命周期。设置导航变更另通过 8 项页面路由回归，全部设置分类在收起控件加入后仍可编译并保持原工作区。

完整 `./script/test.sh` 通过 417 项 Swift、12 项 Rust、Rust fmt/Clippy、24 项真实 WebKit 测试和真实 Agent IPC 冒烟，全部零失败。

这些结果证明功能与持久化已经接通。当前 Codex 无法由 UI 自动化工具直接读取，因此本页不宣称视觉像素已经配对；菜单栏关闭与重新打开仍须在新签名构建中完成原生操作验收。
