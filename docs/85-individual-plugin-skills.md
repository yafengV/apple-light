# 插件技能逐项管理与预览

2026-09-18。技能设置从按插件包启停扩展为逐技能列表，插件详情也复用该列表。

## 对照依据

本机 `/Applications/ChatGPT.app/Contents/Resources/app.asar` 的 `plugin-detail-page-17f962f4fb50.js`：技能卡片以 `skillPath` 打开内容预览，提供启用/停用控制，并区分技能的实际启用状态。预览还包含尝试使用和部分技能的移除入口；这两项不属于本轮完成范围。

## 行为

- 技能设置及插件详情列出实际发现的技能，支持标题、标识和插件名搜索。点击技能打开只读 Markdown 预览，可切换到完整源文件、选择文字、复制代码块、关闭或在读取失败后重试。
- 每个技能有独立启用开关，保存在 ShipiOS 的 `plugins.json`；旧配置缺少该字段时默认全部启用。
- 停用技能仍保留在管理列表，立即从输入区技能候选排除。构造新请求时，`@插件`、`$技能` 和 `$插件/技能` 均不会注入被停用的说明。
- 父插件停用时，技能仍可查看，单个开关不可更改；再次启用父插件不会重置技能自身偏好。卸载插件会一并清理该插件的技能偏好。
- 预览按技能标识重新查找已安装文件，不直接信任视图携带的旧文件路径。缺失、重复标识、无效 UTF-8、过大文件和逃出安装目录的路径均不显示为有效技能。
- 修复了 macOS 枚举结果 `/private/var` 与标准路径 `/var` 混用导致的错误拒绝；仍保留安装目录与符号链接检查。
