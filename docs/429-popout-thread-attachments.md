# 弹出会话附件的任务归属与预览

弹出会话此前可以添加或粘贴图片和文件，但附件卡片使用共享组件的默认移除与预览回调。默认回调针对主窗口当前草稿；当弹出会话与主窗口选中不同任务时，移除可能作用于错误草稿，文件预览也会出现在主窗口。图片预览同样没有弹出会话专属的呈现环境。

现在弹出会话把图片和文件移除操作显式绑定到自己的任务 ID，文件和图片都在弹出窗口内预览；会话历史中的图片也可通过同一窗口的图库环境打开。图库关闭后尝试把焦点还给原图片入口，没有入口时回到输入区；首页预览也补上焦点返回与 Escape 关闭时不隐藏浮窗的保护。图片和文件同时存在时，为两行附件保留足够高度，较多附件仍可在各自列表内滚动。

真实 PNG 和文本文件导入后的 470×640 隐藏原生窗口截图显示两张卡片、移除入口及输入区同时可见；测试还检查移除当前弹出任务的附件不影响另一个任务和文字草稿。附件、文本输入、弹出状态与布局的 45 项相关测试通过；`script/build_and_run.sh --verify` 构建并启动应用，严格深度签名通过，29 个语法资源及七份许可证与源文件逐字节一致。Mac 仍锁屏，启动后工作区可交互、预览焦点和 Escape 的前台验证尚未完成；当前 UI 工具也不允许读取 Codex 应用，双端可见配对仍为 **0/45**。
