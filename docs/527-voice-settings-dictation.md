# 语音设置与设备端听写配置

本机 Codex 设置路由中存在按能力显示的“语音”页，包含语音聊天状态、语言、麦克风与听写词典等区域。ShipiOS 此前只有输入区的设备端听写按钮，没有对应设置页。

ShipiOS 现在把“语音”放入主窗口设置的个人分组并支持设置搜索。语言菜单列出设备端识别可用的语言，选中值和最多 100 个去重、限长的词典条目保存在 ShipiOS 独立配置中；下次听写用所选 `Locale` 创建 `SFSpeechRecognizer`，并把词典传给 `SFSpeechAudioBufferRecognitionRequest.contextualStrings`。旧工作区自动采用系统语言和空词典。页面显示当前系统默认麦克风和实时语音不可用状态，避免提供不能执行的控件。

已检查 760×650 语音页离屏渲染；33 项语音、设置导航和原有听写回归通过，正式构建与严格签名验证通过。麦克风切换、实时语音会话、全局按住/切换听写快捷键和录音恢复记录仍未实现；真实麦克风及 Codex 双端页面验收仍缺。

验收清单新增一项条件显示的语音设置面，当前为主工作区 21 项、设置 26 项，完整配对 **0/47**。此数是待逐项验收的界面数量，不是已确认缺陷数量。
