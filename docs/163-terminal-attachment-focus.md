# 终端重新挂载后的聚焦请求

2026-09-19。修复第 162 篇已记录的焦点请求生命周期问题；代码与 AppKit 自动化验证通过，完整原生操作复验仍待解锁。

## 根因与改动

原 `TerminalHost` 在投递异步聚焦回调之前就标记请求已处理。隐藏面板后的同一终端视图尚未重新附着窗口时，回调发现 `view.window == nil` 而退出；后续附着没有再聚焦的机会。调整窗口前置顺序不能解决这个时序。

现在终端视图通过 `viewDidMoveToWindow` 通知当前宿主协调器重试。协调器仅在 `makeFirstResponder` 成功后完成请求；回调执行时读取最新请求和权限，继续要求目标窗口为 key window 且没有附加 sheet。无关刷新不重复执行已经完成的请求。

终端进程和视图仍由原会话持有。视图弱引用当前宿主，宿主卸载会取消请求，并且只清除属于自己的注册，避免旧宿主清理破坏新宿主。没有引入固定延迟、轮询或全局焦点处理。

## 自动化验证

- 6 项新增测试使用真实 AppKit 视图附着和 first responder；测试窗口显式控制 key-window 条件，以便锁屏环境也能验证生命周期，不等同于桌面键盘验收。
- 覆盖首次附着、同一视图移除后重新附着、请求替换及权限变化、旧宿主清理、新宿主接管、取消请求、非活动窗口、焦点被拒绝后重试，以及普通更新不抢走其他输入框焦点。
- 临时恢复“先标记请求已处理”的错误行为时，挂载回归产生 4 个失败断言。测试后已恢复修复代码，记录位于 `.cache/terminal-host-focus-regression-proof.log`。
- 最终 `TerminalHostFocus|TaskWindow|WorkspaceTab|Sidebar|TerminalSession` 范围 96 项测试全部通过，日志 `.cache/terminal-host-focus-final-tests.log`。
- 项目脚本构建并启动原数据目录成功，严格签名检查通过；日志 `.cache/terminal-host-focus-build.log`。启动本身不计为原生交互通过。

本轮检查时 Mac 仍锁屏，无法执行“独立窗口终端固定 → 隐藏 → 主窗口点击固定项 → 直接输入命令”的桌面操作。已请求用户解锁。后续必须确认键盘命令进入原终端、原 shell 变量和 PID 保留、网页及草稿未被误输入，并继续第 162 篇的关闭恢复与取消固定原生验收。
