# 复制任务链接命令

2026-09-27。官方 [macOS 命令说明](https://learn.chatgpt.com/docs/reference/commands#keyboard-shortcuts) 为复制当前聊天深链接提供 ⌘⌥L。ShipiOS 已能从任务更多菜单复制私有 `shipios://task/<id>` 链接，但尚无相应命令和快捷键。

现在任务菜单与命令菜单均提供“复制任务链接”，默认绑定 ⌘⌥L。主窗口只在当前任务可用时启用，独立任务窗口按本窗口任务执行；尚未保存的弹出草稿不提供指向不存在任务的链接。现有复制动作和可自定义快捷键机制保持复用，链接继续使用 ShipiOS 私有协议，不读取用户 Codex 的任务库。

深链接、快捷键和窗口命令路由共 17 项定向测试通过；`script/build_and_run.sh --build-app` 构建与签名检查通过。当前沙箱测试未能回读临时剪贴板，自动化只验证链接值与命令可用条件；原生剪贴板结果和与当前 Codex 窗口的配对仍待验收。
