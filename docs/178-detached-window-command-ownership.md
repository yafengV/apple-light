# 分离窗口命令与网页附件归属

2026-09-25。修复分离内容窗口缺少命令上下文，网页快捷键、截图和评论可能作用于主窗口其他任务的问题。

## 实现

分离窗口提供本窗口的菜单与快捷键上下文。窗口关闭命令显示为“关闭标签页窗口”，关闭后按现有逻辑将内容返回原任务。浏览器的显式关闭标签命令只关闭本窗口网页；后退、前进、刷新、忽略缓存刷新、复制网址和地址栏聚焦均使用明确网页 ID。

主窗口浏览器快捷键监听器现在要求事件来自其挂载窗口，并检查窗口激活及模态状态，防止后台浏览器监听器先截获其他窗口的按键。

分离网页地址栏使用独立焦点请求，编辑和聚焦不改变共享浏览器会话中主窗口的选择。网页面板显式传入原任务归属，截图、评论、元素引用和评论标记随原任务保存；新任务草稿也能保存元素引用。下载设置仍在主窗口中打开。

不适用于单个内容窗口、尚未接入的任务与布局命令保持禁用，不再回退执行主窗口任务操作。这是防止串窗的阶段性处理，不代表分离窗口的全部命令已与 Codex 配对。

## 原生验收

使用隔离工作区与本机 HTTP 服务，A 网页为分离窗口，B 网页在主窗口。初始布局来自保存记录，不视为拖放验收。

1. 主窗口切到 B，网页输入 `B preserved` 后最小化。
2. A 窗口中按 ⌘L 选中 A 地址，输入新查询参数并回车，只导航 A。⌘← 返回 A 原地址，⌘R 重新请求 A；服务记录没有额外刷新 B。
3. A 窗口添加网页截图，磁盘只出现 A 的 1 个图片附件，主选择仍为 B。
4. 在 A 页面选择标题，填写并保存 `Only A title` 评论。⌘W 关闭 A 分离窗口；主窗口 B 的网页标签和 `B preserved` 输入均保留。
5. 回到 A 任务，原网页已返回主区，仍显示 A 的评论面板和网页标记。磁盘确认评论与截图只属于 A，两个任务标签布局分别保留。
6. 补充复验：A 有可后退历史时，在评论框输入 `comment`，按 ⌘← 后输入 `PREFIX `，结果为 `PREFIX comment`，网址不变。切回网页焦点后，相同快捷键能正常后退。

结束后关闭本机服务，恢复原工作区，确认原任务、原草稿和输入焦点正常。运行数据、网页截图、测试目录和日志不提交。
