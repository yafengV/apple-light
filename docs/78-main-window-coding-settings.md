# Agent、Git、代码审查与环境设置

2026-09-17。依据本机当前 Codex 应用资源中 `settings.nav.agent`、`settings.nav.git-settings`、`settings.nav.codeReview`、`settings.nav.environments` 以及对应设置文案，补齐四个主窗口设置分类。设置仍由 `AppContentView` 接管，不创建 `Settings` Scene 或第二个窗口。

## 当前实现

- Agent：显示独立 API 的默认模型与推理强度，链接到模型配置；“显示建议提示”直接读写现有个性化存储。
- Git：保存并规范化分支前缀，创建本地分支时预填；复用真实工作树根目录选择与恢复；显示当前项目路径、Git 可用状态和分支。
- 代码审查：保存默认未暂存、已暂存、提交或分支范围；打开新审查标签时应用；只读模式隐藏全部/逐块暂存、撤销和提交操作，但保留差异、历史、分支比较和评论；可从设置返回工作区并打开当前项目审查。
- 环境：显示当前项目和实际构建配置，编辑容器、Scheme、Debug/Release 后写回项目 `BuildProfile`；环境诊断与本地构建继续消费同一份配置，永久工作树继承来源项目配置。
- 新字段写入 ShipiOS 自己的 `workspace.json`，旧数据缺失字段时迁移为 `codex/`、未暂存、非只读和底部终端。不会读取用户个人 Codex 配置。
- 按 Codex 的 `settings.general.defaultTerminalLocation` 归属，默认终端位置位于“通用”页，支持右侧或底部；工具栏终端按钮、命令菜单和固定终端恢复会真实使用该选择。
- 通用页进一步按当前 Codex 资源加入三种发送快捷键、富文本/纯文本编辑器、上下文窗口用量、底部面板标题栏控制、插件总开关、网页链接打开位置、项目外任务文件夹和弹出窗口默认项目范围；主窗口与独立任务窗口使用同一编辑与发送规则，项目外任务使用真实独立输出目录。
