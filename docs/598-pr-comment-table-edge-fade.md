# PR 表格横向滚动的边缘渐隐

本阶段接续[滚动区域与焦点](597-pr-comment-table-scroll-region.md)，补齐普通 PR 表格横向溢出时的渐隐，不改变预览窗口。当前安装的参考版本仍是 26.930.21537；公开脚本、共享 CSS 和初始 CSS 哈希及实际浏览器计算样本见 `pr_comment_table_fade_reference.json`。

实际加载两份公开 CSS 到本机浏览器夹具，保留其 `animation-timeline:scroll(self x)`、`animation-range:min(2px,50%) max(100% - 2px,50%)` 和关键帧。根字号为 16px，普通表格使用注册属性的 1rem 默认距离，不使用 eased 样式。实际操作并读取 computed style 证明：

| 视口 / 内容宽度 | 横向位置 | 左 / 右渐隐 |
| --- | --- | --- |
| 200 / 640 | 0、2 | 0 / 16 |
| 200 / 640 | 3 | 16 / 16 |
| 200 / 640 | 438 | 16 / 0 |
| 200 / 40200 | 22 | 8.0008 / 16 |
| 200 / 202 | 0 | 0 / 16 |
| 200 / 202 | 1、2 | 16 / 0 |
| 10 / 640 | 200 | 16 / 16 |

不溢出时 mask 为 none。极窄视口实际图像呈左侧透明到右侧半透明的坡度；原生算法先遵循 CSS 的递减色标修正，再裁剪到可见区，而非把两端长度先缩小或生成逆序渐变位置。该裁剪解释是依据 CSS 色标规则和可见夹具的推导，没有宣称完整像素配对。

`PRCommentTableEdgeFade` 计算滚动范围、两点边界及首尾 0.1% 的线性插值。原生表格滚动容器使用 alpha 渐变 mask，观察所属 clip view 的 bounds 变化并处理 layout、复制按钮滚动和原生滚动反馈；遮罩没有阻挡鼠标的覆盖视图。只有实际溢出、有效尺寸、挂载和未卸载时保留遮罩；内容替换、缩放、窗口移除和退役会清理旧遮罩及观察者。禁用隐式 Core Animation，让遮罩跟随当前滚动位置。

复制与展开工具栏位于滚动容器外，不受遮罩影响；预览窗口的滚动区没有普通表格渐隐。相关原生层级断言、原有焦点/选区/媒体版本/模态保护均在回归中覆盖。

验证：初次 35 项表格关联回归通过；新增 6 项渐隐专项全部通过；最终 **103 项关联回归全部通过**（`.cache/pr-table-fade-regressions.log`），没有布局循环警告。已安装渐变层的离屏 raster 逐点检查透明度，中心不透明、两侧线性变化；`.cache/pr-table-fade-renders/middle-mask-on-white.png` 已实际查看。这是遮罩层图像，不能代替整张真实表格或双端桌面截图验收。

最终源码经 `script/build_and_run.sh` 正式构建及启动命令成功，严格签名通过（`.cache/pr-table-fade-app-run.log`、`.cache/pr-table-fade-signature.log`）。随后前台已可读取：ShipiOS 唯一主窗口 ID main 显示已有任务 other；⌘, 在同一主窗口进入设置，Esc 返回同一任务并恢复输入焦点；⌘K 打开可见命令菜单，Esc 关闭并恢复任务输入。没有持续显示恢复工作区 loading，本轮基础工作区可交互已有实际证据。没有真实 PR 数据，渐隐的真实附件前台验证及 Codex 完整双端配对仍缺，完整验收保持 **0/47**。
