# 设置隐藏编辑器的 Tab 焦点隔离

2026-09-18。检查设置键盘顺序时发现，通用页的搜索框按 Tab 会先进入零尺寸导航辅助视图，再进入不可见页面的 `SwiftUI.PlatformTextView`。临时原生焦点日志确认了响应者类型；诊断日志代码已经移除。

## 本次修复

- 导航辅助视图仍可在点击侧栏后接收上下键，但不再作为原生 Tab 停靠点。
- 个性化、记忆和 Git 指令使用窄范围的原生纯文本编辑器，遵循父级启用状态。隐藏页禁用时，编辑器不可编辑、不可选择、不可成为第一响应者或 Tab 目标。
- 保留编辑器实例和未保存草稿；切回可见页面后恢复编辑。支持原生撤销、字体偏好、辅助功能标签和输入法组合输入。
- 文本编辑器里的 Tab/Shift-Tab 移动焦点，不往指令或记忆插入制表符。输入法尚在组合文字时不接管 Tab。

## 验证

50 项设置、导航、个性化和 Git 相关回归通过，日志 `.cache/settings-tab-tests.log`。新增用真实 `NSWindow` / `NSHostingView` 验证：

- 输入更新 SwiftUI 绑定，禁用后编辑器实例与草稿保留，但退出第一响应者和 key-view 循环；重新启用可继续编辑。
- Tab/Shift-Tab 切换前后文本控件，不修改内容。
- 组合输入不发布中间草稿；卸载后迟到回调不写入绑定。

最终应用通过 `script/build_and_run.sh --app` 构建运行。原生检查确认：通用页连续 Tab 保持在可见搜索框，不再进入隐藏编辑器；个性化编辑器键盘输入、中文粘贴、撤销与切页保留临时草稿正常，测试后已撤销临时草稿。导航 Down 仍可切页，Esc 返回同一主窗口原任务，原待发送草稿保持不变。

## 剩余范围

设置完整的 Tab 顺序仍未通过验收：给 SwiftUI 导航按钮增加可聚焦能力的实验中，虽能遍历 22 项，但侧栏末尾到右侧表单仍会回跳。该未完成方案没有进入本次提交。最终构建中通用页的 Tab 仍不能遍历侧栏和表单；后续需统一侧栏、搜索结果、返回按钮和所有表单控件的可见焦点与跨区域顺序，不能将本次隐藏编辑器隔离描述为完整键盘对齐。
