# 私有技能目录自动发现

2026-09-28。官方[技能文档](https://learn.chatgpt.com/docs/build-skills)说明可直接创建包含 `SKILL.md` 的目录，新增和修改会被自动发现。此前 ShipiOS 的来源监控虽已扫描私有目录，却只加载 `plugins.json` 登记过的技能；直接加入文件夹时，界面和模型目录仍没有对应入口。

本阶段让 ShipiOS 数据根目录内的 `Skills/<id>/SKILL.md` 自动进入技能库、设置列表、输入候选、预览、立即尝试、显式上下文和隐式发现目录。只扫描直接子目录，忽略隐藏的安装/删除暂存文件夹；沿用既有元数据和标识校验。扫描不改写技能或登记配置，不扫描用户个人 Codex 目录。现有应用生命周期监控负责刷新新增、修改和删除，无需手动导入。

自动发现的技能可以直接编辑、启停和卸载。编辑保留资源并校验原文，外部修改后拒绝覆盖；启停时登记准确标识以持久化偏好，发现本身及编辑不会登记。登记来源的目录被外部删除后不会成为幽灵卡片；重新创建或导入时保留其停用状态。大小写变更以磁盘实际目录名为准，在下一次启停时迁移登记；卸载清除同一标识的旧大小写偏好。在大小写敏感卷上，两个实际不同而仅大小写不同的目录明确报错，不静默合并。

设置页技能数量使用实际加载的条目，包含停用技能，不再使用可能过期的登记数或插件组件声明数。卸载确认明确表示移除 ShipiOS 私有目录中的技能及资源，避免直接创建或放入的技能被描述成另有原始副本。

115 项定向回归通过，包含自动发现的完整生命周期、外部大小写变更、同名创建/导入保护、停用后的删除/恢复、隐藏暂存目录、现有技能库与 MCP 回归。基础聊天和 Codex Core 均经本地真实 HTTP 模型服务验证：不含显式引用的新请求可以读取直接加入私有目录的完整指令，初始目录只含元数据；基础聊天记录实际调用标识，Core 经原生文件工具读取。测试使用隔离临时数据，没有用户凭据或真实模型服务消费。本阶段未重跑全量回归。

应用通过 `script/build_and_run.sh --build-app` 构建和严格签名检查。原生可见页面、焦点、候选弹层和双端操作仍未验收：此前打开 ShipiOS 被自动审批因 Mac 锁定且无法自动解锁而拒绝，仍等待用户手动解锁，本阶段未绕过限制或启动应用。完整双端验收仍为 0/43。

符号链接技能仍是已知差异：新发现的目录链接跳过，链接的 `SKILL.md` 和私有根目录拒绝，登记来源的损坏链接沿用错误校验。在线来源目录、系统作用域、依赖配置、动态目录预算及当前用户版本 Codex 的原生页面配对继续待完成。
