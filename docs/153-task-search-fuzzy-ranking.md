# 任务与命令的模糊匹配、排序和高亮

2026-09-18。替换任务和命令菜单中仅按连续包含关系筛选的实现。

## 对照依据

已安装客户端公开静态资源 `app-initial`：

- `m3/FCo/RCo/LCo` 使用忽略大小写的词边界匹配器，支持通配符、路径分隔符归一化、末尾路径片段回退、超过 100 单元的长模式连续匹配。得分包含前缀、边界、大小写、跳过词数量和文本长度。
- `ICo` 返回 UTF-16 高亮片段，与搜索共用匹配规则。
- `iAo/aAo/oAo` 按标题 0、正文摘要 1、分支 2、项目/工作目录 3 排序；同字段按得分递减，同分按更新时间递减。本地任务 ID 至少 8 位前缀也参与检索。
- 命令的 `mwo` 也使用该匹配得分。本轮接入现有命令标题；未凭空添加参考中不存在的搜索别名。

## 实现

- `DesktopFuzzyQuery` 为纯 Swift 匹配器，返回得分和 UTF-16 范围；长查询、数字、词首、路径、Unicode 和取消检查在同一实现中处理。
- 根菜单与专用搜索使用同一任务排序：标题优先，其后正文、分支、项目及完整目录；保留本地历史的只读加载和不同项目记录过滤。
- 摘要围绕匹配片段生成，多段匹配保留首尾命中范围；界面按真实片段高亮，不把缩写当成连续子串。
- 根菜单命令按匹配得分排序，得分相同保留注册顺序；空查询顺序和任务结果数量上限不变。
- 按参考行为调整旧预期：`cafe` 不再视作 `Café`，`*` 是通配符。Markdown 仍检索显示文本，不能通过未显示的代码围栏语言标记命中。
