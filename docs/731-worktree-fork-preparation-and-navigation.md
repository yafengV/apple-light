## 实现范围

主窗口和独立任务窗口各自持有准备页。页面展示当前检查／保存来源／检出／初始化／创建会话阶段，以及可选目录、错误、取消和继续创建按钮。返回仅离开页面，任务继续在后台执行；取消停止同一创建任务，保留已经持久化的准备检查点。继续使用原检出、固定历史和已完成的初始化，不重新复制来源或运行成功的脚本。准备完成但打开目录失败时保留打开聊天入口。

创建不再全局占用工作区 busy。来源聊天内容保持挂载但在准备页选中时隐藏并禁止交互；已写入的子任务在准备完成前不能打开未就绪目录。准备页拦截隐藏内容命令和审批入口，保留返回、搜索、设置及任务切换。完成后只打开仍持有该准备页的窗口；已返回来源、切到设置／其他任务或关闭窗口时不强制导航。后台完成通知及失败提示属于发起窗口。关闭窗口或应用取消尚未完成的创建。

进入 Git 等待前固定历史、模型与权限；等待期间来源和目标的新草稿保留。独立窗口冷恢复先登记持久窗口身份，不提前建立未就绪目录的面板，完成后才打开任务。后台源会话的续聊队列在准备状态及目标目录打开完成后恢复，避免排队提示再次遇到忙状态而滞留。

准备页没有另建输入框；来源输入保留在原页面，完成后使用目标已有草稿。输入布局与焦点的最终体验仍需可见窗口验收。
