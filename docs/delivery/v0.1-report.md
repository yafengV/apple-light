## 启动、配置与接管

在仓库执行 `./script/build_and_run.sh --app` 构建启动。指定开发实例使用 `--data-root <目录>`；`--data-root` 是应用参数，不能误用 Agent 的 `--data-dir`。需要 macOS 14+、完整 Xcode 和本地开发签名身份；参数及工具链以 [README 本地运行](../../README.md#本地运行)为准。进程存在或构建 exit 0 不单独证明窗口可交互。

设置 → 模型与 API 填写自己的服务地址、模型及协议；密钥通过应用专属 Keychain 保存，不在聊天、报告或 Git 中填写。Core 工具开发使用 Responses 协议，服务必须实际支持它；已配置 MiniMax 的原用户设置没有被本轮受控夹具覆盖。模型切换与请求关联证据见第 69–71、80/81 节。

运行中使用应用停止按钮或 Cmd+.；失败后检查卡片的实际退出码／诊断再显式重试。自动修复最多两轮，仍失败保留工件并由用户接管。文件未保存关闭使用保存／放弃／继续编辑；失效项目先恢复目录，再使用原错误上的重试。不要删除历史或缓存来冒充修复。
