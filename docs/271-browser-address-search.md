# 浏览器地址栏的历史建议与搜索

2026-09-27。主窗口和独立任务窗口共用的浏览器地址栏现在接受网址或搜索词。输入期间按标题、网址匹配 ShipiOS 自有历史记录，保留最近访问顺序，最多显示六条；方向键选择、Return 打开，或直接点击历史页面。没有历史匹配的普通词语显示 Google 搜索入口，Return 同样搜索。明确的网址、localhost 和本地回环地址仍直接导航；显式不安全协议及带凭据的网址继续被拒绝。

依据：[OpenAI 官方浏览器说明](https://learn.chatgpt.com/docs/browser)描述地址栏输入时查找历史页面，并在没有匹配时用 Google 搜索。当前实现只查询 ShipiOS 的本地浏览历史，不读取 Codex 或系统浏览器记录。

47 项真实 WebKit 浏览器测试通过，其中新增输入分类、搜索参数编码、安全拒绝和历史匹配测试。原生地址栏弹层的位置、焦点、鼠标及键盘行为仍待解锁后与当前 Codex Mac 配对，不能据此认定浏览器页面已完全对齐。

后续复核发现首版建议列表会占据浏览器纵向布局，输入时推动网页。建议列表现改为覆盖在网页上方的浮层；挂载测试验证列表出现时网页高度不变，背景浏览器面板仍不会抢占标签或焦点。Mac 锁屏期间无法完成真实鼠标命中与当前 Codex 的视觉配对。
