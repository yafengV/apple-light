# 输入区命令菜单的清除与工作树切换

本机 Codex macOS 客户端 26.911.61220 的命令目录包含 `composer.clear`（“Clear prompt”）和 `composer.toggleWorktreeMode`（“Toggle Local/Worktree”）。其已打包界面代码中，前者仅调用 `setText("")`；后者在新任务的工作树选项可用且输入区未禁用时切换 `local` 与 `worktree`。

ShipiOS 现在于命令菜单和原生菜单暴露“清除提示”与“切换本地／工作树”，可在快捷键设置中配置。清除提示只清空当前窗口输入文本，不删除图片、文件、其他任务草稿或当前模式；独立任务窗口使用自身任务草稿并返回输入焦点。工作树切换仅对有 Git 项目且显示新任务输入区的主窗口可用，沿用已有分段选择器的持久化状态；已有任务和独立任务窗口不会把该命令错误地作用于主窗口草稿。

验证：命令菜单 13 项测试和窗口、快捷键、输入区及项目 51 项回归通过；首次测试失败源于夹具的任务项目与当前项目不一致，`selectTask` 因此按设计异步切换项目，修正夹具后全部通过。`script/build_and_run.sh --build-app`、严格深度签名和 `git diff --check` 通过。Mac 锁屏阻止前台菜单、焦点及 Codex 双端操作验收；完整配对仍为 **0/45**。
