## 设置逐页

从原任务侧栏进入设置，依次打开通用、外观、个性化、模型与 API、快捷键、通知、工作树、已归档任务、运行时。各分类均显示在原主窗口内；没有新建独立设置窗口。已观察到各页对应控件或空状态。

实际按 Esc 返回原任务，输入区仍保留“这是一条待发送草稿，重跑后应保留”。另验证 Cmd+/ 打开快捷键分类；录制快捷键时第一次 Esc 仅取消录制；Cmd+K 在设置之上打开命令菜单，Esc 关闭后仍在原设置分类，再按 Esc 返回工作区。

本轮没有更改 API 服务、密钥、通知授权或已有快捷键，没有发送模型请求。没有验收所有分类的全部控件、全部空/错误/加载状态、完整 Tab 顺序或不同窗口尺寸。

## 发现与修复

快捷键页显示启动时读取文件失败的权限错误，原实现只能保留错误并拒绝之后的写入，没有恢复入口。新增“重新读取快捷键设置”。读取成功后更新绑定并清除错误；失败时保留最后有效绑定并继续禁止覆盖原文件。自动化验证损坏文件修复后重新读取、再次失败不覆盖原文件，以及恢复后可正常保存。重新启动最新应用后，原快捷键文件正常读取，错误消失；本轮没有在真实用户文件上制造故障来点击重试按钮。

浏览器实机测试发现：从空标签切换到已加载标签后，焦点丢到主窗口，随后 Ctrl+Tab 被当作切换任务。修复为选中已加载标签时恢复网页焦点，选中空标签时聚焦地址栏；关闭当前标签后也使用相同规则。延迟焦点操作重新检查当前页面、标签和弹层状态。

## 浏览器复测

使用仅监听本机的 HTTP 测试服务，实际验证：

- Cmd+T 新建标签并聚焦地址栏，输入地址并回车显示真实网页。
- 页面输入内容后导航到下一页，Cmd+左箭头后退，原页面表单内容保留。
- Cmd+L 全选当前地址；输入未提交的新地址后 Esc 恢复实际页面地址。
- 新建空标签，Ctrl+Shift+Tab 回到已加载网页，焦点留在网页；Ctrl+Tab 回到空标签，焦点进入地址栏，任务不变。
- 连续 Cmd+W 关闭标签，最后一个标签关闭后隐藏面板并聚焦消息输入；主窗口保持打开。
