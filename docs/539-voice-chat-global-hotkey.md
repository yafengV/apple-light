# 语音聊天全局快捷键

语音聊天设置现在可录制或关闭独立的全局快捷键，支持带主键组合和单独修饰键组合。在其他应用中触发时，第一次打开 ShipiOS 主窗口内语音会话，第二次结束会话；录制快捷键期间不会触发。该入口复用已有 Carbon 热键与辅助功能授权下的 AppKit 修饰键监听，不另建并行监听器。它与按住、切换听写快捷键不能相同；新的裸修饰键组合也不能与另一个语音快捷键形成包含关系，避免按键过程同时启动两种录音。

偏好迁移、变化时重注册、修饰键重复触发/文字输入取消和设置搜索由 17 项相关测试覆盖；语音设置整页离屏图片已检查。当前机器未提供麦克风，旧 ShipiOS 进程也尚未获准关闭，因此跨应用实际按键、系统权限弹窗、真实语音会话与 Codex 双端交互仍未验收。完整配对继续为 **0/47**，不是 47 项已确认缺陷。
