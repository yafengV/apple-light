# 四个特殊设置页的滚动结构

2026-09-18。本轮继续第 102 篇，覆盖插件、连接、快捷键与已归档任务页面。设置仍在主窗口中。

## 对照依据

读取本机 Codex 应用的静态 UI 资源，没有访问账户配置或会话数据：

- `app-initial-4d7ea7f81c2d.js` 的共用设置容器将标题、操作按钮和页面内容放在滚动文档中，支持独立的 stickyControls。
- `keyboard-shortcuts-settings-da30bad37b3c.js` 与 `data-controls-177358ad1ff5.js` 将搜索/筛选区域传入 stickyControls，将重置/删除操作传入标题操作区。
- `plugins-settings-3c26d614eada.js` 将标题、副标题、浏览目录和添加操作放入共用设置容器。
- `remote-connections-settings-36f88d643bc9.js` 将连接页放入同一设置容器。

## 实现

- 移除设置根视图为四页添加的外层固定标题，改为页内共用滚动容器。
- 快捷键和归档的搜索栏滚动到顶部后固定；标题与标题操作继续滚出视口。恢复默认仅在存在自定义快捷键时显示。
- 插件页的标题、副标题、操作、分类、搜索和列表共用一个滚动文档；内部 Form 采用不滚动的嵌入布局，显式保留开关样式。
- SSH 主机使用外层页面滚动，消除内部 List 的独立滚动区域。没有变更连接命令或执行权限。
- 页面和固定搜索栏使用应用背景色，防止滚动内容透过搜索栏；插件空状态扩展到可用宽度。

## 验证

67 项设置、导航、快捷键、连接与工作区相关回归全部通过，日志 `.cache/settings-special-final-tests.log`，其中布局测试 6 项。

布局测试在独立临时数据中渲染全部 22 个主设置路由；另用 30 条插件记录、30 条 SSH 主机、30 条归档任务和真实命令表检查四页：每页只有一个滚动容器，文档无水平溢出，长内容可滚动。插件的 MCP 与技能标签也检查无嵌套滚动。技能标签使用空技能数据，不代表已验收长技能列表。

共用容器的位置断言确认：滚动 300 点后，标题移出视口，搜索控件仍在顶部 20 点内。离屏渲染文件位于 `.cache/settings-special-snapshots/`；本轮查看了四页顶部、长列表滚动状态和插件标签的图像，检查中修复了透明背景和开关样式退化。

测试没有连接真实 SSH 主机、导入插件、请求模型或删除用户任务。这些是自身 SwiftUI 的离屏测试，不能替代与 Codex 的真实点击、键盘焦点、菜单及弹层配对。

应用构建及严格深度签名校验通过，日志 `.cache/settings-special-build.log`。以原数据目录启动的开发实例 PID 13733；受保护任务和草稿保留。更新后两次原生应用访问均返回 `timeoutReached`，本轮没有取得新的桌面可见状态，不能将前一轮锁屏观察当成本轮成功检查。
