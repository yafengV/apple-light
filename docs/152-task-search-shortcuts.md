# 任务搜索默认分组与结果快捷键

2026-09-18。本轮补齐专用任务搜索的默认结果和两种搜索中的任务槽快捷键。

## 对照证据

已安装客户端公开静态资源 `app-initial`：

- `dwo(chats)` 的 `maxResults` 为 9。`Qko` 先按置顶 ID 顺序取置顶任务，再按更新时间降序填充最近任务，两组共享数量上限；`MAo` 的空查询专用搜索分别渲染这两个分组。
- `hG` 从 `thread1` 至 `thread9` 命令生成，`uAo/dAo` 将这些已注册命令映射到当前任务结果。`MAo` 同时用于 quick 根查询结果和专用搜索。
- `JAo/$Ao` 的结果行显示相应命令快捷键。根菜单空查询的 `RAo` 显式关闭该数字提示，且没有单独的 `uAo` 注册；本轮没有给它添加与参考不符的数字提示。

## 变更

- 专用任务搜索空查询显示“已置顶”“最近任务”；置顶遵循已有侧栏顺序，其他结果按更新时间排列，同时间保持稳定顺序，去重后最多 9 条。非空查询保留搜索层顺序、最多 9 条。
- 根搜索查询结果和专用搜索结果均显示“切换到聊天 1–9”的当前绑定。槽位只按任务结果计数，命令和浏览器行不占槽位。
- 搜索键盘桥接可选接入快捷键偏好，支持数字目标切换、用户换绑、解绑。文件搜索未接入任务槽。正在使用输入法组合文本时不接管快捷键。
- 结果快捷键复用已有可用性、查询版本和导航检查；不存在的序号被搜索处理，不会向后台任务/标签命令泄漏；旧结果不会因快速改词而打开。
- 原有 Cmd-W、Escape、方向键、Tab 行为保留。

## 验收

- 36 项相关测试通过，覆盖分组及顺序、去重/9 条上限、搜索顺序保留、快捷键目标切换、自定义绑定、解绑、输入法保护，以及命令/浏览器/任务/文件搜索回归。日志 `.cache/task-search-slots-tests.log`。
- 原生隔离工作区置顶 A 后，专用搜索显示 A 为第一组、其余任务为最近组，快捷键连续显示 `⌃1…⌃6`。
- 专用搜索按 `⌃6` 跨项目打开 B，B 原草稿保留且输入框聚焦；根搜索查询“主窗口”显示 A 的 `⌃1`，按键打开 A 并保留草稿。
- 仅一条结果时按 `⌃9`，弹层和当前任务保持；根搜索改为无匹配词后立即按 `⌃1`，没有打开旧结果。
- 在主窗口内快捷键设置将数字目标切换为“⌘1–9 切换聊天”，根搜索和专用搜索提示同步显示 `⌘`。从设置打开根搜索并按 `⌘1`，实际打开结果任务而非后台标签。
- 专用搜索从 6 条默认结果快速改为无匹配词并按 `⌘6`，弹层仍显示空结果。测试结束恢复隔离工作区的置顶状态和数字快捷键偏好。
- 恢复原工作区，确认原任务输入框可交互及未发送草稿完整；严格签名检查通过。未发送模型请求，缓存/日志/运行数据不提交。

## 剩余差异

非空查询精确模糊评分和字段优先级、命令下一级选择栈、可靠鼠标悬停、完整辅助功能选择语义及各页实时视觉配对仍未完成。本轮的分组和快捷键验收不证明完整 UI 对齐。
