## 实现

- 未暂存与已暂存范围顶部显示文件数量及“全部暂存 / 全部取消暂存”；历史范围不显示批量写操作。
- Git 更新期间显示进度并禁用相关按钮。快照尚未准备好、没有变更或正在刷新时，不能触发批量操作。
- 刷新时保存当前范围的状态、索引变化与 HEAD。未暂存范围还流式计算文件内容摘要，包含新增、删除、二进制内容和权限信息。
- 执行前重新读取并比较，发现新增文件、内容或索引变化则不使用旧状态执行，提示刷新。
- 待操作路径写入 0600 权限的 NUL 分隔临时清单；一次 Git 命令更新索引，结束后删除清单，不按文件循环写索引。
- 暂存支持当前 Git 状态中的新增、修改、删除和重命名。取消暂存使用快照中的 HEAD；首次提交前使用仅移除索引记录的命令，保留工作区内容。
- 重命名保留旧、新路径，特殊字符路径按字面处理。
- 符号链接只记录链接本身，不读取其外部目标。父目录越界及 `.git` 内部路径被拒绝。
- 同时修正单文件入口：首次提交前取消暂存能保留后来编辑的文件；链接本身可暂存或取消暂存，不因目标在项目外而误拒绝。

批量操作作用于当前仓库范围。子仓库目录的暂存采用 Git 的提交指针行为，不递归暂存其中的工作区修改；多仓库统一选择仍是独立缺口。

状态校验不构成跨进程事务锁。校验后若其他程序继续修改仓库，最终仍由 Git 的命令执行与索引锁处理错误。
