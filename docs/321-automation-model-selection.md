# 计划任务的模型与推理强度

[OpenAI 官方 Scheduled tasks 文档](https://learn.chatgpt.com/docs/automations?surface=app)允许计划任务沿用默认模型与推理强度，或分别显式选择。ShipiOS 自动化编辑器现从独立 API 服务读取可用模型，也允许输入模型 ID；推理强度可沿用服务配置、选择服务默认，或选具体等级。旧计划任务的空值继续沿用服务配置。

每次运行新建任务时，所选模型与推理强度固化为该任务的配置，随真实 Chat Completions 或 Codex Core 请求发送。编辑器若在运行开始前打开、运行结束后才保存，会从当前存储合并最新的任务 ID、运行历史、审查状态和中断恢复状态，避免旧表单覆盖运行记录。

验证：22 项自动化模型及日程测试、2 项真实请求测试通过，覆盖显式模型和推理等级、沿用全局配置、服务默认推理，以及 Codex Core 工具调用。应用构建和签名检查通过。Mac 锁屏，模型菜单、键盘焦点和布局尚未做原生点击验收。

仍缺：计划任务的完整 RFC 5545、自动化环境文件选择及当前 Codex Mac 的逐页交互配对。无人值守审批行为见[第 322 篇](322-automation-unattended-permissions.md)。
