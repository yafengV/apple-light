# Appshot 原生捕捉过渡

参考 Codex 桌面端把输入区目标区域交给桌面宿主，由宿主执行捕捉动画，截图和最终附件事件分开到达。ShipiOS 此前在截图保存成功后直接显示静态卡片。

现在捕捉结果保留源窗口在屏幕坐标中的矩形；草稿卡片通过一个窄范围的 AppKit 视图桥回报所属窗口和目标位置。保存附件后，若源矩形、目标窗口和可见位置都可用，非激活、忽略鼠标事件的透明原生浮层将截图从源位置移动到目标卡片。过渡完成、失败、取消或两秒超时都会清理浮层并显示卡片。目标只接受发起捕捉的窗口，减少动态效果开启时直接显示附件。没有可靠几何信息时也直接显示。

源矩形优先使用所选 `SCWindow.frame`，系统选择器未提供窗口身份时退回 `SCContentFilter.contentRect`；Apple 将后者定义为屏幕点坐标（[Apple 文档](https://developer.apple.com/documentation/screencapturekit/sccontentfilter/contentrect)）。坐标按对应显示器映射到 AppKit 屏幕空间。自动化测试覆盖有效／无效源矩形、跨显示器映射、窗口归属、减少动态效果和现有附件路径；构建与签名结果见本阶段提交。

这一实现尚未达到动画最终验收：当前使用保存后的截图作为过渡图，参考宿主的早期过渡快照、动态弹簧参数和最终截图事件仍需对照；Mac 锁屏阻止了真实跨应用及多显示器可见验证。完整 Codex／ShipiOS 配对仍为 **0/45**。
