# 独立任务窗口会话查找

2026-09-17。独立任务窗口现在可直接搜索自己的会话，不再把 `/find` 或 `⌘F` 路由回主窗口。工具栏搜索按钮和 `⌘F` 打开窗口内查找条；Return、`⌘G` 和向下按钮前进，`⌘⇧G` 和向上按钮后退，结果循环定位，关闭后输入焦点回到任务输入区。

查找索引严格使用窗口绑定任务的运行顺序。提示词、Markdown 段落和标题、代码块、表格、本地执行名称与摘要、诊断输出、错误和停止提示进入索引；其他任务内容不会混入。活动匹配使用现有原生文本高亮和实际排版锚点，懒加载内容先滚动到所属运行，再定位到具体文本片段。查找期间的新流式内容会重新索引，但不会强制滚回会话底部。

任务窗口工具栏同时增加设置入口。它只修改共享 Store 的主窗口页面并唤起 `Window("ShipiOS", id: "main")`，不会创建 `Settings` Scene 或新的设置窗口。

4 项任务窗口测试包含精确草稿/附件归属、跨项目模型会话和搜索索引隔离；原有 6 项会话搜索测试继续覆盖 Unicode、Markdown 分段、流式更新和取消竞争。完整回归为 349 项 Swift、12 项 Rust、fmt/Clippy 和真实 IPC 冒烟全部通过，日志 `.cache/task-window-find-full-tests.log`。

以原数据目录重建启动 PID 67561 后，原生任务窗口查询“构建”得到 8 项，Return 定位到 2/8，下一项按钮移动到 3/8；关闭后 `⌘F` 恢复同一查询和位置。点击任务窗口齿轮后，辅助功能树显示标题“设置”且窗口仍为 `ID: main`。Esc 返回任务“验证新输入框的真实构建”，草稿“这是一条待发送草稿，重跑后应保留”未变化。
