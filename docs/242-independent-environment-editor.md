# 环境设置与任务工作区隔离

Codex Mac 的环境设置可以查看和编辑其他项目，同时保留当前任务上下文。ShipiOS 的环境页现使用独立 Agent 会话和临时私有数据目录处理所选项目的本地环境；选择、创建、重载和保存均不调用主工作区的项目切换。主窗口的任务、草稿和运行连接保持原样。编辑当前项目并保存时，会刷新其工作树环境与顶部快捷操作；编辑其他项目只更新所选项目的共享 TOML 文件。

环境编辑会话具有单独的文件修订号和未保存状态。返回概览时明确放弃会重载原文件；存在未保存内容时，跨项目选择先要求处理草稿，不会静默覆盖。应用关闭时停止辅助 Agent 并移除临时目录。用户的个人 Codex 配置和认证仍与 ShipiOS 独立。

真实 Agent 集成测试覆盖编辑第二个项目并保存后，原项目、任务选择和原项目文件均保持不变。页面视觉、焦点和键盘行为仍受 Mac 锁屏阻碍，不能记为完整 Codex 配对。43 个验收面完整配对数仍为 0。
