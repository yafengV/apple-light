# 弹出窗口首页与会话的位置对齐

当前 Codex 26.911.61220 / build 9647 的主进程分发资源 `main-DS3FMq4P.js`（SHA-256 `9f4ce005ae6422a85758fe1d8e8f26e049f85026dc65618f6901fa65b0be35c0`）定义弹出窗口首页 470×290、会话 470×640，后者最小 400×400。会话首次显示时位于鼠标所在显示器工作区的水平中间，顶部留 52px；首页以会话的底边为基准摆放。两种表面互相切换时共用底边：从首页进入会话时居中对齐，从会话返回首页时首页宽度匹配会话宽度。可用工作区不足时窗口尺寸和位置受其边界约束。

三组数值测试覆盖 1440×900 工作区的实际参考尺寸与坐标、拖动／改宽后的双向切换，以及小屏幕边界；连同状态与离屏布局共九项定向测试通过，扩大至设置和恢复流程后的 41 项回归也通过。`script/build_and_run.sh --build-app` 构建、严格深度签名通过，29 个语法资源和七份许可证与源文件逐字节一致。真实多显示器、拖动缩放、前台焦点、过渡动画及 Codex 双端可见对照仍待验收，完整配对仍为 **0/45**。
