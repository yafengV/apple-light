# 文件外部改动与大文件只读预览

2026-10-01。已选中文件每秒检查磁盘的大小、修改时间和文件编号；变化时重新读取实际文本。编辑器没有本地改动时，预览同步新内容并保留原生选区；存在未保存草稿时，停止自动保存并显示本地与磁盘版本的冲突，仍由用户决定保留哪份。切换文件或项目会取消旧监控，关联目录移除后不再写入该目录。未选中的文件在再次打开时读取最新内容。

UTF-8 普通文本现在可预览至 20 MiB；超过 1 MiB 的文件以只读方式显示，不执行语法高亮或应用内写入，缩小后自动恢复可编辑状态。磁盘版本超过编辑上限时，冲突面板不提供无法成功的“覆盖”操作。超过 20 MiB、二进制内容及不支持的编码仍引导用户在外部编辑器打开。
