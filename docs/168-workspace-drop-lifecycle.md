# 主窗口隐藏投放目标与共享拖动清理

2026-09-19。

## 实现

主窗口补齐侧面板隐藏时的边缘投放区域，以及底部面板隐藏或没有终端时的底部目标。侧面板目标和提示文字跟随左右交换，底部仅接受终端；设置等非工作区页面拒绝内容投放。移动保留原网页和 PTY 实例。

原来的主窗口拖动状态会在固定 10 秒后清除，长时间拖动会失去提示，提前取消则可能残留提示。现在主窗口与独立任务窗口共用 `TabDragLifecycle`：仅在活动拖动期间观察鼠标释放，Escape 不被消费，视图退出也清理状态。释放回调携带会话身份，旧回调不能清除新拖动；关闭源标签、切换主窗口任务或页面也会结束主窗口拖动。

## 原生检查与边界

- 隔离工作区重新启动后，独立窗口命令菜单可打开，Escape 后返回任务输入和原草稿。
- 主窗口正常新建网页标签；账户菜单的设置仍使用 `ID: main`，返回后网页标签保留。
- 设置搜索输入有自己的 Escape 清空规则，不退出页面。Shift-Tab 将焦点移到返回按钮后，Escape 正常返回原任务。此行为与已有搜索编辑器测试一致，未修改设置键盘路由。
- 本轮在独立窗口从标签文字和图标各尝试一次合成拖动，主窗口尝试一次。页面均未显示完成移动；这些尝试不能证明系统拖放成功，也不足以区分输入合成和产品投放问题。

隐藏目标命中、长拖动的原生反馈、窗口外释放、Escape 取消系统拖动和全部跨窗口路径仍需原生验收。自动化状态与实例身份测试不替代系统鼠标投放。完整 Codex 逐页配对尚未完成。
