# PR Code 跳转到文件

Codex Mac 的 PR Code 工具栏有独立“跳转到文件”弹层；ShipiOS 此前只有右侧文件树中的常驻搜索。现在工具栏新增按钮，打开后自动聚焦搜索框。空查询按文件名、父目录排序；输入时优先模糊匹配文件名，再匹配路径；方向键选择、回车打开、Esc 关闭，点击或悬停也能选择结果。没有命中时显示明确的空状态。

选择文件会清除文件树的旧筛选、展开目标差异，并通过现有页面定位请求滚动到该文件；无效路径不会改变状态。2 项排序/匹配测试和新增的定位状态测试连同原有 PR Code 用例共 21 项通过。`script/build_and_run.sh --build-app` 与严格签名检查通过。Mac 锁屏阻止了弹层实际焦点、键盘与 Codex 双端视觉验收；完整页面配对仍为 **0/47**，不是已确认缺陷数量。
