# 普通侧栏任务行操作与标题重命名

普通侧栏与 Activity 任务行现在共用置顶、归档控件。鼠标悬停或任务行获得键盘焦点时显示操作，隐藏原有快捷键提示或尾部状态；按钮按任务 ID 读取最新状态，不先选择另一任务。跨项目任务暂时不能打开时，仍可在满足操作条件时置顶或归档，当前会话和草稿保持原归属。

双击标题区域调用独立重命名入口，只允许当前工作区选中且未归档的任务，读取最新标题。项目名称、状态文字及其他任务的标题不直接触发该入口；菜单明确选择重命名另一任务的行为保持可用。项目重命名、模型/分支弹层、确认及归档保留目标均保护菜单操作。

参考依据是此前缓存的 Codex 26.908.70816/build 9275 静态资源：`e8t` 的选中标题双击条件、`eV` 的置顶/归档按钮，以及 `pXt` 的悬停/焦点动作和快捷键提示互斥。共用按钮采用 20 点区域、16 点图标、8 点间距和 52 点尾部预留。Activity 本地任务行仍没有普通侧栏数字提示。缓存资源不等于当前版本双端实机证据，也未引入没有对应账户来源的 Work 操作。
