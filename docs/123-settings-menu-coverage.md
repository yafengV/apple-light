# 设置菜单接入范围与辅助功能焦点

2026-09-18。接续 [设置菜单键盘操作](122-settings-menu-keyboard.md)，记录本次提交的实现、验证与待验收范围。

## 实现

七处设置下拉控件接入统一的 `SettingsMenuPicker`：模型推理强度、代码审查默认范围、项目构建配置、外部浏览器链接快捷键、数字快捷键目标、默认网站访问权限及逐站点权限。原有绑定和持久化逻辑保持不变；分段选择器及归档菜单中的选项不在本次范围内。

辅助功能打开菜单时先将焦点交给实际原生控件，使取消后焦点回到触发按钮。禁用、隐藏或卸载的控件拒绝辅助功能激活。逐站点权限菜单的辅助功能名称包含域名；隐藏标签仍保留辅助功能名称，但不占据行内布局宽度。
