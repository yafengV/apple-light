# 实时语音音色试听

Codex macOS 当前公开语音设置资源在“选择音色”对话框启用了试听。ShipiOS 的选择对话框现为每个内置音色和有效自定义 ID 提供播放／停止按钮。试听建立一条独立的短时 Realtime WebSocket 会话，使用用户在 ShipiOS 配置的同一实时模型及 Keychain 凭据，发送一句短样例并直接播放返回的 24 kHz PCM；切换音色、关闭对话框或点击停止会取消连接和音频。试听不改变已保存音色，也不需要麦克风。按钮旁明确说明调用独立服务可能产生用量。

协议依据 [OpenAI Realtime 会话与音频事件](https://developers.openai.com/api/docs/guides/realtime-conversations)。常规语音相关回归为 27 项：25 通过，2 项本地夹具测试在未设置 URL 时跳过。另以仅监听 `127.0.0.1` 的 WebSocket 夹具运行这 2 项，验证会话握手、文本样例、静音 PCM 播放到结束及中途取消，均通过。选择对话框离屏图片、正式应用构建和严格签名通过；夹具已经停止。

用户尚未在 ShipiOS 填入真实独立服务，本机也未完成新版前台启动，所以真实音色品质、计费用量、实际点击/焦点和 Codex 双端配对仍须验收。完整配对仍为 **0/47**，表示 47 个验收面均缺双端完整证据，不表示 47 项功能都缺失。
