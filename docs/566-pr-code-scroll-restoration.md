# PR Code 页面纵向位置恢复

当前 Codex PR Code 页面在差异滚动视图卸载时记住纵向 `scrollTop`，重新进入同一 PR Code 页面时恢复。ShipiOS 原先在 Code／概览切换后重建 `ScrollView`，每次回到顶部或重放旧的文件跳转。

现在 PR 代码状态保存纵向位置，原生滚动探针只观察外层差异文档，不干预各文件内部横向代码滚动。Code 页离开、重新进入后恢复原位置；新 PR 代码请求或状态失效会清除旧位置。新文件和评论定位仍执行一次，但离开 Code 页后不会在下次打开时重放。初始位置为零时直接开始记录，避免迟到的恢复操作把用户的新滚动拉回顶部。

隐藏原生窗口测试覆盖滚动到 640 点、Code→概览→Code、选中另一个文件后的再次往返，以及失效后位置清零；文件标题、折叠、复制、窄窗口和评论行跳转共 **11 项回归通过**（`.cache/pr-code-scroll-header-regression.log`），PR Code 状态另 **29 项通过**（`.cache/pr-code-scroll-state-regression.log`）。复制路径用例需系统剪贴板访问，沙箱内单独失败，授予该测试所需权限后通过。`script/build_and_run.sh --build-app` 正式构建和严格深度签名通过。真实可见桌面的鼠标／触控板与 Codex 双端配对尚未完成，完整验收保持 **0/47**。
