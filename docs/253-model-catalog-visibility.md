# 模型目录优先级与可见性

2026-09-26。Codex Core 模型目录允许服务为模型提供 `priority` 和选择器可见性。ShipiOS 现在在独立服务 `/models` 提供这些字段时按优先级排序，并尊重 `show_in_picker` / `showInPicker` 或 `visibility`（`list`、`hide`、`none`）。没有这些字段时维持按模型 ID 排序和全部可见。当前已选择的模型即使后来从选择器目录隐藏，仍作为当前项显示，可让用户识别并更换。

这只使用当前用户配置的独立服务所返回的目录，不读取个人 Codex 模型配置，也不推断服务不支持的模型。Codex Mac 的跨模型版本预设、弹层布局以及鼠标、键盘、焦点行为仍未完成实机配对。

模型选择相关 12 项测试通过，包含优先级解码、隐藏条目过滤和当前隐藏模型保留；应用构建及签名校验另行完成。
