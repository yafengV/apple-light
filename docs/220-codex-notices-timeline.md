# Codex 会话提示时间线

2026-09-26。Codex Core 的 `warning`、需展示的 `guardian_warning`、`deprecation_notice` 与 `model_reroute` 现在作为独立提示留在任务时间线。它们不被拼进助手回复，也不会把继续运行的回合误标为失败。提示按事件顺序保存，主窗口与独立任务窗口使用同一视图；Core TUI 隐藏的自动审批通过噪声同样被过滤。

真实 Codex Core `/compact` 经本地假模型执行后会发出长会话警告。集成测试确认它位于上下文整理标记之后，整理回合仍成功，重启后提示可恢复。单元测试覆盖警告位于前后回复之间、弃用与模型切换提示的解析，以及自动审批通过消息的过滤。相关应用构建通过 `script/build_and_run.sh --build-app`。

当前 Mac 锁屏，原生提示的颜色、位置、辅助功能、键盘与当前 Codex Mac 的配对尚未完成；43 类完整配对数量不变。
