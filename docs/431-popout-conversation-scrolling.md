# 弹出会话的流式滚动与返回底部

弹出会话此前只在回合 ID 列表变化时直接滚到底部。单个回合内持续生成的内容不能跟随；用户上翻阅读旧消息后，新回合又会强制把视图拉走。主工作区已使用 `ConversationScrollState` 和原生滚动几何观察器处理这两种状态，弹出会话现在采用同一规则。

打开已有长会话时视图定位到最新回复。用户用滚轮、滚动条或键盘离开底部后，后续回复增长保留阅读位置，并显示“返回底部”按钮；有新内容时按钮带提示点。点击按钮恢复追随最新内容，窗口改变高度和 Markdown 迟到排版也由原有几何状态处理。

隐藏原生 470×640 弹出窗口加载八个长回合后，测试确认初始视图靠近底部；上翻到旧回合并更新末尾回复后，滚动位置变化小于 10pt。截图检查了旧消息、返回按钮和新内容提示点。弹出窗口、滚动状态及任务窗口的 33 项相关回归通过，初始定位断言另行复跑通过。`script/build_and_run.sh --verify` 构建启动、严格深度签名和 29 个语法资源／七份许可证逐字节核对通过。Mac 锁屏阻挡真实滚轮、点击和工作区可交互检查；Codex 应用仍不能由当前 UI 工具读取，完整双端验收保持 **0/45**。
