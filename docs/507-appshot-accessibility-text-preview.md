# Appshot 预览中的辅助功能文字

Codex 桌面端的 Appshot 灯箱在当前截图有非空辅助功能文字时提供“View text”操作；文字态显示标题为 `plaintext` 的可滚动文字面板，保留下载，隐藏图片缩放控件。切到图库另一张图时回到截图态。

ShipiOS 的共用图片图库现在只对带有非空 Appshot 辅助功能文字的附件显示“查看文字”。文字面板支持滚动和选择；按钮的辅助功能标签随截图／文字态变化，键盘 Tab 和激活可操作。图片缩放命令在文字态不执行，图片切换会重置文字态。普通图片、空文字 Appshot 和工具输出图片不提供此入口。

18 项相关测试覆盖文字可用性、空值、普通图片、工具输出以及既有图库与捕捉路径，正式构建和签名结果见本阶段提交。由于 Mac 锁屏，实际图库页面、焦点和 Codex 双端对照尚未验收。捕捉移入输入区的宿主动画仍未实现；完整配对保持 **0/45**。
