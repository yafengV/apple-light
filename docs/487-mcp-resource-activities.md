# MCP 资源活动进入来源页

本阶段依据本机 Codex 桌面包 `26.911.61220` 的静态界面资源，补齐 MCP 工具结果 `_meta["openai/resourceActivities"]` 的解析。该元数据必须为版本 1，资源包含 ID、HTTP(S) URL、可选标题和 MIME 类型，以及 `read`、`created`、`updated` 活动。无效、失败或缺失元数据的工具结果不会被猜测为网页来源。

ShipiOS 在本地 MCP 与 Codex Core 的成功调用结束时保存结构化活动，避免 Core 输出预览截断后丢失来源。来源按规范化 URL 跨回合合并；仅用户提供过，或在某一回合读取且该回合未创建的资源进入来源列表。纯创建／更新的资源仍保留在原工具调用记录中，不冒充已阅读来源。来源详情可显示“聊天期间创建／更新”。

解析、回合筛选、旧记录恢复、本地 MCP 真实调用与持久化由定向测试覆盖。静态对照仍不能替代 Codex 和 ShipiOS 两端的前台视觉、焦点和逐项交互验收；同一 URL 下不同 MCP 资源 ID 的独立展示、创建产物区的单独呈现也待继续核对。
