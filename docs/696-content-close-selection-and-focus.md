## 参考依据

参考版本为 `26.930.51102`、build `13100`。只读公开资源 `app-initial-f9b16fbf8fc7.js` 的 SHA-256 为 `22f3ea455585cfc0508e3d3627eac161c80c849c0aace3d76d09fdebaa0aeca3`。

公开关闭调用 `oe` 先考虑配对伙伴，再调用 `IBn`；`IBn` 先尝试有效 opener 家族，最后按右邻、左邻回退。`RBn` 只记录显式打开来源；`zBn` 处理选择及 generation，`HBn` 在移动家族成员时清空关系，`VBn` 递归删除关闭项及其后代关系。普通聊天的 `SHn` 改变外层呈现，没有清空底层内容选择，因此回到聊天不能顺带作废 opener 家族。

`script/extract_content_close_reference.cjs` 校验来源摘要，只执行上述纯函数及其依赖，不初始化参考应用或原生桥接。夹具包含 24 组控制器操作序列和 4 组显式构造的缺失 opener 状态。后者只证明纯函数回退规则，不宣称已通过界面形成那些状态。配对伙伴、关闭确认、原生焦点和 primary workspace 不在该提取器的证明范围内。

## 已实现的行为

| 动作／状态 | 实现与验证范围 |
| --- | --- |
| 关闭当前内容 | 在同任务、同内容面板的混合标签顺序内，优先有效显式 opener，再取右邻或左邻；为空才退出当前内容 |
| 完整视图／普通分屏 | left 与 right 保存位置共享主内容集合；关闭及回选保留当前布局，不把聊天、底部、分离或其他任务混入候选 |
| 来源关系 | 浏览器子页紧邻显式来源插入；嵌套、同家族选择、无关选择、独立新页、排序、删除和新 generation 对照实际参考结果；普通独立新标签不会自动认前一个标签为来源 |
| 聊天与布局切换 | 完整视图／分屏切换及回到聊天保留底层来源关系；聊天已有焦点时关闭子页，只修复底层选择，不抢输入焦点 |
| 范围隔离 | 独立任务窗口维护自身控制器；后台任务关闭只修复自己的保存布局，不改变当前任务的浏览器选择或焦点；底部终端独立回退，保留存活 shell 的实例和 PID |
| 隐藏及分离内容 | 以实际可见内容焦点判断是否请求焦点；关闭隐藏侧栏不重新打开它，关闭分离标签不向主窗口请求输入焦点；清理已关闭项的陈旧焦点 ID |
| 保存与恢复 | 后台子页在内存和保存布局中都紧邻来源；冷恢复不重播瞬时来源关系，按恢复后的相邻顺序关闭回退 |
| 文件保存 | 复用现有保存策略，失败／磁盘冲突保留标签及选择；重复关闭合并等待，同 ID 编辑器已替换或任务资源已重建时，迟到保存结果不能关闭新对象 |
| 原生焦点路由 | 浏览器选择与原生焦点请求分离，任务窗口只请求一次；替代项为浏览器、文件或终端时走对应焦点通道，视图继续检查可见性、模态状态和请求身份 |

主窗口关闭浏览器不再由共享 BrowserSession 先选一个全局相邻浏览器，再由内容控制器选第二次。内容所有者统一决定回退，避免跨任务或跨内容种类选择。独立使用 BrowserSession 的默认行为保持既有约定。
