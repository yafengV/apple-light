# 输入区语音听写

2026-09-27。Codex [命令参考](https://learn.chatgpt.com/docs/reference/commands)列出听写入口和 macOS 默认快捷键 `⌃⇧D`。ShipiOS 主窗口及独立任务窗口现提供麦克风按钮、相同默认快捷键、听写状态和失败反馈。两类窗口共享单个录音会话，切换任务或关闭所属窗口会结束原会话；识别文字写回启动时的任务草稿。用户在录音期间修改草稿时，结果追加到新内容末尾，不覆盖修改。文本未变时优先插入到原光标或选区。

实现仅在用户启动听写时请求麦克风与语音识别权限，要求当前语言支持 Apple 设备端语音识别，并在停止、错误或退出时释放音频输入。构建应用包含两项系统隐私用途说明。权限被拒或设备端识别不可用时会在原输入区显示错误。该实现不读取用户个人 Codex 账户或配置。

本阶段 16 项相关自动化测试通过，覆盖 UTF-16 光标、选区替换、用户编辑保留、标点、空输入、快捷键默认值与任务窗口命令归属。`script/build_and_run.sh --build-app`、`codesign --verify --deep --strict` 以及两项隐私用途说明检查通过。设备仍锁屏，麦克风权限弹窗、真实录音结果、焦点恢复和 Codex 双端视觉/交互配对尚未实测，因此听写项仍属待原生验收。Codex 可能使用不同识别后端，当前仅提供系统设备端听写，不宣称其全部行为一致。
