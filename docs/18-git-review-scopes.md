## 已实现

- 范围菜单提供未暂存、已暂存、提交、分支。
- 提交选择来自真实 Git 历史，显示最近 100 条可从 HEAD 到达的提交及短哈希。首次提交与空树比较，普通和合并提交与第一个父提交比较。
- 分支选择列出实际本地与远程跟踪分支，排除符号引用；需要用户明确选择基准。比较共同祖先到当前 HEAD 的已提交变更，不包含脏工作区。
- 历史范围提供变更文件选择、全部文件返回、加载中、无提交、未选基准、空差异与 Git 错误状态。暂存、取消暂存及提交入口仅用于工作区范围，存储层也拒绝历史范围的修改操作。
- Git 引用先解析为不可变提交 ID，再执行比较。参数独立传递，路径按字面值处理，不调用外部 diff / textconv；现有命令超时和输出上限继续有效。
- 项目切换使未完成的读取失效；范围、引用或文件改变后，旧请求不能覆盖当前结果。
- 审查视图拆分到 `GitReviewView.swift`，Git 读取逻辑放在 `GitReviewService.swift`。

范围种类参考[官方代码审查说明](https://learn.chatgpt.com/docs/code-review)。本实现的历史条数上限、首父比较和界面排版属于当前 ShipiOS 实现选择，不能据此认定与用户安装的 Codex 完全一致。
