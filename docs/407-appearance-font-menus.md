# 外观页字体菜单与自定义输入

界面、内容和代码字体的浅／深六组控件改用主窗口内浮层，复用代码主题菜单的窗口、生命周期与焦点桥接。字体与样式按钮均为 144×28、12 点基础文字；字体菜单宽 240、样式菜单宽 208、总高度最多 350。样式只有一项时菜单按实际 34 点高度打开，不能被原主题菜单的最小高度规则拒绝。

## 选择与默认值

显示和选择只解析 CSS 字体列表的第一项，处理引号内逗号、转义、Unicode 和 JavaScript trim 边界。未知第一项仍显示其名称，不在菜单插入额外的当前项，也不把后面的已安装回退字体当成已选择字体。渲染使用完整回退列表，但 face 覆盖只能属于第一项；系统默认通用字体在首项生效，避免错误落到后面的 Georgia 等字体。

目录内家族名称不区分大小写匹配；样式按同家族和精确 PostScript 名匹配，否则显示目录中的第一项。代码字体候选仅保留全部 face 均为等宽的家族；已保存的非等宽家族仍显示名称，但禁用样式选择。

重复选择当前家族或当前 face 关闭菜单且不写入，不清除原样式或回退列表。选择新家族清除 face；选择第一项样式也清除 face，其余保存家族、完整名称和 PostScript 名。默认清除属于该角色和浅／深侧的覆盖；内容默认动态继承 UI 字体。旧存储使用空字符串表示清除，送入显示逻辑时按默认值处理。

## 窗口、键盘与失败

加载字体目录时显示小进度指示，查询由六组控件共享并在当前进程缓存。目录为 nil 或空时，字体菜单显示默认、编辑字段和“使用自定义字体值”；有目录时只显示目录选项。打开重置草稿，字段自动获得焦点、关闭自动拼写和引号替换；输入本身不保存，Enter 或明确菜单动作 trim 后保存并清除旧 face。marked text 不拦截 Enter，取消／失焦／卸载不隐式保存。

菜单内普通选项的键盘入口选中第一项，鼠标入口不预选；上下键不循环，Home／End、Tab 阻止离开普通菜单、一秒文字匹配、外部点击透传、窗口失焦关闭与选择后焦点恢复沿用共用桥接。字体匹配仅使用标签文字，没有代码主题的 Aa 前缀。自定义字段的键盘交给原生编辑器，Esc 在字段内保持菜单；输入法及原生文本撤销路径不交给菜单搜索。

同一窗口打开其他字体、样式或代码主题菜单会关闭前一个浮层，其他窗口保持独立。设置页 Esc 返回保护现覆盖全部此类浮层；卸载、隐藏、禁用、工作区恢复和旧回调不能提交。保存失败关闭菜单、恢复实际标题与样式状态、显示原错误并返回触发按钮，保留任务草稿和另一侧主题。原页面六组字体控件的持久化／失败测试继续保留。

## 验证与剩余范围
