## 修复

- 未修改配置时禁用保存；必需字段、名称重复、请求头或环境变量无效时禁用保存并提供错误提示。
- 改动后重新验证表单，清除上次保存留下的旧错误。
- 新建表单显示 [MCP 文档](https://developers.openai.com/codex/mcp/) 入口。
- 保存入口也识别无效改动，即使调用方绕过按钮状态，仍不会写文件、断开现有连接或拒绝待审批调用。
- 配置比较依据实际连接字段：忽略表格行身份、环境变量透传顺序、HTTP 请求头大小写，以及不属于当前传输方式的字段；参数顺序、变量值等实际变化仍须保存。

设置页仍位于主窗口，返回、保存和卸载不创建独立设置窗口。
