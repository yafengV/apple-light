# `/project` 与 `/task` 输入区命令

2026-09-28。依据 [官方斜杠命令参考](https://learn.chatgpt.com/docs/reference/slash-commands)，`/project` 应选择新任务的项目，`/task` 应创建无项目任务。此前 ShipiOS 的 `/project` 打开项目管理页，且没有 `/task` 候选。

现在主窗口的 `/project` 打开项目选择器。选中已保存项目或“无项目”时，创建对应的新任务；“打开其他文件夹”在选定后创建该项目的新任务。正常快捷键和命令菜单打开的项目选择器继续执行“打开工作区”，两种模式在底部提示中区分；取消后清除新任务模式。`/task` 复用已有无项目新任务流程。独立任务窗口可把这两个命令交给主窗口处理，同时保持原任务草稿归属。

项目导航与任务窗口相关 25 项测试通过，原生应用构建及签名检查通过。macOS 锁屏阻止了本轮的点击、焦点和当前 Codex 双端配对；因此 43 个验收面的完整配对数仍为 0。
