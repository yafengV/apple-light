# 合并插件设置导航

2026-09-18。本轮纠正此前把 MCP、插件、技能都作为独立侧栏页的实现。设置仍在主窗口内。

## 当前参考证据

直接读取本机 `/Applications/ChatGPT.app/Contents/Resources/app.asar` 的静态前端资源：

- `plugins-settings-3c26d614eada.js` 的 `w`：同一设置页管理插件、技能、MCP，包含浏览目录入口，内部使用 `manageOnly` 插件页面。
- `use-visible-settings-sections-feb3772d7f7f.js`：技能设置不显示在侧栏；统一插件页开启时，MCP 也从导航中隐藏。不能只依据完整设置注册表推断实际侧栏。
- `plugins-page-8862e0071989.js` 的 `Wc`：管理标签按插件、应用、MCP、技能、市场排序并显示数量；MCP 保留，其他标签需要非零数量。
- `plugins-page-section-c57ec60930b7.js` 的 `da`：当前分类为空时回退到可用分类；全局插件关闭时使用 MCP。

这些是静态实现证据，不是当前登录账号的原生截图或实际可见性验收。

## 本轮变化

- 侧栏保留一个插件入口。原 `.skills`、`.mcpServers` 路由映射到插件页中的对应标签；现有 24 个路由对应 22 个顶级设置页。
- 插件页增加管理标签、已安装数量、共用搜索、浏览目录和导入入口。标签数量来自本地已安装插件声明，单个插件停用不使其从管理页消失。
- 当前支持插件、MCP、技能三个分类。非 MCP 分类为空时隐藏；全局插件关闭时保留 MCP。加载中展示进度，不给原生 Picker 传入尚不存在的选项。
- 设置搜索结果统一归属于插件页，并切换相应标签、清除旧筛选。手动切换标签、再次筛选、移除相关插件或关闭全局插件时清除过期定位。隐藏分类不提供具体控件搜索结果。
- 普通页面切换保留搜索词和标签。搜索导航不启用插件，不运行技能，不修改任务草稿。
