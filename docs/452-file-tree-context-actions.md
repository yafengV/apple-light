# 文件树右键操作

当前 Codex 本地资源的文件树菜单含“复制路径”和“添加到聊天”；参考 `review-file-tree-pane-9f1d22d58471.js`（SHA-256 `b7df1c1f5fee7721a1a388f96c1eb5c1452b8e23bde91c7924b1cb4404df1b67`）。ShipiOS 的文件叶节点现提供打开文件、添加到聊天、复制路径及在外部编辑器打开；目录节点提供复制路径。

操作时重新按当前项目及关联目录解析路径，拒绝越界文件。添加到聊天沿用应用附件导入，图片进入图片附件、文本及 PDF 进入文件附件；独立任务窗口使用该窗口的任务草稿，主窗口使用当前草稿。定向测试验证主项目和关联目录文件进入所属任务草稿，越界路径被拒绝，主窗口草稿保持不变。配置本地测试 agent 后，46 项文件树、附件、编辑器及关联目录回归通过；`script/build_and_run.sh --verify` 完成构建启动，严格深度签名检查通过。

前台 Mac 仍锁屏；右键菜单显示、键盘导航、剪贴板内容和 Codex 双端操作尚未在可见桌面逐项验收。本阶段不计入 45 项完整配对验收。
