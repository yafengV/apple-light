# 计划任务的托管工作树运行

[OpenAI 官方 Scheduled tasks 文档](https://learn.chatgpt.com/docs/automations?surface=app)说明 Git 项目的计划任务可以选择在本地检出或独立后台工作树中运行。ShipiOS 自动化编辑器现加入“运行位置”选择。工作树模式为每次 Git 仓库根目录运行准备独立托管工作树；非 Git 项目仍在原目录运行。

准备过程复用项目已有的托管工作树记录、未提交文件快照、来源修改应用、项目初始化脚本及归档清理。任务 ID 在准备前保存；创建中断后可复用同一记录。跨项目日程记录已完成项目，恢复时只继续未完成的项目。若 Git 的 `stash create` 碰到已观察到的瞬时索引写入错误，先刷新状态再有界重试一次；其他错误仍直接报告。

验证：临时 Git 仓库含已修改的跟踪文件和新增文件；Codex Core 测试确认两者进入工作树，工具只修改工作树，来源检出未被更改。预先准备工作树后的恢复、非 Git 项目本地回退、部分完成的多项目日程恢复也由真实请求测试覆盖。相关自动化回归 24 项通过，曾间歇失败的工作树集成测试在修复后连续三次通过；原生应用构建与签名检查通过。

仍缺：自动化环境文件选择、完整 RRULE 与当前 Codex Mac 的可见页面/交互对照。官方要求本地项目计划任务运行时保持桌面应用开启，退出应用后继续调度不属于本轮 Codex 对齐范围。Mac 锁屏，因此运行位置控件的原生点击、焦点和布局仍未验收。
