## 实现

`TaskPullRequestDetailView` 删除合并确认的 `.sheet`，保留一个零尺寸的原生挂载点。`PullRequestMergeDialogPresenter` 把完整遮罩和确认内容加入同一 `NSWindow.contentView`，PR 位于侧栏、独立任务窗口或分离标签窗口时都使用实际所属窗口，不受 PR 面板宽度限制。

- 对话框居中，默认宽 520 点；窄窗口按可用宽度收缩；显示字段、方法顺序和按钮标签按参考结构调整。
- 多方法时以“压缩／合并提交”两个独立原生按钮选择；只允许一种时省略整区。取消/确认是表单尾部按钮，没有独立关闭按钮。
- 初始聚焦第一个可用控件，Tab/Shift-Tab 在控件间循环；Enter、空格和键盘 Enter 激活当前按钮，重复按键不会重复操作。Esc/⌘W 与遮罩点击取消；右键不取消。
- 提交立即复查当前资格；共享操作锁防止重复请求。忙碌时阻止关闭和再次提交，仍可调整显示的方式，已经发出的操作继续使用原方式。失败保留表单、显示红色错误并支持压缩方式重试。
- 原生窗口内模态作用域限制背景焦点和工作区命令；主工作区、独立任务、浏览器、审批及 modified-Esc 键盘入口均检查所属窗口的作用域。其他窗口保留自己的操作资格。
- 关闭后异步恢复仍存在的来源控件；重新打开、替换模态、挂载点移除和迟到回调有身份保护。卸载不会清除其他模态的作用域。
- 操作仍通过原来的服务重新读取权限和头提交，仅呈现位置改变；没有移除 GitHub 的结果确认和写入保护。
