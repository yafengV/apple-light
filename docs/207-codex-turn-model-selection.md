# Codex Responses 回合模型选择

2026-09-26。任务中的模型选择器现在会改变同一 Codex 线程的下一轮真实模型请求。每次提交都将当时的模型 ID 和推理强度传入 Agent；Codex Core 通过回合设置更新模型与强度。选择“服务默认”时清除上一轮的显式强度，让所选模型恢复自身默认值。已经开始的回合仍使用提交时的设置，历史运行元数据不回写。

本地假服务集成测试在同一任务中依次验证 `gpt-5.4/high`、`gpt-5.5/low` 和 `gpt-5.5/服务默认` 的 `/responses` 请求，最后一轮使用固定版模型目录的默认 `medium`。该测试确认请求行为，尚不等于模型选择弹层与当前 Codex Mac 的布局、焦点和快捷键逐项配对。
