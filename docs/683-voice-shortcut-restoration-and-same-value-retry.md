## 实现

新增 `VoiceHotkeyRegistrationController` 持有实际三个 Carbon 对象、已登记组合和各行错误。启动恢复逐模式注册，可用模式独立成功；强制重试只尝试指定模式，不清除未尝试行的错误。按住状态只在成功改变其已登记组合后通知释放，同值重试或注册失败不会无故结束原按住状态。

`WorkspaceStore.connectVoiceHotkeys` 是 AppDelegate 与测试共同使用的连接路径，覆盖初始恢复、注册／保存事务和单行重试。原生页面录入已保存同值时调用重试，仍经过本地验证和冲突检查；同值不改磁盘偏好。启动 Carbon 错误也显示于对应行，移除重复的卡片下 Carbon 错误聚合；裸修饰键权限错误保留原路径。

AppDelegate 的恢复完成逻辑只安装一次运行控制器和监视器，之后仍处理待打开通知／链接，避免主窗口再出现时重建热键对象但沿用旧登记缓存。该整窗生命周期的前台验收仍待完成，不以控制器单元测试代替。退出时清除三个连接回调并释放原生注册。
