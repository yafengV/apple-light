# Appshot 全局入口与设置

Codex 当前 macOS 资源中的默认 Appshot 快捷键是同时按下左右两个 ⌘ 键，不是双击一个 ⌘ 键。参考设置还有“无”、自动／当前聊天／新聊天发送目标和音效开关，并把应用快照放在主窗口设置导航内。

ShipiOS 现添加独立“应用快照”设置页和持久化偏好。左右 Command 键在短时间内重叠时触发一次；键盘有其他输入或两键释放后重置。全局与应用内分别使用 NSEvent 监视，其他应用中的键盘事件需要 macOS 辅助功能权限。截图开始前保存最近外部窗口目标；截图编码完成后将附件路由到当前聊天或新聊天、返回主工作区并显示主窗口。自动模式在当前主窗口最近 60 秒获得焦点时沿用当前聊天。音效使用系统提示音，尚未取得 Codex 原音频资产。

验证：偏好默认值与旧库迁移、左右按键重叠、重复触发保护、发送去向和设置搜索的 5 项定向测试通过；设置导航 15 项测试通过；`script/build_and_run.sh --build-app` 与严格签名检查通过。脚本在受限环境的 `--verify` 启动阶段收到 LaunchServices `-10827`，检查确认包内可执行文件存在且签名有效，在桌面会话中直接打开应用包的命令成功。包含离屏 AppKit 渲染的更宽 Appshot 测试组在当前锁屏状态下未运行结束，已停止；Mac 锁屏也阻挡可交互工作区、真实跨应用按键、权限、声音、焦点及 Codex 双端页面验收。本阶段不能标记 Appshot 完全对齐。

原验收矩阵有 21 项主工作区、24 项设置。新增独立“应用快照”设置页后，矩阵为 46 项；其中没有一项完成 Codex 与 ShipiOS 的完整双端逐交互配对验收，仍是 0/46。这个数字是验收项，不是未实现功能数或完成率。
