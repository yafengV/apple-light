# 原生标签拖动会话与隐藏投放区域

2026-09-19。

## 调整原因与实现

第 168 篇使用鼠标按键轮询清理拖动状态；按键释放不等于系统目的地已经完成投放，无法准确表达拖动会话生命周期。本轮移除该轮询和独立 Escape 监听，主窗口与独立任务窗口的内容标签标题改用小型 AppKit 拖动源。

SwiftUI 继续拥有标签、选中项、关闭按钮和菜单。标题的左键按下/拖动/释放由 `ContentTabDragSource` 处理，轻微移动仍算点击；达到阈值后调用 `beginDraggingSession`，只在系统 `endedAt` 回调清理状态。完成回调绑定开始时的会话 ID，不能清除新的拖动；SwiftUI 移动标签、卸载源控件时不会把旧回调重定向到新模型。

隐藏侧面板和底部区域增加 `ContentTabDropSurface`，临时覆盖嵌入的网页/终端；它只接受应用内部通过模型验证的字符串标记和移动操作，直接通过原生 pasteboard 调用现有状态迁移。其他可见面板、标签重排及侧栏仍使用原有投放接线，未在本轮声称全部原生验收通过。

## 自动化证据

新增 8 项测试覆盖：标题点击与区域外释放、轻微移动不启动拖动、卸载源取消待执行点击、重复/重入完成只执行一次、旧系统完成不清除新会话、真实 `NSPasteboard` 传递后原网页对象移动、外部文本/只复制操作拒绝，以及已卸载目标不执行投放。

`ContentTabDragSource|ContentTabDropSurface|WorkspaceDrop|TaskWindowDrop|TaskWindowTab|TaskWindowPanel|TaskWindowPin|WorkspaceTab|TerminalHostFocus|Sidebar` 共 75 项通过，0 失败。日志 `.cache/native-drop-final-tests.log`。
