# 设置标题滚动与搜索定位高亮

2026-09-18。设置继续在主窗口内展示。本轮对照本机 Codex 静态资源 `app-initial-4d7ea7f81c2d.js` 的设置容器与搜索定位动画，修复共用布局和定位反馈。

## 实现

- 18 个使用 Form 的设置页将标题放入同一个滚动文档，内容滚动时标题一起移出视口，避免外层固定标题与内层表单分离。嵌套表单不重复显示页面标题。
- 共用容器采用 768 点内容基准和两侧各 24 点边距；原生分组表单仍有自身行间距与卡片内边距，不能据此声称像素完全一致。
- 搜索结果使用 450 毫秒中性底色高亮，替换持续蓝色背景；重复选择同一结果会重新播放。快捷键搜索结果使用相同机制。
- 减少动态效果时保持短暂稳定高亮后清除；旧动画取消或到期不会清除新的定位反馈。切页与离开设置会清除不再适用的高亮。
