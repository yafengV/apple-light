# Agent 回复设置与逐回合权限

2026-09-26。Agent 设置新增“回复详细度”（模型默认、简洁、适中、详细）和“推理摘要”（自动、简要、详细、关闭），作为新 Codex Core 线程的默认值。偏好保存在 ShipiOS 工作区，线程在私有恢复记录中保存创建时的快照，重启续接不会意外采用后来的默认值。

固定版 Core 对支持 `text.verbosity` 的模型发送详细度，并把推理摘要选项送入 Responses 请求。模型目录中未知或不支持该参数的模型会忽略详细度；独立 API 服务也可能不支持这些参数，因此界面明确提示。这些选项不是对任意服务输出长度或推理展示的保证。

检查逐回合提交路径时发现，之前会话启动配置虽采用所选文件沙箱，每次提交普通回合却又覆盖为工作区写入。现由同一权限配置生成线程与回合的沙箱；计划模式和代码审查仍强制只读。Rust 单元测试覆盖完整访问、计划与审查的回合映射。本地假模型集成测试使用固定版目录中支持详细度的 `gpt-5.4`，检查首次及续接请求均带有所选 `text.verbosity` 和 `reasoning.summary`。Swift 设置持久化、迁移与搜索相关测试通过。

该阶段仍缺实际 Mac 页面逐项配对，Web Search 也未接入独立服务。当前桌面锁屏，不能据此认定 Agent 页完整对齐。
