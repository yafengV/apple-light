# 聚焦终端清屏

2026-09-28。[Codex 桌面快捷键参考](https://learn.chatgpt.com/docs/reference/commands)列出终端获得焦点时以 `⌃L` 或 `⌘K` 清屏。ShipiOS 此前没有对应动作，`⌘K` 会打开命令菜单。

终端现在只在其 `SessionTerminalView` 是当前窗口第一响应者时接收这两个按键；本地按键监视器先于应用菜单处理事件。清屏只清除该终端模拟器的可见内容和滚动历史，不向子进程发送字符、结束 shell 或重启会话。拆分终端的左右两侧各有独立视图，右键菜单也提供“清除终端”。终端未获得焦点时，`⌘K` 继续打开命令菜单。

42 项终端及窗口相关测试通过，其中新增测试验证两种按键识别、拆分两侧显示隔离及清屏后 shell 仍运行。`script/build_and_run.sh --build-app` 与严格签名检查通过。当前 Mac 锁屏，真实按键分发、菜单优先级和 Codex 双端交互仍待原生验收。
