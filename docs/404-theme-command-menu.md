# 命令菜单的主题子菜单

主题入口位于命令菜单的“配置”组首项，展示当前模式图标、当前代码预设名称及进入箭头。进入后使用同一窗口中的专属搜索菜单，其他命令、任务、浏览器结果和 Git 检查提示不混入该子菜单；返回行始终保留，返回时清空搜索。

“主题”是菜单贡献项，没有伪造对应的全局快捷键执行命令。浅色模式仅显示 16 个预设，深色仅显示 27 个；选中项显示勾选，预设描述分别为浅色／深色配色主题。每项色样使用预设种子，24×24、Aa、强调色字形、背景色及前景色 16% 与背景色 84% 的 sRGB 边框混合。手改当前主题颜色不改写预设预览；字形继承当前界面字体及字号偏好。

选择预设只更新当前侧代码主题及其明确的 chrome patch，不切换基础模式，不覆盖另一侧。独立的“切换为浅色／深色主题”使用当前实际模式的反向，并保存为明确的 light／dark；从 system 切换后也不保留 system。两种操作均关闭原窗口的命令菜单，主窗口和独立窗口共享外观偏好但不改变其他窗口的任务与弹层。

保存使用既有独立工作区的原子外观提交。失败保留原外观、草稿及应用回调状态，错误保存在外观错误状态；仍关闭菜单，符合参考选择操作的关闭顺序。返回不保存、不关闭外层菜单。执行前重新核对当前模式可用项，已经退出或已失效的行不能再次应用。

## 验证与边界

新增 11 项主题回归覆盖根入口关键词与当前预设、16／27 个选项、始终可返回、单侧保存、system 切换、深色预设及同一 ID 重新应用、过期项、失败保留、sRGB 混合和离屏色样，以及实际隐藏窗口中的方向键／回车、返回／Esc 和独立窗口归属。

隐藏路由初次复验发现方向键后的选中行被搜索输入框相同文本回写清除。主题选中状态进入窗口内的可观察会话；搜索绑定忽略相同文本写入，关闭先清除焦点，返回／进入再聚焦查询。失败用例保留立即选中与布局后仍选中的断言，复验不再执行旧的返回行。扩展相关回归最终 115 项全部通过（49.890 秒，`.cache/theme-command-final.log`）。Aa 改为继承界面字体后，最终主题／字体 22 项再通过（5.587 秒，`.cache/theme-command-swatch-final.log`）；这些为同一集合中的复验，不重复计数。

正式应用经 `script/build_and_run.sh --build-app` 构建（Swift 2.50 秒）与签名，没有启动或激活。严格深度签名通过；29 个高亮资源逐字节一致，目录与 manifest 哈希检查通过，26 个组件与引擎保持第 402 篇版本。日志分别为 `.cache/theme-command-app-build.log`、`.cache/theme-command-package-signature.log` 和 `.cache/theme-command-package-resources.log`。Rust 与高亮 JavaScript 未改动，未重复其完整测试。
