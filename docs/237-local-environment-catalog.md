# 本地环境目录与选择

ShipiOS 现在枚举项目 `.codex/environments` 中的 TOML 文件，在设置页列出有效环境和需要修复的文件。已有选择随项目持久化；没有选择时优先使用有效的 `environment.toml`，否则使用首个有效文件。切换环境会载入其名称、setup、cleanup 和 Actions，切换、新建或重新载入前若有未保存修改会询问是否丢弃。重新载入会刷新目录列表。新建环境依 Codex 的命名规则使用 `environment.toml`，随后使用 `environment-2.toml`、`environment-3.toml` 等未占用名称，并在显式保存后创建文件；不完整的 Action 会阻止保存并提示补齐名称和命令。

Agent 限定文件名为当前目录内的 `.toml`，拒绝路径穿越和符号链接；单个损坏文件不会遮蔽其他有效环境。所选环境字段写入既有项目配置，现有托管工作树初始化与顶部 Actions 使用载入后的设置。Rust 测试覆盖多文件列表、无效文件、创建和路径边界；Swift 真实 Agent 测试覆盖切换、新建和重启恢复。

此阶段的设置页环境选择只作用于当前项目。Codex 在新任务工作树入口提供单次环境选择、无环境选项，还可显示从父目录继承的环境；这些行为及实际页面布局、焦点和键盘配对仍待完成。
