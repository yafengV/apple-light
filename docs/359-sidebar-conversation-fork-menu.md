# 侧栏任务菜单中的普通会话分叉

日期：2026-09-28。普通侧栏与 Activity 的共享任务菜单新增「分叉」子菜单，复用已有普通会话分叉。读取被操作任务的最新已结束历史，保存新任务后再打开，不先切到来源任务；来源运行、草稿和未读保持原归属。

## 参考与实现边界

旧版本 Codex 26.908.70816 / build 9275 的缓存资源中，`h6t`、`e8t` 包含侧栏分叉和本地/相同工作树、新工作树选项。这是静态参考，不能替代当前用户版本的原生双端配对。

本阶段接入普通本地、无项目及永久工作树任务的已有分叉能力。已结束历史复制为新记录，运行中的回合不复制；保存失败没有幽灵任务。跨项目打开失败保留当前任务、草稿、预览和导航历史，已保存分叉通过侧栏或通知重试打开。

主窗口、独立任务窗口和菜单分叉均拒绝正在确认或执行归档/删除的目标；其他未保留的任务仍可分叉。临时侧聊、归档任务、恢复中和工作树准备中也不可分叉。

**尚未实现新工作树分叉及托管工作树的相同检出分叉。** 当前托管检出仍保持单任务所有权，不能直接放开限制让归档误删其他任务使用的目录。Core 续聊使用独立新线程和已结束聊天上下文，并非 Core 原生完整 rollout 分叉，后者仍是差异。
