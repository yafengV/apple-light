# 分钟频率与秒值

按 [RFC 5545](https://www.rfc-editor.org/rfc/rfc5545.html) 的分钟频率和秒值规则，自定义日程接受 `FREQ=MINUTELY`，例如 `RRULE:FREQ=MINUTELY;INTERVAL=15`。分钟日程从保存的起点每隔指定分钟生成候选，未填写 `BYSECOND` 时沿用起点的秒值；可用 `BYHOUR`、`BYMINUTE`、`BYDAY` 等字段筛选，也可用 `BYSECOND` 在同一分钟运行多次。`BYSETPOS` 在每个分钟周期内选位置，`COUNT` 和 UTC `UNTIL` 继续限制总次数或截止时间。

已有小时/日/周/月/年规则在未填写 `BYSECOND` 时仍使用第 0 秒，避免旧日程改变。支持 `BYSECOND=0…59`；RFC 5545 允许的闰秒值 60 因本地日历无法表示而明确拒绝。自定义编辑器显示新字段，仍由应用进程每 30 秒检查到期日程，因此秒级候选可能延迟执行。
