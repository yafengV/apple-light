# 外观设置与主窗口返回验收

2026-09-17。设置继续作为主窗口内页面，未增加独立 Settings Scene。此次补齐外观控件，并修复从原生终端进入设置后 Esc 被隐藏终端消费的问题。**这些检查不等于 Codex 全页面已经对齐。**

## 实现范围

- 基础主题：系统、浅色、深色；强调色、背景色、前景色及各自重置。
- UI 与代码字体分别选择，支持已安装字体搜索、独立字号、即时预览和恢复默认。代码字体应用到代码块、文件/审查与终端；更改终端字体不会重启 shell。
- 主题 JSON 导入、导出。文件只包含外观字段，不包含项目、会话、模型服务或凭据。限制 64 KiB、校验版本和颜色、约束字号；缺失字体回退系统字体。
- 主题保存在当前数据根目录的 workspace.json。旧工作区缺失该字段时仍可读取。
- 启动时将工作区及模型配置读取移出主线程，并显示恢复状态。上次项目改从当前工作区的项目访问顺序恢复，不再读取全局 lastProject，避免独立测试目录打开其他目录的项目。
- 进入设置时清除原生 first responder，防止隐藏的 PTY 接收 Esc；返回后仍保留终端、项目与会话状态。

功能依据：[官方外观设置](https://learn.chatgpt.com/docs/reference/settings#appearance) 与 [代码字体在终端的应用](https://learn.chatgpt.com/docs/reference/troubleshooting#terminal-issues)。这些文档不能证明当前用户版本的具体布局、字体选择器样式或主题文件格式相同；ShipiOS 主题 JSON 是自己的格式，不声称兼容 Codex 主题导入。
