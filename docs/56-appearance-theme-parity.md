## 当前实现

- 基础主题支持跟随系统、浅色和深色；浅色与深色分别保存强调色、背景色、前景色、侧栏半透明状态和对比度。
- 旧版本单组颜色自动迁移到两套主题，不丢失已有自定义颜色。无效颜色、字号和对比度在加载时归一化。
- 当前主题颜色应用到工作区、设置侧栏、选择状态、内容背景和终端；对比度会即时调整活动主题的背景表现。
- 界面字体和代码字体继续独立选择。代码字体用于代码块、文件预览、审查和终端。
- “交互控件使用指针光标”可选开启；开启后，AppKit 本地事件监视器在按钮和链接上使用指针光标，并在关闭或偏好复位时恢复箭头。
- “差异标记”可选择“颜色”或“+/−”。颜色模式用绿色/红色背景并隐藏行首符号；符号模式保留 Git 行首符号并移除颜色背景，直接作用于主窗口和独立任务窗口的真实审查行。
- “减少动态效果”可选择“跟随系统 / 开启 / 关闭”。跟随系统读取 macOS 辅助功能状态；开启后在主窗口、独立任务窗口和独立内容标签窗口的根 transaction 禁用动画。
- 主题导入/导出包含新的浅色、深色和指针配置；旧主题文件继续兼容。
