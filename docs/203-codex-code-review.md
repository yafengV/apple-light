# Codex Core 代码审查接入

2026-09-26。主窗口 `/review` 的未提交更改、基础分支以及“在当前任务中 / 单独任务”呈现方式，现在可使用独立配置的 Codex Responses。审查先取得不可变的 Git 差异快照；Codex 回合使用单独的只读线程，差异通过私有临时附件传递，避免普通回合的 48 KiB 文字上限。现有 512 KiB 差异上限保持不变。

审查回合不继承普通任务的可写线程。若 Core 请求命令或补丁审批，ShipiOS 自动拒绝并在时间线保留该工具记录，不显示一个可批准写入的卡片。内联审查结果仍属于原任务，不消耗输入草稿；后续普通消息继续走原任务的可写线程。单独呈现会创建并选中审查任务。独立 API 凭据与用户个人 Codex 保持隔离。

本地假模型端到端测试验证 60 KiB 差异成功进入审查、模型尝试补丁后项目文件未被创建、审查回复成功，以及内联审查后的普通续轮。相关 `ModelTransportTests` 50 项、Rust 测试 8 项与格式检查通过。原生窗口读取仍超时，因此审查选择器、时间线、焦点和当前 Codex Mac 的逐项可见配对尚未验收；本阶段不增加完整页面配对数量。
