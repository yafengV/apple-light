# Appshot 文件名与附件卡片

对照当前本机 Codex 桌面资源，Appshot 文件名由应用名、`Appshot` 和 ISO UTC 时间组成，应用名中的 `/`、`:` 被替换为 `-`，连续空白压成一个空格。ShipiOS 现在按这个格式命名，PNG 超限而 JPEG 可用时保留同一基础名并使用 `.jpg`。原有中文“截图”文件名仍可恢复，不会被迁移。

带有 Appshot 元数据的图片在输入区显示 232×140 的截图卡片，底部叠放对应应用图标；历史消息的卡片额外显示窗口标题，标题为空时显示应用名。普通图片仍使用原有缩略图卡片。截图卡片仍能通过点击、Return 或 Space 打开现有图片预览，草稿卡片可移除。

28 项相关测试通过，覆盖命名、存储、元数据兼容和图片预览相关路径。正式构建与签名结果见本阶段提交记录。当前尚未实现 Codex 捕捉时由桌面宿主驱动的快照移入输入区动画，也没有在图片预览中切换截图与辅助功能文字；应用图标按当前安装的 bundle ID 查找，原应用不在本机时使用占位图标。Mac 锁屏阻止可见页面与逐项交互验收，完整配对仍为 **0/45**。
