## 页面与导航

- 正式 PR 内容标签的概览和 Code 位于同一个已有内容容器，主窗口、独立任务窗口及分离标签共用入口。紧凑摘要保持概览形式。两页共用提交审查、审查对话框和删除确认，Code 不要求先回概览才能审查。
- 左右方向键在两页之间循环并将焦点移到相应按钮。切页保留已加载的代码、筛选、文件选择、展示选项和评论草稿；重新创建内容标签仍沿用原标签恢复机制。
- 文件差异按 GitHub 返回顺序连续显示。搜索只筛选右侧文件树，不删减正文差异；文件树按目录组织，目录优先，同名文件保持完整路径身份。文件行含修改类型和同版本审查线程数，选择文件定位其标题。
- 默认隐藏文件树；宽窗口使用右侧可调整面板，拖动、方向键和辅助功能均可调整宽度。680 点以下使用右侧覆盖抽屉。统一和并排呈现分别保留左右行号；并排按连续增删行组配对，数量不等的一侧留空。
- 删除文件默认收起，普通文件默认展开；逐文件及整体展开/收起、换行开关、差异标记偏好进入实际呈现。仅权限变化或标题/检查时间更新不会重新读取同版本差异。
- Activity 折叠评论的文件名仍先展开卡片。展开后点击文件名进入 Code，清空筛选，展开目标文件，在当前侧定位末行并高亮。左侧旧路径可以匹配重命名后的文件。重复点击会再次定位；滚动任务先使离屏文件出现再定位嵌套行，切页或离开会取消待执行定位。
- 行已不在当前差异时定位文件；未知文件不生成假文件，且清除上一评论的行高亮。Code 中既有线程放在相应行后，未出现在当前差异的线程保留在文件末尾并明确说明位置不在差异中。PR 元数据读取中显示加载，失败或版本不可用提供刷新入口；评论读取失败与差异读取失败分开，提供评论重试；版本不一致时不把旧评论叠到新代码行。
- 既有线程复用原评论编辑、回复、删除、解决和重开流程及草稿作用域；Code 卡片不重复显示另一段代码上下文。媒体与富文本的既有边界没有因此消失。

## 来源与状态保护

差异从远端 PR 读取，不依赖任务当前检出的分支或本地工作区文件。读取前后均核对 PR 节点、仓库、编号和链接、源提交、目标提交、两侧分支名和文件数。源或目标单独变化都使该次差异失效。文件数与实际差异切片不一致时显示不完整错误，而不是以完整结果呈现。

解析保留增删、重命名、复制、仅文件模式变化及二进制标识。共享 Git 路径解码处理引用、UTF-8 八进制与普通空格；二进制文件名内出现 ` b/` 也不会被简单分词截断。PR 路径拒绝绝对路径、上级穿越和重复目标；原会话累计差异仍保留它自己的跨仓库相对路径规则。

读取结果按任务、目录、PR 和源提交绑定。取消、离开、任务范围失效和迟到读取不能安装旧结果。相同范围重试保留待定位评论；换任务时清除旧定位、文件筛选和文件树开关。标题与检查时间不进入代码版本比较，切换分支目标仍使请求改变。
