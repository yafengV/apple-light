# 确认弹层关闭后的焦点返回

2026-09-18。本次整理并提交设置确认弹层的阶段性焦点修复，不代表全产品已经完成 Codex UI 对齐。

## 改动

记忆删除、归档删除和快捷键恢复默认由所属页面保存操作入口，在确认弹层关闭、底层控件重新启用后恢复焦点。按钮支持可见焦点框及空格、Enter 激活。原入口已消失时回到设置搜索框。

共享回调检查页面、导航位置及其他弹层状态，并在页面卸载或新弹层出现时作废，避免迟到回调抢走焦点。移除原生弹层桥中不可靠的旧 responder 恢复逻辑。

项目归档菜单的 SwiftUI Menu 尚不能可靠恢复键盘焦点，本次明确回退到设置搜索框；返回菜单并通过键盘重新打开仍待后续原生控件接入。

## 验证与范围

- 最终 24 项相关测试通过，覆盖确认回调生命周期、记忆删除、归档确认、快捷键状态及设置布局；日志 `.cache/confirmation-commit-tests.log`。
- 通过 `script/build_and_run.sh` 构建启动，并通过严格签名检查；日志 `.cache/confirmation-commit-build.log`。
- 隔离原生样本验证：单条记忆删除确认 → Esc → 原按钮获得焦点 → 空格再次打开确认 → Esc。测试记录保留，未执行永久删除。
- 原生验证项目归档菜单打开确认后取消，焦点回到设置搜索框。
- 其他按钮入口的完整键盘循环、删除成功后入口消失的实际焦点、VoiceOver 及逐页配对验收仍待继续；自动化通过不等同于这些交互已完成实机验收。
