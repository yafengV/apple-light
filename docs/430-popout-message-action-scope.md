# 弹出会话消息操作的任务作用域

弹出会话此前直接复用主窗口的 `ExecutionMessageView`。消息卡片里的重试、从此处分叉、按计划继续、查看执行详情及历史文件预览仍读取主窗口选中的任务或打开主窗口面板；弹出会话与主窗口查看不同任务时，操作可能无效或落到错误任务。

消息卡片现接受所属窗口的动作路由。主窗口保留既有行为；弹出会话把历史文件预览和执行详情留在自身窗口，分叉以自身任务和所选回合为源并在浮窗内打开新任务，计划继续写入自身草稿。模型回复的重新执行使用显式任务 ID，包含已有模型审查快照的重试路径；非模型本地运行不显示没有安全弹出重试实现的按钮。弹出会话中的本地运行详情从该回合记录显示诊断、输出和产物基础信息。

本地模型服务集成测试确认：从弹出会话重试后的新回合仍归属原任务，主窗口草稿和选择保持不变；任务作用域测试拒绝把其他任务回合用于当前弹出会话，并核对计划继续的草稿归属。分叉、命令与弹出布局共 45 项相关测试通过；固定 470×640 隐藏窗口已渲染计划卡片和操作入口。`script/build_and_run.sh --verify` 构建并启动应用，严格深度签名和 29 个语法资源、七份许可证逐字节核对通过。Mac 锁屏使前台点击、焦点和详情弹层验收无法进行；当前 UI 工具也不允许读取 Codex 应用。完整双端逐页配对仍为 **0/45**。
