# 语音聊天音色选择确认

Codex macOS 当前公开语音设置资源的音色控件是“选择音色”对话框，提供取消与完成；打开时带入当前选项，选择后的值在完成前不保存。ShipiOS 原先用即时保存的下拉菜单，切换后无法取消。

ShipiOS 语音设置现改为从音色行打开附属于主窗口的选择对话框。十个内置音色与自定义服务音色 ID 均可选择；点击“完成”才更新独立偏好，“取消”或关闭保留原值，空白自定义值不能保存。设置页和选择对话框的离屏图像已目视检查，23 项语音相关测试通过，正式 `.app` 构建和严格签名通过。

尝试用隔离数据目录启动新包时，Launch Services 返回 `kLSNoExecutableErr`，尽管可执行文件存在且签名有效；直接启动二进制在本机桌面服务通知注册处终止。因此本阶段没有取得新包的真实点击、焦点、取消/完成及重启状态证据，也没有 Codex 双端配对。音色预览需要可用的服务或官方素材，当前未实现；完整配对仍为 **0/47**（验收面数量，不是缺陷数量）。
