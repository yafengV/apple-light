# 弹出窗口首页附件与独立草稿

上阶段的弹出窗口首页只接收文字，粘贴图片或文件时会直接忽略。当前 Codex 分发的首页输入区复用带 `addContextButton` 和 `hotkeyWindowHomeFooterControls` 的 composer；参考为本地只读资源 `app-primary-d63a2421d501.js`（SHA-256 `e381729764540940326372f7785bd5f68bc7dd2e49fad0eed4d8a99bbb3de706`）。本阶段补齐 ShipiOS 已支持的图片与文本／PDF 文件路径，不把静态代码检查称作正式客户端的可见交互验收。

首页文字保存在 `popout-home` 专用草稿，图片与文件使用相同键保存；关闭／恢复弹出窗口及重启后仍归属于首页，主窗口草稿不受影响。加号菜单可选图片或文件，粘贴使用项目现有的类型判断和导入流程；附件可移除，文件和图片可在弹出窗口内预览。只有文字或附件实际存在、导入结束且工作区已加载时才允许发送。首条消息可以只有附件。创建任务时一次性将文字、图片、文件移入新任务的草稿并清空首页来源，随后交由原有任务发送流程处理。
