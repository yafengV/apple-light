# Codex 网页工具时间线

2026-09-26。固定版 Codex Core 的 `web_search_begin` / `web_search_end` 现在按调用 ID 合并成任务时间线中的一条网页工具卡。运行中显示进度，结束后展示搜索词、打开的网址或页内查找内容；Core 提供结构化结果时可展开和复制。卡片与最终回复保持事件顺序，主窗口和独立任务窗口使用同一视图，重启后继续显示记录。

本地假模型服务返回真实 Responses `web_search_call`，经 Codex Core 和私有 Agent 进入 Swift 会话；集成测试确认网页卡先于最终回复、状态完成、搜索词正确以及持久化恢复。运行中停止测试还确认未结束的网页卡会转为已取消，而不是永久显示正在执行；相同收尾规则覆盖其他未结束工具。另有缺少开始事件、重复结束事件和结构化结果的边界测试。构建通过 `script/build_and_run.sh --build-app`。

这是工具事件与自动化验证，尚不表示真实联网搜索、结果链接操作或当前 Codex Mac 的卡片视觉、展开、焦点和键盘行为已验收。Mac 锁屏期间无法完成原生配对；43 类完整配对数量不变。
