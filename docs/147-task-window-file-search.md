# 独立任务窗口文件搜索

2026-09-18。补齐独立窗口此前禁用的搜索文件命令，避免斜杠入口切换后台主项目。

## 依据与实现

公开静态资源 `app-initial` 的 `searchFiles` 定义使用 `CmdOrCtrl+P`，属于本地项目能力。本阶段接入已有文件搜索流程的窗口归属；不宣称当前搜索算法、原生 sheet 和 Codex 自定义命令面板的完整呈现已经一致。

- 主窗口与独立窗口共用 `WorkspaceFileSearchView`，显式传入对应 `DeveloperWorkspace` 和选择、取消回调。搜索仍按路径不区分大小写过滤，最多展示 200 项。
- 独立窗口支持 `⌘P`（及用户配置）、工作区菜单、工具栏、`/files` 候选及命令发送入口。无项目任务不启用该能力，输入 `/files` 不会发送模型请求。
- 选中文件后在当前窗口展开文件面板、建立文件标签；关闭搜索后聚焦文件内容。取消则返回发起搜索的输入框或文件预览。
- 搜索读取失败显示错误和重试，不同时冒充“无匹配”；任务窗口的其他命令及工具审批在搜索弹层期间保持隔离。
- 文件预览的焦点请求等待读取结束再处理，避免异步读取期间提前消耗请求。

## 验证

- 18 项文件工作区、任务窗口及命令回归通过，日志 `.cache/task-window-file-search-tests.log`。
- 新增 1 项真实 AppKit 预览测试：加载中不抢焦点，读取完成后同一请求聚焦文件，主工作区文件状态与焦点请求保持；日志 `.cache/task-window-file-search-focus-test.log`。
- 原生隔离项目：主窗口 A 无项目，B 的独立窗口用 `⌘P` 列出自己的 5 个文件；过滤 `.txt`，方向键选中 Beta，Enter 在 B 窗口打开正确内容并聚焦源码。
- 已挂载的搜索输入框中键入无匹配查询后 Enter 保留搜索；Esc 返回原文件。测试中一次在 sheet 尚未挂载时连续注入按键，查询未进入输入框、Enter 打开首项，因此后续等待实际输入焦点再进行验收；不把这次自动化连发当作输入就绪通过的证据。
- `/files` 用发送快捷键打开本地搜索，取消后返回草稿；任务回合数保持 2，没有发送模型请求。菜单入口也在同一独立窗口打开搜索。
- 临时移动隔离项目目录，搜索显示读取错误；还原后点击重试恢复 5 个文件。原生验证后补充隐藏错误时的无匹配提示，并重新构建。
- 持久化检查确认主窗口仍为 A、A 草稿保持；B 的合成草稿在斜杠测试后恢复。最终构建回归主窗口 `⌘P` 搜索 Alpha 并聚焦内容通过。
- 项目脚本恢复原工作区，严格签名检查通过。缓存、运行数据、测试日志不提交。
