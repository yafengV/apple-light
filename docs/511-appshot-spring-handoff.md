# Appshot 过渡弹簧与淡出时序

本机 Codex 桌面资源对输入区 Appshot 占位和附件宽高变化使用默认 spring：`visualDuration` 为 0.35 秒，阻尼分数为 0.73，延迟 0.15 秒。ShipiOS 的首版原生浮层使用 0.55 秒固定缓动并让截图从起点持续淡出，视觉节奏与参考端不同。

现将屏幕浮层的位移和大小变化改为由相同响应／阻尼值换算的 Core Animation 弹簧，在 0.15 秒后开始；截图保留可见直到接近目标，最后 0.16 秒淡出。完成时清理浮层并显示草稿卡片，取消和超时仍沿用已有清理路径。

弹簧参数和相关捕捉／图片测试已加入回归，正式构建与签名结果见本阶段提交。当前数据来自保存后的截图；参考宿主的更早过渡快照和最终截图事件尚未接入。Mac 锁屏使真实跨应用轨迹与当前 Codex 客户端逐帧对照无法完成，完整配对仍为 **0/45**。
