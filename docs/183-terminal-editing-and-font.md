# 终端文本操作与字体缩放

2026-09-26。补齐任务终端中可直接使用的文本与字号操作。

原生复现时，底部终端右键没有菜单；底层 SwiftTerm 虽支持选择、复制、粘贴和全选，用户无法从终端右键发现这些操作。现在终端右键提供复制、粘贴、全选、放大字体、缩小字体和恢复默认字号。复制只在有选区时启用。终端获得键盘焦点后可使用 ⌘+、⌘−、⌘0 调整与复位字号；字号限制在 8–32 点。每个终端视图保留自己的缩放偏移，外观设置中的代码字体与字号改变时仍沿用该偏移。

`TerminalHostFocusTests` 增加菜单状态、外观字号变化、快捷键焦点和字号边界检查。连同终端会话、重启和任务窗口面板相关回归共 25 项通过，0 失败；`script/build_and_run.sh` 已构建运行签名应用。原生底部终端已检查右键菜单、全选后复制启用、菜单放大/复位、聚焦终端时连续快捷键放大；随后隐藏终端并确认原任务草稿不变。

这轮尚未完成与当前 Codex 的菜单布局、终端文本选择边界、独立窗口和完整快捷键逐项配对。
