# 弹出首页工作树启动模式

弹出首页的“聊天设置”现提供“启动模式”：本地或工作树。只有选中的项目是可创建工作树的 Git 仓库时，才能选择工作树。选中后，输入提示、菜单标签和发送按钮状态随之更新。

工作树发送会先验证独立 Responses 模型配置，再为所选项目创建托管检出、复制来源项目的未提交修改，并执行该项目的工作树环境设置。准备成功后才把弹出首页草稿和附件转入新任务，打开弹出会话并发送。准备失败时保留首页草稿和主窗口选择；准备过程的任务 ID 写入工作区数据，重试时恢复同一个检出，避免创建重复工作树。

本阶段用真实临时 Git 仓库验证了成功、配置缺失、草稿变化和检出恢复路径。弹出首页的分支、环境和权限菜单，以及当前 Codex Mac 的逐页原生交互配对仍未完成。锁屏期间不能把构建、测试或离屏视图验证计入完整双端验收；完整配对保持 **0/45**。
