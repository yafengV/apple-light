# 按任务恢复已关闭的内容标签

主窗口多个任务共用内容标签列表。此前“重新打开已关闭标签”只取全局最后一项：先关闭任务 A 的文件或网页，再关闭任务 B 的标签，回到任务 A 执行恢复时会消耗任务 B 的记录；浏览器还会从自身关闭历史取错页面。

现在恢复命令只查找当前任务的最近可恢复标签。浏览器关闭历史记录原标签身份，可按该身份取回对应地址，因此交错关闭多个任务的网页也不会互换内容。其他任务的关闭记录保留，回到对应任务仍可恢复；恢复命令的可用状态也按当前任务判断。

111 项文件标签、工作区标签、独立任务窗口标签和浏览器相关测试通过，包含两任务交错关闭文件及网页的定向测试。`script/build_and_run.sh --verify` 完成正式构建和进程启动，严格深度签名通过。Mac 锁屏，前台键盘、焦点和 Codex 双端配对仍未完成；完整验收保持 **0/45**。
