# Appshot 截图与辅助功能采集并行

Appshot 此前在截图生成、编码完成后才开始读取目标窗口的辅助功能文字。该读取有最长约 1.5 秒的截止时间，因而截图与文字采集的等待完全串行，附件卡片和原生过渡只能在两者完成后出现。

现在对已选定的同一个窗口并行启动辅助功能文字采集与 ScreenCaptureKit 截图，仍在两者结束后一次性保存带有完整文字元数据的附件。图片编码失败或捕捉取消不会产生草稿附件。这样减少等待的上限取决于两项操作的实际重叠时长，并不保证固定提速。

验证：Appshot 捕捉及交接 16 项 Swift 定向测试通过，`script/build_and_run.sh --build-app` 构建通过，正式应用严格深度签名验证通过。当前 Mac 仍锁屏，无法确认前台等待时间、真实跨应用动画和 Codex 双端配对。参考端在最终附件完成前就能显示占位并执行过渡；ShipiOS 尚未实现这一早期快照阶段。21 类工作区及 24 类设置面的完整逐项配对验收仍为 **0/45**。
