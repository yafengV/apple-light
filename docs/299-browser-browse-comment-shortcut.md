# 浏览器浏览与评论模式切换

2026-09-28。[Codex 桌面命令参考](https://learn.chatgpt.com/docs/reference/commands)列出浏览器可评论时用 `⌘.` 切换浏览／评论模式。ShipiOS 原有单次元素／区域选择、评论表单和 `Esc` 取消，但缺少统一的切换命令。

浏览器工具栏现在标明“切换到评论模式”或“切换到浏览模式”。打开评论模式后可点击元素或拖选区域，选中后再次切换会清除选区；选择进行中再次切换会取消，`Esc` 入口保留。主窗口、独立任务窗口和独立浏览器窗口共用浏览器本地 `⌘.` 按键桥接，只有对应网页获得原生焦点时才处理；其他焦点下，原有停止执行命令保留。浏览器菜单和命令菜单也可显式切换。未加载的网页不能进入评论模式。

99 项浏览器与窗口相关测试通过，包括本地 WebKit 的命令可用状态、开启／取消与选中后返回，以及所属任务命令路由。应用构建与签名检查通过。原生快捷键优先级、跨窗口焦点与 Codex 双端视觉／交互仍待 Mac 解锁后配对，不能据此认定完整对齐。
