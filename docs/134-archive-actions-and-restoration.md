# 归档危险操作样式与恢复流程

2026-09-18。对照公开分发资源 `data-controls-177358ad1ff5.js`、`button-6325b3939f12.js`：归档恢复或删除进行中统一禁用动作；恢复按钮在原文字旁增加进度；全部删除采用浅红背景与红色文字，行删除为红色图标，项目删除菜单带危险色和垃圾桶图标。

## 实现

- 新增归档工具栏按钮样式：全部删除为浅红底，行删除为透明底红色图标并有悬停反馈，恢复为中性次级按钮；禁用透明度统一为 40%。
- 项目删除原生菜单项配置红色文字、红色垃圾桶符号；通用菜单仍支持普通动作。
- `archiveActionsBusy` 统一页面动作的禁用条件，操作层也拒绝恢复期间的新恢复或删除确认。失败与成功都会释放忙碌状态。
- 恢复按钮保留“恢复”文字，在左侧附加进度；忙碌时辅助功能名称包含“正在恢复”。复用键盘焦点修饰器，支持 Tab 到达、空格/Enter 激活；该修饰器由确认专用名称改为通用 `settingsActionFocus`。
