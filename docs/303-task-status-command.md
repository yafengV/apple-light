# `/status` 会话状态入口

2026-09-28。[Codex 官方斜杠命令参考](https://learn.chatgpt.com/docs/reference/slash-commands)将 `/status` 定义为显示会话 ID、上下文用量和额度状态。ShipiOS 过去保存了任务 ID、部分 Codex Core 会话 ID 与服务返回的 token 用量，但输入区没有状态入口。

现在主窗口和独立任务窗口可从输入区或命令菜单打开所属任务的会话状态。状态视图分别显示 ShipiOS 任务 ID 和实际存在的 Codex 会话 ID；最近一轮上下文输入取自该任务最近一次有用量数据的模型回合，累计 token 仅汇总该任务已记录的服务数据。ID 可复制。缺少真实 Codex 线程、上下文窗口上限或独立 API 服务商额度时，界面明确显示尚未建立或暂无数据，不推算百分比及重置时间。

17 项相关测试、原生应用构建与签名检查通过。原生点击、焦点、窗口归属及与当前 Codex Mac 的视觉交互配对仍待桌面解锁后验收。此阶段不改变 43 个验收面的完整配对计数。
