# 本地环境快捷操作

2026-09-26。依据 Codex [本地环境说明](https://learn.chatgpt.com/docs/environments/local-environment)中的 Actions 行为，ShipiOS 的主窗口“设置 → 环境”现在可为当前项目添加、编辑、删除带名称和图标的命令脚本。保存后，主窗口和独立任务窗口的顶部“操作”菜单显示可运行项。每次点击都会在该任务项目目录中新建终端标签并执行脚本，输出留在标签内；多行及引号通过编码后的单条终端输入传递。

项目配置继续保存在 ShipiOS 的独立工作区记录中；托管工作树继承来源项目的快捷操作。旧配置缺少 Actions 字段时读取为空。真实终端测试覆盖主窗口、独立任务窗口的执行目录和资源隔离，相关 27 项终端、窗口标签与工作区存储回归通过。

这补齐了本地 action 的基础链路，但尚未实现 Codex 的项目 `.codex` 共享文件、平台专用脚本、cleanup 和云环境。当前 Mac 锁屏，尚未与 Codex 实际页面逐控件配对。
