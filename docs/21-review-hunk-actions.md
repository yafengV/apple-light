# 审查页分块操作

> 2026-09-17 更新：设备已解锁，后续实测范围与未覆盖项见 [原生审查、撤销与导航验收](23-native-review-validation.md)。下文保留本篇实现时的记录。

2026-09-16。继续落实[官方审查页说明](https://learn.chatgpt.com/docs/code-review)中的 per-hunk 操作，当前支持暂存、取消暂存及未暂存内容的撤销。

## 实现与行为

- 普通文本差异的 hunk 标题旁显示“暂存此块”或“取消暂存此块”。未暂存范围额外提供“撤销此块”。
- 暂存和取消暂存只操作索引，不改工作区文本；撤销仅反向应用未暂存的选中块，保留已暂存内容。
- 撤销先显示文件路径和 hunk 范围的确认提示，取消不执行修改。
- 历史范围不显示写操作，存储层也拒绝从历史范围执行分块修改。
- 点击后重新读取状态与文件差异，对比完整 diff 指纹，旧快照失效时拒绝操作并提示刷新。
- 提取单一 hunk 时保留缺少末尾换行标记；新增/删除文件保留所需的文件头。普通修改和已暂存重命名使用当前文件路径，去掉会连带修改名称或权限的元信息。
- 通过 Git C 风格 UTF-8 路径引用处理引号、换行、中文和 pathspec 字符。补丁写入权限为 0600 的临时文件，结束后删除。
- 使用 `git apply --check` 验证后执行，不使用 `--reject`、`--3way`、不改写空白。每次操作后刷新状态与差异，操作期间禁用 Git 操作按钮。
- 差异读取固定 `a/`、`b/` 前缀和三行上下文，避免用户全局前缀配置使补丁指向错误路径。

外部进程仍可能在校验与应用之间修改仓库；最终由 Git 的上下文校验决定是否应用，没有宣称提供跨编辑器事务锁。

## 验证

`./script/test.sh` 通过 Rust fmt/Clippy、12 项 Rust、75 项 Swift 及真实 Agent IPC 冒烟，日志 `.cache/hunk-actions-tests.log`。

新增 9 项测试全部使用独立临时 Git 仓库，验证：

- 两个差异块中只暂存一个，反向取消暂存后工作区保持原样。
- 撤销未暂存块保留已经暂存的块。
- 外部内容变化后旧快照不能修改索引或工作区。
- 无末尾换行的暂存与取消暂存。
- 特殊字符文件名的补丁应用。
- 已暂存重命名按块取消内容变化后保留重命名。
- 暂存文本块不连带暂存可执行权限变化。
- 删除文件暂存/取消暂存；新增文件取消暂存保留工作区文件。
- 无效 hunk、越界路径、历史范围修改被拒绝。

## 原生验收与边界

工具再次报告 Mac 锁定且无法自动解锁，最新包未重启验收。解锁后需要检查标题旁按钮的布局、键盘焦点、点击命中、确认框取消/确认、操作期间状态、刷新后的滚动与折叠状态，以及失败提示。

当前分块操作针对可应用的单文件文本补丁。二进制、符号链接、子模块和纯权限变更不显示分块按钮；未跟踪文件目前使用文件级暂存。撤销已暂存块尚未实现，已暂存范围提供取消暂存。

文件级/全局撤销、整批暂存控制、Last turn、多仓库、PR 和完整编码工具循环等仍有缺口。原生验收和用户当前 Codex 版本的逐页配对证据仍缺失，不能标为完全对齐。
