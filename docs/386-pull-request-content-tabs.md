## 实现范围

- 新增 PR 标签类型，按任务和 URL 去重，保留标题、面板、选中状态、侧栏固定和重启恢复。任务窗口保存到本窗口的布局，恢复要求项目及有效关联记录一致。
- 摘要打开标签后关闭摘要弹层。PR 可沿既有主区/右侧/分离窗口路径移动；关闭后恢复原面板，不重新请求合并。标签的跨聊天移交仍未实现，不把现有拒绝行为计为对齐。
- 合并命令读取实际作者和 PR 状态。未打开详情时允许进入关闭 PR 的详情；已选中 PR 页面时只允许开放、非草稿且未启用自动合并的入口。只读、模态、操作锁、旧目录/任务/修订及排队期间的资格变化会阻止打开。
- 选中的 PR 标签优先于当前 Git 分支；独立任务窗口和分离 PR 窗口具有自己的命令上下文，不使用主窗口选择。该命令只请求确认，不执行远端合并。
- 合并确认请求使用窗口内一次性 UUID，不保存到磁盘。旧 token 不能消费新请求；关闭、工作区变化及取消清理请求。PR 已移除或保存身份不一致时不恢复该标签。
- 元数据读取失败隐藏合并命令并显示可重试错误。旧读取结果不能恢复已取消或被新请求替换的状态。
