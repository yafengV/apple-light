# 任务重命名与窗口归属

2026-09-18。主窗口和独立窗口共用窗口内重命名弹层，补上独立窗口菜单与快捷键入口。

## 参考与实现

读取本机安装包的公开静态资源 `app-primary-4af6ed7f68d1.js`，其中 `T2t` 重命名组件包含紧凑对话框、简短名称说明、初始输入全选、取消/保存、非空校验与保存失败后保留表单。`app-initial` 的命令定义将重命名绑定为 ⌘⌥R。未读取私人配置、认证或会话，也没有取得 Codex 当前窗口的视觉配对证据。

- 主窗口任务重命名由系统 alert 改为窗口内容内的居中弹层，背景控件禁用并从辅助功能树隐藏；项目重命名暂保留原流程。
- 独立窗口增加任务操作菜单，重命名使用窗口本地状态和固定 taskID，不改变主窗口选择。菜单、⌘⌥R 共用执行入口。
- 弹层打开后聚焦并全选名称。空白名称不能提交，普通空格保留为文本输入，输入法组合期间不拦截 Enter/Esc；Tab/Shift-Tab 循环名称、取消、保存。Enter 根据当前焦点保存或取消，Esc/⌘W 只关闭弹层，随后返回草稿。
- 任务保存先写入候选工作区，成功才替换内存状态；失败展示错误并保留输入供重试。缺失任务和空名称返回错误，保留原有 120 字符上限。
- 主窗口与独立窗口的任务命令、应用菜单和审批入口在当前重命名弹层期间停止响应，防止编辑标题时触发后台动作。
