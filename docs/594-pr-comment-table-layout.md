## 参考与实现

参考版本 26.930.21537。公开分发的 Markdown 组件默认 `allowWideBlocks: false`；PR 评论没有覆盖该选项，使用普通非宽表格。对应共享组件包含复制表格、溢出时展开预览、横向键盘滚动等交互，本阶段尚未实现这些新增入口，不把它们记为完成。

`app-initial-341eb5dd9ad5.css` 的实际表格使用内容字体，字号是代码字号与小号正文 13 × 0.875 的较大值；普通表格使用等宽数字。表头行高 13，上下内边距各 6.5，底边 1；正文行高 21.125，上下内边距各 8.125，非末行底边 1；末行下边距 19.5 且没有底边。非末列右内边距 19.5，末列表头右内边距 32.5、正文为 0。没有原实现的条纹背景和外框。

新的 PR 表格使用原生可选择的文本、当前链接路由与左右/居中对齐。按单元格内在宽度及最小内容宽度分配列空间，去掉固定 100—280 点范围；按分配后的宽度测量换行，共享每一行的最大高度。最小宽度仍超过容器时保留横向滚动。纯数字内容保留不折断的列宽，内容字体加入等宽数字特性，代码字号变化仍重新计算表格字号。媒体单元格保留现有富内容组件，实际高度经 SwiftUI 子视图测量回报；真实媒体混排仍需进一步验收。

只在 loopback 加载公开 CSS 的语义 HTML 夹具，使用匹配的字体继承、基础 padding reset、普通非宽和等宽数字规则。源哈希和实际浏览器测量保存于 `pr_comment_table_reference.json`；原资产、HTML、脚本及运行日志留在忽略缓存。默认代码字号 12 的结果为：

| 夹具 | 宽度 | 表格高度 | 表头/正文/末行高度 |
| --- | ---: | ---: | --- |
| 短两列表格 | 500 | 114.125 | 27 / 38.375 / 48.75 |
| 长描述、数字列 | 500 | 135.25 | 27 / 59.5 / 48.75 |
| 同一长描述窄窗口 | 220 | 177.5 | 27 / 101.75 / 48.75 |
| 表头与十个正文行 | 500 | 421.125 | 27 / 九个 38.375 / 48.75 |

短表格第一列为 225.8515625；长描述窄窗口第一列为 156.484375，第二列为 63.515625。原生用这些测量验证实际单元格位置、宽度重排和行高，不只检查模型常量。浏览器 `line-clamp-6` 夹具仍显示完整 421.125 高的长表格，内部单元格不计入六个正文行；原生同样不把表格文字送入段落的裁剪计数。表格后的混排仍需进一步对照。
