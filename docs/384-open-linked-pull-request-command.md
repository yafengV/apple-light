## 实现

新增“在 GitHub 打开 PR”命令，接入命令菜单、原生工作区菜单及可配置的主/备用快捷键。没有默认按键。使用当前窗口的任务上下文，不通过主窗口选中任务推断独立窗口的操作对象。

主仓库已读取的关联 PR 优先；同一任务、仓库和工作区范围内，查询因 Git 忙碌而暂停时保留已确认链接，换范围、显式取消或成功查询确认无 PR 时清除。否则使用该任务保存的有效 PR 记录，当前命名分支优先于保存的旧分支；附加仓库的分支不参与任务 PR 记录筛选。分离 HEAD 可使用任务保存的分支；已关闭或已合并的已知链接仍可打开。没有链接或地址无效时不注册命令，不生成比较地址或打开仓库首页来替代关联 PR。

链接命令独立于 Git 写入资格。只读、历史审查、Git 操作忙碌及无可提交变更均不因提交禁用而隐藏已知链接；其他弹层、不可用窗口、工作区代次变化、任务删除及任务目录变化仍阻止旧命令。附加仓库审查使用任务关联记录，不误用附加仓库的 PR。

按链接设置选择应用内或系统浏览器。主窗口使用明确任务 ID，因此无历史运行的任务也能定位；独立任务窗口使用自身浏览器标签，保留主窗口选择；分离审查窗口在选择应用内浏览器时打开所属任务并显示主窗口。打开过程不创建 PR，不推送、不提交、不修改草稿或任务的 PR 记录。

失败结束 opening，显示当前工作区错误与所属任务通知，允许重试。重复激活、排队后换任务/链接、窗口消失、工作区重置以及取消后的迟到失败均有保护；旧请求不能清除新请求的状态。
