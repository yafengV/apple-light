# 会话用户消息导航轨道

参考本机 Codex 应用包中的 `thread-user-message-navigation-rail-app` 组件：时间线左侧有细线标记，靠近指针的标记展开，悬停显示消息预览与书签操作，点击和拖动可在用户消息间导航。该组件还会读取音频级别改变标记宽度；ShipiOS 当前尚未接入这部分动画。

ShipiOS 的主会话、独立任务窗口与弹出窗口现共用轨道。每条初始提问及 Codex Core 同轮追加的用户消息各有一个标记。点击标记滚动到对应内容；拖动时预选标记、松手定位。预览可增删书签，状态写入应用私有 `workspace.json`，旧状态没有字段时按空集合读取，永久删除归档任务时一并清理。小窗口轨道限制在可视高度的 70%，长会话可在轨道内滚动。

Swift 测试覆盖标记排序、追加消息、书签重启恢复、无效消息拒绝、任务删除清理、旧状态解码、拖动边界与离屏视图构建。正式包使用 `script/build_and_run.sh --build-app` 构建并检查签名。当前桌面控制接口超时，尚未在前台把 Codex 与 ShipiOS 的悬停、焦点、拖动、滚动跟随和布局逐项配对；因此完整双端验收仍为 **0/47**。数字表示验收面，并非 47 个确认缺陷。
