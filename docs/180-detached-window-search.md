# 分离窗口命令菜单与任务搜索

2026-09-25。本轮整理分离内容窗口的搜索上下文与焦点恢复，尚不代表全产品 UI 对齐完成。

## 实现

分离窗口独立保存命令菜单和任务搜索状态。窗口内快捷键打开本地搜索，搜索期间阻止底层网页和终端抢占焦点；在命令与任务搜索之间切换时保留最初的焦点来源，取消后恢复。

网页命令继续作用于来源窗口。任务结果导航到主窗口；设置等全局页面在主窗口打开并还原最小化状态。网页结果可定位已有分离窗口。执行前重新检查结果和来源是否有效，关闭或过期结果不再执行。未提供上下文的任务修改命令保持不可用。

## 原生检查

1. B 网页输入 `B preserved during search` 后最小化主窗口。
2. A 的 Delta 网页通过 ⌘K 打开本窗口命令菜单；Esc 关闭后，确认地址栏可继续编辑，实际网页仍停留 Delta。
3. 再次打开命令菜单，搜索并执行“设置”。主窗口从最小化恢复，在 ID 为 `main` 的窗口内显示设置页；后台任务仍为 B，网页输入值保留。
