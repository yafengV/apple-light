# 独立任务窗口文件与终端面板

2026-09-17。项目任务的独立窗口现在直接承载文件与终端面板。两个入口位于任务窗口工具栏；无项目任务不显示这些项目能力。

文件面板为每个任务窗口持有独立 `DeveloperWorkspace`，根目录固定为任务所属项目，不读取主窗口当前项目。它支持项目文件树、筛选、刷新、多文件标签、关闭标签、只读原生文本选择、行号跳转、外部编辑器打开，以及文件预览获得焦点时的 `⌘W`、标签前后切换和 `⌘L`。主窗口切换项目不会替换任务窗口文件根目录、所选文件或标签。

终端面板在任务项目目录启动独立 zsh，支持隐藏并保留会话、停止、重新打开、退出状态与原生输入。终端会话属于窗口，不会复用或移动主窗口的 PTY；关闭任务窗口时终止并回收进程，避免后台遗留 shell。

文件预览组件已改为显式接收 `DeveloperWorkspace`，主窗口继续使用原工作区，任务窗口使用自己的工作区。键盘事件只作用于当前获得焦点的预览和当前标准窗口，不会关闭另一个窗口的标签。

5 项任务窗口测试新增独立项目工作区隔离，配合 7 项文件工作区和 8 项真实终端生命周期测试共 20 项定向通过。完整回归为 350 项 Swift、12 项 Rust、fmt/Clippy 和真实 IPC 冒烟全部通过，日志 `.cache/task-window-panels-full-tests.log`。

以原数据目录重建启动 PID 70444 后，原生任务窗口列出 `HelloShipiOS.xcodeproj` 与 `HelloShipiOSApp.swift`。打开 Swift 文件后可见任务窗口自己的文件标签、行跳转、外部打开和完整源码；同时打开终端后，提示符目录为该任务的 `HelloShipiOS` 项目，并显示停止、重启、隐藏操作。返回主窗口进入设置时窗口仍为 `ID: main`；Esc 返回后任务“验证新输入框的真实构建”和草稿“这是一条待发送草稿，重跑后应保留”未变化。

任务窗口 Git 审查面板现已补齐，见 [独立任务窗口 Git 审查](69-task-window-git-review.md)。当前文件面板仍为只读预览，与主窗口现有能力一致；完整代码编辑依赖配置的外部编辑器。
