# Appshot 快捷键无窗口时不新建聊天

本机 Codex 参考客户端的全局 Appshot 快捷键先查询前台目标窗口；查询结果为空时直接结束，不进入附件流程。ShipiOS 此前虽然已经避免此时弹出窗口选择器，但“新聊天”或“自动”发送目标可能在捕捉前就先新建空聊天。

现在快捷键必须先取得可用目标，之后才决定聊天去向。没有目标时既不显示首次使用说明，也不新建聊天；手动附件入口仍按原流程处理。取得目标后到实际截图之间仍可能发生窗口消失，真实跨应用竞争条件与双端焦点行为需要前台验收。

Mac 已解锁，但电脑使用工具不允许读取 Codex 参考客户端。当前运行的 ShipiOS 进程仍是旧版本；退出操作被自动审批拒绝，理由是可能丢失未保存状态。构建产物可验证，但这轮无法对最新二进制做前台验收。完整双端配对维持 **0/46**。

相关 33 项 Appshot 回归、`script/build_and_run.sh --build-app` 与 `codesign --verify --deep --strict` 均通过。
