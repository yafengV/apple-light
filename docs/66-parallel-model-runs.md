# 按任务并行模型会话

2026-09-17。模型请求现在按运行 ID 独立持有，不再由 `WorkspaceStore` 的单一全局任务槽串行化。主窗口和独立任务窗口可以让不同任务同时流式响应；每个运行保留自己的任务、项目、草稿、附件、队列、目标状态和取消句柄。

同一任务仍只允许一个活动模型回合。发送、停止、运行中引导、等待下一轮和目标自动续轮都按任务查找活动运行：停止一个任务只取消该任务的请求，另一个任务继续流式接收；完成或失败只消费所属任务的队列，并只触发所属目标的下一轮。应用退出时会取消并回收全部仍在运行的请求，运行期间防休眠则依据所有活动模型请求统一持有。

独立任务窗口不再依赖主窗口当前选中的项目。窗口可在主窗口切到其他项目或无项目页面后，继续向它绑定的原任务发送；新回合始终记录原任务的项目身份。项目切换、通知跳转和“下一个需关注任务”只在本地诊断、构建等 Agent 执行期间阻止跨项目导航，后台兼容 API 会话不会占用全局项目导航锁。

真实本地 HTTP 夹具覆盖两个任务同时开始和流式完成、跨项目任务窗口提交，以及取消一个任务后另一个请求继续运行。通知和关注任务测试分别覆盖模型会话允许跨范围导航、本地执行保持项目锁。完整回归为 348 项 Swift、12 项 Rust、fmt/Clippy 和真实 IPC 冒烟全部通过，日志为 `.cache/parallel-model-runs-full-tests.log`。
