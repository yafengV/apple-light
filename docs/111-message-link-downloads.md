# 回复链接的 Option 点按下载

2026-09-18。延续 Codex 26.908.70816（build 9275）的公开前端资源对照：`app-initial-4d7ea7f81c2d.js` 的 `Mji` 仅匹配左键加 Option；当外部浏览器链接设置不是 `alt` 时，点击交给下载入口。`jIi` 在无法开始下载时给出错误反馈。WebKit 接口依据本机 macOS SDK 的 `WKWebView.h`：`startDownloadUsingRequest` 要在开始回调中设置下载 delegate。

## 实现

- 仅 Option 左键点按网页链接启动下载；额外 Command、Control 或 Shift 不触发这条分支。若用户已配置“⌥点按在默认浏览器打开”，该明确偏好优先。
- 使用同一浏览器会话的数据环境和专用下载 WebKit 实例，不生成可见浏览器标签，不改变任务、项目、草稿或焦点。
- 从准备阶段即登记下载。服务器给出建议文件名后更新同一记录，保留 ID 和开始时间；进度、保存位置、历史持久化、打开文件、Finder 显示和取消复用已有下载管理。
- 普通 HTML 页面也可作为文件下载，不要求服务器提供 attachment 响应头。
- 支持 WebKit 交回下载对象前立即取消；取消后的迟到回调会终止底层下载。会话关闭同样取消准备中的下载。
- 保存目标选择明确区分保存、主动取消和失败。不可写/错误目录、无可用窗口、保存操作失败进入失败记录；用户取消保存不报失败。取消后迟到的保存回调不能重新开始下载。
- 回复链接下载的网络或保存失败显示当前窗口通知，并在下载历史保留原因。非法协议无法启动下载。
