# 会话导航预览中的真实产物

本机 Codex 会话轨道的悬停卡片在助手回复下方最多列出两项产物，再以 `+数量` 表示其余产物。类别包括文件、网页等。该区域描述回合的输出，不能把用户输入附件或普通工具文本当作产物。

ShipiOS 现从已记录的 Codex Core 轮次差异提取文件路径，从成功工具的 MCP 创建／更新元数据提取外部资源。文件差异是同一运行记录的累计值：含追加用户消息的运行无法确定每个文件对应哪条消息，此时不把文件错误分配给某个标记。MCP 工具事件在有序时间线中，因此资源只归属于事件所在的消息段。卡片最多显示两项，余量按实际条目和差异截断记录计算；加载占位时不显示产物。

自动化覆盖真实差异路径、截断数量和追加消息后的资源归属。Codex 与 ShipiOS 的前台悬停、布局、图标、焦点和点击仍待双端验收；完整配对保持 **0/47**（主工作区 21 项、设置 26 项），该数字为验收面而非已确认缺陷。
