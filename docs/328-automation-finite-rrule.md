# 有限自动化日程

自定义 RRULE 接受正数 `COUNT`（最多 100,000 次）或 UTC `UNTIL=YYYYMMDDTHHMMSSZ`，两者不能同时出现。`UNTIL` 当秒包含在日程内。`COUNT` 从保存的日程起点开始计算符合规则的运行时间，而不是从每次查询时重新计数。无效日期、过期且没有未来运行时间的新增日程会被拒绝。

最后一次计划运行结束后，自动化转为“已完成”并停止到期轮询；运行结果仍保留供审查。完成项留在“全部”列表，不归入“已暂停”。重新启用完成项会更新日程起点，从第一次数重新开始；编辑名称或指令不会重置运行次数。运行失败也视为该次已消费，与现有到期运行语义一致。

本阶段 27 项自动化测试通过，覆盖规则边界、到期运行结束、持久化、停止重复轮询和重启；应用构建与签名检查通过。页面显示与当前 Codex Mac 版本尚未完成原生双端配对，不能据此声称 UI 完全一致。
