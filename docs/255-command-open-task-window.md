# 命令菜单在新窗口中打开任务

2026-09-26。本机安装的 Codex 客户端命令菜单代码包含 `openThreadInNewWindow` 命令。ShipiOS 此前仅在主窗口任务操作菜单提供“在新窗口中打开”，命令菜单无法调用。现在会话命令组提供该入口：主窗口使用当前所选任务及当前数据根目录；独立任务窗口使用该窗口的任务，避免主窗口后台选择影响结果。没有选中任务或处于设置页时，主窗口命令不可用。

14 项相关 Swift 测试通过，覆盖命令分组、主窗口路由、设置页禁用和独立窗口命令归属。`script/build_and_run.sh --build-app` 构建成功，`codesign --verify --deep --strict` 通过。当前 Mac 锁屏，无法启动可交互工作区验收；两端的菜单外观、焦点、键盘、窗口激活与系统恢复行为仍须在解锁后的原生会话中配对。这项改动不构成完整 UI 验收。
