# PR 监控进度内容标签与启动反馈

2026-10-03 对照当前安装的 Codex/ChatGPT 桌面包 `26.930.21537`、构建 `12776` 的公开分发资源。`open-pull-request-fix-automation-panel-7a3f637700a2.js` 使用目标任务的稳定标签 ID，默认打开在右侧，并保留已有位置；持久路由记录自动化 ID 和目标任务 ID，恢复时检查有效 heartbeat 与任务身份。`app-initial-60d038a052d7.js` 将此标签连接到 `LocalConversationBackgroundAgentTab`，不添加额外 header rows；对应会话实现关闭 utility bar，复用普通会话和输入区。`pull-request-detail-query-da2fa14a2b60.js` 显示启动通知中的 View progress 动作、运行状态按钮和独立暂停按钮。此处只读取公开应用资源，没有读取个人认证、配置或历史。

ShipiOS 的 PR 监控进度现在是独立内容标签，默认在右侧打开，重复打开复用当前标签和位置；标签 ID 在应用的全局集合中额外包含来源任务，避免不同来源聊天碰撞。启动监控先显示带“查看进度”的通知，不自动切走原任务；活动监控的主按钮打开进度，右侧暂停图标独立操作；真正有活动任务回合时显示“正在修复”，其余时间显示监控状态。暂停后回到统一的“监控并修复 PR”入口，暂停成功或保存失败分别反馈。

进度页复用完整的任务会话视图、消息动作、附件、模型选择、命令与技能候选、听写、队列和输入区，隐藏独立任务窗口的 utility toolbar 与初始聊天标签条，不替换来源窗口标题。输入写入目标监控任务的草稿；在主任务与监控任务间切换焦点时按内容标签归属处理。关闭进度标签只关闭该表面，监控保留；窗口关闭命令作用于进度标签。实际前台快捷键竞争仍待双端验证。

布局及固定标签保存自动化 ID、目标任务 ID 和来源任务；主窗口、独立任务窗口及分离标签恢复均检查这些身份。自动化配置尚未读取完成时延后恢复，不把进度标签丢失后覆盖到磁盘；配置加载成功后再恢复。等待期间在独立窗口打开了其他内容时只补回监控标签，保留新增内容、选择与焦点。监控删除、替换、目标任务归档或 PR 关联消失时不误恢复；新监控复用同一目标时只保留一个标签。通知动作同时检查通知代际，替换后的旧通知无法再打开进度。
