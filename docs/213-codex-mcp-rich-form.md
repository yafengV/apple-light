# Codex MCP 表单选项与默认值

2026-09-26。任务时间线中的 MCP 表单现在识别当前固定版 Codex Core 的带标题单选（`oneOf`）、旧式 `enumNames`、带标题或普通多选（`items.anyOf` / `items.enum`）和字段默认值。没有默认值的单选保持未选择；必填单选须由用户明确选择。多选用逐项开关呈现，并按 schema 校验候选值、重复值和数量限制。文字字段还校验常见的 email、URI、日期与日期时间格式。

本地模型与 STDIO MCP 假服务的真实 `elicitation/create` 集成测试覆盖带标题选项、默认值、格式与数量校验、结构化响应和回合续接。当前 Codex Mac 的卡片外观、焦点、键盘顺序和辅助功能仍需解锁后做原生配对。
