# 窗口内图片图库与缩放交互

2026-09-18。将草稿附件与历史消息附件共用的固定尺寸图片 sheet 改为所属任务窗口内的预览覆盖层。主窗口与独立任务窗口使用同一预览组件。

## 实现范围

- 以点击的附件组建立图库，直接定位点击项，上一张/下一张在首尾停止；切图重置缩放并防止旧图片的异步回调覆盖新选择。
- 初始按窗口适应、最大初始比例 100%，使用原始像素与方向；缩放阶梯包含实际适应比例，范围上限 500%。小图居中，放大后可拖动或滚动，缩放保留中心或指针下的图像位置。
- 支持 ⌘+、⌘−、⌘0、左右箭头、Tab/Shift-Tab、Enter/空格、Esc 和 ⌘W。预览期间隔离底层控件与应用任务命令；关闭后回到对应任务输入框。
- 加载错误显示原因并可原位重试；保存使用原生保存面板，写出经过校验的原附件，保存失败单独显示。缩放比例提供辅助功能数值。
- 修复原生验收发现的独立窗口关闭预览后焦点未返回的问题。

参考来自允许读取的客户端公开静态资源中共享图片预览实现与图库调用方：窗口内遮罩、自然尺寸适应、缩放阶梯、锚点保持及首尾边界。未读取个人配置或会话，也未进行原生 Codex 页面配对。

## 验证

- 50 项相关测试全部通过，覆盖 ImagePreviewTests、ImageAttachmentTests、SettingsInteractionTests、PageNavigationTests、TaskWindowTests、ComposerCommandTests；日志 `.cache/image-preview-tests.log`。
- 新增 5 项测试覆盖适应与缩放阶梯、锚点与平移边界、按键解析、图库归属与命令隔离，以及实际 NSHostingView 画布缩放/调整窗口/卸载后不回调。
- 通过项目构建脚本启动隔离工作区，严格签名校验通过。使用 1600×1000 和 200×200 的合成图片验证主窗口内预览、中心缩放、拖动平移、切换到小图保持 100%、首尾边界、Tab 焦点、⌘N 隔离及 ⌘W/Esc 关闭。
- 人为损坏合成附件后呈现完整性错误；恢复原字节，点击重试成功显示图片。
- 独立任务窗口验证直接打开第二张、左右切图、底层辅助功能隔离、⌘N 不创建任务、⌘W 仅关闭预览，以及返回输入框且草稿保留。最后重建后复测焦点和缩放辅助功能数值。
- 通过项目脚本恢复原工作区，确认原任务、待发送草稿保留且输入框可聚焦。恢复日志 `.cache/image-preview-restore.log`。构建缓存、合成附件和运行数据均不提交。
