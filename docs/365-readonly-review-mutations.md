# 只读审查的文件、差异块与跨窗口操作

## 实际差异

继续核对审查页时，用临时真实 Git 仓库复现：开启主窗口设置中的「只读审查」后，文件级暂存仍写入索引。原实现仅在总工具栏隐藏操作，逐文件、差异块及其实际执行方法未使用该设置。这与[第 78 篇](78-main-window-coding-settings.md)记录的只读审查行为相矛盾。

当前[官方审查文档](https://developers.openai.com/codex/app/review)确认审查页保留范围选择、差异、行评论和分级 Git 操作。本阶段修复已有只读设置的执行和呈现，不据此推断当前 Codex 的每项布局或 PR 联合创建方式。

## 修复

主窗口、独立任务窗口及分离审查工作区绑定同一个实时设置。只读时隐藏文件级暂存/取消暂存、撤销及差异块写入控件，继续呈现代码差异和评论。待确认的整体撤销不会在只读状态下显示或执行；切回可写后按正常入口操作。

执行方法也检查权限，预检查后的实际 Git/文件写入再次校验最新设置、工作区和项目代次。批量暂存、差异块、撤销、提交准备/新分支和推送均接入这一检查。创建 PR 在生成与远端检查结束后重新检查，避免生成期间切换只读仍发布。

已启动的 Git 命令可能完成，不能承诺回滚已经写入的提交或远端操作；后续步骤按当前设置判断，撤销出现部分完成时保留其结果提示。
