# 环境设置页面导航与迟到回复隔离

日期：2026-10-09。接续第 710 篇，检查环境项目列表、概览和编辑器之间的异步页面切换。

## 问题与改动

旧视图在等待项目打开或文件选择之后直接切换页面，保存／放弃后的返回则只检查当前页面枚举值。这无法区分“从未离开编辑器”和“离开后又返回编辑器”；搜索及工作区直达还有等待后无条件进入编辑器的分支。

将实际视图的打开、选择、保存返回和放弃返回流程接入 `EnvironmentSettingsNavigation`。每次操作捕获导航请求身份、设置路由代数和工作区连接会话；等待前后核对当前性。`WorkspaceStore` 的 destination／settingsPage 在实际变化时同步更新路由代数，避免依赖稍后的 SwiftUI onChange 才发现离开。内部页面切换、同页新操作和视图消失也使旧操作失效。

| 入口／场景 | 当前行为及验证范围 |
| --- | --- |
| 打开项目等待期间内部页面往返 | 保留最新页面，旧打开不再跳转 |
| 环境设置→其他设置→环境设置 | 路由代数变化，旧打开不能进入编辑器 |
| 设置→工作区→设置 | 同样隔离旧打开，即使当前 destination 又相同 |
| 视图消失 | 使当前导航请求失效；共享流程测试直接调用视图使用的失效入口，实际 onDisappear 尚待窗口验收 |
| 同项目的新打开先结束 | 新概览保留；更早要求进入编辑器的请求不覆盖新导航 |
| 环境文件选择回复迟到 | 返回项目列表后不再被旧选择跳回概览 |
| 保存／放弃等待期间编辑器→概览→编辑器 | 保持最新编辑器，不被旧操作自动返回概览 |
| 退出环境设置后排队启动的操作 | 不发出加载、保存、选择或同步请求；草稿、选择和 revision 保留 |
| 当前有效的正常操作 | 项目打开、文件选择、保存返回、放弃返回和显式打开编辑器继续可用 |
| 项目文件夹选择器 | 展示时捕获请求身份，回调写入项目列表及打开前再次核对；源码接入已检查，原生选择器点击尚待验收 |

搜索与工作区直达把“打开编辑器”作为同一导航请求的参数，移除 await 后的额外无条件跳转。已经发出的保存仍由原保存流程完成；导航失效仅禁止旧请求改变页面，不回滚已发生的磁盘写入。第 708—710 篇的表单版本、新输入和模型生命周期保护继续保留。
