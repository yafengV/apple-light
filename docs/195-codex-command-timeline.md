# Codex 命令时间线

现在按 Codex Core 的 `call_id` 合并开始与结束事件，把命令、工作目录、运行状态及聚合输出写入任务的有序回复条目。与已有 MCP 工具卡片共用展示和持久化结构；应用重启时未结束的命令沿用现有“已取消”恢复处理。命令输出在任务记录中最多保留 65,536 个字符，避免无界增长。文字与命令交错时保持各自位置，后续文字不覆盖已有工具卡片。

自动化覆盖命令开始/结束的单条合并、状态、输出、时间线次序和任务记录往返序列化。39 项模型传输回归及 `script/build_and_run.sh --build-app` 通过，应用签名校验通过。原生页面交互未在锁屏状态下验收。本阶段只接入命令事件的展示。Codex Core 仍使用只读权限与无需审批配置；文件修改、审批、其他工具类型、原生页面逐项验收均尚未完成，不能据此宣称 UI 完全对齐。
