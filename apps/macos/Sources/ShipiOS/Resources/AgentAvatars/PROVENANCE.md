# Avatar artwork provenance

Original SVG artwork: OpenAI. These 28 light/dark pairs match the public Codex desktop distribution 26.930.51102, build 13100. Their order and original file/inline references are recorded in manifest.json with SHA-256 digests.

The native renderer selects the Codex palette by the public component's UTF-16 hash. The ChatGPT palette is the first ten entries. No user images, account data, authentication, personal configuration, or conversation history are included.

This provenance record does not assert that desktop artwork is covered by the Apache-2.0 license of the separately distributed open-source Codex Core. Product licensing/distribution decisions remain tracked in the project documents.
